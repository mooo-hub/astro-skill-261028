## 一、核心概念

### 1.1 心理健康的定义

```
┌──────────────────────────────────────────────────────────────┐
│              心理健康判断                                      │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【定义】                                                    │
│  ├─ 精神状态                                                │
│  ├─ 情绪问题                                                │
│  └─ 心理倾向（抑郁、焦虑）                                  │
│                                                              │
│  【核心参考】                                                │
│  ├─ 月亮：情绪、感受度                                      │
│  ├─ 水星：思维、想得通与否                                  │
│  ├─ 火土掺杂：焦虑/抑郁倾向                                 │
│  └─ 十二宫：精神层面                                        │
│                                                              │
│  【输出】                                                    │
│  ├─ 心理健康综合判断                                        │
│  ├─ 抑郁倾向：低/中/高                                      │
│  └─ 焦虑倾向：低/中/高                                      │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、心理健康判断思维链

### 2.1 完整思维链流程

```
┌──────────────────────────────────────────────────────────────┐
│            心理健康判断完整思维链                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 1: 看月亮状态                                          │
│    │                                                         │
│    ├─ 月亮与情绪                                            │
│    │   ├─ 月亮得吉 → 情绪稳定、快乐                         │
│    │   ├─ 月亮受克 → 情绪波动、不快乐                       │
│    │   └─ 月亮落陷 → 心理问题风险                           │
│    │                                                         │
│    └─ 月亮决定感受度                                        │
│        ├─ 月亮好 → 懂得珍惜、满足                           │
│        └─ 月亮受克 → 不满、挑剔、抑郁倾向                   │
│                                                              │
│  Step 2: 看水星状态                                          │
│    │                                                         │
│    ├─ 水星与思考                                            │
│    │   ├─ 水星得吉 → 想得通、能找到解决方案                 │
│    │   └─ 水星受克 → 想不通、容易陷入困境                   │
│    │                                                         │
│    └─ 水星决定思维方式                                      │
│        ├─ 水星好 → 思路清晰、能自我调节                     │
│        └─ 水星不好 → 钻牛角尖、容易内耗                   │
│                                                              │
│  Step 3: 看是否有火星、土星掺杂                              │
│    │                                                         │
│    ├─ 掺杂火星                                              │
│    │   ├─ 表现：焦虑、焦躁、急躁                            │
│    │   └─ 特点：情绪来得快、反应强烈                        │
│    │                                                         │
│    └─ 掺杂土星                                              │
│        ├─ 表现：抑郁、收缩特质、想不开                      │
│        ├─ 特点：土星是收缩特质                              │
│        └─ 压制、悲观、压抑                                  │
│                                                              │
│  Step 4: 判断是否影响身体健康                                │
│    │                                                         │
│    └─ 心理问题严重时会伤及六宫和八宫                        │
│        ├─ 长期抑郁 → 可能导致身体疾病                       │
│        └─ 长期焦虑 → 可能导致免疫力下降                     │
│                                                              │
│  Step 5: 看十二宫状态                                        │
│    │                                                         │
│    ├─ 十二宫与精神层面                                      │
│    │   ├─ 十二宫得吉 → 精神修行、灵性成长                   │
│    │   └─ 十二宫受克 → 精神困扰、抑郁                       │
│    │                                                         │
│    └─ 走十二宫运容易抑郁                                    │
│        └─ 十二宫运期间需要特别关注心理健康                  │
│                                                              │
│  Step 6: 综合心理健康判断                                     │
│    │                                                         │
│    ├─ 汇总所有心理因素                                      │
│    ├─ 判断抑郁/焦虑倾向                                     │
│    └─ 输出心理健康综合描述（禁止打分）                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、心理健康判断要点

### 3.1 月亮状态影响

| 月亮状态 | 情绪表现 | 心理影响 |
|----------|----------|----------|
| 庙旺 | 情绪稳定、快乐 | 感受度好、懂得珍惜 |
| 受克 | 情绪波动、不快乐 | 抑郁倾向 |
| 落陷 | 心理问题风险 | 需要关注心理健康 |

### 3.2 水星状态影响

| 水星状态 | 思维表现 | 心理影响 |
|----------|----------|----------|
| 庙旺 | 想得通、能找到解决方案 | 思路清晰、能自我调节 |
| 受克 | 想不通、容易陷入困境 | 钻牛角尖、内耗 |

### 3.3 火土掺杂影响

| 掺杂类型 | 心理表现 | 特点 |
|----------|----------|------|
| **火星掺杂** | 焦虑、焦躁、急躁 | 情绪来得快、反应强烈 |
| **土星掺杂** | 抑郁、悲观、压抑 | 压制特质、收缩型 |
