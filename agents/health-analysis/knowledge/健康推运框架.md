# 健康推运分析框架

健康推运分析整合法达大运与小限法，判断健康关键期与疾病风险节点。

---

## 一、健康推运核心概念

### 1.1 推运优先级

```
┌──────────────────────────────────────────────────────────────┐
│              健康推运方法优先级                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心方法                                                   │
│                                                              │
│  【第一层：法达大运】                                         │
│  ├─ 决定健康大方向                                           │
```

## 二、法达大运健康判断

### 2.1 法达主运与健康

| 主运行星 | 健康基调 | 具体表现 |
|----------|----------|----------|
| **太阳** | 健康贵气期 | 生命力强、恢复力好、心脏健康 |
| **月亮** | 健康敏感期 | 情绪影响健康、消化系统敏感 |
| **水星** | 健康学习期 | 神经系统关注、学习调整 |
| **金星** | 健康顺遂期 | 身体状况好、享受健康 |
| **火星** | 健康风险期 | 外伤风险、炎症可能、行动力强 |
| **木星** | 健康扩张期 | 身体状况改善、肝胆健康 |
| **土星** | 健康考验期 | 慢性病、骨骼关节、压力期 |
| **北交点** | 健康成长期 | 成长方向、业力推动 |

### 2.2 法达与健康宫位关系

```
【判断方法】
├─ 法达主运行星与六宫主星的关系
│   ├─ 接纳/互容 → 健康风险高
│   ├─ 吉相位 → 健康顺遂
│   ├─ 凶相位 → 健康有挑战
│   └─ 无关系 → 中等影响
│
└─ 法达主运行星主什么宫位
    ├─ 主六宫 → 健康焦点期
    ├─ 主八宫 → 意外风险期
    ├─ 主吉宫 → 健康有助力
    └─ 主凶宫 → 健康有阻碍
```

### 2.3 法达健康关键期判断

| 法达配置 | 健康判断 |
|----------|----------|
| 法达主运 = 六宫主星 | 疾病关键期，需重点关注 |
| 法达主运 = 八宫主星 | 意外风险期，需谨慎 |
| 法达主运接纳六宫主星 | 健康贵人期，有治疗机会 |
| 法达主运刑冲六宫主星 | 健康考验期，有挑战 |
| 法达主运主凶宫 | 健康需克服阻碍 |
| 法达主运与八宫主星结构 | 意外风险判断 |

## 三、小限法健康判断

### 3.1 小限走宫与健康

| 小限宫位 | 年度健康主题 | 重点关注 |
|----------|--------------|----------|
| **一宫年** | 生命力年 | 个人健康、自我关注 |
| **二宫年** | 价值财年 | 财务健康、安全感 |
| **三宫年** | 交通意外年 | 出行安全、交通事故 |
| **四宫年** | 家庭根基年 | 家庭健康、房产安全 |
| **五宫年** | 创意子女年 | 子女健康、娱乐安全 |
| **六宫年** | **健康焦点年** | **疾病关注、体检期** |
| **七宫年** | 关系健康年 | 关系健康、合作安全 |
| **八宫年** | **意外风险年** | **意外关注、隐性风险** |
| **九宫年** | 扩展远行年 | 远行健康、异地就医 |
| **十宫年** | 事业名年 | 工作压力、职业健康 |
| **十一宫年** | 人脉社年 | 社交健康、群体活动 |
| **十二宫年** | **精神健康年** | **心理关注、隐性疾病** |

### 3.2 六宫年（余数6）健康判断

```
【小限六宫年特征】
├─ 健康成为年度焦点
├─ 疾病可能显现
├─ 需要体检关注
├─ 工作与健康平衡
└─ 服务他人健康

【判断要点】
├─ 年主星（六宫主星）状态
│   ├─ 庙旺 → 健康年顺遂
│   └─ 落陷 → 健康年有挑战
│
├─ 年主星与命主星关系
│   ├─ 和谐 → 健康发展顺畅
│   └─ 紧张 → 健康有压力
│
└─ 六宫内行星状态
    ├─ 吉星 → 健康有助力
    └─ 凶星 → 健康有阻碍
```

### 3.3 八宫年（余数8）意外判断

```
【小限八宫年特征】
├─ 意外风险增加
├─ 需特别注意安全
├─ 深度健康关注
├─ 转变期健康问题
└─ 隐性风险显现

【判断要点】
├─ 八宫主星状态
├─ 八宫内行星
└─ 与六宫的关系
```

## 四、法达+小限配合判断

### 4.1 双重触发

```
【最强健康风险期】
├─ 法达主运 = 六宫主星
│   AND
└─ 小限走六宫年
    → 健康重大风险期，必须重点关注

【健康考验期】
├─ 法达主运刑冲六宫主星
│   AND
└─ 小限走凶宫年
    → 健康压力大，需谨慎应对

【意外风险期】
├─ 法达主运 = 八宫主星
│   AND
└─ 小限走八宫年
    → 意外重大风险期，必须特别谨慎
```

### 4.2 健康时间线分析

```
【判断流程】
Step 1: 确定当前年龄
    │
    ├─ 计算法达主运/子运
    └─ 计算小限宫位

Step 2: 判断法达与健康关系
    │
    ├─ 主运行星与六宫主星关系
    └─ 主运行星宫性判断

Step 3: 判断小限与健康关系
    │
    ├─ 小限宫位是否为六宫/八宫
    └─ 年主星状态判断

Step 4: 综合健康运势
    │
    ├─ 法达基调
    ├─ 小限主题
    └─ 输出健康判断
```
