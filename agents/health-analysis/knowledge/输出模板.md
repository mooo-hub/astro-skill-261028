## 一、核心分析方法

### 1.1 健康三维度分析法（核心理念）

```
┌──────────────────────────────────────────────────────────────┐
│                    健康论断三维度                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心理念：健康论断需要区分三个不同维度                     │
│                                                              │
│  【维度一：身体健康】                                         │
│  ├─ 实际疾病                                                 │
│  ├─ 身体部位问题                                             │
│  └─ 核心参考：日月、命主星、六宫、八宫                       │
│                                                              │
│  【维度二：心理健康】                                         │
│  ├─ 精神状态                                                 │
│  ├─ 情绪问题、抑郁症                                         │
│  └─ 核心参考：月亮、水星、三宫、十二宫                       │
│                                                              │
│  【维度三：意外伤害】                                         │
│  ├─ 车祸、外伤                                               │
│  ├─ 突发事件、突发导致的死亡或伤害                           │
│  └─ 核心参考：三宫、六宫、八宫、十二宫                       │
│                                                              │
│  ★ 重要：这三个维度必须分开判断，判断方法不同                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 多项交叠原则（★核心原则★）

```
┌──────────────────────────────────────────────────────────────┐
│                  多项交叠原则                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 凶相必须多项交叠才能导致严重问题 ★                         │
│                                                              │
│  【基本原则】                                                 │
│  ├── 单一凶相不会导致重病或死亡                               │
│  ├── 一定要看六宫和八宫是否紧密相连                           │
│  ├── 凶像反复出现两次或三次才会真正严重                       │
│  └── 多个负面因素重叠 → 问题更严重                            │
│                                                              │
│  【程度比喻】                                                 │
│  ├── 像掉了一片羽毛：单一刑克，伤害不大                       │
│  ├── 像砸了一个苹果：几项凶像叠加，开始严重                   │
│  └── 多项凶像全部叠加：非常凶险                               │
│                                                              │
│  【必须交叠的宫位】                                           │
│  ├── 三宫：速度意外                                          │
│  ├── 六宫：疾病本身                                          │
│  ├── 八宫：死亡、意外                                        │
│  └── 十二宫：意外、业力、粗心大意                             │
│                                                              │
│  【判断公式】                                                 │
│  ├── 单项凶 → 轻微问题                                       │
│  ├── 两项交叠 → 需要关注                                     │
│  ├── 三项交叠 → 严重问题                                     │
│  └── 四项交叠 → 极严重问题                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**凶像交叠程度判断表**：

| 凶像数量 | 严重程度 | 比喻 |
|----------|----------|------|
| 单一凶像 | 轻微 | 像掉了一片羽毛 |
| 两项凶像 | 中等 | 开始有实质影响 |
| 三项及以上 | 严重 | 非常凶险 |
| 四项交叠 | 极严重 | 命悬一线 |

## 二、Synthesis 字段规范

> **核心要求**：必须是具体描述，禁止打分，必须说明交叠程度

### 2.1 身体健康 synthesis

**正确示例**：

```json
{
  "physical_health_synthesis": "身体健康整体风险中等偏低。日月状态良好，太阳入庙提供生命力支持。六宫与八宫无紧密连接，疾病不致命。命主星水星受土星刑克（两项交叠），需关注神经系统健康。实例：可能有偏头痛倾向，建议保持规律作息，避免过度思虑。风险等级：中。"
}
```

**错误示例**：

```json
{
  "physical_health_synthesis": "健康：3分"  ✗ 禁止打分
  "physical_health_synthesis": "健康一般"   ✗ 禁止笼统表述
}
```

---

### 2.2 心理健康 synthesis

**正确示例**：

```json
{
  "mental_health_synthesis": "心理健康整体稳定。月亮入庙巨蟹座，情绪基础好，感受度高。但水星落陷且受土星刑克，思维表达有障碍，可能内耗。土星掺杂带来一定的压抑倾向（中等程度）。实例：工作中可能想得多、表达不出来，建议通过写作或创作释放压力。抑郁倾向：低；焦虑倾向：中。"
}
```

---

### 2.3 意外伤害 synthesis

**正确示例**：

```json
{
  "accident_risk_synthesis": "意外风险中等。三宫主火星与八宫主土星形成结构，但十二宫未卷入（两项交叠）。月火三合带来速度判断：中等。命主星未直接卷入，风险可控。实例：交通出行需注意，避免疲劳驾驶，骑行佩戴头盔。风险等级：中。"
}
```

## 五、输出禁忌

### 5.1 禁止格式

```json
// ✗ 禁止打分
"physical_health_synthesis": "健康：3分"
"health_score": 4

// ✗ 禁止笼统表述
"mental_health_synthesis": "心理健康还可以"
"accident_risk_synthesis": "意外风险一般"

// ✗ 禁止无交叠说明
"physical_health_synthesis": "身体健康良好"

// ✗ 禁止模糊时间
"key_periods": [{"period": "近期", "event": "..."}]
```

---

### 5.2 正确原则

```
1. 具体描述 > 笼统表述
2. 交叠说明 > 空洞判断
3. 实例说明 > 抽象结论
4. 明确时间 > 模糊表述
5. 可操作建议 > 空洞建议
```

## 六、具体化输出要求

### 6.1 健康分析具体化要求

| 分析维度 | 具体化要求 | 示例 |
|----------|------------|------|
| **身体关注** | 具体部位+具体行动+执行频率 | "消化系统：①每天规律三餐时间，避免空腹超过4小时；②减少生冷食物摄入（每周最多1-2次）；③每年体检关注胃肠镜检查" |
| **心理建议** | 具体方法+执行频率+持续时间 | "情绪管理：①每周至少3次30分钟有氧运动（跑步/游泳/瑜伽）；②每天睡前10分钟冥想或深呼吸；③如持续低落超过2周，寻求心理咨询" |
| **意外预防** | 具体场景+预防措施+注意事项 | "交通安全：①骑行必戴头盔；②长途驾驶每2小时休息；③避免夜间疲劳驾驶（22点后）" |

---

### 6.2 抽象表述禁止清单

```
❌ 禁止表述                          → ✅ 具体化要求

"注意消化系统"                       → "消化系统：每天规律三餐，空腹不超过4小时，每年胃肠镜检查"
"关注情绪管理"                       → "情绪管理：每周3次30分钟有氧运动，每天睡前10分钟冥想"
"适度运动"                           → "每周至少3次30分钟有氧运动（具体如跑步/游泳/瑜伽）"
"注意睡眠"                           → "每天23点前入睡，保证7-8小时睡眠，睡前1小时不看手机"
"定期体检"                           → "每年体检，重点关注：胃肠镜、肝功能、甲状腺"
"心理健康需要关注"                   → "如持续低落超过2周，建议寻求心理咨询；每周与朋友深度交流1-2次"
```

## 八、常见错误警示

| 错误认知 | 正确认知 |
|----------|----------|
| 单一刑克就很严重 | 凶相必须多项交叠才严重 |
| 六宫不好就有重病 | 必须六宫与八宫相连才有重病 |
| 心理问题不影响身体 | 心理问题严重时会伤及六宫八宫 |
| 意外只看三宫 | 必须三宫六宫八宫十二宫串联 |
| 一宫有凶星就身体差 | 要看整体结构和交叠程度 |
| 身体健康=心理健康 | 身体/心理/意外三个维度必须分开判断 |
