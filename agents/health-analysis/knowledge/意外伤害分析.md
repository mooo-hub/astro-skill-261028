## 一、核心概念

### 1.1 意外伤害的定义

```
┌──────────────────────────────────────────────────────────────┐
│              意外伤害判断                                      │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【定义】                                                    │
│  ├─ 车祸、外伤                                              │
│  ├─ 突发事件                                                │
│  └─ 突发导致的死亡或伤害                                    │
│                                                              │
│  【核心宫位】                                                │
│  ├─ 三宫：交通、出行、路上                                  │
│  ├─ 六宫：身体受到伤害                                      │
│  ├─ 八宫：死亡                                              │
│  └─ 十二宫：意外、业力、粗心大意                            │
│                                                              │
│  【判断原则】                                                │
│  ├─ 必须交杂在一起                                          │
│  ├─ 不能单纯只有一个项                                      │
│  └─ 多项凶像叠加才会严重                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、意外伤害判断思维链

### 2.1 完整思维链流程

```
┌──────────────────────────────────────────────────────────────┐
│            意外伤害判断完整思维链                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 1: 确定核心宫位                                        │
│    │                                                         │
│    └─ 意外判断宫位：三宫、六宫、八宫、十二宫                 │
│        ├─ 三宫：交通、出行、路上                            │
│        ├─ 六宫：身体受伤害                                   │
│        ├─ 八宫：死亡                                         │
│        └─ 十二宫：意外、业力、粗心大意                       │
│                                                              │
│  Step 2: 判断宫位是否相连（★ 核心原则 ★）                    │
│    │                                                         │
│    ├─ 这些宫位必须交杂在一起                                 │
│    │   └─ 不能单纯只有一个项                               │
│    │                                                         │
│    ├─ 意外标准                                              │
│    │   ├─ 八宫主和十二宫主必须有结构                        │
│    │   ├─ 必须与三宫、六宫相关联                            │
│    │   └─ 命主星被卷入结构                                  │
│    │                                                         │
│    └─ 桥梁作用                                              │
│        └─ 星体像桥梁一样把凶宫串在一起                      │
│                                                              │
│  Step 3: 判断速度                                            │
│    │                                                         │
│    ├─ 月火结构=速度快                                       │
│    │   └─ 月亮与火星形成结构，意外发生快                   │
│    │                                                         │
│    └─ 其他结构看具体情况                                    │
│        └─ 根据星体性质判断意外类型                         │
│                                                              │
│  Step 4: 综合判断                                            │
│    │                                                         │
│    ├─ 交叠程度                                              │
│    │   ├─ 单一宫位 → 轻微意外                               │
│    │   ├─ 两项交叠 → 需要关注                               │
│    │   ├─ 三项交叠 → 严重意外                               │
│    │   └─ 四项交叠 → 极严重                                 │
│    │                                                         │
│    └─ 速度判断                                              │
│        ├─ 月火结构 → 速度快                                 │
│        └─ 土星结构 → 速度慢但后果严重                      │
│                                                              │
│  Step 5: 输出意外伤害综合判断                                │
│    │                                                         │
│    ├─ 汇总所有意外因素                                      │
│    ├─ 判断风险等级                                          │
│    └─ 输出意外伤害综合描述（禁止打分）                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、凶宫串联判断表

| 串联程度 | 风险等级 | 具体表现 |
|----------|----------|----------|
| 单一宫位 | 轻微 | 普通意外，伤害小 |
| 两项交叠 | 中等 | 需要关注，可能造成伤害 |
| 三项交叠 | 严重 | 重大意外，后果严重 |
| 四项交叠 | 极严重 | 非常凶险，命悬一线 |

---

## 四、速度判断表

| 结构类型 | 速度判断 | 特点 |
|----------|----------|------|
| 月火结构 | 速度快 | 意外发生快，来不及反应 |
| 土星结构 | 速度慢 | 后果严重，长期影响 |
| 其他结构 | 视情况 | 根据星体性质判断 |

## 五、实务案例

### 案例1：保罗沃克（车祸死亡）

```
【结构分析】
├─ 月火接纳（火星=3r、8r）
├─ 土星落陷巨蟹
└─ 土火接纳

【分析】
├─ 六宫主落陷、八宫主落陷
├─ 连在一起又掺着三宫主
├─ 月火结构=死亡速度快

【结论】车祸死亡，三宫、六宫、八宫串联
```

### 案例2：舒马赫（滑雪意外）

```
【结构分析】
├─ 水火接纳（水星=命主，火星=6r）
├─ 日土刑接纳（土星=8r）
└─ 日火六合

【分析】
├─ 一宫主、三宫主、六宫主、八宫主连在一起
├─ 速度很快的意外
└─ 滑雪意外导致瘫痪

【结论】意外伤害，多项凶宫串联
```
