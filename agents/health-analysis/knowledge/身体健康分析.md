## 二、身体健康判断思维链

### 2.1 完整思维链流程

```
┌──────────────────────────────────────────────────────────────┐
│            身体健康判断完整思维链                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 1: 确定征象星（生命征象）                               │
│    │                                                         │
│    ├─ 1.1 看日月状态                                        │
│    │   ├─ 日月得吉、庙旺 → 生命力强，身体底子好             │
│    │   ├─ 日月受克、落陷 → 生命力弱，身体底子差             │
│    │   └─ 日月被六宫、八宫主刑克 → 身体有问题信号           │
│    │                                                         │
│    └─ 1.2 看命主星状态                                      │
│        ├─ 命主得吉 → 身体状况好                             │
│        └─ 命主受克 → 身体有问题                             │
│                                                              │
│  Step 2: 看六宫与八宫是否相连（★ 核心 ★）                    │
│    │                                                         │
│    ├─ 2.1 六宫主与八宫主的关系                              │
│    │   ├─ 六宫主与八宫主形成结构 → 疾病与死亡相连，重病信号 │
│    │   └─ 六宫主与八宫主无结构 → 单纯疾病，不致命           │
│    │                                                         │
│    └─ 2.2 星体与身体部位对应                                 │
│        └─ 根据被刑克的星体确定具体部位                      │
│                                                              │
│  Step 3: 判断凶像是否交叠（★ 最重要 ★）                       │
│    │                                                         │
│    ├─ 3.1 凶像类型                                          │
│    │   ├─ 征象星被先天凶星（火星、土星）刑克                 │
│    │   ├─ 征象星被后天凶星（六宫主、八宫主、十二宫主）刑克   │
│    │   ├─ 征象星落陷                                        │
│    │   └─ 六宫、八宫、十二宫主星相互连接                    │
│    │                                                         │
│    └─ 3.2 严重程度判断                                       │
│        ├─ 单一凶像 → 轻微，像掉了一片羽毛                   │
│        ├─ 两项凶像 → 中等，开始有实质影响                   │
│        └─ 三项及以上凶像叠加 → 严重，非常凶险                │
│                                                              │
│  Step 4: 确定具体部位                                         │
│    │                                                         │
│    └─ 看被刑克的星体对应部位                                 │
│        ├─ 太阳：心脏、眼睛、脊椎                             │
│        ├─ 月亮：胃、乳房、子宫、体液                         │
│        ├─ 金星：泌尿系统、肾脏、喉咙                         │
│        ├─ 火星：血液、炎症、外伤                             │
│        ├─ 水星：肺部、呼吸道、神经系统                       │
│        ├─ 木星：肝脏、肿瘤                                   │
│        └─ 土星：骨骼、牙齿、皮肤、慢性病                     │
│                                                              │
│  Step 5: 综合身体健康判断                                     │
│    │                                                         │
│    ├─ 汇总所有健康因素                                      │
│    ├─ 判断风险等级                                          │
│    └─ 输出身体健康综合描述（禁止打分）                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、星体与身体部位对应表

| 星体 | 身体部位 | 相关疾病 |
|------|----------|----------|
| **太阳** | 心脏、眼睛、脊椎（支撑身体的原动力器官） | 心脏病、脊椎问题、眼部疾病 |
| **月亮** | 乳房、子宫、妇科、肠胃、消化系统、体液（经血、汗、粘液）、记忆力 | 消化系统疾病、妇科疾病、体液问题 |
| **金星** | 泌尿系统、肾脏、喉咙、皮肤、性腺体、分泌激素的腺体 | 肾脏问题、性病、咽喉疾病 |
| **火星** | 血液、肾脏、发炎、炎症、外伤、刀伤、挫伤、突发疾病（上火、发烧） | 发炎、刀伤、发烧、外伤 |
| **水星** | 肺部、呼吸道、气管、神经系统、神经痛、头疼 | 呼吸道疾病、神经痛、头疼 |
| **木星** | 肝脏、臀部、大腿、肥胖、增生、肿瘤 | 肝病、肥胖、肿瘤 |
| **土星** | 慢性病、骨骼、牙齿、关节、皮肤、长期吃药的毛病 | 慢性病、骨骼疾病、牙齿问题 |

## 四、凶像交叠程度判断表

| 凶像数量 | 严重程度 | 比喻 | 判断 |
|----------|----------|------|------|
| 单一凶像 | 轻微 | 像掉了一片羽毛 | 不必过度担心 |
| 两项凶像 | 中等 | 开始有实质影响 | 需要关注 |
| 三项及以上 | 严重 | 非常凶险 | 必须重视 |
| 四项交叠 | 极严重 | 命悬一线 | 高度警惕 |

## 五、一宫健康区分

```
【一宫】童年健康
├─ 宫内行星 = 小时候毛病
└─ 如一宫有火星 → 小时候容易发烧、上火

【命主星】先天身体底子
├─ 代表生命力
├─ 命主星落陷 → 身体底子弱
└─ 命主星入庙 → 身体底子好
```
