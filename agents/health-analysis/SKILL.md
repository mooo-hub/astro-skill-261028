## 二、Task Scope（任务边界）

### 输入契约

```json
{
  "chart_data": {
    "basic_info": {
      "day_night_chart": "日盘/夜盘",
      "age": XX,
      "gender": "男/女"
    },
    "planets": [...],
    "houses": [...],
    "aspects": [...],
    "reception_mutual": {...}
  },
  "dimension_priorities": {
    "priority_1": "健康",
    ...
  }
}
```

### 输出契约

```json
{
  "task_id": "与输入保持一致",
  "status": "success|failed|partial",
  "error": null,
  "health": {
    "meta": {
      "analysis_date": "YYYY-MM-DD",
      "chart_type": "日盘/夜盘",
      "gender": "男/女",
      "kvp_log": [...]
    },
    "first_house": {...},
    "sixth_house": {...},
    "eighth_house": {...},
    "twelfth_house": {...},
    "physical_health_synthesis": "身体健康综合判断...",
    "mental_health_synthesis": "心理健康综合判断...",
    "accident_risk_synthesis": "意外伤害综合判断...",
    "risk_level": "低/中/高/极高",
    "forecast": {
      "firdaria_health": {...},
      "profection_health": {...},
      "key_periods": [...]
    },
    "advice": {...}
  }
}
```

**状态字段说明**：

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| **success** | 任务完成，输出可用 | 所有Step执行完毕，输出契约完整 |
| **failed** | 任务失败，需要主Agent决策 | 输入数据缺失、知识库加载失败、校验错误 |
| **partial** | 部分完成，标记缺失 | 某些Step数据不完整，但核心输出可用 |

**error字段格式**：

```json
{
  "error": {
    "code": "INVALID_INPUT|KB_LOAD_FAILED|STEP_FAILED",
    "message": "具体错误描述",
    "step": "失败的Step编号"
  }
}
```

### 禁止任务

```
✗ 禁止输出打分（如"健康：4分"）
✗ 禁止单一凶相就判断重病
✗ 禁止不检查多项交叠程度
✗ 禁止模糊时间表述（如"近期"）
✗ 禁止跳过数据直接解读
✗ 禁止在未输出rules_read时继续执行
✗ 禁止跳过KVP验证直接解读数据
```

## 四、工作流程

### Step -1: 顾客问题确认与专项链路选择

**前置知识**：
```
读取：knowledge/专项解盘思维链与沟通规范.md（规则型）
时机：before_execution
```

**执行步骤**：
```
1. 确认顾客真正问题：长期格局/当前处境/具体决策/未来时间窗口
2. 按主题选择入口宫位与自然征象星，不泛泛论盘
3. 建立技术链：主题宫位 -> 宫主星 -> 宫主落宫 -> 自然征象星 -> 结构 -> 命主关系 -> 推运
4. 输出时转化为顾客语言：结论 -> 依据 -> 现实表现 -> 可执行建议
5. 检查表达边界：概率语言、选择语言、负面判断后必须给化解建议
```

```
读取：knowledge/行星先天性质分析框架.md（规则型）

```

```json
{
  "kvp": "KVP-S0B",

    "innate_nature_rule": "征象星先天性质（吉/凶/中性）是健康分析底层维度",
```

```
   └─ 一宫内行星列表

3. 提取六宫数据：
   ├─ 六宫宫头星座
   ├─ 六宫宫主星
   ├─ 六宫主星位置及状态
   ├─ 六宫主星先天性质
   └─ 六宫内行星列表

4. 提取八宫数据：
   ├─ 八宫宫头星座
   ├─ 八宫宫主星
   ├─ 八宫主星先天性质
   └─ 八宫内行星列表

5. 提取十二宫数据：
   ├─ 十二宫宫头星座
   ├─ 十二宫宫主星
   └─ 十二宫内行星列表

6. 提取日月状态：
   ├─ 太阳位置及状态及先天性质
   └─ 月亮位置及状态及先天性质
```

### Step 1: 身体健康分析

**前置知识**：
```
读取：knowledge/身体健康分析.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  "kvp": "KVP-H1",
  "loaded_rules": {
    "physical_health": "身体健康看日月+命主星+六宫+八宫",
    "multi_overlap": "凶相必须多项交叠才严重",
    "body_parts": "星体对应身体部位"
  }
}
```

**执行步骤**：
```
1. 分析日月状态：
   ├─ 太阳庙旺落陷（生命力）
   ├─ 月亮庙旺落陷（情绪健康）
   └─ 输出生命力判断

2. 分析命主星状态：
   ├─ 命主星庙旺落陷（先天底子）
   ├─ 命主星落宫
   └─ 输出先天底子判断

3. 分析六宫与八宫关系：
   ├─ 六宫主与八宫主关系
   ├─ 是否形成串联结构
   └─ 输出疾病严重程度判断

4. 判断凶像交叠程度：
   ├─ 检查六宫、八宫、十二宫串联
   ├─ 评估交叠程度（单项/两项/三项/四项）
   └─ 输出风险等级判断

5. 综合身体健康判断：
   ├─ 汇总所有健康因素
   └─ 输出身体健康综合描述（禁止打分）
```

---

### Step 2: 心理健康分析

**执行步骤**：
```
1. 分析月亮状态：
   ├─ 月亮庙旺落陷
   ├─ 月亮受克情况
   └─ 输出情绪稳定性判断

2. 分析水星状态：
   ├─ 水星庙旺落陷
   ├─ 水星受克情况
   └─ 输出思维状态判断

3. 分析火土掺杂：
   ├─ 火星掺杂（焦虑倾向）
   ├─ 土星掺杂（抑郁倾向）
   └─ 输出心理倾向判断

4. 分析十二宫状态：
   ├─ 十二宫主星状态
   ├─ 十二宫与六宫/八宫关系
   └─ 输出精神层面判断

5. 综合心理健康判断：
   ├─ 汇总所有心理因素
   └─ 输出心理健康综合描述（禁止打分）
```

**执行步骤**：
```
1. 分析三宫状态：
   ├─ 三宫主星状态

2. 分析八宫状态：
   ├─ 八宫主星状态
   ├─ 八宫与六宫/十二宫关系

3. 分析十二宫状态：
   ├─ 十二宫主星状态
   ├─ 十二宫与六宫/八宫关系
   └─ 输出隐性风险判断

4. 判断凶宫串联程度：
   ├─ 检查三宫/六宫/八宫/十二宫串联
   ├─ 评估交叠程度
   └─ 输出意外风险等级判断

5. 综合意外伤害判断：
   ├─ 汇总所有意外因素
   └─ 输出意外伤害综合描述（禁止打分）
```

## 五、输出格式规范

### synthesis字段规范

> **核心要求**：必须是具体描述，禁止打分，必须说明交叠程度

**正确示例**：
```
"physical_health_synthesis": "身体健康整体风险中等偏低。日月状态良好，太阳入庙提供生命力支持。六宫与八宫无紧密连接，疾病不致命。命主星水星受土星刑克（两项交叠），需关注神经系统健康。实例：可能有偏头痛倾向，建议保持规律作息，避免过度思虑。风险等级：中。"
```

**错误示例**：
```
"physical_health_synthesis": "健康：3分"  ✗ 禁止打分
"physical_health_synthesis": "健康一般"   ✗ 禁止笼统表述
```

### forecast字段规范

```json
{
  "forecast": {
    "firdaria_health": {
```
