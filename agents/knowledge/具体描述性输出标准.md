# 具体描述性输出标准

> **用途**：所有古典占星Agent输出内容的核心标准
> **版本**：v1.0 | 2026-06-09
> **重要级别**：★ 强制执行 ★
> **适用范围**：所有专项分析输出（事业、感情、财运、健康、六亲）

---

## 核心理念

```
┌──────────────────────────────────────────────────────────────┐
│                    输出核心标准                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 每条论断必须具备完整因果链                                  │
│                                                              │
│  完整论断 = 能量来源描述 + 状态描述 + 结果描述                  │
│           = 什么行星 + 什么状态 + 什么结果                      │
│           = 行星属性 + 状态含义 + 具体推导                      │
│                                                              │
│  ❌ 禁止：标签式、空洞式、跳跃式表述                           │
│  ✅ 要求：每条论断都有完整的三层描述                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 一、三层描述标准

### 1.1 第一层：能量来源描述

**必须包含四个要素：**

```
┌──────────────────────────────────────────────────────────────┐
│              第一层：能量来源描述（必须）                       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【要素1】行星/宫主星名称                                      │
│  ├─ 明确说明是哪颗行星                                        │
│  ├─ 如果是宫主星，说明是哪个宫的主星                          │
│  ├─ 示例："事业宫主星木星"、"七宫主土星"                      │
│  └─ ❌ 禁止："事业受影响"（未说明是什么行星）                   │
│                                                              │
│  【要素2】行星的先天属性                                      │
│  ├─ 说明该行星在古典占星中代表什么                            │
│  ├─ 必须引用下方的"行星先天属性速查表"                        │
│  ├─ 示例："木星为先天吉星，代表扩展与机遇、贵人与智慧"        │
│  └─ ❌ 禁止："木星在10宫"（未说明木星是什么）                  │
│                                                              │
│  【要素3】行星与该领域的关系                                   │
│  ├─ 守护关系：是否为该宫宫主星                                │
│  ├─ 庙旺关系：在哪个星座、什么状态                            │
│  ├─ 飞宫关系：从哪个宫飞来、落入哪个宫                        │
│  └─ 示例："从6宫飞入10宫，形成命-官结构"                      │
│                                                              │
│  【要素4】数据来源标注                                        │
│  ├─ 格式：(来源: JSON字段名) 或 (来源: XX表)                  │
│  ├─ 示例：(来源: JSON Jupiter.sign: Pisces)                   │
│  └─ ❌ 禁止：无来源标注的判断                                  │
│                                                              │
│  【合格模板】                                                 │
│  "XX宫主星[行星名]，[行星名]为先天[吉/凶]星，                  │
│   代表[核心含义]，目前在[星座名][状态]，                       │
│   从[X宫]飞入[Y宫](来源: JSON字段)"                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 第二层：状态描述

**必须包含四个要素：**

```
┌──────────────────────────────────────────────────────────────┐
│              第二层：状态描述（必须）                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【要素1】行星的庙旺落陷状态                                   │
│  ├─ 明确说明状态：入庙/入旺/失势/落陷/入闲(中性)               │
│  ├─ 必须标注来源：(来源: JSON XX.dignity)                     │
│  └─ 示例："木星入庙于射手座(来源: JSON Jupiter.dignity)"       │
│                                                              │
│  【要素2】状态含义解释                                        │
│  ├─ 入庙入旺：能量顺畅、正面表达、机遇多                      │
│  ├─ 失势落陷：能量受阻、负面表达、需努力                      │
│  ├─ 入闲(中性)：能量一般、需要引导                            │
│  └─ 必须说明状态意味着什么                                    │
│                                                              │
│  【要素3】状态对领域的直接影响                                │
│  ├─ 必须说明该状态如何影响该领域                              │
│  ├─ 不能只说状态，不说影响                                    │
│  └─ 示例："入庙状态意味着事业上的机遇容易被当事人把握"         │
│                                                              │
│  【要素4】量级和强度描述                                      │
│  ├─ 显著影响：主相位、宫主星、核心结构                        │
│  ├─ 次要影响：次要相位、宫内星、辅助参考                      │
│  └─ 示例："这是该领域的主要影响力量"                          │
│                                                              │
│  【合格模板】                                                 │
│  "[行星名][状态]，能量[强/中/弱]，这意味着在该领域              │
│   [具体影响]，可能导致[潜在结果](来源: XX)"                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.3 第三层：结果描述

**必须包含四个要素：**

```
┌──────────────────────────────────────────────────────────────┐
│              第三层：结果描述（必须）                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【要素1】具体结果推导                                        │
│  ├─ 基于"能量来源+状态"推导结果                               │
│  ├─ 结果必须具体，不能是笼统标签                              │
│  └─ ❌ 禁止："事业好"、"感情有挑战"                           │
│                                                              │
│  【要素2】结果性质判断                                        │
│  ├─ 吉凶判断：吉/凶/中性 + 判断依据                           │
│  ├─ 顺逆判断：顺遂/波折 + 原因                               │
│  ├─ 高低判断：高成就/中等/低 + 依据                           │
│  └─ 稳定判断：稳定/波动 + 原因                                │
│                                                              │
│  【要素3】情境化描述                                          │
│  ├─ 适用领域：适合什么类型工作/事业                           │
│  ├─ 行为建议：应该如何做                                      │
│  ├─ 时间节点：什么时候有机会/挑战（如适用）                    │
│  └─ 预期结果：可能达到什么层次                                │
│                                                              │
│  【要素4】因果链完整性                                        │
│  ├─ 检查：能量来源→状态→结果 是否连贯                         │
│  ├─ 不允许跳跃式结论                                          │
│  └─ 每一步都要有推导过程                                      │
│                                                              │
│  【合格模板】                                                 │
│  "因此，在该领域[具体结果]，[情境化描述]，                      │
│   [时间节点]，[性质判断](来源: XX)"                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 四、输出检查清单

**每个Agent在输出前必须自查：**

```markdown
□ 论断中的行星/宫主星名称是否明确？
□ 行星的先天属性是否说明？
□ 行星的状态（庙旺落陷）是否说明？
□ 状态的含义是否解释？
□ 状态对领域的影响是否说明？
□ 具体结果是否推导？
□ 结果是否情境化（含具体建议）？
□ 时间节点是否给出（如适用）？
□ 数据来源是否标注？
□ 是否避免了所有禁止表述？

★ 任何一项为"否"，该论断即为不合格 ★
```

## 五、快速参考卡

### 完整论断公式

```
完整论断 = 
  "XX宫主星[行星名]，[行星名]为先天[吉/凶]星，代表[核心含义]，
   在[星座名][状态](来源: JSON XX.dignity)，能量[强/中/弱]。
   这意味着在该领域[具体影响]，可能导致[潜在结果]。
   因此，[情境化描述]，[时间节点]，[性质判断]。"
```

### 常见禁止表述对照表

| ❌ 禁止 | ✅ 替换为 |
|---------|----------|
| "事业好" | "事业上有贵人提携迹象，适合XX领域" |
| "感情有挑战" | "婚姻经营有压力，可能表现为XX情况" |
| "财运平稳" | "正财稳定，年入XX万级别；偏财风险高" |
| "要注意健康" | "神经系统需关注，建议XX措施" |
| "受XX影响" | "XX宫主星[行星名]，[状态]，[影响]" |
