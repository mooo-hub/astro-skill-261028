## 四、工作流程

---

### Step 0: 命主气质链路确认

**前置知识**：
```
读取：knowledge/专项解盘思维链与沟通规范.md（命主气质/性格画像章节）
读取：knowledge/行星先天性质分析框架.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  “kvp”: “KVP-S0B”,
  “loaded_rules”: {
    “innate_nature_rule”: “命主星先天性质（吉/凶/中性）是性格分析底层维度”,
    “personality_benefics”: “木星/金星作为命主星先天吉星，带来乐观和魅力”,
    “personality_malefics”: “土星/火星作为命主星先天凶星，带来严肃和张力”,
    “combination_rule”: “吉星+庙旺=性格顺畅，凶星+落陷=性格有张力需整合”
  }
}
```

**执行步骤**：
```
1. 以”让顾客感到被看见”为目标组织语言
2. 建立链路：日月升 -> 命主星 -> 强势宫位/轴上行星 -> 庙旺资产 -> 土星/交点功课
3. 分析命主星先天性质（吉/凶/中性）及对性格的影响
4. 输出时说明外在姿态、内在需求、核心驱动力、天赋资产、人生功课与整合建议
5. 避免贴标签式断语，使用”容易/倾向/可以训练”的表达
```

---

### Step 1: 上升星座解读

**前置知识**：
```
读取：knowledge/上升解读框架.md
时机：before_execution
```

**执行步骤**：
```
1. 提取上升星座信息
2. 确定命主星（按古典守护关系）
   ├─ 水瓶座上升 → 命主星=土星（非天王星）
   ├─ 双鱼座上升 → 命主星=木星（非海王星）
   └─ 天蝎座上升 → 命主星=火星（非冥王星）
3. 分析命主星位置和状态
4. 输出第一层性格描述
```

---

### Step 2: 命主星解读

**执行步骤**：
```
1. 提取命主星落宫信息
2. 分析人生焦点领域
3. 分析命主星先天性质（★新增★）：
   ├─ 判断：先天吉星（木/金）vs 先天凶星（土/火）vs 中性（水）
   ├─ 含义：吉星=乐观有魅力，凶星=严肃有张力
   └─ 与尊贵状态结合：吉星+庙旺=最顺畅，凶星+落陷=需更多整合
4. 分析命主星状态（庙旺落陷）
5. 分析命主星相位关系
6. 输出第二层性格描述
```

---

### Step 3: 太阳解读

**前置知识**：
```
读取：knowledge/太阳解读框架.md
时机：before_execution
```

**执行步骤**：
```
1. 提取太阳星座信息
2. 提取太阳宫位信息
3. 分析太阳相位关系
4. 分析太阳尊贵状态
5. 输出第三层性格描述
```

---

### Step 4: 月亮解读

**前置知识**：
```
读取：knowledge/月亮解读框架.md
时机：before_execution
```

**执行步骤**：
```
1. 提取月亮星座信息
2. 提取月亮宫位信息
3. 分析月亮相位关系
4. 分析月亮尊贵状态
5. 输出第四层性格描述
```

---

### Step 5: 综合输出

**执行步骤**：
```
1. 汇总四层性格描述
2. 提取性格关键词（3-5个）
3. 分析性格优点
4. 分析性格挑战
5. 计算人格整合度（日月关系、命主星关系）
```
