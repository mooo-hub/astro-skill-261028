## 一、星座判断方法论

### 1.1 核心判断原则

```
┌──────────────────────────────────────────────────────────────┐
│                    星座判断核心原则                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【最准确的验证方法】                                          │
│  找那种星盘里有三四颗行星都聚集在一个星座的人跟他相处           │
│  你就能切实地感觉到这个星座的特点                               │
│                                                              │
│  【判断标准】                                                  │
│  ├─ 每个星座都有独有特点，其他星座没有                         │
│  ├─ 不能对应到什么星座上面都准的，那说明没有抓住特质           │
│  └─ 一句话就能判断这个人什么星座特质强                         │
│                                                              │
│  【星座三要素整合判断】                                        │
│  ├─ 元素（火/土/风/水）：决定能量表达方式                     │
│  ├─ 性质（基本/固定/变动）：决定行动模式                      │
│  └─ 守护星：提供核心驱动力                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 行星落入星座判断公式

```
行星表达效果 = 行星本质 + 星座特质 + 宫位领域 + 相位关系

【核心原则】
├─ 行星是"什么能量"
├─ 星座是"如何表达"
├─ 宫位是"在哪个领域"
└─ 相位是"与什么互动"
```

## 二、星座分类系统

### 2.1 二元划分（阴阳/昼夜）

| 类型 | 星座 | 核心特点 |
|------|------|----------|
| **阳性（昼）** | 白羊、双子、狮子、天秤、射手、水瓶 | 外放、外向、主动表达、较直 |
| **阴性（夜）** | 金牛、巨蟹、处女、天蝎、摩羯、双鱼 | 内敛、敏感、情绪化、藏心里 |

**记忆法**：火元素 + 风元素 = 阳性；水元素 + 土元素 = 阴性

### 2.2 四元素划分

| 元素 | 星座 | 特点 | 纯质料 |
|------|------|------|--------|
| **火象** | 白羊、狮子、射手 | 勇往直前、积极、冲动、大度、不记仇 | 热 + 干 |
| **土象** | 金牛、处女、摩羯 | 坚持、能忍、踏实、注重实际 | 冷 + 干 |
| **风象** | 双子、天秤、水瓶 | 理性、适合出主意、不愿坚持 | 热 + 湿 |
| **水象** | 巨蟹、天蝎、双鱼 | 敏感、直觉强、情绪化、调查能力强 | 冷 + 湿 |

**元素性格倾向**：
- 火象强：容易冲动、直接
- 土象强：保守稳重
- 风象强：灵活
- 水象强：感性

### 2.3 三性质划分

| 类型 | 星座 | 特点 | 心理动机 |
|------|------|------|----------|
| **基本宫** | 白羊、巨蟹、天秤、摩羯 | 可制定规则也可适应环境 | 倾向于影响他人 |
| **固定宫** | 金牛、狮子、天蝎、水瓶 | 不愿变、守习惯、习惯=安全感 | 易于固执己见与坚定 |
| **变动宫** | 双子、处女、射手、双鱼 | 愿意不断尝试、变通性强 | 较能适应变局 |

### 2.4 星座纯质料（热冷湿干）

| 属性 | 特点 |
|------|------|
| **热** | 主动、燥热、急躁 |
| **冷** | 被动、收缩、务实 |
| **干** | 蒸发水分、固执、界限分明 |
| **湿** | 湿润、感性、融合、包容 |

**四元素纯质料对应**：
- 火象：热 + 干 → 黄胆汁
- 土象：冷 + 干 → 黑胆汁
- 风象：热 + 湿 → 血液
- 水象：冷 + 湿 → 黏液

## 三、星座轴线（对宫关系）

| 轴线 | 主题 | 共性 |
|------|------|------|
| 白羊-天秤 | 自我与他者 | 目标感、懂礼貌 |
| 金牛-天蝎 | 情色、情欲 | 懒、占有欲强、控制欲强 |
| 双子-射手 | 学习 | 知识兴趣、新鲜感、变动性强 |
| 巨蟹-摩羯 | 世俗 | 注重世俗标准、爱面子、养备胎 |
| 狮子-水瓶 | 自大自恋 | 想当老大、自尊心强、要尊重 |
| 处女-双鱼 | 奉献奴性 | 服务他人、没有边界感、爱加戏 |
