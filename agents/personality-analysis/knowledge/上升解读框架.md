## 一、上升核心概念

### 1.1 上升的定义

```
【上升是什么】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  上升点（Ascendant）= 东升点                                 │
│                                                              │
│  ★ 定义：出生时刻，东方地平线上升起的黄道星座度数             │
│                                                              │
│  ★ 本质：                                                    │
│    ├─ 地球自转造成的现象（每天旋转一圈）                      │
│    ├─ 代表灵魂进入物质世界的"入口"                           │
│    └─ 影响全盘宫位划分（决定各宫头位置）                      │
│                                                              │
│  ★ 变化速度：                                                │
│    ├─ 约2小时走一个星座                                      │
│    ├─ 约4分钟走1度                                           │
│    └─ 出生时间的准确性对上升判断至关重要                      │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

┌──────────────────────────────────────────────────────────────┐

│    ├─ 只看上升星座不看上升星                                 │
│    └─ 正确做法：上升星可能比上升星座更重要                   │
│                                                              │
│  错误3：忽略命主星状态                                       │
│    ├─ 只看命主星落宫不看命主星状态                           │
│    └─ 正确做法：命主星状态决定人生发展的顺利程度             │

│    └─ 正确做法：四层性格画像需要整合分析                     │
│                                                              │

│    ├─ 时间误差大时上升可能不对                               │
