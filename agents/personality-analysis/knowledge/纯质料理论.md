## 一、纯质料基础概念

### 1.1 四种基本属性

```
┌──────────────────────────────────────────────────────────────┐
│                    纯质料四种属性                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【热（Hot）】                                                 │
│  ├─ 特点：主动、燥热、急躁                                    │
│  ├─ 性质：扩张、上升、向外                                   │
│  └─ 表现：积极、主动、热情                                   │
│                                                              │
│  【冷（Cold）】                                                │
│  ├─ 特点：被动、收缩、务实                                    │
│  ├─ 性质：收缩、下降、向内                                   │
│  └─ 表现：冷静、保守、稳重                                   │
│                                                              │
│  【干（Dry）】                                                 │
│  ├─ 特点：蒸发水分、固执、界限分明                            │
│  ├─ 性质：固化、分离、界限                                   │
│  └─ 表现：坚持、独立、不妥协                                 │
│                                                              │
│  【湿（Wet）】                                                 │
│  ├─ 特点：湿润、感性、融合、包容                              │
│  ├─ 性质：融合、连接、包容                                   │
│  └─ 表现：柔和、适应、感性                                   │
│                                                              │
│  ★ 热与冷相对，干与湿相对                                     │
│  ★ 每种物质由两种属性组成                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 属性组合规律

```
【相对关系】
热 ←→ 冷：主动 vs 被动
干 ←→ 湿：固化 vs 融合

【组合原则】
├─ 热+干：最活跃、最固定（火）
├─ 热+湿：活跃但融合（风）
├─ 冷+干：被动但固定（土）
└─ 冷+湿：被动且融合（水）
```

## 四、纯质料与性格分析

### 4.1 元素分布性格论法

| 元素强 | 特质 | 性格特点 |
|--------|------|----------|
| 火象（热+干）| 热情积极 | 可能冲动急躁 |
| 土象（冷+干）| 务实稳定 | 可能固执保守 |
| 风象（热+湿）| 灵活社交 | 可能善变不专 |
| 水象（冷+湿）| 敏感直觉 | 可能情绪化依赖 |
| **平衡分布**| 性格全面 | 适应力强 |

### 4.2 纯质料组合性格

```
【热+干强】（火象、太阳、火星）

├─ 稳重踏实、有耐力

└─ 建议：学会灵活适应

【热+湿强】（风象、木星）
├─ 灵活多变、善于社交
├─ 理性智慧、有扩展力
├─ 可能不够坚持、疏离
└─ 建议：学会深度专注
```

## 五、纯质料与健康

### 5.1 体液学说对应

| 纯质料 | 体液 | 健康影响 |
|--------|------|----------|
| 热+干（火）| 黄胆汁 | 可能上火、发热、炎症 |
| 冷+干（土）| 黑胆汁 | 可能抑郁、消化不良 |
| 热+湿（风）| 血液 | 循环好、可能多动 |
| 冷+湿（水）| 黏液 | 可能水肿、代谢慢 |

### 5.2 行星与健康

```
【行星健康对应】

太阳（热+干）：
├─ 身体部位：脊椎、心脏、眼睛

月亮（冷+湿）：
├─ 身体部位：乳房、子宫、肠胃、体液
└─ 影响：消化系统、情绪、记忆力

金星（冷+湿）：
├─ 身体部位：喉咙、肾脏、腰部
└─ 影响：泌尿系统、性腺体

火星（热+干）：
├─ 身体部位：血液、肌肉、性腺

水星（中性）：

木星（热+湿）：
├─ 身体部位：肝脏、臀部、大腿

├─ 身体部位：皮肤、牙齿、骨骼、关节
└─ 影响：慢性病、长期吃药
```

## 六、纯质料与行星吉凶

### 6.1 吉凶判断原理

```
┌──────────────────────────────────────────────────────────────┐
│                    行星吉凶判断原理                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【从日月主宰星座与其他行星的托勒密相位推导】                   │
│                                                              │
│  木星：与日月形成三分相关系（120°）→ 第一吉星                  │
│  金星：与日月形成六分相关系（60°）→ 次吉                       │
│  土星：与日月形成对相关系（180°）→ 第一凶星                    │
│  火星：与日月形成四分相关系（90°）→ 次凶                       │
│  水星：未形成传统相位 → 中性                                  │
│                                                              │
│  【吉凶与纯质料的关系】                                        │
│  ├─ 木星（热+湿）：扩展、融合 → 吉                            │
│  ├─ 金星（冷+湿）：和谐、融合 → 吉                           │
│  ├─ 土星（冷+干）：收缩、限制 → 凶                           │
│  ├─ 火星（热+干）：冲动、冲突 → 凶                           │
│  └─ 水星（中性）：随伴星而定 → 中性                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
