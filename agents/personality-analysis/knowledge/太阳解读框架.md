### 1.2 太阳与月亮核心差异

| 层面 | 太阳 | 月亮 |
|------|------|------|
| **代表** | 核心自我、人生主轴 | 情感需求、安全感来源 |
| **判断** | 人生追求什么 | 人生需要什么 |
| **关键词** | "我要成为" | "我需要感到" |
| **课题** | 如何实现自我 | 如何满足情感 |
| **表现** | 外在追求、主动表达 | 内在需求、被动感受 |
| **性格层面** | 有意识的自我认同 | 无意识的情感反应 |
| **时间性** | 相对稳定不变 | 变动性强（2.5天换座） |

## 二、太阳必然尊贵判断（完整思维链）

### 2.1 庙旺落陷速查表

| 状态 | 星座 | 力量评分 | 核心特点 | 解读要点 |
|------|------|----------|----------|----------|
| **入庙** | 狮子座 | +5 | 自我力量最强 | 天生自信，有王者气质，领导力强 |
| **入旺** | 白羊座 | +4 | 自我表达旺盛 | 积极进取，有开创力，行动力强 |
| **外来** | 其他星座 | 0 | 力量中性 | 无加成也无减损，需配合其他因素综合判断 |
| **失势** | 水瓶座 | -5 | 自我认同需后天建立 | 独立但不随众，需找到独特性 |
| **落陷** | 天秤座 | -4 | 自我表达受制 | 需要他人关系才能定义自我 |

│  ├─ 正确：必须判断太阳是否灼烧其他行星                        │

│  └─ 原因：尊贵可以累加                                        │
│                                                              │

│  ├─ 正确：太阳定位星的状态影响太阳表达                        │
