## 一、月亮核心概念

### 1.1 月亮本质含义

```
┌──────────────────────────────────────────────────────────────┐
│                    月亮核心含义速查表                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【基本属性】                                                 │
│  ├─ 英文名：Moon                                              │
│  ├─ 符号：☽                                                  │
│  ├─ 阴阳性：阴性                                              │
│  ├─ 昼夜：夜星（夜生盘月亮更强势）                            │
│  ├─ 纯质料：冷 + 湿                                          │
│  ├─ 吉凶：先天吉星                                            │
│  ├─ 体液：黏液                                                │
│  └─ 特性：变动性最强的行星，所有含义围绕此展开                 │
│                                                              │
│  【核心象征】                                                 │
│  ├─ 人物：新生儿、生育能力（男女皆看）、母亲、妻子            │
│  │         重要女性角色、照顾者                               │
│  ├─ 心理：感知快乐的能力、安全感、亲密感                      │
│  │         （月不佳难建立亲密关系）                           │
│  ├─ 能力：先天学习能力（与水星区别：水星是后天学习）          │
│  ├─ 事物：液体、食物、家、日常习惯                            │
│  └─ 健康：消化系统、肠胃、情绪、记忆力、体液、乳房、子宫       │
│                                                              │
│  【关键词】                                                   │
│  「我需要感到」——情感需求与安全感来源                         │
│                                                              │
│  【判断核心】                                                 │
│  ├─ 月亮落宫 = 人生快乐源泉 = 满足月亮就是打动人心            │
│  ├─ 月亮星座 = 情感表达方式 = 安全感来源模式                  │
│  ├─ 月亮相位 = 情感互动关系 = 内在需求满足程度                │
│  └─ 月亮变动性 = 该领域事物容易发生变动                       │
│                                                              │
│  【重要原则】                                                 │
│  ├─ 月亮落宫事物容易发生变动（如月4宫 → 经常搬家）            │
│  ├─ 男生精子质量看月亮，非火星                                │
│  ├─ 月亮 = 液体，适合做酒、茶、咖啡等液体相关行业              │
│  └─ 月亮不佳难建立亲密关系                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 月亮与太阳核心差异

| 层面 | 太阳 | 月亮 |
|------|------|------|
| **代表** | 核心自我、人生主轴 | 情感需求、安全感来源 |
| **判断** | 人生追求什么 | 人生需要什么 |
| **关键词** | "我要成为" | "我需要感到" |
| **课题** | 如何实现自我 | 如何满足情感 |
| **表现** | 外在追求、主动表达 | 内在需求、被动感受 |
| **性格层面** | 有意识的自我认同 | 无意识的情感反应 |
| **时间性** | 相对稳定不变 | 变动性强（2.5天换座） |
| **阴阳** | 阳性、主动 | 阴性、被动 |
| **昼夜** | 昼星 | 夜星 |
| **纯质料** | 热+干 | 冷+湿 |
| **体液** | 黄胆汁 | 黏液 |

## 二、月亮必然尊贵判断（完整思维链）

### 2.1 庙旺落陷速查表

| 状态 | 星座 | 力量评分 | 核心特点 | 解读要点 |
|------|------|----------|----------|----------|
| **入庙** | 巨蟹座 | +5 | 情感力量最强 | 天生敏感，有照顾本能，家庭导向强 |
| **入旺** | 金牛座 | +4 | 情感最稳定 | 情绪稳定，需要物质安全感，享受舒适 |
| **失势** | 摩羯座 | -5 | 情感需求受限 | 情感内敛，需要尊重和地位保障 |
| **落陷** | 天蝎座 | -4 | 情感体验剧烈 | 情绪强烈，需要深层安全感，执念强 |
