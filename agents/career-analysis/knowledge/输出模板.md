# 事业分析输出模板

本文档定义事业专项分析的输出格式规范，包括 synthesis 字段规范和 forecast 字段规范。

---

```json
{
  "career": {
    "meta": {

      "kvp_log": [...]
    },
    "tenth_house": {...},
    "aspects": [...],
    "structures": [...],
    "profession_indicators": [...],
    "sun": {...},
    "moon": {...},

    "primary_benefic": "太阳",

    },
    "career_fortune": {

  }
}
```

## 二、Synthesis 字段规范

> **核心要求**：必须是具体描述，禁止打分，必须有实例说明

### 2.1 行业方向 synthesis

**正确示例**：

```json
{
  "industry_synthesis": "职业方向以金融管理为主，涉及他人资源运作。十宫主星土星落八宫巨蟹座，官禄星为先天凶星且落陷，表示事业发展需要长期积累。但土木互容结构带来木星（吉星）的能量补充，可能通过合作关系获得贵人支持。星座性为水象巨蟹，偏向情感服务、民生相关领域。实例：可能在金融机构的后台管理部门工作，涉及风险控制、资产管理，虽然压力较大、节奏较慢，但长期发展稳定。"
}
```

**错误示例**：

```json
{
  "industry_synthesis": "职业方向：金融类"  ✗ 过于笼统
  "industry_synthesis": "职业：3分"        ✗ 禁止打分
  "industry_synthesis": "事业运势一般"     ✗ 禁止模糊表述
}
```

---

### 2.2 职场环境 synthesis

**正确示例**：

```json
{
  "workplace_dimension_synthesis": "职场环境呈现公权单位特征。职业征象星形成一四十连接（命主星+十宫主星+四宫主星关系），说明适合在稳定性强的单位工作。六宫主星水星入庙双子座三宫，工作环境以沟通学习为主，可能涉及频繁的信息交流和技能培训。十一宫内无行星，同事关系相对平淡，平级同事互动不多。领导风格呈现土星特质，十宫主土星参与结构，领导可能表现为压制型、等级森严的管理风格。实例：适合在国企、政府部门或大型企业的后台管理部门工作，工作环境严格规范，与上级关系需要谨慎经营。"
}
```

---

### 2.3 贵人运 synthesis

**正确示例**：

```json
{
  "benefic_fortune_synthesis": "事业有贵人支持。十宫主星土星与太阳形成接纳关系，太阳作为贵人星带来领导垂青。太阳入庙狮子座十宫，有贵气加持，可能获得上级领导的强力支持。同时土木互容带来木星贵人，木星主五宫+八宫（吉凶混合），贵人效力部分有效，贵人支持可能伴随某些代价。贵人来源领域为七宫（伴侣/合伙），说明贵人可能来自合作关系或伴侣引荐。实例：工作中可能获得领导的赏识和支持，在关键晋升时刻有贵人相助，但贵人支持可能伴随某些条件或代价。"
}
```

---

### 2.4 事业高度 synthesis

**正确示例**：

```json
{
  "height_synthesis": "事业可能比较辛苦，需要在严格的环境中发展，可能涉及他人资源/投资等领域。十宫主星土星为先天凶星，落陷于巨蟹座，能量表达受限。但贵人结构（土木互容）可能带来关键的转折机会和支持。需要综合看待辛苦与贵人支持并存的情况。实例：可能在金融机构的后台风控部门工作，虽然压力大、节奏慢，但上级领导可能在关键时刻给予支持。"
}
```

---

### 2.5 事业稳定度 synthesis

**正确示例**：

```json
{
  "stability_synthesis": "事业稳定度中等偏低，存在一定波动。土星落陷且落在凶宫八宫，事业上可能遇到一些阻碍和变数。土木互容虽然带来贵人支持，但这种支持可能是阶段性的，不是持续性的。八宫特质带来收入动荡、起伏较大的特点。实例：可能在某个项目周期内得到领导支持，但项目结束后需要重新寻找机会。建议在贵人结构激活期把握机会，在压力期保持耐心。"
}
```

---

### 2.6 整体格局 synthesis

**正确示例**：

```json
{
  "pattern_synthesis": "整体格局属于'主结构好但有破格'类型。土木互容作为最可倚仗的结构，结构较为紧密且有一定贵气支持。但官禄星落八宫、木星主吉凶混合（5r+8r）带来一定破格影响。格局特点是有成有败，发达早晚看运。实例：可能在事业上有一定成就，但伴随起伏波动，建议把握贵人结构激活期的机会，同时做好风险应对准备。"
}
```

## 三、Forecast 字段规范

### 3.1 完整格式

```json
{
  "forecast": {
    "firdaria_career": {
      "major_period": "土星",
      "minor_period": "木星",
      "period_years": "2024-2026",
      "career_tone": "事业考验期，需要耐心积累"
    },
    "profection_career": {
      "annual_house": 10,
      "theme": "事业焦点年",
      "key_events": ["事业转折", "晋升机会"]
    },
    "key_periods": [
      {"period": "2025年", "event": "事业关键窗口"},
      {"period": "2026年", "event": "贵人支持期"}
    ]
  }
}
```

## 四、Advice 字段规范

### 4.1 基础格式

```json
{
  "advice": {
    "direction": {
      "suitable": ["长期积累型行业", "他人资源管理", "深度专业领域", "结构化管理工作"],
      "avoid": ["短期投机", "依赖人气的职业", "快速变现模式"],
      "reasoning": "十宫主星土星落八宫，凶宫掺入，适合深度而非广度，需要长期耕耘"
    },
    "timing": {
      "favorable_window": "土木互容激活期、木星过境相关宫位时",
      "risk_window": "土星回归前后、土星刑冲关键点",
      "reasoning": "互容结构为阶段性贵人支持，非持续性；土星周期带来压力节点"
    },
    "action": [
      "主动建立深度合作而非广泛社交",
      "专注专业积累而非频繁跳槽",
      "把握贵人结构激活期的机会"
    ]
  }
}
```

## 五、输出禁忌

### 5.1 禁止格式

```json
// ✗ 禁止打分
"height_synthesis": "事业高度：3分"
"career_score": 4

// ✗ 禁止笼统表述
"industry_synthesis": "事业运势一般"
"workplace_synthesis": "工作环境还可以"

// ✗ 禁止无实例
"height_synthesis": "事业有成，社会地位较高"

// ✗ 禁止模糊时间
"key_periods": [{"period": "近期", "event": "..."}]
```

---

### 5.2 正确原则

```
1. 具体描述 > 笼统表述
2. 实例说明 > 空洞判断
3. 数据支撑 > 主观臆断
4. 明确时间 > 模糊表述
5. 可操作建议 > 空洞建议
```
