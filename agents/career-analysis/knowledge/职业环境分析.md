# 职业环境分析

职业环境分析是事业专项分析的第二步，包含**数据收集**和**职场环境维度判断**两部分。

---

## 一、数据收集

### 1.1 六宫数据收集

```
Step 1: 确定六宫宫头星座
    └─ 输出：六宫宫头星座名称

Step 2: 确定六宫主星
    ├─ 查表：六宫宫头星座 → 古典守护星
    └─ 输出：六宫主星名称

Step 3: 收集六宫主星状态数据
    ├─ 落入星座 → 能量状态
    ├─ 落入宫位 → 宫性
    ├─ 宫主星身份 → 后天宫性
    └─ 输出：六宫主星完整数据

Step 4: 收集六宫宫内星数据 ★四维度分析★
    ├─ 列出六宫内所有行星
    ├─ 对每个宫内星执行四维度分析：
    │   ├─ 先天星性（吉/凶/中性）
    │   ├─ 后天宫性（主吉宫/主凶宫）
    │   ├─ 能量状态（庙旺/落陷/普通）
    │   └─ 结构关系（相位）
    └─ 输出：六宫宫内星列表

Step 5: 收集六宫主星相位数据 ★核心★
    ├─ 六宫主星与其他行星的相位
    └─ 六宫主星与官禄星的关系
```

**六宫宫内星含义表**：

| 行星落入六宫 | 工作环境特质 |
|------------|-------------|
| 太阳 | 受领导关注、有机会展示 |
| 月亮 | 情感导向、需要照顾他人 |
| 水星 | 沟通频繁、学习型环境 |
| 金星 | 人际和谐、有美感需求 |
| 火星 | 竞争激烈、行动导向 |
| 木星 | 有人助力、发展型环境 |
| 土星 | 严格规范、责任重 |

### 1.3 宫位组合分析

```
Step 1: 检查职业征象星的宫位组合
    ├─ 一四十连接 → 公权单位/国企/公务员
    ├─ 二五十一连接 → 企业/私企/商业性质
    └─ 三六宫参与 → 基层/技能型/白手起家

Step 2: 分析宫位组合关系 ★核心补充★
    ├─ 相位关系（吉相位/凶相位）
    │   ├─ 凶相位（刑/冲）也代表实质连接，不可忽略
    │   ├─ 刑相 = 过程有张力，但确实在国企环境中
    │   └─ 一宫主星与十宫内星的刑相 = 在国企工作有压力感
    ├─ 接纳/互容关系
    └─ 一宫主星与十宫内星的关系也属于一四十连接

Step 3: 输出宫位组合分析
```

**宫位组合补充规则**：

```
┌──────────────────────────────────────────────────────────────┐
│            一四十连接判断补充规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【一宫主星与十宫内星的关系也属于一四十连接】                     │
│  ├─ 一宫主星与十宫内星的相位 = 一宫与十宫的连接                   │
│  ├─ 即使是凶相位（刑/冲），也代表实质连接                        │
│  ├─ 凶相位 ≠ 没有连接                                          │
│  ├─ 凶相位表示在公权单位/国企环境中工作有压力感                   │
│  └─ 判断时必须检查一宫主星与十宫内星的所有相位关系               │
│                                                              │
│  【本质说明】                                                  │
│  ├─ 一四十连接本质就是看"宫主星之间的关系"                      │
│  └─ 统一用"宫主星"表述即可                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、职场环境维度判断

```
Step 1: 判断公司性质
    ├─ 检查宫位组合（应用职业征象星数据）
    │   ├─ 一四十连接 → 公权单位/国企/公务员
    │   ├─ 二五十一连接 → 企业/私企/商业性质
    │   └─ 三六宫参与 → 基层/技能型/白手起家
    │   └─ 九宫参与 → 高校/学术/研究机构
    └─ 输出：公司性质判断

Step 2: 判断工作环境
    ├─ 应用六宫数据
    │   ├─ 六宫主星状态 → 环境质量
    │   ├─ 六宫宫内星 → 环境特质
    │   └─ 六宫宫头星座 → 环境氛围
    └─ 输出：工作环境描述

Step 3: 判断领导风格
    ├─ 应用十宫数据（来自职业类型分析）
    │   ├─ 十宫=上司/前辈
    │   ├─ 贵人星类型 → 支持类型
    │   ├─ 土星参与 → 压制型
    │   └─ 灼烧状态 → 接近权贵
    └─ 输出：领导风格描述

Step 4: 判断同事关系
    ├─ 应用十一宫数据
    │   ├─ 十一宫=平级同事
    │   ├─ 十一宫主星状态 → 同事本身的特质
    │   ├─ 十一宫宫内星 → 关系特质
    │   └─ 相位关系 → 和谐/冲突
    ├─ 检查命主星与十一宫主星的关系
    │   ├─ 有相位（含凶相位）→ 命主与同事有实质连接
    │   ├─ 命主星强旺 → 本人主动建立友好关系
    │   └─ 刑相 = 命主愿意付出努力与同事建立连接
    ├─ 分析命主星特质的主导作用
    │   ├─ 命主星入庙 → 天生情感连接能力强
    │   ├─ 月亮入庙 → 滋养、照顾、社交能力强
    │   └─ 命主特质可化解十一宫主星状态不佳的影响
    └─ 输出：同事关系描述

Step 5: 综合输出 → 职场环境描述
```

### 3.4 同事关系判断补充规则

```
┌──────────────────────────────────────────────────────────────┐
│            同事关系判断核心补充规则                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【同事关系由命主星特质主导】                                    │
│  ├─ 命主星强旺（入庙/入旺）→ 本人主动建立友好关系                 │
│  ├─ 命主星与十一宫主有刑相 → 命主愿意付出努力与同事建立连接        │
│  ├─ 刑相 ≠ 关系不好，而是"需要付出努力"                         │
│  └─ 命主主动付出 → 与同事建立友好关系                           │
│                                                              │
│  【十一宫主星弱化的正确理解】                                    │
│  ├─ 十一宫主星失势/落陷/逆行 ≠ 同事不好                          │
│  ├─ 十一宫主星弱化 = 同事本身能力/竞争力较弱                     │
│  ├─ 弱化反而减少竞争冲突 → 同事关系更平和                        │
│  └─ 命主星强旺时可化解十一宫主星状态不佳的影响                    │
│                                                              │
│  【命主星入庙的特殊加持】                                        │
│  ├─ 命主星入庙 → 天生情感连接和社交能力强                        │
│  ├─ 命主星为月亮入庙 → 滋养、照顾、社交能力强                     │
│  └─ 即使十一宫主星状态不佳，命主也能主动化解                      │
│                                                              │
│  【判断要点】                                                  │
│  ├─ 命主星状态：主导本人主动建立关系的能力                        │
│  ├─ 命主与十一宫主相位：有相位（含凶相位）表示有实质连接            │
│  ├─ 十一宫主星状态：辅助判断同事本身的特质                        │
│  └─ 命主星特质：决定本人化解关系问题的能力                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**同事关系判断要点**：

| 检查项 | 作用 | 说明 |
|--------|------|------|
| 命主星状态 | 主导 | 强旺则本人主动建立友好关系 |
| 命主与十一宫主相位 | 连接 | 有相位（含凶相位）表示有实质连接 |
| 十一宫主星状态 | 辅助 | 弱化反而可能减少竞争冲突 |
| 命主星特质 | 决定性 | 如月亮入庙则天生社交能力强 |
