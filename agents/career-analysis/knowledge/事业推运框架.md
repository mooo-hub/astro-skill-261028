# 事业推运分析框架

事业推运分析整合法达大运与小限法，判断事业关键期与发展节点。

> **核心原则**：本命不会出现的问题，流年也不会出现。一切土壤和来源还是本命，本命盘必须过关才能看推运。
>
> —— 来源：[[sources/古典占星课-解盘/解盘班-第11课-法达-提炼]]

## 与其他模块的关系

本模块是事业分析的**第四步**，需要**引用**前面步骤的数据：

```
【引用关系】
├─ Step 1 职业类型分析 → 官禄星身份、位置、状态
├─ Step 3 事业运势分析 → 贵人结构、格局判断、清纯度
└─ Step 4 事业推运分析 → 引用上述数据，进行时间推运
```

## 二、法达大运事业判断

### 2.1 法达主运与事业

| 主运行星 | 事业基调 | 具体表现 |
|----------|----------|----------|
| **太阳** | 事业贵气期 | 获得认可、晋升机会、名声提升、领导垂青 |
| **月亮** | 事业适应期 | 情感导向、变动较多、需要适应、家庭与事业平衡 |
| **水星** | 事业学习期 | 技能提升、沟通重要、学习期、文书事务 |
| **金星** | 事业顺遂期 | 人际和谐、贵人支持、机会多、合作顺利 |
| **火星** | 事业竞争期 | 竞争激烈、行动重要、压力期、需要开拓 |
| **木星** | 事业扩张期 | 机会扩展、贵人运强、发展期、"躺赢"人生赢家 |
| **土星** | 事业考验期 | 压力大、考验多、需要耐心、积累期 |
| **北交点** | 事业成长期 | 成长方向、业力推动 |

### 2.2 法达推运核心原则

#### 直限星判断原则

> **核心原则**：直限星引动的事件是看与直限星产生结构的星体，不是看直限星本身。
>
> —— 来源：[[sources/古典占星课-解盘/解盘班-第11课-法达-提炼]]

**例**：月亮小运时，月亮接纳火星
- 事件以火星为主，不是以月亮为主
- 看火星的宫性和星性

#### 关系优先级

```
【结构紧密程度优先级】
├─ 接纳、互容 → 最紧密（就像"小三一个电话就走了"）
├─ 合相 → 次紧密
├─ 刑、冲 → 再次
└─ 三合、六合 → 太弱，基本不考虑（远亲，远水解不了近渴）

【判断要点】
└─ 与直限星关系最紧密的星体为主
```

#### 大小线在同一结构

```
【原则】
├─ 如果大运星和小运星在一个结构里
│   └─ 整条结构都要看 → "一根绳子上的蚂蚱"
│
└─ 如果不在一个结构里
    └─ 只看小运星的结构，不考虑大运星
```

#### 无结构的直限星处理

```
【处理方法】
├─ 没有接纳、互容、合相
├─ 直接看这颗星本身
├─ 看庙旺落陷
└─ 看掌管的宫位
```

#### 南北交点处理

```
【处理方法】
├─ 看与交点合的星体
└─ 如果没有合的星体，看定位星
```

### 2.3 法达与十宫主星关系

```
【判断方法】
├─ 法达主运行星与十宫主星的关系
│   ├─ 接纳/互容 → 事业运强
│   ├─ 吉相位 → 事业顺遂
│   ├─ 凶相位 → 事业有挑战
│   └─ 无关系 → 中等影响
│
└─ 法达主运行星主什么宫位
    ├─ 主十宫 → 事业焦点期
    ├─ 主吉宫（1、4、5、9、10、11）→ 事业有助力
    └─ 主凶宫（3、6、8、12）→ 事业有阻碍
```

### 2.4 法达事业关键期判断

| 法达配置 | 事业判断 |
|----------|----------|
| 法达主运 = 十宫主星 | 事业关键转折期，需重点关注 |
| 法达主运接纳十宫主星 | 事业贵人期，有支持 |
| 法达主运与十宫主星互容 | 事业双向发展期 |
| 法达主运刑冲十宫主星 | 事业考验期，有挑战 |
| 法达主运主吉宫（1、4、5、9、10、11）| 事业有外部助力 |
| 法达主运主凶宫（3、6、8、12）| 事业需克服阻碍 |

### 2.5 庙旺落陷在推运中的表现

> **重要提醒**：庙旺落陷重点在运势中间表现明显，不能用庙旺落陷评判命的好坏。

**例**：落陷的火星被引动
- 即使宫性良好，也会不舒服
- 在行运时感触会比较深

## 三、小限法事业判断

### 3.1 小限法基础概念

**英文**：Annual Profection（年进）

**核心规则**：
1. **生日换运**：小限从生日时刻换运，而非公历新年
2. **每年一宫**：按逆时针方向，每年推进一个宫位
3. **整宫制原则**：必须用整宫制判断（忽略劫夺，按星座取守护星）
4. **出生年为第一宫**：0岁=第一宫，1岁=第二宫，以此类推

### 3.2 小限走宫与事业

| 小限宫位 | 年度事业主题 | 重点关注 |
|----------|--------------|----------|
| **一宫年** | 自我发展年 | 个人品牌、自我创业、自我定位 |
| **二宫年** | 财富事业年 | 收入提升、财务规划、资源积累 |
| **三宫年** | 沟通学习年 | 技能培训、沟通事务、文书信息 |
| **四宫年** | 家庭根基年 | 房产、家庭事业、家族事业 |
| **五宫年** | 创意投资年 | 创意项目、投资机会、娱乐事业 |
| **六宫年** | 工作事务年 | 日常工作、技能提升、技术服务 |
| **七宫年** | 合作关系年 | 合伙、客户关系、一对一合作 |
| **八宫年** | 转变资源年 | 投资、他人资源、融资、暗中沟通 |
| **九宫年** | 扩展远行年 | 外贸、教育、远方、学术研究 |
| **十宫年** | **事业焦点年** | **事业关键节点、名声、社会地位变化** |
| **十一宫年** | 人脉社群年 | 社交、群体项目、大机构、大众服务 |
| **十二宫年** | 隐秘研究年 | 幕后工作、研究、灵性事业 |

### 3.3 年主星判断三要素

> **核心方法**：年主星结合三要素解读

| 要素 | 内容 | 取象 |
|------|------|------|
| 1. 落宫 | 年主星落在哪个宫位 | 事件发生的领域 |
| 2. 守护宫位 | 年主星守护哪些宫位 | 涉及的人生事项 |
| 3. 星座 | 年主星落在什么星座 | 事件呈现的方式 |

**完整判断维度**：
1. 年主星落在哪个宫位
2. 年主星守护第几宫
3. 年主星落在什么星座（方式过程）
4. 年主星的相位、互容接纳
5. 推进宫位内有什么行星

**取象原则**：
- 宫位 = 领域
- 星座 = 方式过程
- 行星 = 结果好坏

### 3.4 十宫年（余数10）事业判断

```
【小限十宫年特征】
├─ 事业成为年度焦点
├─ 可能的事业转折
├─ 晋升、跳槽、创业机会
├─ 名声、社会地位变化
└─ 与上级、权威关系重要

【判断要点】
├─ 年主星（十宫主星）状态
│   ├─ 庙旺 → 事业年顺遂
│   └─ 落陷 → 事业年有挑战
│
├─ 年主星与命主星关系
│   ├─ 和谐 → 事业发展顺畅
│   └─ 紧张 → 事业有压力
│
├─ 十宫内行星状态
│   ├─ 吉星 → 事业有助力
│   └─ 凶星 → 事业有阻碍
│
└─ 年主星的相位、互容接纳
    ├─ 与吉星结构 → 贵人支持
    └─ 与凶星结构 → 考验挑战
```

### 3.5 六宫年（余数6）工作判断

```
【小限六宫年特征】
├─ 工作事务增加
├─ 日常工作忙碌
├─ 技能提升期
├─ 服务他人期
├─ 白手起家、手艺饭
└─ 健康需关注

【判断要点】
├─ 六宫主星状态
├─ 六宫内行星
└─ 与十宫的关系
```

### 3.6 特殊技法

#### 项目完成时间判断

> **原理**：在某个星座开始的事情，在该星座守护星落的宫位年份完成。

**示例**：
- 十宫狮子开始的事情 → 太阳落12宫 → 走到12宫年完成
- 从开始到完成需走完整一圈

**应用**：
- 离婚：离婚念头开始的星座 → 走到守护星落宫年完成
- 盖房：开始盖房的星座 → 走到守护星落宫年完成

**规划建议**：开始重要事项时，选择守护星本身强旺且年份不久的时机。

#### 浮点四轴技法

**浮点**：北交点所在位置

**规律**：
- 小限走到浮点四轴（浮点星座的基本宫四轴）时，发生人生大事件
- 事件不可预测，被动做出选择

**基本宫四轴**：
- 白羊-天秤轴
- 巨蟹-摩羯轴

### 4.1 双重触发

```
【最强事业期】
├─ 法达主运 = 十宫主星
```

## 六、格局与层次判断

### 6.1 格局两个维度

> **重要理解**：格局好不等于人生顺遂

| 维度 | 含义 | 判断要点 |
|------|------|----------|
| **高度（成就）** | 社会地位、富贵程度、阶级层次 | 贵星加持、结构完整 |
| **稳定度（顺遂程度）** | 命运的稳定程度、人生是否顺遂 | 是否有凶宫乱入 |

**例**：戴安娜
- 名人（高度高）
- 但生命不顺遂（稳定度差）

### 6.2 贵气来源

#### 木星的贵气

**特质**：
- 大吉星
- "躺赢"的人生赢家
- 主1、4、5、9、10、11宫 = 有气（吉宫）
- 主3、6、8、12宫 = 无气（降低贵气）

**含义**：
- 做什么事都有人帮
- 运作自媒体就很多人follow
- 很快成为网红
- 有人助力

#### 太阳的贵气

**特质**：
- 更像是领导垂青
- 大的国家层面、公权层面
- 强有力的支持者

**例**：火星得太阳贵气
- 事业得到大领导支持
- 七宫主 = 来自伴侣或身边人助力

### 6.3 结构好坏判断

#### 好的结构

```
├─ 结构中要吉星吉宫参与
├─ 命主星得一颗贵星加持
├─ 结构非常紧密
└─ 可以靠这个结构过活
```

#### 坏的结构

```
├─ 结构中掺杂凶宫（3、6、8、12r）
├─ 会降低结构的贵气
├─ 后天凶星形成结构
└─ "一只老鼠坏了一锅汤"
```

## 七、职业征象星判断

### 7.1 寻找职业征象星的方法

```
【基本思路】
第一步：看官禄宫
├─ 官禄宫宫内星
└─ 官禄宫宫主星

第二步：找结构
├─ 与官禄星形成结构的星体
├─ 该星体掌管哪些宫位
└─ 那个星体和宫位就是职业增长性

第三步：看日月
├─ 太阳/月亮形成结构的星体也是职业征象
└─ 何时看太阳、何时看月亮，参考初阶班

第四步：命主星（最次考量）
└─ 表示想要在哪个领域发展
```

### 7.2 太极点转化

> **核心概念**：看山要在山外看

**规则**：
- 如果某星体本身就是官禄星，不能再作为判断依据
- 必须找结构之外的星体
- 例：水星是官禄星，不能从月水结构来看水星，要从月来看

### 7.3 星座与职业特性

| 元素 | 工作性质 | 具体表现 |
|------|----------|----------|
| **火象星座**（白羊、狮子、射手）| 开拓、创业 | 要当头头、要开拓、要领导别人 |
| **土象星座**（金牛、处女、摩羯）| 技术、稳定 | 与利益、钱有关、技术类 |
| **风象星座**（双子、天秤、水瓶）| 沟通、人际 | 需要沟通、分项宫位、跟人打交道 |
| **水象星座**（巨蟹、天蝎、双鱼）| 细腻、服务 | 细腻服务类、可能跟艺术有关 |

### 7.4 宫位组合与职业

| 宫位组合 | 职业特征 |
|----------|----------|
| 一四十连接 | 角宫相连、稳定性职业、公权单位、国家单位 |
| 二五十一连接 | 赚钱导向、公司企业、私营性质 |
| 三六宫 | 基层、技能、重复性劳动、白手起家、手艺饭 |
| 九宫 | 高科技、研究、高学历导向、高校、学术 |
