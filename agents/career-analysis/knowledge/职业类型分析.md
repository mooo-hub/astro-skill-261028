# 职业类型分析

职业类型分析是事业专项分析的第一步，包含**数据收集**和**行业维度判断**两部分。

---

## 一、数据收集

### 1.1 十宫数据收集

```
Step 1: 确定十宫宫头星座
    └─ 输出：十宫宫头星座名称

Step 2: 确定十宫主星（官禄星）
    ├─ 查表：十宫宫头星座 → 古典守护星
    └─ 输出：官禄星名称

Step 3: 收集官禄星状态数据
    ├─ 落入星座 → 能量状态（庙旺/落陷/普通）
    ├─ 落入宫位 → 宫性（吉宫/凶宫）
    ├─ 宫主星身份 → 后天宫性（主几宫）
    └─ 输出：官禄星完整数据

Step 4: 收集十宫宫内星数据 ★四维度分析★
    ├─ 列出十宫内所有行星
    ├─ 对每个宫内星执行四维度分析：
    │   ├─ 先天星性（吉/凶/贵/中性）
    │   ├─ 后天宫性（主吉宫/主凶宫）
    │   ├─ 能量状态（庙旺/落陷/普通）
    │   └─ 结构关系（与官禄星的相位/接纳）
    └─ 输出：十宫宫内星列表（含四维度数据）
```

### 1.2 相位数据收集

```
Step 1: 收集官禄星的相位
    ├─ 合相关系：官禄星与哪颗星合相（度数+容许度）
    ├─ 刑相关系：官禄星与哪颗星刑相（度数+容许度）
    ├─ 冲相关系：官禄星与哪颗星冲相（度数+容许度）
    ├─ 三合关系：官禄星与哪颗星三合（度数+容许度）
    └─ 六合关系：官禄星与哪颗星六合（度数+容许度）

Step 2: 收集职业征象星之间的相位
    ├─ 主征象星与辅助征象星之间的相位
    └─ 辅助征象星之间的相位

Step 3: 计算相位容许度 ★核心★
    ├─ 获取行星黄经值
    ├─ 计算黄经差（考虑圆周）
    ├─ 判断相位类型
    └─ 验证容许度是否有效
```

**相位类型含义表**：

| 相位 | 度数 | 性质 | 含义 | 在事业分析中的作用 |
|------|------|------|------|------------------|
| **合相** | 0度 | 中性 | 两星能量融合 | 直接连接，无阻碍，紧密程度中等 |
| **刑相** | 90度 | 凶 | 困难、摩擦、僵持 | 方式方法不对，需要付出更多努力 |
| **冲相** | 180度 | 凶 | 对立、冲突 | 有共同点可调和，外在张力 |
| **三合** | 120度 | 吉 | 协调、顺畅 | 天赋能量，顺畅表达 |
| **六合** | 60度 | 吉 | 机会、和谐 | 温和助力，机会连接 |

**相位容许度计算表**：

| 星体 | 容许度 |
|------|--------|
| 太阳 | 15度 |
| 月亮 | 12度 |
| 水星 | 7度 |
| 金星 | 7度 |
| 火星 | 8度 |
| 木星 | 9度 |
| 土星 | 9度 |

**计算公式**：
```
两星体间容许度 = (星体A容许度 + 星体B容许度) ÷ 2
相位有效范围 = 标准相位度数 ± 两星体间容许度
```

### 1.3 结构数据收集

```
Step 1: 查找官禄星参与的结构（相位+接纳/互容）
    ├─ 接纳关系（官禄星被接纳/官禄星接纳他星）
    │   └─ 注意：接纳比相位更紧密
    ├─ 互容关系（官禄星与哪颗星互容）
    │   └─ 双向能量互换
    ├─ 合相+接纳（强度最强）
    ├─ 刑/冲+接纳（过程艰辛，结果可得）
    └─ 三合/六合+接纳（顺畅得到）

Step 2: 执行太极点转化 ★核心★
    ├─ 原则：官禄星本身是"太极点"，不参与对自己的判断
    ├─ 转化：转从结构对象星的角度分析
    └─ 输出：结构对象星列表

Step 3: 收集结构对象星数据
    ├─ 对每个结构对象星执行：
    │   ├─ 落入星座 → 星座性质
    │   ├─ 落入宫位 → 宫性
    │   ├─ 宫主星身份 → 后天宫性
    │   ├─ 与官禄星的相位类型
    │   └─ 与官禄星的接纳/互容关系
    └─ 输出：结构对象星完整数据

Step 4: 分析结构的紧密程度
    ├─ 庙旺接纳：最紧密
    ├─ 普通接纳：紧密
    ├─ 互容：紧密程度中等
    ├─ 合相：紧密程度中等
    ├─ 刑/冲+接纳：过程艰辛但结果可得
    └─ 三合/六合：远亲结构，有紧密结构时作为补充

Step 5: 汇总职业征象星
    ├─ 主征象星：官禄星（权重最高）
    ├─ 辅助征象星：结构对象星（权重次之）
    └─ 输出：职业征象星列表（含权重+相位类型）
```

**结构优先级**：

```
接纳 > 互容 > 合相 > 刑冲 > 三合六合

紧密程度说明：
├─ 庙旺接纳：最紧密，即使凶相位，形成接纳后凶性减弱
├─ 普通接纳：紧密，相位影响过程但不影响结果
├─ 互容：双向能量互换，紧密程度中等
├─ 合相：能量融合，紧密程度中等
├─ 刑/冲+接纳：过程艰辛，需付出更多努力，但结果可得
└─ 三合/六合：远亲结构，有紧密结构时作为补充，无紧密结构时才作为主要依据
```

**相位与接纳的关系**：

| 相位类型 | 接纳强度 | 过程特点 |
|---------|---------|---------|
| 合相+接纳 | 最强 | 直接得到，无阻碍 |
| 三合+接纳 | 强 | 顺畅得到 |
| 六合+接纳 | 较强 | 机会连接，温和助力 |
| 刑相+接纳 | 中等 | 过程艰辛，需付出更多努力才能得到帮助 |
| 冲相+接纳 | 中等 | 需应一下分离或对立，但结果可得 |

**核心原则**：
```
相位只代表过程，不代表结果
├─ 凶相位：过程艰辛，需要付出更多努力
├─ 吉相位：过程顺畅，表达舒适
├─ 结果归到接纳强度，与相位无关
└─ 必须结合宫性、星性、结构综合判断
```

**太极点转化示例**：

```
例：水星（官禄星）与月亮形成合相

错误做法：
└─ 从水星看月亮 → 分析月亮的特质

正确做法：
├─ 水星是官禄星，是太极点
├─ 不能用水星来判断自己
└─ 转从月亮看 → 月亮的宫性+星性+星座性 = 职业征象

输出：
├─ 水星（主）- 十宫主星
└─ 月亮（辅）- 水月合相，太极点转化后为辅助征象星
```

## 二、行业维度判断

```
Step 1: 取职业征象星宫性 → 领域
    ├─ 主征象星（官禄星）的飞宫 → 主要领域
    └─ 辅助征象星的飞宫 → 补充领域

Step 2: 取职业征象星星性 → 风格
    ├─ 主征象星的星性 → 主要风格
    └─ 辅助征象星的星性 → 补充风格

Step 3: 取职业征象星落星座性 → 细节
    ├─ 火象：开创、竞争、表现
    ├─ 土象：稳定、务实、积累
    ├─ 风象：沟通、社交、灵活
    └─ 水象：情感、直觉、深度

Step 4: 检查十宫宫内星 → 补充征象
    └─ 应用数据收集阶段的十宫宫内星四维度分析结果

Step 5: 综合输出 → 行业方向
    └─ 职业 = 宫性（领域）+ 星性（风格）+ 星座性（细节）
```

## 五、职业转型分析方法

> **核心原则**：职业转型源于官禄星的召唤，当官禄星与另一个行业领域的行星形成紧密结构时，职业方向会指向该行星掌管的领域

### 5.1 转型判断逻辑

```
【职业转型识别】
├─ 官禄星与某行星形成紧密结构（接纳/互容/合相）
├─ 该行星掌管的宫位 = 转型方向领域
├─ 该行星落星座 = 转型方向表现方式
└─ 结构紧密程度 = 转型的必然性程度

【转型时间判断】
├─ 法达大运触发官禄星结构 → 转型关键期
├─ 小限走十宫年 → 事业焦点年，可能转型
└─ 双重触发 → 转型必然性最强
```

### 5.2 官禄星与行星结构对应转型方向

| 官禄星结构对象 | 转型方向领域 | 具体表现 |
|---------------|-------------|----------|
| 太阳 | 领导/政府/管理 | 从执行层转向管理层，从技术转向领导岗位 |
| 月亮 | 服务/民生/情感 | 从竞争型转向服务型，从技术转向情感服务 |
| 水星 | 教育/传播/沟通 | 从实务型转向传播型，从管理转向教育培训 |
| 金星 | 艺术/美业/公关 | 从技术型转向艺术型，从管理转向公关协调 |
| 火星 | 创业/竞争/开拓 | 从稳定型转向创业型，从服务转向竞争开拓 |
| 木星 | 教育/理念/扩展 | 从实务型转向教育型，从技术转向理念传播 |
| 土星 | 管理/实务/政企 | 从开创型转向管理型，从创业转向政企管理 |

### 5.3 转型案例分析方法

```
【分析步骤】
Step 1: 确认官禄星状态
    ├─ 官禄星落星座 → 当前职业方向表现方式
    └─ 官禄星落宫位 → 当前职业领域倾向

Step 2: 检查官禄星紧密结构
    ├─ 接纳/互容/合相 → 结构对象星
    └─ 结构对象星掌管宫位 → 转型方向领域

Step 3: 分析转型方向
    ├─ 结构对象星落星座 → 转型方向表现方式
    ├─ 结构对象星宫主星身份 → 转型领域细节
    └─ 相位类型 → 转型过程特点（吉相位=顺畅，凶相位=艰辛）

Step 4: 判断转型必然性
    ├─ 接纳结构 → 转型必然性最强
    ├─ 互容结构 → 转型必然性强
    ├─ 合相结构 → 转型必然性中等
    └─ 法达/小限触发 → 时间节点

Step 5: 综合输出
    ├─ 当前职业方向（官禄星主导）
    ├─ 转型方向（结构对象星主导）
    ├─ 转型过程特点（相位类型）
    └─ 转型时间节点（推运触发）
```
