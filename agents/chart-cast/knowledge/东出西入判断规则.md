> **调用时机**：Step 7 东出西入判断阶段

## 一、东出西入基本定义

### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                    东出西入定义                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【东出（Oriental/Oriens）】                                  │
│  ├─ 定义：行星在太阳之前东升                                 │
│  ├─ 位置：顺时针方向距离太阳较短                              │
│  └─ 含义：快、新、年轻、表现明显                              │
│                                                             │
│  【西入（Occidental/Occidens）】                              │
│  ├─ 定义：行星在太阳之后下降                                 │
│  ├─ 位置：逆时针方向距离太阳较短                              │
│  └─ 含义：慢、旧、老、表现稳定                                │
│                                                             │
│  【判断原则】                                                 │
│  ├─ 以太阳为参照点                                           │
│  ├─ 比较行星与太阳的黄经位置                                  │
│  └─ 不要求同一星座                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、东出西入判断方法

### 2.1 黄经比较法

```
Step 1: 获取太阳黄经（Sun_Longitude）
Step 2: 获取行星黄经（Planet_Longitude）
Step 3: 计算黄经差：
  ├─ 差值 = 行星黄经 - 太阳黄经
  └─ 如果差值 < 0，则差值 += 360
Step 4: 判断东出/西入：
  ├─ 差值 < 180° → 行星在太阳东边 → 东出
  └─ 差值 > 180° → 行星在太阳西边 → 西入
```

### 2.2 图解说明

```
              东出区域
          （行星在太阳前方）
                ↓
    ────────────────────────
    │                       │
    │         ★ 太阳        │
    │                       │
    ────────────────────────
                ↑
          （行星在太阳后方）
              西入区域


黄经示例：
太阳：狮子座 15°（黄经 135°）
火星：狮子座 20°（黄经 140°）
差值 = 140° - 135° = 5° < 180° → 东出

太阳：狮子座 15°（黄经 135°）
金星：巨蟹座 10°（黄经 100°）
差值 = 100° - 135° = -35° + 360° = 325° > 180° → 西入
```

## 三、行星偏好规则

### 3.1 行星阴阳分类

| 行星性质 | 行星 | 喜好 |
|----------|------|------|
| **阳性行星** | 火星、木星、土星 | 喜东出 |
| **阴性行星** | 月亮、金星、水星 | 喜西入 |

### 3.2 偏好对照表

| 行星 | 偏好位置 | 东出效果 | 西入效果 |
|------|----------|----------|----------|
| **火星** | 喜东出 | 行动力强、积极 | 行动力减弱、被动 |
| **木星** | 喜东出 | 运气强、扩张力强 | 运气减弱、保守 |
| **土星** | 喜东出 | 权威强、责任感强 | 权威减弱、压力重 |
| **月亮** | 喜西入 | 情绪波动大、不稳定 | 情绪稳定、内敛 |
| **金星** | 喜西入 | 感情外露、主动 | 感情内敛、被动 |
| **水星** | 喜西入 | 思维活跃、表达直接 | 思维深沉、表达含蓄 |

### 3.3 判断是否偏好位置

```
Step 1: 确定行星阴阳性质
Step 2: 判断东出/西入状态
Step 3: 对照偏好规则：
  ├─ 阳性行星 + 东出 → 偏好位置（preferred: true）
  ├─ 阳性行星 + 西入 → 非偏好位置（preferred: false）
  ├─ 阴性行星 + 西入 → 偏好位置（preferred: true）
  └─ 阴性行星 + 东出 → 非偏好位置（preferred: false）
```

## 四、判断步骤

### 完整流程

```
Step 1: 数据提取
  ├─ 获取太阳黄经
  └─ 获取各行星黄经

Step 2: 计算黄经差
  ├─ 对每个行星计算与太阳的黄经差
  └─ 归一化到0-360°范围

Step 3: 判断东出/西入
  ├─ 黄经差 < 180° → 东出
  └─ 黄经差 > 180° → 西入

Step 4: 判断偏好位置
  ├─ 查行星阴阳性质
  └─ 对照偏好规则

Step 5: 输出结果
```

## 五、计算示例

### 示例1：火星东出

```
太阳：狮子座 15°（黄经 135°）
火星：处女座 10°（黄经 153°）

计算：
黄经差 = 153° - 135° = 18° < 180°

判断：
状态：东出
行星性质：火星为阳性行星
偏好：阳性行星喜东出 → 偏好位置（preferred: true）
```

### 示例2：金星西入

```
太阳：狮子座 15°（黄经 135°）
金星：巨蟹座 5°（黄经 95°）

计算：
黄经差 = 95° - 135° = -40° + 360° = 320° > 180°

判断：
状态：西入
行星性质：金星为阴性行星
偏好：阴性行星喜西入 → 偏好位置（preferred: true）
```

### 示例3：木星西入（非偏好）

```
太阳：狮子座 15°（黄经 135°）
木星：金牛座 20°（黄经 50°）

计算：
黄经差 = 50° - 135° = -85° + 360° = 275° > 180°

判断：
状态：西入
行星性质：木星为阳性行星
偏好：阳性行星喜东出，但实际西入 → 非偏好位置（preferred: false）
```

## 六、特殊情况处理

### 6.1 太阳本身

```
太阳不参与东出西入判断
输出中跳过太阳
```

### 6.2 行星与太阳合相

```
┌─────────────────────────────────────────────────────────────┐
│                    合相时的判断                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 行星与太阳黄经差 < 容许度 → 合相                         │
│                                                             │
│  【处理方式】                                                 │
│  ├─ 合相处在临界状态，东出/西入判断意义减弱                   │
│  ├─ 仍然计算黄经差并判断                                      │
│  └─ 但需标注"合相处，东出西入判断意义减弱"                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.3 逆行行星

```
┌─────────────────────────────────────────────────────────────┐
│                    逆行行星判断                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【判断方法】                                                 │
│  ├─ 逆行不影响东出西入的静态判断                              │
│  └─ 仍然按黄经差判断                                         │
│                                                             │
│  【动态变化】                                                 │
│  ├─ 逆行行星的东出/西入状态可能发生变化                       │
│  ├─ 原本东出可能变成西入                                     │
│  └─ 需要标注"逆行中，状态可能变化"                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 八、注意事项

```
┌─────────────────────────────────────────────────────────────┐
│                    判断注意事项                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【计算范围】                                                 │
│  ├─ 计算月亮、水星、金星、火星、木星、土星                    │
│  └─ 不计算太阳本身                                           │
│                                                             │
│  【黄经计算】                                                 │
│  ├─ 使用黄经差值，不是度数差的绝对值                          │
│  └─ 考虑方向性（顺时针/逆时针）                               │
│                                                             │
│  【偏好判断】                                                 │
│  ├─ 偏好位置为参考，不是绝对好坏                              │
│  ├─ 非偏好位置不代表凶                                       │
│  └─ 需结合其他因素综合判断                                    │
│                                                             │
│  【不解读含义】                                               │
│  ├─ 仅判断东出/西入状态，不解读含义                           │
│  └─ 含义解读由personality-analysis Agent负责                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
