# 日夜盘判断规则

> **用途**：根据太阳所在宫位判断日盘/夜盘类型
> **调用时机**：Step 3 日夜盘判断阶段
> **版本**：v1.0 | 2026-06-15

---

## 一、核心定义

```
┌─────────────────────────────────────────────────────────────┐
│                    日夜盘定义                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【日盘】太阳在地平线以上                                     │
│  ├─ 判断标准：太阳在7-12宫                                   │
│  ├─ 特点：太阳为发光体，能量外显                              │
│  └─ 影响：三分性判断、法达大运顺序                           │
│                                                             │
│  【夜盘】太阳在地平线以下                                     │
│  ├─ 判断标准：太阳在1-6宫                                    │
│  ├─ 特点：月亮为发光体，能量内敛                              │
│  └─ 影响：三分性判断、法达大运顺序                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 二、判断步骤

```
Step 1: 从排盘数据获取太阳所在宫位
Step 2: 判断宫位范围
  ├─ 7、8、9、10、11、12宫 → 日盘
  └─ 1、2、3、4、5、6宫 → 夜盘
Step 3: 输出 day_night_chart = "日盘/夜盘"
Step 4: 标注影响项（三分性、法达大运）
```

---

## 三、影响说明

### 3.1 三分性判断影响

| 元素 | 日盘三分性守护星 | 夜盘三分性守护星 |
|------|------------------|------------------|
| 火象（白羊/狮子/射手）| 太阳、木星、土星 | 木星、太阳、土星 |
| 土象（金牛/处女/摩羯）| 金星、月亮、火星 | 月亮、金星、火星 |
| 风象（双子/天秤/水瓶）| 土星、水星、木星 | 水星、土星、木星 |
| 水象（巨蟹/天蝎/双鱼）| 金星、火星、月亮 | 火星、金星、月亮 |

**关键差异**：日夜盘的三分性守护星顺序不同

### 3.2 法达大运顺序影响

| 类型 | 大运顺序 |
|------|----------|
| **日盘** | 太阳→金星→水星→月亮→土星→木星→火星→北交→南交 |
| **夜盘** | 月亮→土星→木星→火星→北交→南交→太阳→金星→水星 |

**关键差异**：日盘从太阳开始，夜盘从月亮开始

### 3.3 六亲取用影响

| 情况 | 父亲征象星 | 母亲征象星 |
|------|------------|------------|
| 日盘男性 | 太阳（4宫主）| 月亮 |
| 日盘女性 | 太阳（4宫主）| 月亮 |
| 夜盘男性 | 太阳（4宫主）| 月亮 |
| 夜盘女性 | 太阳（4宫主）| 月亮 |
