> **用途**：chart-cast Agent判断行星先天尊贵与特殊状态
> **调用时机**：Step 4 行星先天禀赋与特殊状态判断

## 一、必然尊贵（Essential Dignities）

### 1.1 入庙（Domicile/庙）

**定义**：行星在自己守护的星座，好比回到自己的家。

**评分**：+5分

**入庙对照表**：

| 行星 | 入庙星座 |
|------|----------|
| 太阳 | 狮子座 |
| 月亮 | 巨蟹座 |
| 水星 | 双子座、处女座 |
| 金星 | 金牛座、天秤座 |
| 火星 | 白羊座、天蝎座 |
| 木星 | 射手座、双鱼座 |
| 土星 | 摩羯座、水瓶座 |

---

### 1.2 擢升（Exaltation/旺）

**定义**：行星在某星座表现特别好，好比受到接待的贵宾。

**评分**：+4分

**擢升对照表**（含度数）：

| 行星 | 擢升星座 | 擢升度数 |
|------|----------|----------|
| 太阳 | 白羊座 | 19° |
| 月亮 | 金牛座 | 3° |
| 水星 | 处女座 | 15°（一说水瓶座15°）|
| 金星 | 双鱼座 | 27° |
| 火星 | 摩羯座 | 28° |
| 木星 | 巨蟹座 | 15° |
| 土星 | 天秤座 | 21° |

---

### 1.3 三分性（Triplicity）

**定义**：同一元素的三个星座，行星在其中任一星座都有三分性尊贵。

**评分**：+3分

**重要**：三分性守护星顺序受日夜盘影响！

#### 三分性守护星表

| 元素 | 日盘三分性守护星 | 夜盘三分性守护星 |
|------|------------------|------------------|
| 火象（白羊/狮子/射手）| 太阳、木星、土星 | 木星、太阳、土星 |
| 土象（金牛/处女/摩羯）| 金星、月亮、火星 | 月亮、金星、火星 |
| 风象（双子/天秤/水瓶）| 土星、水星、木星 | 水星、土星、木星 |
| 水象（巨蟹/天蝎/双鱼）| 金星、火星、月亮 | 火星、金星、月亮 |

**判断规则**：
- 行星落在某元素星座 → 查该元素的三分性守护星
- 如果该行星是该元素的**第一**三分性守护星 → +3分
- 如果该行星是该元素的**第二/第三**三分性守护星 → 可累加但权重较低

---

### 1.5 面（Face）

**定义**：每个星座均分成三个十度的区间，各由一颗行星主管。

**评分**：+1分

**面分区表**：

| 度数 | 火象（白羊/狮子/射手）| 土象（金牛/处女/摩羯）| 风象（双子/天秤/水瓶）| 水象（巨蟹/天蝎/双鱼）|
|------|---------------------|---------------------|---------------------|---------------------|
| 0-10° | 火星 | 水星 | 木星 | 火星 |
| 10-20° | 太阳 | 金星 | 土星 | 木星 |
| 20-30° | 木星 | 月亮 | 水星 | 月亮 |

## 二、必然无力（Essential Debilities）

### 2.1 外来（Peregrine）

**定义**：行星所落位置完全没有具备任何必然尊贵。

**评分**：0分（中性，非负分）

**判断**：无入庙、无入旺、无三分性、无界、无面 = 外来

---

### 2.2 弱（Fall）

**定义**：行星落在自己入旺星座的正对面星座。

**评分**：-4分

**弱对照表**：

| 行星 | 弱星座 |
|------|--------|
| 太阳 | 天秤座（白羊对面）|
| 月亮 | 天蝎座（金牛对面）|
| 水星 | 双鱼座（处女对面）|
| 金星 | 处女座（双鱼对面）|
| 火星 | 巨蟹座（摩羯对面）|
| 木星 | 摩羯座（巨蟹对面）|
| 土星 | 白羊座（天秤对面）|

---

### 2.3 陷（Detriment）

**定义**：行星落在自己入庙星座的正对面星座。

**评分**：-5分

**陷对照表**：

| 行星 | 陷星座 |
|------|--------|
| 太阳 | 水瓶座（狮子对面）|
| 月亮 | 摩羯座（巨蟹对面）|
| 水星 | 射手座（双子对面）、双鱼座（处女对面）|
| 金星 | 天蝎座（金牛对面）、白羊座（天秤对面）|
| 火星 | 天秤座（白羊对面）、金牛座（天蝎对面）|
| 木星 | 双子座（射手对面）、处女座（双鱼对面）|
| 土星 | 巨蟹座（摩羯对面）、狮子座（水瓶对面）|

## 三、积分计算规则

### 3.1 基础评分表

| 级别 | 分值 |
|------|------|
| 入庙 | +5分 |
| 入旺 | +4分 |
| 三分性 | +3分 |
| 界 | +2分 |
| 面 | +1分 |
| 外来 | 0分 |
| 弱 | -4分 |
| 陷 | -5分 |

### 3.2 累加规则

```
┌─────────────────────────────────────────────────────────────┐
│                    积分累加规则                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【尊贵累加】                                                 │
│  ├─ 行星可同时拥有多种尊贵状态                                 │
│  └─ 例：行星同时有「入旺」+「界」+「面」= +4+2+1 = +7分        │
│                                                             │
│  【无力不累加】                                               │
│  ├─ 只取最严重的无力状态                                      │
│  ├─ 外来（0分）不与弱/陷累加                                  │
│  └─ 例：行星在陷的位置，不会再加上外来                         │
│                                                             │
│  【尊贵无力共存】                                             │
│  ├─ 可以既有尊贵又有无力                                      │
│  └─ 例：入旺+弱的位置，入旺有但实际在弱星座 → 按实际位置判断    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 力量等级划分

| 积分范围 | 力量等级 |
|----------|----------|
| ≥+5分 | 极强 |
| +3~+4分 | 强 |
| 0~+2分 | 中等 |
| -4~-1分 | 弱 |
| ≤-5分 | 极弱 |

## 四、判断步骤

```
Step 1: 获取行星所在星座和度数
Step 2: 判断入庙（查入庙对照表）
Step 3: 判断入旺（查入旺对照表）
Step 4: 判断三分性（查三分性表，需日夜盘信息）
Step 5: 判断界（查界分区表，需度数）
Step 6: 判断面（查面分区表，需度数）
Step 7: 若均无 → 外来
Step 8: 判断弱（查弱对照表）
Step 9: 判断陷（查陷对照表）
Step 10: 计算积分
Step 11: 确定力量等级
Step 12: 输出完整尊贵信息
```

## 六、注意事项

```
┌─────────────────────────────────────────────────────────────┐
│                    判断注意事项                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【使用古典守护关系】                                         │
│  ├─ 天蝎座守护星 = 火星（不是冥王星）                          │
│  ├─ 水瓶座守护星 = 土星（不是天王星）                          │
│  └─ 双鱼座守护星 = 木星（不是海王星）                          │
│                                                             │
│  【日夜盘影响三分性】                                         │
│  ├─ 三分性守护星顺序受日夜盘影响                              │
│  └─ 判断前需确认日夜盘类型                                    │
│                                                             │
│  【度数精确判断】                                             │
│  ├─ 界和面需要精确度数                                        │
│  └─ 擢升有特定度数，但一般只要在星座即可                       │
│                                                             │
│  【不解读含义】                                               │
│  └─ 仅计算尊贵状态，不解读好坏含义                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
