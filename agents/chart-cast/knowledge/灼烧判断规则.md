# 灼烧判断规则

> **用途**：chart-cast Agent判断行星与太阳的距离关系
> **调用时机**：Step 6 灼烧状态判断阶段
> **版本**：v1.0 | 2026-06-15

---

## 一、灼烧基本定义

### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                    灼烧定义                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【灼烧】行星与太阳在同一星座内的距离关系                       │
│                                                             │
│  【核心原则】                                                 │
│  ├─ 只有与太阳在同一星座的行星才判断灼烧                       │
│  ├─ 不同星座的行星不判断灼烧                                  │
│  └─ 灼烧影响行星能量表达                                      │
│                                                             │
│  【计算对象】                                                 │
│  ├─ 水星、金星、火星、木星、土星                              │
│  └─ 不计算月亮（月亮与太阳的关系另有判断）                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、灼烧三种状态

### 状态对照表

| 状态 | 距离范围 | 能量影响 | 含义 |
|------|----------|----------|------|
| **核心内（Cazimi）** | < 17分 | 格局提升 | 进入太阳宫殿，受保护并提升 |
| **焦伤（Combust）** | 17分 - 8°30' | 能量被遮蔽 | 伴君如伴虎，被权威压制 |
| **太阳光束下（Under Sunbeams）** | 8°30' - 17° | 部分受损 | 能量暧昧不明，部分被遮蔽 |
| **无灼烧** | > 17° 或 不同星座 | 无影响 | 能量正常表达 |

### 状态判断图示

```
        太阳
          ★
          │
    ──────┼────── 17分（核心内边界）
          │ ← Cazimi（核心内）
    ──────┼────── 8°30'（焦伤边界）
          │ ← Combust（焦伤）
    ──────┼────── 17°（光束下边界）
          │ ← Under Sunbeams（太阳光束下）
    ──────┼──────
          │ ← 无灼烧
```

## 三、判断步骤

### 计算流程

```
Step 1: 获取各行星所在星座
Step 2: 筛选与太阳同一星座的行星
Step 3: 计算各行星与太阳的距离（度数差）
Step 4: 根据距离判断灼烧状态：
  ├─ 距离 < 17分 → 核心内（Cazimi）
  ├─ 距离 17分 - 8°30' → 焦伤（Combust）
  ├─ 距离 8°30' - 17° → 太阳光束下
  └─ 距离 > 17° 或 不同星座 → 无灼烧
Step 5: 输出各行星灼烧状态
```

### 计算示例

```
示例1：
太阳：狮子座 15°20'
水星：狮子座 12°00'
距离：|15°20' - 12°00'| = 3°20'
判断：3°20' 在 17分 - 8°30' 范围内 → 焦伤

示例2：
太阳：狮子座 15°20'
金星：狮子座 15°10'
距离：|15°20' - 15°10'| = 10分
判断：10分 < 17分 → 核心内（Cazimi）

示例3：
太阳：狮子座 15°20'
火星：处女座 10°00'
判断：不同星座 → 无灼烧
```

## 四、灼烧对不同行星的影响（仅列举）

### 影响对照表

| 行星 | 焦伤影响 | 核心内效果 |
|------|----------|------------|
| **水星** | 思考受权威影响，表达受压制 | 思维敏锐，智慧提升 |
| **金星** | 感情受父/夫影响，人际关系受压制 | 魅力非凡，贵气提升 |
| **火星** | 行动受权威限制，斗志被压制 | 行动力强，领导力提升 |
| **木星** | 运气受权威影响，扩张受限 | 贵人运强，机遇提升 |
| **土星** | 压力加重，责任更重 | 反而有权威，地位提升 |

### 注意事项

```
┌─────────────────────────────────────────────────────────────┐
│                    影响说明                                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【仅列举，不解读】                                           │
│  ├─ 表中影响为通用参考                                        │
│  ├─ 具体解读由personality-analysis Agent负责                 │
│  └─ 不在本步骤进行命运判断                                    │
│                                                             │
│  【判断原则】                                                 │
│  ├─ 焦伤：格局受损，需看其他助力                              │
│  ├─ 太阳光束下：能量部分受损，影响较轻                        │
│  └─ 核心内：格局提升，获得太阳加持                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五、特殊情况处理

### 5.1 逆行行星灼烧

```
┌─────────────────────────────────────────────────────────────┐
│                    逆行行星灼烧                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【判断方法】                                                 │
│  ├─ 逆行不影响灼烧判断                                       │
│  └─ 仍然按距离判断灼烧状态                                    │
│                                                             │
│  【特殊情况】                                                 │
│  └─ 逆行行星可能与太阳距离变化趋势相反                        │
│     （从入相位变成出相位，或反之）                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 月亮与太阳的关系

```
┌─────────────────────────────────────────────────────────────┐
│                    月亮特殊处理                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【不判断灼烧】                                               │
│  └─ 月亮与太阳的关系另有专门判断（月相）                       │
│                                                             │
│  【月相判断】                                                 │
│  ├─ 新月：月亮与太阳合相                                     │
│  ├─ 上弦月：月亮与太阳刑克                                   │
│  ├─ 满月：月亮与太阳对冲                                     │
│  └─ 下弦月：月亮与太阳刑克                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────┐
│                    判断注意事项                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【计算范围】                                                 │
```
