# 飞星判断规则

> **用途**：chart-cast Agent计算宫主星、宫内星、飞星关系
> **调用时机**：Step 5 宫位信息计算
> **版本**：v2.0 | 2026-06-15

---

## 一、数据整合原则

```
┌─────────────────────────────────────────────────────────────┐
│                    数据整合原则                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【行星数据】直接包含                                         │
│  ├─ 该行星是几宫主（后天身份）                                │
│  └─ 如：金星 = 1宫主 + 8宫主                                  │
│                                                             │
│  【宫位数据】直接包含                                         │
│  ├─ 宫主星是谁                                               │
│  ├─ 宫主星落在哪里（飞星）                                    │
│  ├─ 宫内星有哪些                                             │
│  └─ 同主宫位组标注                                           │
│                                                             │
│  【避免重复】                                                 │
│  └─ 不单独输出飞星表，信息整合到行星和宫位数据中               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、行星数据中的飞星信息

每个行星数据中直接包含其**后天身份**：

```json
{
  "name": "金星",
  "sign": "天秤座",
  "degree": "15°30'",
  "house": 8,
  "dignity": {...},
  
  "house_ruler_of": [1, 8],  // 该行星是1宫主和8宫主
  "ruler_note": "一八同组"    // 同组标注（如有）
}
```

**判断步骤**：
```
Step 1: 获取行星守护的星座列表
  例：金星守护金牛座、天秤座

Step 2: 查找这些星座对应的宫头
  例：1宫头在天秤座、8宫头在金牛座

Step 3: 记录该行星是这些宫的宫主星
  → 金星 = 1宫主 + 8宫主

Step 4: 若守护多个宫位 → 标注同组
  → "一八同组"
```

## 三、宫位数据中的飞星信息

每个宫位数据中直接包含：

```json
{
  "house": 1,
  "cusp_sign": "天秤座",
  "cusp_degree": "15°30'",
  
  // 宫主星信息
  "ruler": "金星",
  "ruler_in_house": 8,      // 宫主星所在宫位（即"一飞八"）
  "ruler_status": "入庙",   // 宫主星尊贵状态
  
  // 同主宫位组
  "ruler_other_house": 8,   // 同守护星的另一宫
  "same_ruler_group": "一八同组",
  
  // 宫内星
  "planets_in_house": ["月亮"]
}
```

**计算步骤**：
```
Step 1: 宫头星座 → 古典守护星 → 宫主星
Step 2: 宫主星所在宫位 → 飞入宫位
Step 3: 查找同守护星的其他宫 → 同组
Step 4: 统计落入该宫的行星 → 宫内星
```

## 六、常见同组模式含义

| 同组类型 | 特征倾向 |
|----------|----------|
| 一八同组 | 重视钱财、自带偏财属性、一宫问题影响八宫 |
| 一四同组 | 顾家、孝顺、与父母关系好、家庭影响自我 |
| 一十二同组 | 对玄学天生感兴趣、自我与隐秘相关 |
| 二七同组 | 财务与伴侣相关、金钱影响关系 |
| 五十同组 | 子女与事业相关、恋爱影响事业 |
| 三九同组 | 学习与远行相关、沟通影响眼界 |

## 七、注意事项

```
【使用古典守护关系】
├─ 天蝎座 → 火星（不是冥王星）
├─ 水瓶座 → 土星（不是天王星）
└─ 双鱼座 → 木星（不是海王星）

【数据整合原则】
├─ 行星数据中直接标注是几宫主
├─ 宫位数据中直接包含宫主星和飞入宫位
└─ 不单独输出飞星表，避免数据分散

【不解读含义】
└─ 仅计算飞星关系，不解读好坏含义
```
