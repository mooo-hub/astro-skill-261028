# 排盘工具使用规范

> **用途**：chart-cast Agent调用astro-chart skill的规范
> **版本**：v1.0 | 2026-05-28

---

## 一、工具调用

### 依赖检查

```bash
# Step 1: 确认Swiss Ephemeris库可用
python -c "import swisseph as swe; print('Swiss Ephemeris版本:', swe.version)"

# Step 2: 如果库不可用，执行安装
pip install pyswisseph
# 国内镜像加速
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pyswisseph
```

### 排盘命令

```bash
# 基本格式
python .claude/skills/classical-astro-natal/astro-chart/astro_calc.py 年 月 日 时 分 经度 纬度 时区 [分宫制]

# 参数说明
# 年：四位年份，如1997
# 月：1-12
# 日：1-31
# 时：0-23（24小时制）
# 分：0-59
# 经度：东经为正，如118.5
# 纬度：北纬为正，如37.4
# 时区：东八区为8
# 分宫制（可选）：alcabitius（默认）、whole、placidus
```

### 古典占星参数

```bash
# 古典占星排盘（默认参数即为古典模式）
python .claude/skills/classical-astro-natal/astro-chart/astro_calc.py 1997 2 18 13 34 118.5 37.4 8

# 明确指定阿卡比特制
python .claude/skills/classical-astro-natal/astro-chart/astro_calc.py 1997 2 18 13 34 118.5 37.4 8 alcabitius

# 整宫制（辅助参考）
python .claude/skills/classical-astro-natal/astro-chart/astro_calc.py 1997 2 18 13 34 118.5 37.4 8 whole
```

## 二、输出解读

### 排盘输出包含

1. **四轴配置**：上升ASC、中天MC、下降DSC、天底IC
2. **十大行星配置**：星座、宫位、度数、庙旺落陷、逆行状态
3. **十二宫位配置**：根据指定分宫制
4. **元素与性质分布统计**
5. **主要相位列表**
6. **原始数据JSON**

### 日夜盘判断

```
日盘：太阳在7-12宫（地平线以上）
夜盘：太阳在1-6宫（地平线以下）
```

---

## 三、精度说明

Swiss Ephemeris比估算更精确，可能发现重大修正：
- 上升星座可能完全改变（如射手→巨蟹）
- 月亮宫位可能不同
- 火星逆行状态更准确
- 精确相位（容许度1°以内）更可靠
