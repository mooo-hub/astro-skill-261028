## 一、相位基本定义

### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                    相位定义                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【相位】= 行星之间的角度关系，代表能量流动                     │
│                                                             │
│  【核心原则】                                                 │

│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、托勒密五大相位

### 相位对照表

| 相位 | 角度 | 性质 | 容许度 | 能量特征 |
|------|------|------|--------|----------|
| **合相** | 0° | 中性 | ±8° | 能量融合、合一 |
| **六合** | 60° | 吉 | ±6° | 机会、协调、温和助力 |
| **三合** | 120° | 大吉 | ±8° | 和谐、天赋、顺畅流动 |
| **刑克** | 90° | 凶 | ±8° | 压力、挑战、内在紧张 |
| **对冲** | 180° | 大凶 | ±8° | 对立、冲突、外在张力 |

### 相位计算公式

```
相位角度 = |行星A黄经 - 行星B黄经|

判断规则：
├─ 角度 ≈ 0° ±容许度 → 合相
├─ 角度 ≈ 60° ±容许度 → 六合
├─ 角度 ≈ 90° ±容许度 → 刑克
├─ 角度 ≈ 120° ±容许度 → 三合
└─ 角度 ≈ 180° ±容许度 → 对冲
```

## 三、容许度系统

### 3.1 传统统一容许度

| 相位 | 容许度 |
|------|--------|
| 合相 | ±8° |
| 六合 | ±6° |
| 三合 | ±8° |
| 刑克 | ±8° |
| 对冲 | ±8° |

### 3.2 行星容许度（William Lilly体系）

| 行星 | 容许度半径 |
|------|-----------|
| 太阳 | ±10° |
| 月亮 | ±10° |
| 木星 | ±9° |
| 土星 | ±9° |
| 水星 | ±7° |
| 金星 | ±7° |
| 火星 | ±7° |

### 3.3 双行星容许度计算

**公式**：两颗行星的容许度 = A行星半径 + B行星半径

**示例**：
```
太阳-月亮合相容许度 = 10° + 10° = 20°
火星-水星刑克容许度 = 7° + 7° = 14°
木星-土星三合容许度 = 9° + 9° = 18°
```

## 四、入相位与出相位

### 4.1 定义

| 类型 | 定义 | 含义 |
|------|------|------|
| **入相位** | 快速行星接近慢速行星 | 代表**未来**将要发生的事件 |
| **出相位** | 快速行星远离慢速行星 | 代表**过去**已发生的事件 |

### 4.2 行星速度排序（由快到慢）

```
月亮 > 水星 > 金星 > 太阳 > 火星 > 木星 > 土星

快速行星判定：
├─ 月亮：最快，总是作为快速行星
├─ 水星、金星：较快，对太阳以外行星为快速
├─ 太阳：中等速度
├─ 火星：较慢，对外行星为快速
└─ 木星、土星：最慢，总是作为慢速行星
```

### 4.3 入/出相位判断步骤

```
Step 1: 确定两颗行星的速度快慢
Step 2: 比较两者黄经距离变化趋势
  ├─ 快速行星黄经 < 慢速行星黄经 → 入相位
  └─ 快速行星黄经 > 慢速行星黄经 → 出相位
Step 3: 计算精确度数（距离精确相位的角度）
Step 4: 标注入相位/出相位状态
```

### 4.4 入/出相位重要性

```
┌─────────────────────────────────────────────────────────────┐
│                    入/出相位权重                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【核心原则】                                                 │
│  └─ 入相位比出相位更重要                                      │
│                                                             │
│  【原因】                                                     │
│  ├─ 入相位：事件正在形成，能量在聚集                          │
│  ├─ 出相位：事件已经结束，能量在消散                          │
│  └─ 卜卦占星中，出相位通常表示"已经发生过"                    │
│                                                             │
│  【判断优先级】                                               │
│  ├─ 入相位精确度数小 → 更重要                                 │
│  ├─ 出相位精确度数大 → 可忽略                                 │
│  └─ 精确相位（度数差<1°）→ 能量最强                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五、空相位

### 定义

**空相位**：行星无任何主要相位（托勒密相位）

### 特征

| 正面含义 | 负面含义 |
|----------|----------|
| 独立自主 | 难以连接他人 |
| 不受干扰 | 孤立无援 |
| 特立独行 | 能量难以表达 |

## 七、相位格局判断

### 7.1 主要相位格局

| 格局 | 构成 | 特征 |
|------|------|------|
| **大三角** | 三颗行星互成三合（120°） | 和谐、天赋、能量循环 |
| **T型三角** | 两颗行星对冲 + 第三颗与两者均刑克 | 内在张力，顶点行星为焦点 |
| **大十字** | 四颗行星形成两对对冲 + 四个刑克 | 四方受压，极度挑战 |
| **风筝型** | 大三角 + 一颗行星与其中一颗对冲 | 大三角有了方向和出口 |
| **神秘矩形** | 两对对冲 + 两对六合 + 两对三合 | 对立中有和谐 |
| **上帝之指** | 两颗行星六合 + 第三颗与两者均成150° | 特殊使命，顶点指向命运 |

### 7.2 格局判断步骤

```
Step 1: 遍历所有相位组合
Step 2: 识别三合组（大三角基础）
Step 3: 识别对冲+刑克组（T型三角、大十字基础）
Step 4: 判断格局类型
Step 5: 标注格局的焦点行星和能量流向
```

## 八、后天身份标注

### 8.1 定义

```
┌─────────────────────────────────────────────────────────────┐
│                    后天身份标注                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 后天身份 = 该行星是几宫的宫主星                            │
│                                                             │
│  【标注原则】                                                 │
│  ├─ 每个相位中的两颗行星都需要标注后天身份                     │
│  ├─ 如果行星守护多个宫位，列出所有宫位                         │
│  └─ 例：金星守护1宫和8宫 → house_ruler = [1, 8]             │
│                                                             │
│  【作用】                                                     │
│  ├─ 相位不只是两颗行星的关系                                  │
│  ├─ 还代表两个宫位领域的能量流动                              │
│  └─ 例：金星(1,8宫主)刑克火星(2,7宫主)                        │
│       → 代表自我财务(1/8)与伴侣财务(2/7)的张力                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 8.2 后天身份获取

```
Step 1: 从行星数据中获取 house_ruler_of 字段
  例：金星.house_ruler_of = [1, 8]

Step 2: 标注到相位数据中
  ├─ planet_a_house_ruler = [1, 8]
  └─ planet_b_house_ruler = [2, 7]

Step 3: 计算相位紧密程度等级
  ├─ 精确(<1°)：极紧密
  ├─ 1-3°：紧密
  ├─ 3-5°：较紧密
  └─ >5°：普通
```

## 十、注意事项

```
┌─────────────────────────────────────────────────────────────┐
│                    计算注意事项                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【计算范围】                                                 │
│  ├─ 只计算七大行星间相位                                      │
│  └─ 不计算三王星、南北交点相位                                │
│                                                             │
│  【容许度选择】                                               │
│  ├─ 推荐使用行星容许度体系                                    │
│  └─ 必须标注使用的容许度体系                                  │
│                                                             │
│  【入/出相位】                                                │
│  ├─ 必须判断入相位/出相位                                     │
│  ├─ 入相位权重高于出相位                                      │
│  └─ 精确相位（度数差<1°）需特别标注                           │
│                                                             │
│  【后天身份标注】                                             │
│  ├─ 每个相位必须标注两颗行星的后天身份                        │
│  ├─ 后天身份来自行星数据的 house_ruler_of 字段               │
│  └─ 用于分析宫位领域的能量流动                               │
│                                                             │
│  【不解读含义】                                               │
│  ├─ 仅计算相位关系，不解读含义                                │
│  └─ 相位含义解读由personality-analysis Agent负责             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
