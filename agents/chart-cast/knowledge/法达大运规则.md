## 一、法达大运基本定义

### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                    法达大运定义                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【法达大运（Firdaria）】                                     │
│  ├─ 定义：古典占星的时间周期系统                              │
│  ├─ 将人生划分为七大行星+南北交点的周期                       │
│  └─ 每个行星掌管一段人生时期                                  │
│                                                             │
│  【核心原则】                                                 │
│  ├─ 日夜盘决定起始星                                         │
│  ├─ 每颗行星有固定的大运年数                                  │
│  ├─ 大运内分多个子运                                         │
│  └─ 南北交点在最后                                           │
│                                                             │
│  【与三分性的关系】                                           │
│  └─ 日盘从太阳的三分主星开始，夜盘从月亮的三分主星开始          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、大运周期表

### 2.1 各行星大运年数

| 行星 | 大运年数 | 性质 |
|------|----------|------|
| **太阳** | 10年 | 吉，代表自我、父亲、权威 |
| **月亮** | 9年 | 吉，代表母亲、情绪、家庭 |
| **土星** | 11年 | 凶，代表责任、限制、成熟 |
| **木星** | 12年 | 吉，代表扩张、幸运、智慧 |
| **火星** | 7年 | 凶，代表行动、冲突、挑战 |
| **金星** | 8年 | 吉，代表爱情、财富、享受 |
| **水星** | 13年 | 中性，代表学习、沟通、商业 |
| **北交点** | 3年 | 吉，代表业力、命运提升 |
| **南交点** | 2年 | 凶，代表业障、阻碍 |

**总计**：75年完整周期

### 2.2 日盘大运顺序

```
日盘（太阳在7-12宫）：

太阳(10年) → 金星(8年) → 水星(13年) → 月亮(9年) → 土星(11年) → 木星(12年) → 火星(7年) → 北交(3年) → 南交(2年)

年龄分配：
├─ 0-10岁：太阳大运
├─ 10-18岁：金星大运
├─ 18-31岁：水星大运
├─ 31-40岁：月亮大运
├─ 40-51岁：土星大运
├─ 51-63岁：木星大运
├─ 63-70岁：火星大运
├─ 70-73岁：北交大运
└─ 73-75岁：南交大运
```

### 2.3 夜盘大运顺序

```
夜盘（太阳在1-6宫）：

月亮(9年) → 土星(11年) → 木星(12年) → 火星(7年) → 太阳(10年) → 金星(8年) → 水星(13年) → 北交(3年) → 南交(2年)

年龄分配：
├─ 0-9岁：月亮大运
├─ 9-20岁：土星大运
├─ 20-32岁：木星大运
├─ 32-39岁：火星大运
├─ 39-49岁：太阳大运
├─ 49-57岁：金星大运
├─ 57-70岁：水星大运
├─ 70-73岁：北交大运
└─ 73-75岁：南交大运
```

## 三、子运分配规则

### 3.1 子运定义

```
┌─────────────────────────────────────────────────────────────┐
│                    子运定义                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【子运】                                                     │
│  ├─ 每个大运内部分为多个子运                                  │
│  ├─ 子运顺序与大运顺序相同                                    │
│  ├─ 子运年数 = 大运年数 × 该行星子运比例                     │
│  └─ 第一个子运由大运主星掌管                                  │
│                                                             │
│  【子运计算公式】                                             │
│  子运年数 = 大运年数 × 子运行星年数 / 75                     │
│                                                             │
│  【示例】                                                     │
│  太阳大运(10年)的月亮子运 = 10 × 9 / 75 = 1.2年             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 子运年数比例

```
子运年数比例（总75年）：

太阳：10/75 = 0.133
月亮：9/75 = 0.120
土星：11/75 = 0.147
木星：12/75 = 0.160
火星：7/75 = 0.093
金星：8/75 = 0.107
水星：13/75 = 0.173
北交：3/75 = 0.040
南交：2/75 = 0.027
```

## 四、当前大运计算步骤

```
Step 1: 确定日夜盘类型
  └─ 太阳在7-12宫→日盘，太阳在1-6宫→夜盘

Step 2: 确定大运顺序
  ├─ 日盘：太阳→金星→水星→月亮→土星→木星→火星→北交→南交
  └─ 夜盘：月亮→土星→木星→火星→太阳→金星→水星→北交→南交

Step 3: 根据年龄计算当前大运
  例：32岁，日盘
  ├─ 太阳(0-10) → 金星(10-18) → 水星(18-31) → 月亮(31-40)
  └─ 当前大运：月亮大运

Step 4: 计算大运内已过年数
  └─ 32 - 31 = 1年（月亮大运第1年）

Step 5: 计算当前子运
  月亮大运(9年)子运：
  ├─ 月亮子运：9 × 0.120 = 1.08年
  ├─ 1年 < 1.08年
  └─ 当前子运：月亮子运

Step 6: 输出结果
  ├─ 当前大运：月亮大运
  ├─ 当前子运：月亮子运
  └─ 大运剩余：8年
```

## 五、小限年运

### 5.1 定义

```
┌─────────────────────────────────────────────────────────────┐
│                    小限年运                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【小限】                                                     │
│  ├─ 每年对应一个宫位                                         │
│  ├─ 从上升点（1宫）开始                                      │
│  └─ 每年推进一宫                                             │
│                                                             │
│  【计算公式】                                                 │
│  小限宫位 = 年龄 ÷ 12 余数                                   │
│  ├─ 余数0 = 12宫                                            │
│  └─ 余数1-11 = 对应宫位                                     │
│                                                             │
│  【年运主题】                                                 │
│  └─ 该宫位代表的生活领域                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 七、注意事项

```
┌─────────────────────────────────────────────────────────────┐
│                    计算注意事项                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【日夜盘判断】                                               │
│  ├─ 日夜盘决定大运起始星                                     │
│  ├─ 必须先判断日夜盘再计算大运                               │
│  └─ 日夜盘影响整个大运顺序                                   │
│                                                             │
│  【年龄计算】                                                 │
│  ├─ 年龄 = 当前年份 - 出生年份                               │
│  ├─ 需考虑是否已过生日                                       │
│  └─ 精确到月份更准确                                         │
│                                                             │
│  【子运精度】                                                 │
│  ├─ 子运年数通常为小数                                       │
│  ├─ 实际判断时四舍五入到月                                   │
│  └─ 不需要精确到日                                           │
│                                                             │
│  【南北交大运】                                               │
│  ├─ 只在晚年出现（70岁后）                                   │
│  ├─ 北交大运较为吉利                                         │
│  └─ 南交大运需注意阻碍                                       │
│                                                             │
│  【不解读含义】                                               │
│  ├─ 仅计算大运周期，不解读含义                               │
│  └─ 含义解读由运势分析Agent负责                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
