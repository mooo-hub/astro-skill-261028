> **用途**：chart-cast Agent判断夹星与围攻现象
> **调用时机**：Step 10 夹星与围攻判断阶段
> **版本**：v1.0 | 2026-06-15

## 一、夹星基本定义

### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                    夹星定义                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【夹星（Sandwich）】                                         │
│  ├─ 定义：三颗行星在同一星座，中间行星被两边行星"夹住"         │
│  ├─ 效果：中间行星被两边行星的能量影响                        │
│  └─ 比喻：中间行星被困在两颗行星的能量场中                     │
│                                                             │
│  【核心原则】                                                 │
│  ├─ 三颗行星必须在同一星座                                    │
│  ├─ 中间行星被两边行星"夹住"                                  │
│  └─ 两边行星的能量性质决定夹星效果                            │
│                                                             │
│  【计算对象】                                                 │
│  ├─ 七大行星：太阳、月亮、水星、金星、火星、木星、土星         │
│  └─ 不计算三王星夹星                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、夹星类型

### 2.1 先天层面（按行星吉凶）

| 夹星类型 | 两边行星 | 效果 |
|----------|----------|------|
| **日月夹** | 太阳 + 月亮 | 最吉，光芒照耀，自我与情绪调和 |
| **金木夹** | 金星 + 木星 | 大吉，幸运加持，财富与爱情顺利 |
| **火土夹** | 火星 + 土星 | 大凶，压力重重，行动受阻 |
| **吉星夹** | 金/木 + 日/月/金/木 | 吉，能量加持 |
| **凶星夹** | 火/土 + 火/土 | 凶，压力增强 |
| **吉凶混合夹** | 吉星 + 凶星 | 中性，需具体分析 |

### 2.2 后天层面（按宫主身份）

```
┌─────────────────────────────────────────────────────────────┐
│                    后天夹星层面                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 两边行星的后天身份（宫主星）影响中间行星                   │
│                                                             │
│  【判断步骤】                                                 │
│  Step 1: 获取两边行星的后天身份                              │
│    例：左边行星 = 金星 = 1宫主 + 8宫主                        │
│    例：右边行星 = 火星 = 2宫主 + 7宫主                        │
│                                                             │
│  Step 2: 分析宫位领域夹持                                    │
│    ├─ 中间行星被"1宫/8宫"和"2宫/7宫"领域夹持                 │
│    └─ 代表自我财务、伴侣财务对中间行星的影响                  │
│                                                             │
│  Step 3: 标注宫位联动关系                                    │
│    └─ house_ruler_link = "一八同组-二七同组"                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 三、夹星判断步骤

```
Step 1: 遍历所有同星座的行星组
Step 2: 筛选出≥3颗行星的同星座组
Step 3: 对每组：
  ├─ 按度数排序（从小到大）
  ├─ 中间行星 = 被夹行星
  └─ 两边行星 = 夹持行星
Step 4: 判断先天层面：
  ├─ 确定两边行星的吉凶性质
  └─ 标注夹星类型（日月夹/金木夹/火土夹等）
Step 5: 判断后天层面：
  ├─ 获取两边行星的 house_ruler_of
  └─ 标注宫位领域夹持
Step 6: 检查得救条件：
  └─ 中间行星是否被吉星接纳
Step 7: 输出夹星信息
```

## 四、夹宫头与劫夺夹

### 4.1 夹宫头

```
┌─────────────────────────────────────────────────────────────┐
│                    夹宫头                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 两颗行星分布在某宫头的两侧，夹住该宫头                     │
│                                                             │
│  【判断条件】                                                 │
│  ├─ 两颗行星在同一星座或相邻星座                              │
│  ├─ 宫头落在两颗行星之间                                     │
│  └─ 两颗行星夹住该宫头                                       │
│                                                             │
│  【效果】                                                     │
│  └─ 该宫位事务受到两颗行星影响                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 劫夺夹

```
┌─────────────────────────────────────────────────────────────┐
│                    劫夺夹                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 不等宫制下，某星座被完整劫夺于某一宫内                     │
│  │   该星座两端的宫头在同一星座                               │
│                                                             │
│  【判断条件】                                                 │
│  ├─ 阿卡比特制下，某两宫头落在同一星座                        │
│  ├─ 该星座被劫夺于两宫头之间                                 │
│  └─ 行星落在该劫夺星座内                                     │
│                                                             │
│  【效果】                                                     │
│  ├─ 被劫夺星座的守护星能量受限                                │
│  └─ 该宫位事务与劫夺星座相关                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五、光线围攻

### 5.1 定义

```
┌─────────────────────────────────────────────────────────────┐
│                    光线围攻                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 土星和火星形成合相，对介于两者之间的行星形成围攻           │
│                                                             │
│  【核心条件】                                                 │
│  ├─ 土星和火星形成合相（容许度内）                           │
│  ├─ 被围攻行星介于土星和火星之间                             │
│  └─ 土星和火星是两大凶星                                    │
│                                                             │
│  【效果】                                                     │
│  ├─ 极凶，被围攻行星受到极大压力                             │
│  └─ 代表该行星所掌管的事务受困                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 判断步骤

```
Step 1: 检查土星和火星是否形成合相
Step 2: 如果形成合相，检查两者之间的行星
Step 3: 如果有行星介于土星和火星之间：
  ├─ 标注该行星被光线围攻
  ├─ 标注围攻类型：土火围攻
  └─ 标注后天层面：土星和火星分别是几宫主
Step 4: 检查得救条件：
  └─ 被围攻行星是否被吉星接纳
Step 5: 输出围攻信息
```

## 六、得救条件判断

### 6.1 定义

```
┌─────────────────────────────────────────────────────────────┐
│                    得救条件                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 被夹/被围攻的行星通过接纳关系获得支持，减轻压力           │
│                                                             │
│  【得救条件】                                                 │
│  ├─ 条件1：被夹行星被吉星接纳                                │
│  ├─ 条件2：被夹行星本身有先天尊贵                            │
│  └─ 条件3：被夹行星与吉星形成和谐相位                        │
│                                                             │
│  【判断步骤】                                                 │
│  Step 1: 检查被夹行星是否被任何行星接纳                      │
│  Step 2: 如果被接纳，检查接纳方的吉凶性质                    │
│  Step 3: 如果被吉星接纳 → 标注"得救"                        │
│  Step 4: 如果被凶星接纳 → 标注"部分得救"                    │
│  Step 5: 如果无接纳 → 标注"无得救"                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 八、注意事项

```
┌─────────────────────────────────────────────────────────────┐
│                    判断注意事项                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【计算范围】                                                 │
│  ├─ 只计算七大行星的夹星                                      │
│  └─ 不计算三王星夹星                                         │
│                                                             │
│  【同星座判断】                                               │
│  ├─ 夹星要求三颗行星在同一星座                                │
│  └─ 不同星座不算夹星                                         │
│                                                             │
│  【先后天层面】                                               │
│  ├─ 先天层面：按行星本身吉凶判断                              │
│  ├─ 后天层面：按宫主星身份判断                               │
│  └─ 两个层面都需要标注                                       │
│                                                             │
│  【得救判断】                                                 │
│  ├─ 需检查被夹行星是否被接纳                                 │
│  ├─ 接纳方为吉星才算得救                                     │
│  └─ 需标注接纳方的后天身份                                   │
│                                                             │
│  【不解读含义】                                               │
│  ├─ 仅判断夹星关系，不解读含义                                │
│  └─ 含义解读由personality-analysis Agent负责                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
