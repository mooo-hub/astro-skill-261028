# 特殊点计算规则

> **用途**：chart-cast Agent排盘时计算阿拉伯点和南北交点
> **调用时机**：排盘计算时标注特殊点
> **版本**：v2.0 | 2026-06-15

---

## 一、福点（最重要）

### 计算公式

| 类型 | 公式 |
|------|------|
| **日盘** | 福点 = ASC + 月亮 - 太阳 |
| **夜盘** | 福点 = ASC + 太阳 - 月亮 |

### 计算步骤

```
Step 1: 判断日夜盘类型
Step 2: 获取ASC、太阳、月亮的黄经度数
Step 3: 应用对应公式计算
Step 4: 结果取模360°，转换为星座度数
```

### 福点位置含义

| 福点宫位 | 幸运领域 |
|----------|----------|
| 1宫 | 个人魅力、自我表现 |
| 2宫 | 财富积累、物质资源 |
| 5宫 | 子女、恋爱、投资 |
| 7宫 | 婚姻、合作 |
| 10宫 | 事业成就、社会地位 |

## 三、南北交点

### 定义

| 交点 | 定义 | 性质 |
|------|------|------|
| **北交点** | 月亮由南向北与黄道交会点 | 吉，前世业果、好运 |
| **南交点** | 月亮由北向南与黄道交会点 | 凶，前世业障、阻碍 |

### 与行星合相影响

| 组合 | 影响 |
|------|------|
| 北交点 + 吉星 | 吉上加吉，好运增强 |
| 北交点 + 凶星 | 凶性减弱，阻碍缓解 |
| 南交点 + 吉星 | 吉性减弱，好运受阻 |
| 南交点 + 凶星 | 凶上加凶，阻碍加剧 |

### 法达大运中的南北交点

| 类型 | 大运顺序 |
|------|----------|
| 日盘 | ...→火星→北交(3年)→南交(2年) |
| 夜盘 | ...→火星→北交(3年)→南交(2年) |
