## 三、喜乐宫判断

### 3.1 定义

行星依属性有其喜好的宫位，在喜乐宫能更好地发挥能量。

### 3.2 喜乐宫对照表

| 行星 | 喜乐宫 | 原因 |
|------|--------|------|
| 水星 | 1宫 | 沟通表达，与自我认知相关 |
| 月亮 | 3宫 | 情绪感知，与日常联系相关 |
| 金星 | 5宫 | 爱与美，与恋爱享乐相关 |
| 火星 | 6宫 | 行动力，与工作劳动相关 |
| 太阳 | 9宫 | 生命力，与远见探索相关 |
| 木星 | 11宫 | 扩张，与群体愿望相关 |
| 土星 | 12宫 | 压制限制，与隐秘精神相关 |

### 3.3 判断步骤

```
Step 1: 获取行星所在宫位
Step 2: 查询该行星的喜乐宫
Step 3: 比较是否匹配
Step 4: 输出：joy_house = true/false
```

## 四、得时失时判断

### 4.1 定义

| 类型 | 定义 |
|------|------|
| **得时** | 行星在符合其性质的条件下，能量增强 |
| **失时** | 行星在不符合其性质的条件下，能量减弱 |

### 4.2 昼星与夜星

| 类型 | 行星 |
|------|------|
| **昼星** | 太阳、木星、土星 |
| **夜星** | 月亮、金星、火星 |
| **中性** | 水星 |

### 4.3 得时判断标准

| 日盘条件 | 夜盘条件 |
|----------|----------|
| 昼星在地平线上（7-12宫）| 夜星在地平线上（7-12宫）|
| 且昼星在阳性星座 | 且夜星在阳性星座 |

**阳性星座**：白羊、双子、狮子、天秤、射手、水瓶
**阴性星座**：金牛、巨蟹、处女、天蝎、摩羯、双鱼

### 4.4 判断步骤

```
Step 1: 确定行星是昼星还是夜星
Step 2: 确定日夜盘类型
Step 3: 确定行星在地平线上还是下
Step 4: 确定行星在阳性还是阴性星座
Step 5: 判断得时/失时：
  ├─ 日盘 + 昼星 + 地平线上 + 阳性星座 → 得时
  ├─ 夜盘 + 夜星 + 地平线上 + 阴性星座 → 得时
  └─ 其他组合 → 失时或中性
Step 6: 输出：sect = "得时"/"失时"/"中性"
```

## 五、输出格式

```json

  "house": 1,
  "house_type": "始宫",
  "fortune_type": "吉宫",
  "energy_level": "★★★★★"
}
```

```json
  "joy_house": true,
```

## 六、整合到宫位/行星数据

**原则**：落宫类型信息直接整合到宫位和行星数据中，不单独输出。

### 宫位数据中包含

```json
{
  "house": 1,
  "cusp_sign": "天秤座",
  "cusp_degree": "15°30'",
  "ruler": "金星",
  "ruler_in_house": 8,
  "ruler_status": "入庙",
  "ruler_other_house": 8,
  "same_ruler_group": "一八同组",
  "planets_in_house": ["月亮"],
  
  // 落宫类型信息
  "house_type": "始宫",
  "fortune_type": "吉宫",
  "energy_level": "★★★★★"
}
```

### 行星数据中包含

```json
{
  "name": "金星",
  "sign": "天秤座",
  "degree": "15°30'",
  "house": 5,
  "dignity": {...},
  "house_ruler_of": [1, 8],
  
  // 落宫类型信息
  "house_type": "续宫",
  "fortune_type": "次吉",
```
