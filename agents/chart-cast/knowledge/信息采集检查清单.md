# 信息采集检查清单

> **用途**：验证用户提供的出生信息完整性
> **调用时机**：Step 1 信息采集阶段
> **版本**：v1.0 | 2026-06-15

---

## 一、必填项清单

| 项目 | 必填性 | 说明 |
|------|--------|------|
| 出生年份 | ✅ 必填 | 四位年份，如1997 |
| 出生月份 | ✅ 必填 | 1-12 |
| 出生日期 | ✅ 必填 | 1-31 |
| 出生时辰 | ✅ 必填 | 0-23（24小时制）|
| 出生分钟 | ⚠️ 尽量填 | 0-59，缺失需标注不确定性 |
| 出生地点 | ✅ 必填 | 城市名，用于查经纬度 |
| 性别 | ✅ 必填 | 男/女，影响六亲取用 |

## 二、验证规则

### 时间验证

```
┌─────────────────────────────────────────────────────────────┐
│                    时间验证规则                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【年份范围】                                                │
│  ├─ 有效范围：1900-2100                                      │
│  └─ 异常处理：超出范围需询问确认                              │
│                                                             │
│  【月份范围】                                                │
│  ├─ 有效范围：1-12                                          │
│  └─ 异常处理：超出范围需询问                                  │
│                                                             │
│  【日期范围】                                                │
│  ├─ 有效范围：根据月份判断（1-28/29/30/31）                   │
│  └─ 闰年判断：2月29日需检查年份是否闰年                        │
│                                                             │
│  【时辰范围】                                                │
│  ├─ 有效范围：0-23                                          │
│  └─ 格式：24小时制，不接受"上午/下午"表述                     │
│                                                             │
│  【分钟缺失】                                                │
│  ├─ 处理方式：可使用00作为默认值                             │
│  ├─ 标注：必须标注"分钟缺失，使用默认值"                       │
│  └─ 影响：上升星座可能有偏差                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 地点验证

```
┌─────────────────────────────────────────────────────────────┐
│                    地点验证规则                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【城市在中国】                                              │
│  ├─ 查表：调用 城市经纬度表.md                               │
│  ├─ 时区：统一使用+8                                         │
│  └─ 经纬度：从表中获取                                       │
│                                                             │
│  【城市不在表中】                                            │
│  ├─ 处理方式：询问具体城市名或经纬度                          │
│  ├─ 替代方案：使用省会城市数据作为近似                        │
│  └─ 标注：必须标注"经纬度近似，可能影响准确性"                 │
│                                                             │
│  【国外出生】                                                │
│  ├─ 处理方式：询问具体城市名和时区                           │
│  ├─ 经纬度：需用户提供或网络查询                             │
│  └─ 时区：需明确确认，不能假设                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 性别验证

```
┌─────────────────────────────────────────────────────────────┐
│                    性别验证规则                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【必填原因】                                                │
│  ├─ 六亲取用：父母征象星选择依赖性别                         │
│  ├─ 日夜盘：日盘女性月亮代表母亲，夜盘反之                     │
│  └─ 配偶判断：男命七宫为妻，女命七宫为夫                       │
│                                                             │
│  【处理方式】                                                │
│  ├─ 性别未确认 → 必须询问后才能继续                          │
│  ├─ 不接受模糊表述（如"可能是男"）                            │
│  └─ 有效值：男/女                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 三、数据缺失处理矩阵

| 缺失项 | 严重程度 | 处理方式 | 标注要求 |
|--------|----------|----------|----------|
| 年份 | 🔴 阻塞 | 必须询问 | 无 |
| 月份 | 🔴 阻塞 | 必须询问 | 无 |
| 日期 | 🔴 阻塞 | 必须询问 | 无 |
| 时辰 | 🔴 阻塞 | 必须询问 | 无 |
| 分钟 | 🟡 警告 | 默认00 | 必须标注"分钟缺失" |
| 地点 | 🔴 阻塞 | 必须询问 | 无 |
| 经纬度近似 | 🟡 警告 | 使用省会 | 必须标注"经纬度近似" |
| 性别 | 🔴 阻塞 | 必须询问 | 无 |
| 时区不确定 | 🟡 警告 | 默认+8 | 必须标注"时区假设" |

## 五、常见问题处理

### 用户表述模糊

| 用户表述 | 问题 | 处理方式 |
|----------|------|----------|
| "上午出生" | 时辰不精确 | 询问具体几点（如"上午10点左右"→询问"能否确认具体时间？"）|
| "农历生日" | 需转换公历 | 询问公历生日或帮助转换 |
| "大概是冬天" | 无具体日期 | 必须询问具体日期 |
| "山东出生" | 城市不具体 | 询问具体城市 |
| "小时候出生" | 无年份 | 必须询问具体年份 |

### 时区问题

| 情况 | 处理方式 |
|------|----------|
| 中国出生 | 统一使用+8 |
| 港澳台出生 | 统一使用+8 |
| 东南亚出生 | 需确认具体时区 |
| 美国出生 | 需确认州和时区（美国有多个时区）|
