## 一、接纳互容基本定义

### 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                    接纳定义                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【接纳（Reception）】                                        │
│  ├─ 定义：行星A落在行星B所守护的星座                          │
│  │         且行星A与行星B形成托勒密相位                       │
│  ├─ 效果：行星B"接纳"行星A，减轻凶相凶性                      │
│  └─ 比喻：行星A拜访行星B的"家"，行星B接待行星A                │
│                                                             │
│  【核心原则】                                                 │
│  ├─ 必须形成托勒密相位（合相、六合、三合、刑克、对冲）        │
│  ├─ 无相位则无接纳                                          │
│  └─ 即使凶相位，接纳也能减轻凶性                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    互容定义                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【互容（Mutual Reception）】                                 │
│  ├─ 定义：两颗行星各自落在对方守护的星座                      │
│  │         （或庙旺星座）                                    │
│  ├─ 效果：双方力量提升，形成宫位间双向联动                    │
│  └─ 比喻：两颗行星互相"串门"，相互支持                        │
│                                                             │
│  【核心原则】                                                 │
│  ├─ 不要求形成相位                                          │
│  ├─ 互容本身就是一种特殊关系                                 │
│  └─ 可使原本失势/落陷的行星状态改善                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 三、接纳类型与判断

### 3.1 接纳类型对照表

| 类型 | 定义 | 力量 |
|------|------|------|
| **入庙接纳** | 行星A在行星B入庙守护的星座 | 最强 |
| **擢升接纳** | 行星A在行星B擢升的星座 | 强 |
| **三分接纳** | 行星A在行星B三分主星所管的星座 | 中等 |
| **界接纳** | 行星A在行星B界主星所管的区间 | 较弱 |

### 3.2 接纳判断步骤

```
Step 1: 遍历所有托勒密相位组合
Step 2: 对每个相位组合：
  ├─ 获取行星A所在星座
  ├─ 查询该星座的守护星
  └─ 如果守护星是行星B → B接纳A
Step 3: 判断接纳类型：
  ├─ 检查行星A是否在行星B入庙的星座 → 入庙接纳
  ├─ 检查行星A是否在行星B擢升的星座 → 擢升接纳
  ├─ 检查行星A是否在行星B三分主星的星座 → 三分接纳
  └─ 检查行星A是否在行星B界主星的区间 → 界接纳
Step 4: 输出接纳关系列表
```

### 3.3 接纳判断示例

```
示例1：
金星在白羊座（火星守护）
金星与火星形成三合相位
判断：火星接纳金星（入庙接纳）

示例2：
木星在巨蟹座（月亮守护，木星在巨蟹座擢升）
木星与月亮形成六合相位
判断：月亮接纳木星（入庙接纳）
同时：木星也在自己擢升的星座，有额外力量

示例3：
土星在天秤座（金星守护，土星在天秤座擢升）
土星与金星形成刑克相位
判断：金星接纳土星（入庙接纳）
效果：刑克的凶性减轻
```

## 四、互容类型与判断

### 4.1 互容类型对照表

| 类型 | 定义 | 力量等级 |
|------|------|----------|
| **庙庙互容** | 两星各自在对方入庙的星座 | 最强 |
| **庙旺互容** | 一星在入庙，一星在擢升 | 强 |
| **旺旺互容** | 两星各自在对方擢升的星座 | 中等 |
| **其他互容** | 基于三分、界、面的互容 | 较弱 |

### 4.2 互容判断步骤

```
Step 1: 遍历所有行星组合
Step 2: 对每个行星组合：
  ├─ 获取行星A所在星座
  ├─ 获取行星B所在星座
  ├─ 查询行星A所在星座的守护星
  ├─ 查询行星B所在星座的守护星
  └─ 如果：星座A守护星 = 行星B 且 星座B守护星 = 行星A → 互容
Step 3: 判断互容类型：
  ├─ 检查是否双方都在对方入庙的星座 → 庙庙互容
  ├─ 检查是否一方入庙一方擢升 → 庙旺互容
  ├─ 检查是否双方都在对方擢升的星座 → 旺旺互容
  └─ 其他情况 → 其他互容
Step 4: 输出互容关系列表
```

### 4.3 互容判断示例

```
示例1：庙庙互容
金星在白羊座（火星守护）
火星在天秤座（金星守护）
判断：金星与火星互容（庙庙互容）
效果：双方原本失势状态改善，形成1宫-7宫联动

示例2：庙旺互容
月亮在金牛座（金星守护，月亮在金牛座擢升）
金星在巨蟹座（月亮守护）
判断：月亮与金星互容（庙旺互容）
效果：月亮有擢升加持，金星有入庙加持，双方力量都很强

示例3：旺旺互容
土星在天秤座（金星守护，土星在天秤座擢升）
金星在双鱼座（木星守护，金星在双鱼座擢升）
判断：无互容（土星不在金星守护的星座）

示例4：不形成互容
太阳在白羊座（火星守护）
火星在狮子座（太阳守护）
判断：太阳与火星互容（庙庙互容）
效果：双方力量提升，形成自我（太阳）与行动（火星）的联动
```

## 五、接纳互容的综合判断

### 5.1 接纳与互容同时存在

```
┌─────────────────────────────────────────────────────────────┐
│                    接纳+互容                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【特殊情况】                                                 │
│  ├─ 接纳与互容可以同时存在                                   │
│  └─ 此时能量关系最强                                         │
│                                                             │
│  【判断方法】                                                 │
│  ├─ 先判断互容（基于星座守护关系）                           │
│  ├─ 再判断接纳（需要相位关系）                               │
│  └─ 如果同时存在，分别标注                                   │
│                                                             │
│  【示例】                                                     │
│  金星在白羊座，火星在天秤座                                   │
│  ├─ 金星与火星互容（庙庙互容）                               │
│  ├─ 如果金星与火星还有相位 → 火星接纳金星                    │
│  └─ 两重关系叠加，能量最强                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 多层接纳判断

```
┌─────────────────────────────────────────────────────────────┐
│                    多层接纳                                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 行星A可能同时被多个守护关系接纳                           │
│                                                             │
│  【判断方法】                                                 │
│  ├─ 分别判断入庙接纳、擢升接纳、三分接纳、界接纳              │
│  └─ 同时存在时，按力量等级排序                               │
│                                                             │
│  【示例】                                                     │
│  行星A在星座X：                                              │
│  ├─ 星座X入庙守护星为B → B入庙接纳A（最强）                   │
│  ├─ 星座X擢升行星为C → C擢升接纳A（强）                       │
│  ├─ 星座X三分主星为D → D三分接纳A（中等）                     │
│  └─ 按力量排序输出                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 六、后天身份标注

### 6.1 定义

```
┌─────────────────────────────────────────────────────────────┐
│                    后天身份标注                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【定义】                                                     │
│  └─ 后天身份 = 该行星是几宫的宫主星                            │
│                                                             │
│  【标注原则】                                                 │
│  ├─ 接纳关系中的两颗行星都需要标注后天身份                     │
│  ├─ 互容关系中的两颗行星都需要标注后天身份                     │
│  └─ 用于分析宫位领域的能量联动                               │
│                                                             │
│  【作用】                                                     │
│  ├─ 接纳不只是两颗行星的关系                                  │
│  ├─ 还代表两个宫位领域的能量流动                              │
│  └─ 例：金星(1,8宫主)被火星(2,7宫主)接纳                      │
│       → 代表自我财务(1/8)获得伴侣财务(2/7)的支持              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 后天身份获取

```
Step 1: 从行星数据中获取 house_ruler_of 字段
  例：金星.house_ruler_of = [1, 8]

Step 2: 标注到接纳/互容数据中
  ├─ receiving_house_ruler = [2, 7]  // 接纳方
  └─ received_house_ruler = [1, 8]   // 被接纳方

Step 3: 计算宫位联动关系
  └─ house_link = "一八同组-二七同组"
```

## 八、注意事项

```
┌─────────────────────────────────────────────────────────────┐
│                    判断注意事项                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【守护关系】                                                 │
│  ├─ 使用古典守护关系，不使用现代守护                          │
│  ├─ 天蝎座守护星为火星（不是冥王星）                          │
│  ├─ 水瓶座守护星为土星（不是天王星）                          │
│  └─ 双鱼座守护星为木星（不是海王星）                          │
│                                                             │
│  【接纳判断】                                                 │
│  ├─ 必须有托勒密相位才形成接纳                                │
│  ├─ 无相位则无接纳                                          │
│  └─ 小相位不形成接纳                                         │
│                                                             │
│  【互容判断】                                                 │
│  ├─ 不要求有相位                                            │
│  ├─ 基于星座守护关系判断                                     │
│  └─ 可以是入庙互容或擢升互容                                  │
│                                                             │
│  【日夜盘影响】                                               │
│  ├─ 三分性守护星顺序受日夜盘影响                              │
│  ├─ 判断三分接纳时需要考虑日夜盘                              │
│  └─ 日盘和夜盘的三分接纳结果可能不同                          │
│                                                             │
│  【后天身份标注】                                             │
│  ├─ 每个接纳/互容关系必须标注后天身份                        │
│  ├─ 后天身份来自行星数据的 house_ruler_of 字段               │
│  ├─ 宫位联动标注同组关系（如"一八同组"）                     │
│  └─ 用于分析宫位领域的能量联动                               │
│                                                             │
│  【不解读含义】                                               │
│  ├─ 仅判断接纳/互容关系，不解读含义                           │
│  └─ 含义解读由personality-analysis Agent负责                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
