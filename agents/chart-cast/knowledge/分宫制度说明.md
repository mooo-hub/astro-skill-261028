# 分宫制度说明

> **用途**：chart-cast Agent排盘时选择分宫制度
> **默认配置**：阿卡比特制（Alcabitus）
> **版本**：v3.0 | 2026-06-15

---

## 一、默认配置

| 项目 | 配置 | 原因 |
|------|------|------|
| **主分宫制** | 阿卡比特制（Alcabitus） | 古典占星传统，中世纪常用 |
| **辅助对照** | 整宫制（Whole Sign） | 解决度数不准、劫夺问题 |

---

## 二、分宫制度对照表

| 分宫制度 | 英文名 | 特点 | 适用场景 |
|----------|--------|------|----------|
| **阿卡比特制** | Alcabitus | 不等分制，中世纪常用 | 古典占星（默认）|
| **整宫制** | Whole Sign | 每宫30°，宫头在星座起点 | 辅助参考，解决劫夺 |
| **普拉西德制** | Placidus | 最常用，软件默认 | 现代占星 |
| **等宫制** | Equal House | 每宫固定30° | 简化分析 |
| **瑞吉欧蒙塔努斯制** | Regiomontanus | 不等分制，卜卦常用 | 卜卦占星 |

---

## 三、整宫制计算方法

```
上升星座 = 一宫（完整30度）
上升星座+1 = 二宫（完整30度）
上升星座+2 = 三宫（完整30度）
...以此类推

示例：
上升白羊 → 一宫白羊、二宫金牛、三宫双子...
上升狮子 → 一宫狮子、二宫处女、三宫天秤...
```

## 五、双轨对照法

```
【重要判断时使用】

Step 1: 主分宫制排盘（阿卡比特制）
Step 2: 整宫制排盘（辅助参考）
Step 3: 对照行星落宫
  ├─ 两种分宫制一致 → 确认判断
  └─ 两种分宫制不一致 → 标注差异，保守判断

示例：
阿卡比特制：火星在7宫
整宫制：火星在8宫
→ 标注"落宫有差异：阿卡比特7宫/整宫8宫"
```

## 六、劫夺现象处理

### 劫夺定义

**劫夺（Interception）**：不等宫制下，某星座被完整包在某一宫内，没有宫头落入。

### 劫夺处理规则

```
┌─────────────────────────────────────────────────────────────┐
│                    劫夺处理原则                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【发现劫夺】                                                 │
│  ├─ 阿卡比特制下某星座无宫头                                  │
│  └─ 该星座的守护星仍需计算（用于其他结构）                     │
│                                                             │
│  【处理方式】                                                 │
│  ├─ 主分析使用阿卡比特制宫位                                  │
│  ├─ 辅助参考整宫制（无劫夺）                                  │
│  └─ 劫夺夹：两宫头同星座时，行星在两侧可夹整个宫               │
│                                                             │
│  【标注要求】                                                 │
│  └─ 必须标注"存在劫夺：XX星座被劫夺于X宫"                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 七、特殊情况

### 宫头接近星座边界

```
【5度原则】
├─ 宫头距离星座边界<5°，且行星在同一星座内
├─ 可考虑该行星同时影响两宫
└─ 需标注"宫头边界情况"
```

### 行星接近宫头

```
【边界判断】
├─ 行星距离下一宫头<5°
├─ 可考虑该行星落入下一宫
└─ 需标注"接近宫头边界"
```
