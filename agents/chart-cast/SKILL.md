## 二、Task Scope（任务边界）

### 输入契约

```json
{
  "birth_datetime": "YYYY-MM-DD HH:MM",
  "location": "城市",
  "gender": "男/女"
}
```

### 输出契约

```json
{
  "chart_data": {
    "basic_info": {...},
    "axes": {...},
    "planets": [...],
    "houses": [...],
    "aspects": [...],
    "reception_mutual": {...},
    "dispositor_chain": {...},
    "fortune_point": {...},
    "pattern": {...}
  },
  "time_info": {...}
}
```

### 禁止任务

```
✗ 禁止解读任何计算结果的含义
✗ 禁止判断吉凶
✗ 禁止使用现代守护替代古典守护
✗ 禁止对缺失数据主观假设
```

## 四、工作流程

---

### Step 1: 信息采集与验证

**前置知识**：
```
读取：knowledge/信息采集检查清单.md
时机：before_execution
```

**执行步骤**：
```
1. 提取：出生时间、地点、性别
2. 验证：
   ├─ 年月日时：必填
   ├─ 分钟：可默认00
   ├─ 地点：查城市经纬度表.md
   └─ 性别：必须确认
3. 输出：验证通过的 birth_info
```

---

### Step 2: 排盘计算

**前置知识**：
```
读取：knowledge/排盘工具使用规范.md
读取：knowledge/分宫制度说明.md
时机：before_execution
```

**执行步骤**：
```
1. 参数准备：
   ├─ 年月日时分
   ├─ 经纬度（查城市经纬度表.md）
   └─ 时区（中国+8）
2. 执行排盘：
   ├─ 默认：阿卡比特制（Alcabitus）
   └─ 命令：python astro_calc.py ...
3. 解析结果：
   ├─ 四轴：ASC、MC、DES、IC
   ├─ 七行星：太阳、月亮、水星、金星、火星、木星、土星
   └─ 12宫宫头：星座、度数
```

---

### Step 3: 日夜盘判断

**前置知识**：
```
读取：knowledge/日夜盘判断规则.md
时机：before_execution
```

**执行步骤**：
```
1. 判断太阳位置：
   ├─ 太阳在7-12宫 → 日盘
   └─ 太阳在1-6宫 → 夜盘
2. 标注影响：
   ├─ 三分性守护星顺序
   ├─ 法达大运起始星
   └─ 福点计算公式
```

---

### Step 4: 行星先天禀赋与特殊状态

**前置知识**：
```
读取：knowledge/先天禀赋判断规则.md
读取：knowledge/灼烧判断规则.md
读取：knowledge/东出西入判断规则.md
时机：before_execution
```

**执行步骤**：
```
1. 查表判断入庙状态
2. 查表判断入旺状态
3. 查表判断三分性（需日夜盘信息）
4. 查表判断界和面（需精确度数）
5. 计算积分
6. 确定力量等级
7. 判断灼烧状态
8. 判断东出西入
9. 判断喜乐宫
10. 判断得时失时
```

---

### Step 5: 宫位信息计算

**前置知识**：
```
读取：knowledge/飞星判断规则.md
读取：knowledge/落宫类型判断规则.md
时机：before_execution
```

**执行步骤**：
```
1. 宫主星计算：
   ├─ 每宫宫头星座 → 查表得守护星
   └─ 同一守护星的宫位标注（如"一八同组"）

2. 宫内星统计：
   └─ 逐宫统计落入的行星

3. 飞星关系：
   └─ 宫主星所在宫位（如"一飞八"）

4. 落宫类型：
   ├─ 始续果宫：查表分类
   ├─ 吉凶宫：查表分类
   └─ 能量等级：查表评分

5. 整合到行星数据：
   └─ 每颗行星标注 house_ruler_of: [宫位数组]

6. 整合到宫位数据：
   └─ 每宫包含 ruler_in_house, same_ruler_group, planets_in_house
```

---

### Step 6: 格局分析

**前置知识**：
```
读取：knowledge/格局判断规则.md
时机：before_execution
```

**执行步骤**：
```
1. 元素分布：统计七行星+上升的火土风水数量
2. 性质分布：统计基本/固定/变动
3. 半球分布：统计上/下/东/西
4. 阴阳分布：统计阳/阴
5. 干湿冷热：计算属性分布
6. 强弱判断：≥4为强，=0为缺失
7. 星盘型态：散落/集团/碗型/提桶/火车头/跷跷板/分裂
8. 主要格局：大三角/T型三角/大十字/风筝/神秘矩形/上帝之指
```

---

### Step 7: 相位计算

**前置知识**：
```
读取：knowledge/相位计算规则.md
时机：before_execution
```

**执行步骤**：
```
1. 计算所有行星对的黄经差
2. 判断托勒密相位：
   ├─ 合相（0°）
   ├─ 六合（60°）
   ├─ 三合（120°）
   ├─ 刑克（90°）
   └─ 对冲（180°）
3. 判断入相位/出相位（速度差）
4. 计算紧密程度等级
5. 标注后天身份：
   ├─ planet_a_house_ruler: 来自行星数据的 house_ruler_of
   └─ planet_b_house_ruler: 来自行星数据的 house_ruler_of
```

---

### Step 8: 接纳互容

**前置知识**：
```
读取：knowledge/接纳互容判断规则.md
时机：before_execution
```

**执行步骤**：
```
1. 接纳判断：
   ├─ 条件：A在B守护的星座 + A与B有相位
   ├─ 类型：入庙/擢升/三分/界接纳
   └─ 后天身份：从行星数据获取 house_ruler_of

2. 互容判断：
   ├─ 条件：两星各在对方守护的星座
   ├─ 类型：庙庙/庙旺/旺旺/其他互容
   └─ 宫位联动：标注同组关系
```

---

### Step 9: 定位星链与福点

**前置知识**：
```
读取：knowledge/特殊点计算规则.md
时机：before_execution
```

**执行步骤**：
```
1. 定位星链：
   ├─ 各行星所在星座 → 查守护星
   ├─ 追踪链条直到循环或入庙
   └─ 最终定位星：链条终点

2. 福点计算：
   ├─ 日盘公式：ASC + 月亮 - 太阳
   ├─ 夜盘公式：ASC + 太阳 - 月亮
   └─ 福点位置：星座、度数、宫位
```

---

### Step 10: 时间信息

**前置知识**：
```
读取：knowledge/法达大运规则.md
时机：before_execution
```

**执行步骤**：
```
1. 年龄 = 当前年份 - 出生年份
2. 小限宫位 = 年龄 ÷ 12 余数（0=12宫）
3. 法达大运：
   ├─ 根据日夜盘选择顺序
   └─ 计算当前大运/子运
```

---

### Step 11: 输出汇总

**执行步骤**：
```
1. 汇总所有数据 → chart_data
2. 验证必填字段完整
3. 输出完整 JSON
4. 记录所有 KVP 日志
```
