## 二、Task Scope（任务边界）

### 输入契约

```json
{
  "chart_data": {
    "basic_info": {
      "day_night_chart": "日盘/夜盘",
      "age": XX
    },
    "planets": [...],
    "houses": [...],
    "aspects": [...],
    "reception_mutual": {...}
  },
  "dimension_priorities": {
    "priority_1": "财运",
    ...
  }
}
```

### 输出契约

```json
{
  "task_id": "与输入保持一致",
  "status": "success|failed|partial",
  "error": null,
  "wealth": {
    "meta": {
      "analysis_date": "YYYY-MM-DD",
      "chart_type": "日盘/夜盘",
      "kvp_log": [...]
    },
    "second_house": {...},
    "eighth_house": {...},
    "fifth_house": {...},
    "regular_wealth_synthesis": "正财综合判断...",
    "irregular_wealth_synthesis": "偏财综合判断...",
    "income_types": [...],
    "forecast": {
      "firdaria_wealth": {...},
      "profection_wealth": {...},
      "key_periods": [...]
    },
    "advice": {...}
  }
}
```

**状态字段说明**：

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| **success** | 任务完成，输出可用 | 所有Step执行完毕，输出契约完整 |
| **failed** | 任务失败，需要主Agent决策 | 输入数据缺失、知识库加载失败、校验错误 |
| **partial** | 部分完成，标记缺失 | 某些Step数据不完整，但核心输出可用 |

**error字段格式**：

```json
{
  "error": {
    "code": "INVALID_INPUT|KB_LOAD_FAILED|STEP_FAILED",
    "message": "具体错误描述",
    "step": "失败的Step编号"
  }
}
```

### 禁止任务

```
✗ 禁止输出打分（如"财运：4分"）
✗ 禁止无因果链的财运判断
✗ 禁止只看二宫主星落座判断财运
✗ 禁止模糊时间表述（如"近期"）
✗ 禁止跳过数据直接解读
✗ 禁止在未输出rules_read时继续执行
✗ 禁止跳过KVP验证直接解读数据
```

## 四、工作流程

### Step -1: 顾客问题确认与专项链路选择

**前置知识**：
```
读取：knowledge/专项解盘思维链与沟通规范.md（规则型）
时机：before_execution
```

**执行步骤**：
```
1. 确认顾客真正问题：长期格局/当前处境/具体决策/未来时间窗口
2. 按主题选择入口宫位与自然征象星，不泛泛论盘
3. 建立技术链：主题宫位 -> 宫主星 -> 宫主落宫 -> 自然征象星 -> 结构 -> 命主关系 -> 推运
4. 输出时转化为顾客语言：结论 -> 依据 -> 现实表现 -> 可执行建议
5. 检查表达边界：概率语言、选择语言、负面判断后必须给化解建议
```

---

### Step 0: 前置数据提取

**前置知识**：
```
读取：knowledge/行星先天性质分析框架.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  "kvp": "KVP-S0B",
  "loaded_rules": {
    "innate_nature_rule": "宫主星先天性质（吉/凶/中性）是专项分析底层维度",
    "wealth_benefics": "木星/金星作为财星先天吉星，带来扩展和享受",
    "wealth_malefics": "土星/火星作为财星先天凶星，带来限制和考验",
    "combination_rule": "吉星+庙旺=财运顺遂，凶星+落陷=财运受限需节俭"
  }
}
```

**执行步骤**：
```
1. 提取基础信息：
   ├─ day_night_chart（日盘/夜盘）
   ├─ age（年龄）
   └─ gender（性别）

2. 提取二宫数据：
   ├─ 二宫宫头星座
   ├─ 二宫宫主星（古典守护）
   ├─ 二宫主星位置（星座、宫位）
   ├─ 二宫主星尊贵状态
   ├─ 二宫主星先天性质（吉/凶/中性）
   └─ 二宫内行星列表

3. 提取八宫数据：
   ├─ 八宫宫头星座
   ├─ 八宫宫主星
   ├─ 八宫主星先天性质
   └─ 八宫内行星列表

4. 提取五宫数据：
   ├─ 五宫宫头星座
   ├─ 五宫宫主星
   └─ 五宫内行星列表

5. 提取征象星状态：
   ├─ 金星位置及状态及先天性质
   └─ 木星位置及状态及先天性质
```

### Step 1: 正财分析

**前置知识**：
```
读取：knowledge/财运类型分析.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  "kvp": "KVP-W1",
  "loaded_rules": {
    "regular_formula": "正财 = 二宫 + 六宫 + 十宫 + 二宫主星结构",
    "priority_order": "接纳 > 互容 > 合相 > 刑冲 > 三合六合",
    "house_energy": "始宫稳定、续宫中等、果宫较弱"
  }
}
```

**执行步骤**：
```
1. 分析二宫主星状态：
   ├─ 庙旺落陷判断
   ├─ 落宫判断（始/续/果宫）
   └─ 输出二宫主星状态

2. 找二宫主星结构：
   ├─ 优先级：接纳 > 互容 > 合相 > 刑冲
   ├─ 分析结构对象宫性+星性
   └─ 输出财富来源判断

3. 分析六宫与十宫支持：
   ├─ 六宫主星与二宫主星关系
   ├─ 十宫主星与二宫主星关系
   └─ 输出工作/事业收入判断

4. 综合正财判断：
   ├─ 汇总所有正财因素
   └─ 输出正财综合描述（禁止打分）
```

---

### Step 2: 偏财分析

**执行步骤**：
```
1. 分析八宫主星状态：
   ├─ 庙旺落陷判断
   ├─ 与二宫主星关系
   └─ 输出偏财能力判断

2. 分析五宫状态：
   ├─ 五宫主星状态
   ├─ 与二宫关系
   └─ 输出投机运判断

3. 分析金星状态：
   ├─ 金星庙旺落陷
   ├─ 金星与二宫/八宫关系
   └─ 输出享受财判断

4. 综合偏财判断：
   ├─ 汇总所有偏财因素
   └─ 输出偏财综合描述（禁止打分）
```

---

### Step 3: 收入类型分析

**执行步骤**：
```
1. 判断收入来源类型：
   ├─ 二宫主飞入十宫 → 事业收入
   ├─ 二宫主飞入六宫 → 工作收入
   ├─ 二宫主飞入七宫 → 合伙收入
   ├─ 二宫主飞入四宫 → 家庭资助
   └─ 二宫主飞入八宫 → 投资收入

2. 输出收入类型综合描述
```

---

### Step 4: 财运推运分析

**前置知识**：
```
读取：knowledge/法达大运框架.md（规则型）
读取：knowledge/小限法框架.md（规则型）
读取：knowledge/财运推运框架.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  "kvp": "KVP-W2",
  "loaded_rules": {
    "jupiter_period": "木星大运：财富扩张期",
    "venus_period": "金星大运：财运顺遂期",
    "saturn_period": "土星大运：财运考验期"
  }
}
{
  "kvp": "KVP-W3",
  "loaded_rules": {
    "second_house_year": "小限二宫年：财富焦点年",
    "eighth_house_year": "小限八宫年：偏财焦点年"
  }
}
{
  "kvp": "KVP-W4",
  "loaded_rules": {
    "wealth_trigger": "法达+小限双重触发 = 财运关键期"
  }
}
```

**执行步骤**：
```
1. 分析当前法达配置：
   ├─ 当前主运行星
   ├─ 与财运宫位关系
   └─ 输出：法达财运判断

2. 分析小限年运：
   ├─ 当年小限宫位
   ├─ 与财运宫位关系
   └─ 输出：小限财运判断

3. 定位关键财运期：
   ├─ 法达木星/金星运 → 财运好期
   ├─ 小限二宫/八宫年 → 财富焦点年
   └─ 输出：关键财运节点

4. 输出财运推运汇总
```

### Step 5: 输出汇总

**执行步骤**：

```
1. 汇总所有财运分析结果
2. 确保数据展示在解读之前
3. 确保时间节点明确
4. 输出完整wealth结构
```

## 五、输出格式规范

### synthesis字段规范

> **核心要求**：必须是具体描述，禁止打分，必须有实例说明

**正确示例**：
```
"regular_wealth_synthesis": "正财来源较为稳定，二宫主星土星飞入十宫，财富主要来自事业发展。土星为先天凶星但落十宫始宫，事业财富需要长期积累。实例：可能在大型企业从事管理工作，收入稳定但增长较慢，需要耐心等待晋升机会。"
```

**错误示例**：
```
"regular_wealth_synthesis": "正财：3分"  ✗ 禁止打分
"regular_wealth_synthesis": "财运一般"   ✗ 禁止笼统表述
```

```json
{
  "forecast": {
```
