# 财运类型分析

财运类型分析是财运专项分析的第一步，核心原则是**正财与偏财分开判断**。包含**数据收集**、**正财判断**和**偏财判断**三部分。

---

## 一、核心原则：正财与偏财分开判断

```
┌──────────────────────────────────────────────────────────────┐
│              财运论断双维度分析法                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心理念：                                                │
│  财运论断需要区分正财与偏财，判断方法不同                      │
│                                                              │
│  【正财（工作收入）】                                         │
│  ├─ 工作收入、薪资待遇、事业收入                              │
│  ├─ 判断宫位：二宫、六宫、十宫                               │
│  ├─ 判断公式：二宫 + 六宫 + 十宫 + 二宫主星结构               │
│  └─ 特点：稳定性、可持续性                                   │
│                                                              │
│  【偏财（投资收入）】                                         │
│  ├─ 投资收入、意外之财、他人资源                              │
│  ├─ 判断宫位：五宫、八宫                                     │
│  ├─ 判断公式：五宫 + 八宫 + 五宫主星 + 八宫主星 + 金星结构    │
│  └─ 特点：风险性、投机性                                     │
│                                                              │
│  ★ 重要：正财与偏财判断方法完全不同，必须分开判断             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、数据收集

### 2.1 二宫数据收集（正财核心）

```
Step 1: 确定二宫宫头星座
    └─ 输出：二宫宫头星座名称

Step 2: 确定二宫主星（财星）
    ├─ 查表：二宫宫头星座 → 古典守护星
    └─ 输出：财星名称

Step 3: 收集财星状态数据
    ├─ 落入星座 → 能量状态（庙旺/落陷/普通）
    ├─ 落入宫位 → 宫性（吉宫/凶宫）
    ├─ 宫主星身份 → 后天宫性（主几宫）
    ├─ 先天性质 → 吉星/凶星/中性
    └─ 输出：财星完整数据

Step 4: 收集二宫宫内星数据 ★四维度分析★
    ├─ 列出二宫内所有行星
    ├─ 对每个宫内星执行四维度分析：
    │   ├─ 先天星性（吉/凶/中性）
    │   ├─ 后天宫性（主吉宫/主凶宫）
    │   ├─ 能量状态（庙旺/落陷/普通）
    │   └─ 结构关系（与财星的相位/接纳）
    └─ 输出：二宫宫内星列表（含四维度数据）

Step 5: 收集财星相位数据 ★核心★
    ├─ 财星与其他行星的相位
    └─ 财星与六宫主、十宫主的关系
```

### 2.5 相位与结构数据收集

```
Step 1: 收集财星（二宫主）的相位
    ├─ 合相关系：财星与哪颗星合相（度数+容许度）
    ├─ 刑相关系：财星与哪颗星刑相
    ├─ 冲相关系：财星与哪颗星冲相
    ├─ 三合关系：财星与哪颗星三合
    └─ 六合关系：财星与哪颗星六合

Step 2: 收集财星参与的结构 ★核心★
    ├─ 接纳关系（财星被接纳/财星接纳他星）
    ├─ 互容关系（财星与哪颗星互容）
    ├─ 合相+接纳（强度最强）
    ├─ 刑/冲+接纳（过程艰辛，结果可得）
    └─ 三合/六合+接纳（顺畅得到）

Step 3: 执行太极点转化
    ├─ 原则：财星本身是"太极点"，不参与对自己的判断
    ├─ 转化：转从结构对象星的角度分析
    └─ 输出：结构对象星列表

Step 4: 收集结构对象星数据
    ├─ 对每个结构对象星执行：
    │   ├─ 落入星座 → 星座性质
    │   ├─ 落入宫位 → 宫性
    │   ├─ 宫主星身份 → 后天宫性
    │   ├─ 与财星的相位类型
    │   └─ 与财星的接纳/互容关系
    └─ 输出：结构对象星完整数据

Step 5: 汇总财富征象星
    ├─ 主征象星：财星（二宫主，权重最高）
    ├─ 辅助征象星：结构对象星（权重次之）
    └─ 输出：财富征象星列表（含权重+相位类型）
```

**结构优先级**：

```
接纳 > 互容 > 合相 > 刑冲 > 三合六合

紧密程度说明：
├─ 庙旺接纳：最紧密，即使凶相位，形成接纳后凶性减弱
├─ 普通接纳：紧密，相位影响过程但不影响结果
├─ 互容：双向能量互换，紧密程度中等
├─ 合相：能量融合，紧密程度中等
├─ 刑/冲+接纳：过程艰辛，需付出更多努力，但结果可得
└─ 三合/六合：远亲结构，有紧密结构时作为补充
```

## 五、收入类型判断

### 5.1 九种收入类型

| 类型 | 判断标准 | 特点 | 稳定性 |
|------|----------|------|--------|
| **正财稳定** | 财星入庙、土象强 | 工资稳定，有积蓄 | 高 |
| **正财波动** | 财星被刑克 | 收入起伏，需规划 | 中低 |
| **偏财投资** | 八宫主有力、有支持 | 投资机会多 | 中 |
| **偏财投机** | 五宫主强+木星支持 | 投机运好 | 低 |
| **合伙收入** | 财星与七宫主有关系 | 通过合作获利 | 中高 |
| **家庭资助** | 财星与四宫主有关系 | 家庭经济支持 | 高 |
| **工作收入** | 财星与六宫主有关系 | 通过工作赚钱 | 中 |
| **事业收入** | 财星与十宫主有关系 | 事业带来财富 | 高 |
| **多元收入** | 多宫主星有关系 | 收入来源多样 | 中 |

|------|----------|----------|-----------|

| **月亮** | 流动财富 | 日常收支、流动性收入、民生财 | 正财为主 |

| **二宫主** | 个人财富 | 主要的财富判断依据 | 正财核心 |

### 6.2 木星在财运中的特殊作用

```
【木星的贵气特质】
├─ 大吉星，"躺赢"的人生赢家
├─ 主1、4、5、9、10、11宫 = 有气（吉宫）
├─ 主3、6、8、12宫 = 无气（降低贵气）
│
├─ 含义：
│   ├─ 做什么事都有人帮
│   ├─ 运作自媒体很快成为网红
│   ├─ 有人助力，容易成功
│   └─ 财富容易扩张
│
└─ 例：木星主11宫与财星产生结构 = 理财有人帮助，容易成功
```

### 6.3 财星的先天性质影响

| **先天吉星（木/金）** | 财运顺遂 | 收入机会多，有助力 | 可适当扩张 |
| **先天凶星（土/火）** | 财运辛苦 | 需长期积累，有考验 | 需稳健理财 |
| **先天贵星（日/月）** | 有贵气 | 收入与地位相关 | 发展地位 |
| **中性行星（水）** | 财运灵活 | 收入来自沟通技能 | 发展技能 |
