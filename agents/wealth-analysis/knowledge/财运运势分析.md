# 财运运势分析

财运运势分析是财运专项分析的第三步（必执行），包含**数据引用**、**财星运势影响分析**和**四维度判断**三部分。

---

## 一、数据收集

### 1.1 引用 Step 1 的财星核心数据

财运运势分析需要引用财运类型分析（Step 1）已收集的财星核心数据：

```
【必须引用的数据】

├─ 财星身份
│   └─ 二宫宫头星座 → 古典守护星名称

├─ 财星位置
│   ├─ 落入星座 → 能量状态（庙旺/落陷/普通）
│   └─ 落入宫位 → 宫性（吉宫/凶宫）

├─ 财星宫主星身份
│   └─ 主几宫 → 后天宫性（主吉宫/主凶宫/主吉凶混合）

├─ 财星先天性质
│   └─ 吉星/凶星/中性

├─ 财星相位
│   ├─ 合相关系 → 紧密连接
│   ├─ 刑相关系 → 过程艰辛
│   ├─ 冲相关系 → 对立张力
│   ├─ 三合关系 → 顺畅表达
│   └─ 六合关系 → 机会连接

└─ 二宫宫内星
    └─ 列表 + 四维度分析结果
```

### 1.2 财星运势影响分析

财星的**星性、落宫、能量、相位**四个维度共同决定财运运势的具体表现：

#### 1.2.1 星性对运势的影响

| 财星先天性质 | 运势特点 | 具体表现 | 实例说明 |
|--------------|----------|----------|----------|
| **先天吉星（木/金）** | 财运顺遂有机遇 | 收入机会多，有助力，容易获得帮助 | 可能轻松获得加薪，或顺利找到好工作 |
| **先天凶星（土/火）** | 财运辛苦需积累 | 收入需长期耕耘，早期辛苦，后期收获 | 可能从基层做起，逐步积累才晋升 |
| **先天贵星（日/月）** | 有贵气加持 | 收入与地位相关，可能有领导财 | 可能担任管理职务，收入与地位挂钩 |
| **中性行星（水）** | 财运灵活多变 | 收入方向可能多变，需要沟通技能 | 可能从事需要沟通协调的工作，收入可调整 |

**星性吉凶判断规则**：
```
├─ 先天吉星（木星/金星）→ 运势偏顺，有机遇
├─ 先天凶星（土星/火星）→ 运势偏辛，需积累
├─ 先天贵星（太阳/月亮）→ 运势有贵，有地位
└─ 中性行星（水星）→ 运势灵活，可调整
```

---

#### 1.2.2 落宫对运势的影响

| 财星落宫 | 运势影响 | 稳定性 | 具体表现 | 实例说明 |
|----------|----------|--------|----------|----------|
| **吉宫（1/4/5/9/10/11）** | 运势顺畅 | 高稳定 | 财运发展顺利，机会多 | 可能顺利加薪，收入稳定增长 |
| **凶宫（3/6/8/12）** | 运势受阻 | 低稳定 | 财运有阻碍，需克服挑战 | 可能遇到财务瓶颈，收入不稳定 |
| **二宫（财帛）** | 利于理财 | 中等 | 财运与理财关联强 | 可能通过理财获得收入 |
| **七宫（伴侣）** | 利于合伙财 | 中等 | 财运与合作关系关联 | 可能通过合伙或婚姻获得财务帮助 |

**吉宫/凶宫运势判断规则**：
```
├─ 落吉宫（1/4/5/9/10/11）
│   ├─ 运势：顺畅 +1
│   ├─ 稳定：高 +1
│   └─ 实例：收入稳定增长，机会多
│
└─ 落凶宫（3/6/8/12）
    ├─ 运势：受阻 -1
    ├─ 稳定：低 -1
    └─ 实例：收入波动，有财务压力
```

**凶宫具体影响**：

| 凶宫 | 运势特点 | 具体影响 | 实例说明 |
|------|----------|----------|----------|
| **三宫** | 琐事缠身 | 收入需要频繁沟通，可能变动多 | 可能从事销售工作，收入不稳定 |
| **六宫** | 辛苦劳累 | 收入需要付出较多精力，辛苦财 | 可能从事服务性工作，付出多 |
| **八宫** | 动荡起伏 | 收入不稳定，有得有失 | 可能从事提成制工作，收入波动大 |
| **十二宫** | 幕后隐匿 | 收入来源隐秘，可能有隐性收入 | 可能从事研究或幕后工作，收入不公开 |

#### 1.2.3 能量对运势的影响

| 财星能量 | 运势程度 | 具体表现 | 实例说明 |
|----------|----------|----------|----------|
| **庙旺** | 运势强 +2 | 财运能量强，表达顺畅，机会多 | 可能容易获得加薪，收入增长 |
| **普通** | 运势中 0 | 财运能量一般，需要努力争取 | 可能需要等待机会，逐步发展 |
| **落陷** | 运势弱 -2 | 财运能量受限，表达困难，阻碍多 | 可能遇到财务瓶颈，收入受限 |

**能量状态判断规则**：
```
├─ 庙旺 → 运势强，表达顺畅 +2
│   └─ 实例：加薪容易，理财收益好
│
├─ 普通 → 运势中，需努力 0
│   └─ 实例：需要等待机会，逐步发展
│
└─ 落陷 → 运势弱，表达困难 -2
    └─ 实例：加薪困难，理财有阻力
```

#### 1.2.4 相位对运势的影响

| 相位类型 | 过程体验 | 具体表现 | 实例说明 |
|----------|----------|----------|----------|
| **合相** | 直接连接 | 财运能量直接显现，过程无阻碍 | 可能直接面对财务机会 |
| **三合** | 顺畅表达 | 财运能量顺畅表达，过程舒适 | 可能自然展现理财能力 |
| **六合** | 机会连接 | 财运能量有机会连接，过程温和 | 可能遇到温和的财务机会 |
| **刑相** | 过程艰辛 | 财运能量表达过程艰难，需付出努力 | 可能需要多次尝试才能改善财务 |
| **冲相** | 对立张力 | 财运能量表达有张力，过程需调和 | 可能遇到外部阻力，需要协调应对 |

**相位过程判断规则**：

```
├─ 核心原则：相位只代表过程，不代表结果
├─ 相位描述的是能量交互的过程体验
├─ 运势结果由接纳强度决定，与相位类型无关
└─ 必须结合宫性、星性综合判断结果

具体规则：
├─ 吉相位（三合/六合）→ 过程顺畅，表达舒适
│   └─ 实例：理财决策过程轻松

├─ 中性相位（合相）→ 过程直接，无中间环节
│   └─ 实例：财务机会直接呈现

└─ 凶相位（刑相/冲相）→ 过程艰辛，需要付出努力
    └─ 实例：改善财务需要多次尝试

注意：
├─ 刑/冲+接纳：过程艰辛但结果可得
├─ 三合/六合+接纳：过程顺畅且结果可得
└─ 无接纳结构：相位不产生实质帮助
```

#### 1.2.5 四维度综合运势判断表

**财星四维度组合运势判断**：

> **前提说明**：此表格基于"有接纳结构"的前提下，相位描述过程特点，结果由接纳强度决定。

| 组合情况 | 运势判断 | 过程特点 | 实例说明 |
|----------|----------|----------|----------|
| **吉星+吉宫+庙旺+吉相位** | 运势极佳 | 过程顺畅，表达自然 | 若有接纳，可能顺利获得财务支持 |
| **吉星+吉宫+庙旺+凶相位** | 运势良好但过程辛苦 | 过程有阻力，需要付出努力 | 若有接纳，结果可得但需付出代价 |
| **吉星+凶宫+庙旺+吉相位** | 运势中等偏上 | 过程顺畅，但环境有挑战 | 若有接纳，需克服环境后获得支持 |
| **凶星+吉宫+庙旺+吉相位** | 运势中等偏上 | 过程顺畅，但需要长期积累 | 若有接纳，积累后可获得发展 |
| **凶星+凶宫+落陷+凶相位** | 运势困难 | 过程艰辛，表达受阻 | 即使有接纳，效果也大打折扣 |
| **吉星+凶宫+落陷+凶相位** | 运势较差 | 过程艰辛，环境不利 | 即使有接纳，效果有限 |

**判断要点**：
```
├─ 吉相位 → 过程顺畅、表达自然（不等于结果好）
├─ 凶相位 → 过程艰辛、需要付出（不等于结果差）
├─ 结果由接纳强度决定
└─ 无接纳结构时，相位不产生实质性帮助
```

### 1.3 日月数据收集

```
Step 1: 判断日夜盘
    ├─ 太阳在地平线以上 → 日盘
    ├─ 太阳在地平线以下 → 夜盘
    └─ 输出：日夜盘类型

Step 2: 收集太阳数据
    ├─ 落入星座 → 能量状态
    ├─ 落入宫位 → 宫性
    ├─ 宫主星身份 → 后天宫性
    ├─ 与财星的关系 ★核心★
    ├─ 是否被灼烧
    ├─ 与其他行星的相位
    └─ 输出：太阳完整数据

Step 3: 收集月亮数据
    ├─ 落入星座 → 能量状态
    ├─ 落入宫位 → 宫性
    ├─ 宫主星身份 → 后天宫性
    ├─ 与财星的关系 ★核心★
    ├─ 与其他行星的相位
    └─ 输出：月亮完整数据

Step 4: 确定主要贵人星
    ├─ 日盘：太阳为主要贵人星，兼看月亮
    ├─ 夜盘：月亮为主要贵人星，兼看太阳
    └─ 输出：贵人星优先级
```

**日月特殊规则**：

```
日月可忽略宫性：
├─ 日月本身就是天王天后级别
├─ 如果与财星形成结构，直接作为贵人星参考
└─ 不需要太极点转化

灼烧状态判断：
├─ 行星与太阳同星座且度数接近（通常8.5度内）
├─ 灼烧不影响财运格局判断
├─ 灼烧含义：接近权贵（进贵）
└─ 可能接触有财力的人士
```

### 1.4 结构数据收集

```
Step 1: 确定主要参考结构
    ├─ 命主星参与的结构
    ├─ 财星参与的结构
    ├─ 日月参与的结构
    └─ 结构类型：接纳/互容/合相/刑冲

Step 2: 找最清纯的结构 ★核心★
    ├─ 结构最紧密的（接纳>互容>合相）
    ├─ 无凶宫掺入的
    ├─ 有吉星参与的
    └─ 输出：最清纯结构列表

Step 3: 评估结构清纯度
    ├─ 清纯：主结构全部涉及吉宫，无凶宫参与
    ├─ 基本清纯：主结构清纯，次结构有凶宫
    ├─ 一般：主结构有一处凶宫，但有吉星弥补
    └─ 不清纯：多处凶宫掺入，或核心星体全为凶宫宫主

Step 4: 检查凶宫掺入情况
    ├─ 财星落凶宫（3/6/8/12）
    ├─ 结构对象主凶宫
    ├─ 次结构凶宫掺入
    └─ 输出：凶宫掺入列表

Step 5: 检查化解结构
    ├─ 有贵星/吉宫接纳 → 部分化解
    ├─ 有互容关系 → 减轻负面影响
    └─ 无化解 → 完全破格
```

```
Step 5: 判断贵人来源领域
    └─ 根据贵人星所主宫位判断来源

Step 6: 输出贵人财运分析
```

**贵人星含义表**：

|--------|---------|---------|
| 太阳 | 领导垂青 | 大领导支持、国家/公权层面助力、强力财务支持者 |

**贵人效力判断表**：

| 木星主吉凶混合（如5r+8r） | 部分有效 | 贵气有代价，需说明伴随挑战 |

**财星状态对贵人效果的影响**：

### 2.2 财运高度判断

```
Step 1: 确定主要参考结构
    ├─ 应用结构数据
    ├─ 命主星参与的结构
    ├─ 财星参与的结构
    └─ 日月参与的结构

Step 2: 找最清纯的结构
    ├─ 结构最紧密的（接纳>互容>合相）
    ├─ 无凶宫掺入的
    └─ 有吉星参与的

Step 3: 评估结构清纯度
    ├─ 清纯：主结构全部涉及吉宫，无凶宫参与
    ├─ 基本清纯：主结构清纯，次结构有凶宫
    ├─ 一般：主结构有一处凶宫，但有吉星弥补
    └─ 不清纯：多处凶宫掺入，或核心星体全为凶宫宫主

Step 4: 检查财星运势影响 ★新增★
    ├─ 星性：吉星提升高度，凶星降低高度
    ├─ 落宫：吉宫提升高度，凶宫降低高度
    ├─ 能量：庙旺提升高度，落陷降低高度
    └─ 相位：吉相位提升高度，凶相位降低高度

Step 5: 检查破格情况
    ├─ 结构中掺杂凶宫主星（3/6/8/12r）
    ├─ 星体落陷
    ├─ 星性本身凶+宫性凶+凶相位=直接破格
    └─ 评估破格程度

Step 6: 判断整体层次
    └─ 综合清纯度+财星状态+破格情况+贵人支持 → 高度判断
```

**财星四维度对财运高度的影响**：

| 维度 | 提升高度 | 降低高度 | 过程特点 |
|------|----------|----------|----------|
| **星性** | 吉星/贵星 | 凶星 | 吉星表达顺畅，凶星需要更多努力 |
| **落宫** | 吉宫（1/4/5/9/10/11） | 凶宫（3/6/8/12） | 吉宫环境支持，凶宫需要克服挑战 |
| **能量** | 庙旺 | 落陷 | 庙旺表达顺畅，落陷表达受限 |
| **相位** | 吉相位（三合/六合） | 凶相位（刑/冲） | 吉相位过程顺畅，凶相位过程艰辛 |

> **注意**：相位只影响过程特点，不直接决定高度结果。高度由接纳强度+结构清纯度+贵人支持综合决定。

**层次判断标准**：

| 层次 | 特征 | 具体表现 |
|------|------|---------|
| **高** | 主结构清纯+贵星加持+财星状态好 | 财富丰厚、收入稳定、有贵人资助 |
| **中** | 主结构基本清纯或财星状态尚可 | 中等收入、财务稳定、小有积蓄 |
| **低** | 无贵星支持+财星状态差+多处破格 | 收入有限、财务压力、难有大财 |

### 2.3 财运稳定度判断

```
Step 1: 检查凶宫掺入情况
    ├─ 应用财星数据
    ├─ 财星落凶宫
    ├─ 结构对象主凶宫
    └─ 次结构凶宫掺入

Step 2: 评估掺入程度
    ├─ 主结构掺入 → 高破坏力
    ├─ 次结构掺入 → 中破坏力
    └─ 三合六合掺入 → 低破坏力

Step 3: 检查财星落宫的具体影响 ★新增★
    ├─ 三宫：收入变动多，需要频繁调整
    ├─ 六宫：收入辛苦，付出与收获可能不成正比
    ├─ 八宫：收入波动大，有得有失
    └─ 十二宫：收入隐秘，不被关注

Step 4: 检查化解结构
    ├─ 有贵星/吉宫接纳 → 部分化解
    └─ 无化解 → 完全破格

Step 5: 判断稳定度
    └─ 综合凶宫掺入+财星落宫+化解情况 → 稳定度判断
```

**八宫与十二宫的具体影响**：

| 凶宫 | 特质 | 对财运的影响 | 运势特点 | 实例说明 |
|------|------|-------------|----------|----------|
| **八宫** | 不稳定、有得有失、偏财 | 收入动荡、起伏较大、暗中沟通 | 动荡起伏型 | 可能收入波动大，有高有低 |
| **十二宫** | 出世、清闲、隐匿 | 幕后收入、隐性财、不被世俗认可 | 隐匿幕后型 | 可能从事研究或幕后工作，收入不公开 |

**三宫与六宫的具体影响**：

| 凶宫 | 特质 | 对财运的影响 | 运势特点 | 实例说明 |
|------|------|-------------|----------|----------|
| **三宫** | 沟通、信息、变动 | 收入需要频繁沟通，可能频繁变动 | 变动调整型 | 可能从事销售或咨询工作，收入不稳定 |
| **六宫** | 服务、辛苦、劳累 | 收入辛苦，需要付出较多精力 | 辛苦劳累型 | 可能从事服务或体力工作，辛苦财 |

### 2.4 整体格局评估

```
Step 1: 判断是什么样的人
    ├─ 大财还是普通财
    └─ 有无可倚仗的结构

Step 2: 找最可倚仗的结构
    ├─ 结构最清纯的
    ├─ 有贵星加持的
    └─ 有吉宫参与的

Step 3: 评估财星整体运势 ★新增★
    ├─ 星性吉凶 → 基础运势基调
    ├─ 落宫吉凶 → 环境支持程度
    ├─ 能量强弱 → 表达顺畅程度
    └─ 相位吉凶 → 过程顺遂程度

Step 4: 评估其他结构
    ├─ 主结构外的其他结构
    ├─ 是否有凶宫掺入
    └─ 破格程度如何

Step 5: 综合判断
    ├─ 高度综合判断
    └─ 稳定度综合判断
```

**格局好坏的两种情况**：

| 情况 | 特点 | 具体表现 | 实例说明 |
|------|------|---------|----------|
| **层次本来就低** | 无贵气加持+财星状态差+每个小结构都是坏的 | 平庸财务、温饱水平、难有大财 | 可能长期处于低收入状态，难以改善 |
| **主结构好但有破格** | 有很好的主结构+财星状态尚可+其他结构有破 | 有成有败、发达早晚看运 | 可能在财务上有成就，但伴随起伏 |

### 2.5 灼烧状态判断（特殊规则）

```
核心原则：灼烧不影响财运格局判断

灼烧含义：
├─ 接近权贵（进贵）
├─ 可能接触有财力的人士
└─ 有隐匿特质

注意：
├─ 不是影响财运格局好坏的因素
├─ 不是贵人或小人问题
└─ 只是描述财务来源性质
```
