## 一、核心分析方法

### 1.1 财运双维度分析法（核心理念）

```
┌──────────────────────────────────────────────────────────────┐
│              财运论断双维度分析法                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心理念：                                                │
│  财运论断需要区分正财与偏财                                   │
│                                                              │
│  【维度一：正财（工作收入）】                                 │
│  ├─ 工作收入、薪资待遇                                       │
│  ├─ 判断宫位：二宫、六宫、十宫                               │
│  └─ 稳定性、可持续性                                         │
│                                                              │
│  【维度二：偏财（投资收入）】                                 │
│  ├─ 投资收入、意外之财                                       │
│  ├─ 判断宫位：五宫、八宫                                     │
│  └─ 风险性、投机性                                           │
│                                                              │
│  ★ 重要：正财与偏财判断方法不同，必须分开判断                 │
│                                                              │
│  【判断公式】                                                │
│  ├─ 正财 = 二宫 + 六宫 + 十宫 + 二宫主星结构                │
│  └─ 偏财 = 五宫 + 八宫 + 五宫主星 + 八宫主星 + 金星结构     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 宫位能量速查

| 宫位类型 | 宫位 | 能量等级 | 财运稳定性 |
|----------|------|----------|------------|
| **始宫** | 1、4、7、10 | ★★★★★ | 最稳定 |
| **续宫** | 2、5、8、11 | ★★★☆☆ | 中等 |
| **果宫** | 3、6、9、12 | ★★☆☆☆ | 较不稳定 |
| **凶宫** | 3、6、8、12 | 视情况 | 有阻碍 |

**关键记忆**：
```
★ 记住：
├─ 二宫主飞入始宫=财富来源稳定
└─ 二宫主飞入果宫=财富来源不稳定

★ 八宫的特殊性：
├─ 八宫是凶宫，但得吉时偏财好
├─ 八宫主有力=偏财有机会
└─ 八宫主受克=投资风险大
```

## 二、Synthesis 字段规范

> **核心要求**：必须是具体描述，禁止打分，必须有实例说明

### 2.1 正财 synthesis

**正确示例**：

```json
{
  "regular_wealth_synthesis": "正财来源以事业收入为主，财星土星飞入十宫摩羯座。财星为先天凶星但入庙十宫始宫，事业收入需要长期积累，但有稳定基础。土木互容结构带来木星（吉星）的能量补充，可能通过合作关系获得贵人支持。星座性为土象摩羯，偏向务实积累、管理方向。实例：可能在大型企业从事管理工作，收入稳定但增长较慢，需要耐心等待晋升机会才能获得收入提升。"
}
```

**错误示例**：

```json
{
  "regular_wealth_synthesis": "正财：3分"  ✗ 过于笼统
  "regular_wealth_synthesis": "财运：4分"        ✗ 禁止打分
  "regular_wealth_synthesis": "财运一般"     ✗ 禁止模糊表述
}
```

---

### 2.2 偏财 synthesis

**正确示例**：

```json
{
  "irregular_wealth_synthesis": "偏财有潜力但需谨慎。八宫主火星入旺摩羯座十宫，偏财能力有一定基础。八宫主与财星有吉相位，投资可带来财富。但木星落陷处女座，贵人财运效力打折，投资需依赖自身判断而非他人帮助。五宫主太阳入庙狮子座，投机运有基础，可适度尝试。实例：可能有投资机会，但需要自己研究判断，不适合依赖他人推荐，可适度尝试股票或基金投资，但需控制仓位。"
}
```

```json
{

```

### 2.4 贵人财运 synthesis

**正确示例**：

```json
{
  "benefic_fortune_synthesis": "财运有贵人支持。财星土星与太阳形成接纳关系，太阳作为贵人星带来领导垂青。太阳入庙狮子座十宫，有贵气加持，可能获得上级领导的财务支持。同时土木互容带来木星贵人，木星主五宫+八宫（吉凶混合），贵人效力部分有效，贵人支持可能伴随某些代价。贵人来源领域为七宫（伴侣/合伙），说明贵人可能来自合作关系或伴侣引荐。实例：工作中可能获得领导的财务支持或加薪机会，但贵人支持可能伴随某些条件或代价。"
}
```

### 2.5 财运高度 synthesis

**正确示例**：

```json
{
  "height_synthesis": "财运可能比较辛苦，需要在严格的环境中发展，收入与事业挂钩。财星土星为先天凶星，入庙摩羯座十宫，能量表达顺畅但需要长期积累。贵人结构（土木互容）可能带来关键的财务转折机会和支持。需要综合看待辛苦与贵人支持并存的情况。实例：可能在大型企业从事管理工作，收入稳定但增长较慢，上级领导可能在关键晋升时刻给予支持，带来收入提升机会。"
}
```

**正确示例**：

```json
}
```

### 2.7 整体格局 synthesis

**正确示例**：

```json
{
```

## 五、输出禁忌

### 5.1 禁止格式

```json
// ✗ 禁止打分
"regular_wealth_synthesis": "正财：3分"
"wealth_score": 4

// ✗ 禁止笼统表述
"regular_wealth_synthesis": "财运一般"
"wealth_environment_synthesis": "理财环境还可以"

// ✗ 禁止无实例
"height_synthesis": "财运好，收入稳定"

// ✗ 禁止模糊时间
"key_periods": [{"period": "近期", "event": "..."}]

// ✗ 禁止正财偏财混淆
"wealth_synthesis": "财运好"  ✗ 必须区分正财和偏财
```

---

### 5.2 正确原则

```
1. 正财偏财分开 → 禁止混淆判断
2. 具体描述 > 笼统表述
3. 实例说明 > 空洞判断
4. 数据支撑 > 主观臆断
5. 明确时间 > 模糊表述
6. 可操作建议 > 空洞建议
```

## 八、常见错误警示

| 错误认知 | 正确认知 |
|----------|----------|
| 八宫是凶宫=财运差 | 八宫是偏财宫，得吉时偏财好 |
| 二宫主落陷=没钱 | 要看是否有贵星结构弥补 |
| 钱多=财运好 | 要看财富来源是否稳定 |
| 五宫好=投机一定能赚钱 | 五宫只是投机运，不保证一定赚钱 |
| 正财好=偏财也好 | 正财偏财必须分开判断，方法不同 |
