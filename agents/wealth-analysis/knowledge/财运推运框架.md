## 二、法达大运财运判断

### 2.1 法达主运与财运

| 主运行星 | 财运基调 | 具体表现 |
|----------|----------|----------|
| **太阳** | 财运贵气期 | 获得认可、收入提升、贵人资助 |
| **月亮** | 财运流动期 | 变动较多、需要适应、情绪消费 |
| **水星** | 财运学习期 | 技能提升、副业机会、沟通生财 |
| **金星** | 财运顺遂期 | 收入稳定、享受增加、贵人支持 |
| **火星** | 财运竞争期 | 竞争激烈、需要行动、冲动消费 |
| **木星** | 财运扩张期 | 机会扩展、投资运强、贵人资助 |
| **土星** | 财运考验期 | 收缩压力、需要积累、延迟满足 |
| **北交点** | 财运成长期 | 成长方向、业力推动 |

### 2.2 法达与二宫主星关系

```
【判断方法】
├─ 法达主运行星与二宫主星的关系
│   ├─ 接纳/互容 → 财运强
│   ├─ 吉相位 → 财运顺遂
│   ├─ 凶相位 → 财运有挑战
│   └─ 无关系 → 中等影响
│
└─ 法达主运行星主什么宫位
    ├─ 主二宫 → 财运焦点期
    ├─ 主吉宫 → 财运有助力
    └─ 主凶宫 → 财运有阻碍
```

### 2.3 法达财运关键期判断

| 法达配置 | 财运判断 |
|----------|----------|
| 法达主运 = 二宫主星 | 正财关键转折期，需重点关注 |
| 法达主运 = 八宫主星 | 偏财关键转折期，投资机会 |
| 法达主运接纳二宫主星 | 财运贵人期，有支持 |
| 法达主运与二宫主星互容 | 财运双向发展期 |
| 法达主运刑冲二宫主星 | 财运考验期，有挑战 |
| 法达主运主吉宫 | 财运有外部助力 |
| 法达主运主凶宫 | 财运需克服阻碍 |

## 三、小限法财运判断

### 3.1 小限走宫与财运

| 小限宫位 | 年度财运主题 | 重点关注 |
|----------|--------------|----------|
| **一宫年** | 自我发展年 | 个人创业、自我投资 |
| **二宫年** | **正财焦点年** | **收入提升、理财规划** |
| **三宫年** | 沟通学习年 | 副业机会、技能变现 |
| **四宫年** | 家庭根基年 | 房产、家庭资助 |
| **五宫年** | 投机投资年 | 投资机会、风险投资 |
| **六宫年** | 工作收入年 | 工作稳定、薪资提升 |
| **七宫年** | 合作财年 | 合伙收入、客户关系 |
| **八宫年** | **偏财焦点年** | **投资、他人资源** |
| **九宫年** | 扩展远行年 | 外贸、远方机会 |
| **十宫年** | 事业财年 | 事业收入、名声收益 |
| **十一宫年** | 人脉财年 | 社交、群体收益 |
| **十二宫年** | 隐秘财年 | 幕后收益、隐性收入 |

### 3.2 二宫年（余数2）财运判断

```
【小限二宫年特征】
├─ 正财成为年度焦点
├─ 可能的收入提升
├─ 理财规划重要期
├─ 消费观念变化
└─ 财务状况调整

【判断要点】
├─ 年主星（二宫主星）状态
│   ├─ 庙旺 → 财运年顺遂
│   └─ 落陷 → 财运年有挑战
│
├─ 年主星与命主星关系
│   ├─ 和谐 → 财运发展顺畅
│   └─ 紧张 → 财运有压力
│
└─ 二宫内行星状态
    ├─ 吉星 → 财运有助力
    └─ 凶星 → 财运有阻碍
```

### 3.3 八宫年（余数8）偏财判断

```
【小限八宫年特征】
├─ 偏财成为年度焦点
├─ 投资机会增加
├─ 他人资源关系重要
├─ 风险与机会并存
└─ 财务转变期

【判断要点】
├─ 八宫主星状态
├─ 八宫内行星
└─ 与二宫的关系
```

## 四、法达+小限配合判断

### 4.1 双重触发

```
【最强财运期】
├─ 法达主运 = 二宫主星
│   AND
└─ 小限走二宫年
    → 正财重大转折期，必须重点关注

【财运贵人期】
├─ 法达主运接纳二宫主星
│   AND
└─ 小限走吉宫年
    → 财运有贵人支持，顺遂期

【财运考验期】
├─ 法达主运刑冲二宫主星
│   AND
└─ 小限走凶宫年
    → 财运压力大，需谨慎应对
```

### 4.2 财运时间线分析

```
【判断流程】
Step 1: 确定当前年龄
    │
    ├─ 计算法达主运/子运
    └─ 计算小限宫位

Step 2: 判断法达与财运关系
    │
    ├─ 主运行星与二宫主星关系
    └─ 主运行星宫性判断

Step 3: 判断小限与财运关系
    │
    ├─ 小限宫位是否为二宫/八宫
    └─ 年主星状态判断

Step 4: 综合财运运势
    │
    ├─ 法达基调
    ├─ 小限主题
    └─ 输出财运判断
```
