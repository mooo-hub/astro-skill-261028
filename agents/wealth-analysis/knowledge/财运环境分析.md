# 财运环境分析

财运环境分析是财运专项分析的第二步，包含**数据收集**和**财富环境维度判断**两部分。

---

## 一、数据收集

### 1.1 二宫环境数据收集

```
Step 1: 确定二宫宫头星座
    └─ 输出：二宫宫头星座名称

Step 2: 确定二宫主星（财星）
    ├─ 查表：二宫宫头星座 → 古典守护星
    └─ 输出：财星名称

Step 3: 收集财星状态数据
    ├─ 落入星座 → 能量状态（庙旺/落陷/普通）
    ├─ 落入宫位 → 宫性（吉宫/凶宫）
    ├─ 宫主星身份 → 后天宫性（主几宫）
    ├─ 先天性质 → 吉星/凶星/中性
    └─ 输出：财星完整数据

Step 4: 收集二宫宫内星数据 ★四维度分析★
    ├─ 列出二宫内所有行星
    ├─ 对每个宫内星执行四维度分析：
    │   ├─ 先天星性（吉/凶/中性）
    │   ├─ 后天宫性（主吉宫/主凶宫）
    │   ├─ 能量状态（庙旺/落陷/普通）
    │   └─ 结构关系（相位）
    └─ 输出：二宫宫内星列表

Step 5: 收集财星相位数据 ★核心★
    ├─ 财星与其他行星的相位
    └─ 财星与六宫主、十宫主的关系
```

**二宫宫内星环境影响表**：

| 行星落入二宫 | 理财环境特质 | 消费倾向 | 储蓄能力 |
|------------|-------------|---------|---------|
| 太阳 | 有贵气理财环境 | 好面子消费 | 中等储蓄 |
| 月亮 | 情感导向理财 | 情感消费 | 波动储蓄 |
| 水星 | 灵活理财环境 | 理性消费 | 计划储蓄 |
| 金星 | 艺术享受理财 | 美感消费 | 享受优先 |
| 火星 | 竞争型理财 | 冲动消费 | 快进快出 |
| 木星 | 扩张型理财 | 大方消费 | 有储蓄潜力 |
| 土星 | 保守型理财 | 节俭消费 | 强制储蓄 |

### 1.2 八宫环境数据收集

```
Step 1: 确定八宫宫头星座

Step 2: 确定八宫主星（偏财星）
    ├─ 查表：八宫宫头星座 → 古典守护星
    └─ 输出：偏财星名称

Step 3: 收集偏财星状态数据
    ├─ 落入星座 → 能量状态
    ├─ 落入宫位 → 宫性
    ├─ 宫主星身份 → 后天宫性
    ├─ 先天性质 → 吉星/凶星/中性
    └─ 输出：偏财星完整数据

Step 4: 收集八宫宫内星数据
    ├─ 列出八宫内所有行星
    └─ 对每个宫内星执行四维度分析

Step 5: 收集八宫与二宫的关系
    ├─ 相位关系
    └─ 接纳/互容关系
```

| 配置 | 投资环境影响 | 风险特质 | 具体表现 |
|------|-------------|---------|---------|
| 八宫得吉 | 投资环境有利 | 中低风险 | 投资容易获利 |
| 八宫受克 | 投资环境有挑战 | 高风险 | 投资需谨慎 |
| 八宫主落吉宫 | 投资渠道畅通 | 中等风险 | 有外部支持 |
| 八宫主落凶宫 | 投资渠道受限 | 高风险 | 需克服障碍 |
| 八宫有吉星 | 投资有助力 | 中低风险 | 有人脉资源 |
| 八宫有凶星 | 投资有阻力 | 高风险 | 需独立判断 |

## 二、财富环境维度判断

### 2.1 理财环境判断

```
Step 1: 分析二宫整体状态
    ├─ 财星状态 → 理财能力基础
    │   ├─ 庙旺 → 理财能力强
    │   ├─ 普通 → 理财能力一般
    │   └─ 落陷 → 理财能力受限
    │
    ├─ 二宫内行星 → 理财风格
    │   ├─ 吉星入内 → 理财有助力
    │   └─ 凶星入内 → 理财有阻力
    │
    └─ 二宫宫头星座 → 理财倾向
        ├─ 土象 → 稳健理财
        ├─ 火象 → 积极理财
        ├─ 风象 → 灵活理财
        └─ 水象 → 直觉理财

Step 2: 分析财星落宫的理财环境
    ├─ 财星落始宫 → 理财环境稳定
    ├─ 财星落续宫 → 理财环境中等
    └─ 财星落果宫 → 理财环境不稳

Step 3: 分析支持结构
    ├─ 财星得吉星结构 → 理财有外部支持
    └─ 财星受凶星结构 → 理财需克服阻力

Step 4: 输出理财环境判断
```

**理财环境判断表**：

| 理财环境 | 特征 | 具体表现 | 建议 |
|---------|------|---------|------|
| **稳健型** | 财星庙旺+土象强 | 理财保守、重储蓄 | 长期稳健投资 |
| **积极型** | 财星庙旺+火象强 | 理财积极、敢冒险 | 可适度激进投资 |
| **灵活型** | 财星庙旺+风象强 | 理财灵活、分散配置 | 多元化投资组合 |
| **直觉型** | 财星庙旺+水象强 | 理财凭直觉、情绪化 | 需理性控制 |
| **保守型** | 财星受克+凶宫 | 理财受限、需谨慎 | 以储蓄为主 |
| **挑战型** | 财星落陷+凶结构 | 理财有阻力、需学习 | 提升理财知识 |

### 2.2 消费环境判断

```
Step 1: 分析二宫内金星状态（如有）
    ├─ 金星状态 → 消费倾向
    │   ├─ 庙旺 → 消费有品质
    │   └─ 落陷 → 消费可能过度
    │
    └─ 金星与财星关系 → 消费决策风格

Step 2: 分析月亮状态
    ├─ 月亮状态 → 情感消费倾向
    │   ├─ 庙旺 → 情感消费适中
    │   └─ 落陷 → 情感消费可能过度
    │
    └─ 月亮与二宫关系 → 消费稳定性

Step 3: 分析二宫宫头星座
    ├─ 土象星座 → 消费保守
    ├─ 火象星座 → 消费冲动
    ├─ 风象星座 → 消费理性
    └─ 水象星座 → 消费情感化

Step 4: 输出消费环境判断
```

**消费环境判断表**：

| 消费类型 | 特征 | 消费风格 | 建议 |
|---------|------|---------|------|
| **理性型** | 风象强+水星得吉 | 理性消费、比较决策 | 保持理性习惯 |
| **情感型** | 水象强+月亮受克 | 情感消费、情绪购物 | 控制情绪消费 |
| **冲动型** | 火象强+火星受克 | 冲动消费、说买就买 | 延迟消费决策 |
| **享受型** | 金星庙旺+二宫关联 | 品质消费、重享受 | 预算控制 |
| **节俭型** | 土象强+土星得吉 | 节俭消费、重储蓄 | 适度享受 |
| **面子型** | 太阳受克+二宫关联 | 面子消费、重形象 | 内在价值优先 |

### 2.3 投资环境判断

```
Step 1: 分析八宫整体状态
    ├─ 八宫主星状态 → 投资能力基础
    │   ├─ 庙旺 → 投资能力强
    │   └─ 落陷 → 投资能力受限
    │
    ├─ 八宫内行星 → 投资风格
    │   ├─ 吉星入内 → 投资有助力
    │   └─ 凶星入内 → 投资有阻力
    │
    └─ 八宫宫头星座 → 投资倾向

Step 2: 分析八宫与二宫的关系
    ├─ 八宫主飞入二宫 → 投资可带来财富
    ├─ 八宫主与财星有吉相位 → 投资顺遂
    ├─ 八宫主与财星有凶相位 → 投资过程艰辛
    └─ 无直接关系 → 偏财影响较小

Step 3: 分析五宫状态（投机运）
    ├─ 五宫得吉 → 投机运好
    └─ 五宫受克 → 投机需谨慎

Step 4: 输出投资环境判断
```

**投资环境判断表**：

| 投资环境 | 特征 | 投资风格 | 风险等级 | 建议 |
|---------|------|---------|---------|------|
| **激进型** | 八宫得吉+火象强 | 积极投资、敢冒险 | 高风险 | 控制仓位 |
| **稳健型** | 八宫得吉+土象强 | 稳健投资、重配置 | 中低风险 | 长期持有 |
| **灵活型** | 八宫得吉+风象强 | 灵活投资、分散配置 | 中等风险 | 动态调整 |
| **保守型** | 八宫受克+土象强 | 保守投资、重储蓄 | 低风险 | 以储蓄为主 |
| **谨慎型** | 八宫受克+凶结构 | 谨慎投资、控制风险 | 避免高风险 | 提升投资知识 |
| **投机型** | 五宫得吉+木星支持 | 投机运好、可尝试 | 中高风险 | 适度投机 |

## 三、财富环境综合判断

### 3.1 综合判断公式

```
财富环境 = 二宫环境 + 八宫环境 + 支持宫位环境 + 财星结构环境

【具体维度】
├─ 理财环境：二宫整体状态
├─ 消费环境：金星/月亮状态
├─ 投资环境：八宫整体状态
└─ 来源环境：财星飞宫+结构关系
```

### 3.2 环境评分参考

| 维度 | 高分条件 | 中分条件 | 低分条件 |
|------|----------|----------|----------|
| **理财环境** | 财星庙旺+吉宫+吉结构 | 财星普通+中等结构 | 财星落陷+凶宫+凶结构 |
| **消费环境** | 金星得吉+理性星座 | 金星普通+中性星座 | 金星受克+情绪星座 |
| **投资环境** | 八宫得吉+吉宫+五宫得吉 | 八宫普通+中性配置 | 八宫受克+凶配置 |
| **来源环境** | 始宫+吉宫支持+多元结构 | 续宫+中性支持 | 果宫+凶宫+无支持 |
