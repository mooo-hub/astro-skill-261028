# 婚姻质量分析

婚姻质量分析是感情专项分析的第二步，判断两人关系的和谐程度、幸福度和稳定度。

## 一、核心概念

### 1.1 婚姻质量的定义

```
┌──────────────────────────────────────────────────────────────┐
│              婚姻质量判断                                      │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【定义】                                                    │
│  ├─ 两人关系的和谐程度                                       │
│  ├─ 幸福度、甜度、稳定度                                     │
│  └─ 主要看七宫主与命主星的关系                               │
│                                                              │
│  【回答的问题】                                              │
│  └─ 我们过得怎么样？                                         │
│                                                              │
│  【重要区分】                                                │
│  ├─ 配偶能力强 ≠ 婚姻质量好                                 │
│  │   └─ 可能嫁入豪门但各玩各的                             │
│  └─ 配偶能力弱 ≠ 婚姻质量差                                 │
│       └─ 可能贫贱夫妻但相濡以沫                             │
│                                                              │
│  【四种组合】                                                │
│  ├─ 高+高：嫁入豪门，婚姻幸福                                │
│  ├─ 高+低：嫁入豪门，但各玩各的                              │
│  ├─ 低+高：贫贱夫妻，相濡以沫                                │
│  └─ 低+低：贫贱夫妻，感情不好                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 日生盘与夜生盘的征象星区别

```
┌──────────────────────────────────────────────────────────────┐
│            日夜盘夫妻星取用规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【判断方法】                                                │
│  ├─ 日生盘：太阳在地平线（ASC-DSC线）之上（7-12宫）         │
│  └─ 夜生盘：太阳在地平线（ASC-DSC线）之下（1-6宫）         │
│                                                              │
│  【夫妻星取用表】                                            │
│  ┌─────────────┬─────────────┬─────────────┐                  │
│  │    项目     │   日生盘   │   夜生盘   │                  │
│  ├─────────────┼─────────────┼─────────────┤                  │
│  │ 丈夫征象    │   太阳     │   土星     │                  │
│  │ 妻子征象    │   金星     │   月亮     │                  │
│  └─────────────┴─────────────┴─────────────┘                  │
│                                                              │
│  【重要理解】                                                │
│  ├─ 夫妻星 ≠ 七宫主星（概念不同）                           │
│  ├─ 夫妻星 = 日生/夜生盘决定的征象星                        │
│  ├─ 七宫主星 = 七宫（配偶宫）的宫主星                       │
│  └─ 两者都要看，影响不同方面                                │
│                                                              │
│  【判断要点】                                                │
│  ├─ 夫妻星状态影响婚姻质量和心理感受度                     │
│  └─ 七宫主星影响配偶能力和财富来源                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、婚姻质量判断思维链

### 2.1 完整思维链

```
┌──────────────────────────────────────────────────────────────┐
│            婚姻质量判断完整思维链                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一步】看七宫是否受克                                     │
│    │                                                         │
│    ├─ 判断标准                                              │
│    │   ├─ 得吉、落吉宫 → 好                                │
│    │   ├─ 受克、落凶宫 → 差                                │
│    │   └─ 凶星入内 → 有问题                                │
│    │                                                         │
│    └─ 凶星入七宫的影响                                     │
│        ├─ 土星：压制、冷淡、冷暴力                          │
│        └─ 火星：冲突、暴力倾向                              │
│                                                              │
│  【第二步】看日月与夫妻星的关系（★ 最关键 ★）                │
│    │                                                         │
│    ├─ 核心概念                                              │
│    │   └─ 太阳/月亮/命主星与夫妻星的相位关系                │
│    │       影响心理感受度和幸福度                           │
│    │                                                         │
│    ├─ 不同相位类型的具体影响                                │
│    │   ├─ 接纳/互容：感受度最佳，婚姻幸福度高，内心满足      │
│    │   ├─ 三合/六合：感受度良好，婚姻较顺遂，有助力         │
│    │   ├─ 合相：能量融合，与配偶特质相近，但可能过度依赖   │
│    │   ├─ 刑相：有张力，婚姻有摩擦，需要磨合                │
│    │   ├─ 冲相：有对立，婚姻有冲突，可能分离倾向            │
│    │   └─ 无相位：无关联，婚姻感受淡漠，缺乏情感连接        │
│    │                                                         │
│    └─ 重要提醒                                              │
│        ├─ 感情脆弱，心理体验占大部分                        │
│        ├─ 可能没什么大矛盾但离婚                           │
│        └─ 刑冲相位不一定导致离婚，要看是否有吉星化解        │
│                                                              │
│  【第三步】看月亮与夫妻星的关系                              │
│    │                                                         │
│    ├─ 月亮决定幸福感知度                                   │
│    │   ├─ 月亮与夫妻星和谐 → 内心满足、懂得珍惜            │
│    │   ├─ 月亮与夫妻星刑冲 → 内心不满、挑剔伴侣            │
│    │   └─ 月亮被刑克严重 → 容易不满意、不懂惜福           │
│    │                                                         │
│    └─ 月亮受克的婚姻表现                                   │
│        ├─ 即使客观条件好，主观感受也不佳                   │
│        ├─ 容易对配偶挑剔、不满                              │
│        └─ 走月亮运时可能因感情问题离婚                      │
│                                                              │
│  【第四步】看夫妻星本身的星性和能量状态                      │
│    │                                                         │
│    ├─ 夫妻星本身的星性                                     │
│    │   ├─ 太阳（日生盘夫星）：配偶有贵气、领导特质         │
│    │   ├─ 土星（夜生盘夫星）：配偶稳重、压力大、年龄偏大   │
│    │   ├─ 金星（日生盘妻星）：配偶有美感、人缘好           │
│    │   └─ 月亮（夜生盘妻星）：配偶温柔、顾家、情绪化       │
│    │                                                         │
│    ├─ 夫妻星庙旺落陷                                       │
│    │   ├─ 入庙：夫妻特质鲜明、婚姻有助力                   │
│    │   ├─ 入旺：夫妻有明显优势、婚姻有贵气                 │
│    │   ├─ 落陷：夫妻特质受限、婚姻感受度差                 │
│    │   └─ 重要：夫妻星落陷≠婚姻失败，要看是否有贵星弥补   │
│    │                                                         │
│    └─ 夫妻星不见（落暗宫）                                 │
│        ├─ 含义：夫妻星落入八宫或十二宫                     │
│        ├─ 看不到、暗宫、不见光                             │
│        ├─ 对婚姻有阻碍                                     │
│        ├─ 可能晚婚、难婚                                   │
│        └─ 配偶可能有隐秘问题                               │
│                                                              │
│  【第五步】看感情征象星是否不良                             │
│    │                                                         │
│    └─ 不良指标                                             │
│        ├─ 与南交点合相：不世俗、有隐匿特质，婚姻不符合世俗规范 │
│        ├─ 逆行：不稳定，婚姻有变动                         │
│        ├─ 被灼烧：隐匿特质，配偶有隐秘特质、接近权贵       │
│        ├─ 落入暗宫（八宫、十二宫）：不见光，婚姻有阻碍、隐秘问题 │
│        └─ 落陷：能量弱，感情不顺、感受度差                 │
│                                                              │
│  【第六步】看水象星座特质（补充）                            │
│    │                                                         │
│    ├─ 水象星座对感情需求的影响                             │
│    │   ├─ 双鱼、天蝎、巨蟹                                 │
│    │   ├─ 对感情要求高，不是物质要求，而是情感回馈         │
│    │   ├─ 需要感情滋润，没有感情觉得活着没意义            │
│    │   └─ 在乎对方是否疼爱自己                             │
│    │                                                         │
│    └─ 判断要点                                             │
│        ├─ 群星水象 → 感情需求高、婚姻感受度敏感           │
│        ├─ 群星火象/土象 → 感情需求相对较低、不过度内耗   │
│        └─ 水象星座+月亮受克 → 感情问题最严重             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、七宫受克判断表

| 七宫状态 | 判断标准 | 具体表现 |
|----------|----------|----------|
| **得吉** | 吉星入内/吉相位支持 | 婚姻顺遂，有助力 |
| **中性** | 无吉无凶 | 婚姻平淡，需经营 |
| **受克** | 凶星刑冲/落凶宫 | 婚姻有阻碍，有挑战 |
| **严重受克** | 三重凶叠加 | 婚姻有重大问题 |

---

## 四、日月与夫妻星关系表

| 相位类型 | 感受度判断 | 具体表现 |
|----------|------------|----------|
| **接纳/互容** | 最佳 | 内心满足，婚姻幸福 |
| **三合/六合** | 良好 | 婚姻顺遂，有助力 |
| **合相** | 融合 | 与配偶特质相近 |
| **刑相** | 张力 | 婚姻有摩擦，需磨合 |
| **冲相** | 对立 | 婚姻有冲突，需协调 |
| **无相位** | 淡漠 | 缺乏情感连接 |

---

## 五、水象星座特质影响

| 星座分布 | 感情需求 | 婚姻特点 |
|----------|----------|----------|
| **群星水象** | 高需求、高敏感 | 需要情感回馈 |
| **群星火象** | 中等需求 | 重行动、不内耗 |
| **群星土象** | 中等需求 | 重实际、稳定 |
| **群星风象** | 中等需求 | 重沟通、灵活 |
| **水象+月受克** | 最高敏感度 | 感情问题最严重 |
