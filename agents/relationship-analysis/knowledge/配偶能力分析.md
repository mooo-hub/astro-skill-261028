## 二、配偶能力判断思维链

### 2.1 完整思维链

```
┌──────────────────────────────────────────────────────────────┐
│            配偶能力判断完整思维链                             │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一步】看七宫（配偶宫）                                   │
│    │                                                         │
│    ├─ 1.1 先看宫内星（静态）                                 │
│    │   │                                                     │
│    │   ├─ 七宫里落入什么星体？                               │
│    │   │                                                     │
│    │   └─ 该星体的星性是什么？                               │
│    │       ├─ 吉星（日/月/金/木）入内：配偶有能力、有助力   │
│    │       └─ 凶星（火/土）入内：配偶有问题、有阻碍         │
│    │                                                         │
│    └─ 1.2 再看宫主星（动态）★ 权重更高 ★                    │
│        ├─ 七宫的宫主星是什么？                               │
│        ├─ 宫主星飞入哪个宫位？                               │
│        └─ 代表"配偶财富来自该宫位领域"                      │
│                                                              │
│  【第二步】分析七宫主星结构                                   │
│    │                                                         │
│    ├─ 2.1 看七宫主星与其他行星的相位关系                     │
│    │   │                                                     │
│    │   ├─ 接纳/互容（最紧密，最主要判断依据）               │
│    │   ├─ 合相（两星体能量融合）                            │
│    │   ├─ 刑/冲（有张力和拉锯）                              │
│    │   └─ 三合/六合（"远亲"，作用较弱）                    │
│    │                                                         │
│    └─ 2.2 结构好坏判断公式                                  │
│        │                                                     │
│        └─ 婚姻结构好坏 = 结构类型 + 星性 + 宫性             │
│            ├─ 【好婚姻结构】= 紧密结构 + 吉星 + 吉宫         │
│            ├─ 【坏婚姻结构】= 紧密结构 + 凶星 + 凶宫         │
│            └─ 【中等婚姻结构】= 其他组合                     │
│                                                              │
│  【第三步】分析七宫主星的星性                                 │
│    │                                                         │
│    └─ 七宫主星本身的性质影响配偶特质                        │
│        ├─ 太阳：配偶有贵气、领导特质                         │
│        ├─ 月亮：配偶温柔、顾家、情绪化                       │
│        ├─ 水星：配偶聪明、善于沟通                           │
│        ├─ 金星：配偶有美感、有人缘                           │
│        ├─ 火星：配偶行动力强、竞争性                         │
│        ├─ 木星：配偶有福气、教育背景好                       │
│        └─ 土星：配偶稳重、压力大、年龄偏大                   │
│                                                              │
│  【第四步】分析七宫主星庙旺落陷                               │
│    │                                                         │
│    └─ ★ 重要提醒：庙旺落陷不决定婚姻结果                     │
│        ├─ 入庙：配偶能力强、有助力                          │
│        ├─ 入旺：配偶有掌控力                                │
│        ├─ 落陷：需要其他结构支持                            │
│        └─ 落陷+有贵星接纳=可以弥补                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 五、七宫主与行星结构影响

### 5.1 与吉星的相位

```
【七宫主与吉星形成结构】

├─ 七宫主与太阳接纳/互容
│   ├─ 配偶有贵气、领导支持、有社会地位
│   └─ 太阳是天王级别贵星，配偶得贵人助力
│
├─ 七宫主与月亮接纳/互容
│   ├─ 配偶温柔、顾家、有家庭观念
│   └─ 配偶带来家庭支持、情感满足
│
├─ 七宫主与金星接纳/互容
│   ├─ 配偶有财运、人缘好、有美感
│   └─ 配偶带来财运、社交助力
│
└─ 七宫主与木星接纳/互容
    ├─ 配偶有贵人运、扩张机会、教育背景
    └─ 木星主吉宫=有气；主凶宫=无气（降低贵气）

【关键判断】
├─ 不能只看是吉星，要看该吉星主什么宫位
└─ 同一个木星，主不同宫位，结构好坏不同！

【案例分析】
├─ 木星主1r、4r、5r、9r、10r、11r
│   └─ 木星本身吉+主吉宫=有气，配偶有贵人运，结构好
└─ 木星主3r、6r、8r、12r
    └─ 木星本身吉但主凶宫=无气，降低贵气，配偶助力受限
```

### 5.2 与凶星的相位

```
【七宫主与凶星形成结构】

├─ 七宫主与火星刑冲
│   ├─ 配偶有冲突、竞争、行动力强
│   └─ 要看火星主什么宫位
│       └─ 火星主6宫（宫性凶）= 健康、工作压力问题
│
└─ 七宫主与土星刑冲
    ├─ 配偶有压力、冷淡、年龄偏大
    └─ 要看土星主什么宫位

【关键判断】
├─ 凶星+凶宫+凶相位=三重凶叠加，直接破坏婚姻格局
└─ 例：火星（6r）刑七宫主
    ├─ 火星本身凶（先天凶星）
    ├─ 火星主六宫（宫性凶=健康、工作压力）
    ├─ 刑七宫主（相位凶）
    └─ 三重凶性叠加=配偶健康有问题、工作压力大
```

### 5.3 日月的特殊规则

```
【日月可忽略宫性】

├─ 日月本身就是天王天后级别
├─ 如果日月本身是夫妻星，直接作为贵星参考
└─ 不需要看日月主什么宫位

【规则】
├─ 七宫主与太阳形成结构=配偶有天王级别贵气加持
└─ 七宫主与月亮形成结构=配偶有天后级别贵气加持
```
