# 感情推运分析框架

## 二、法达大运感情判断

### 2.1 法达主运与感情

| 主运行星 | 感情基调 | 具体表现 |
|----------|----------|----------|
| **太阳** | 感情贵气期 | 获得认可、伴侣支持、名声提升 |
| **月亮** | 情感敏感期 | 情感需求强、家庭导向、情绪化 |
| **水星** | 感情沟通期 | 沟通重要、学习期、认识新的人 |
| **金星** | 感情顺遂期 | 桃花运强、婚姻顺遂、享受感情 |
| **火星** | 感情竞争期 | 竞争激烈、冲突可能、行动重要 |
| **木星** | 感情扩张期 | 机会扩展、贵人相助、感情发展 |
| **土星** | 感情考验期 | 压力大、考验多、需要耐心 |
| **北交点** | 感情成长期 | 成长方向、业力推动 |

### 2.2 法达与七宫主星关系

```
【判断方法】
├─ 法达主运行星与七宫主星的关系
│   ├─ 接纳/互容 → 感情运强
│   ├─ 吉相位 → 感情顺遂
│   ├─ 凶相位 → 感情有挑战
│   └─ 无关系 → 中等影响
│
└─ 法达主运行星主什么宫位
    ├─ 主七宫 → 感情焦点期
    ├─ 主吉宫 → 感情有助力
    └─ 主凶宫 → 感情有阻碍
```

### 2.3 法达感情关键期判断

| 法达配置 | 感情判断 |
|----------|----------|
| 法达主运 = 七宫主星 | 婚姻关键转折期，需重点关注 |
| 法达主运 = 金星（女）/火星（男） | 桃花期，恋爱机会 |
| 法达主运接纳七宫主星 | 感情贵人期，有支持 |
| 法达主运与七宫主星互容 | 感情双向发展期 |
| 法达主运刑冲七宫主星 | 感情考验期，有挑战 |
| 法达主运主吉宫 | 感情有外部助力 |
| 法达主运主凶宫 | 感情需克服阻碍 |

| 小限宫位 | 年度感情主题 | 重点关注 |
|----------|--------------|----------|

| **五宫年** | **恋爱焦点年** | **恋爱、桃花、创意** |
| **六宫年** | 工作事务年 | 工作与感情平衡 |

| **八宫年** | 隐秘关系年 | 深度关系、隐秘问题 |
| **九宫年** | 扩展远行年 | 远方缘分、异地恋 |
| **十宫年** | 事业名年 | 事业与婚姻平衡 |
| **十一宫年** | 人脉社年 | 社交、朋友变恋人 |
| **十二宫年** | 隐秘灵年 | 隐秘关系、精神契合 |

### 3.2 七宫年（余数7）感情判断

```
【小限七宫年特征】
├─ 婚姻成为年度焦点
├─ 可能的婚姻大事
├─ 合作关系重要期
├─ 感情转折节点
└─ 与伴侣关系深化

【判断要点】
├─ 年主星（七宫主星）状态
│   ├─ 庙旺 → 感情年顺遂
│   └─ 落陷 → 感情年有挑战
│
├─ 年主星与命主星关系
│   ├─ 和谐 → 感情发展顺畅
│   └─ 紧张 → 感情有压力
│
└─ 七宫内行星状态
    ├─ 吉星 → 感情有助力
    └─ 凶星 → 感情有阻碍
```

### 3.3 五宫年（余数5）恋爱判断

```
【小限五宫年特征】
├─ 恋爱成为年度焦点
├─ 桃花机会增加
├─ 创意、娱乐相关
├─ 子女、投资相关
└─ 恋爱体验丰富

【判断要点】
├─ 五宫主星状态
├─ 五宫内行星
└─ 与七宫的关系
```

## 四、法达+小限配合判断

### 4.1 双重触发

```
【最强感情期】
├─ 法达主运 = 七宫主星
│   AND
└─ 小限走七宫年
    → 婚姻重大转折期，必须重点关注

【感情贵人期】
├─ 法达主运接纳七宫主星
│   AND
└─ 小限走吉宫年
    → 感情有贵人支持，顺遂期

【感情考验期】
├─ 法达主运刑冲七宫主星
│   AND
└─ 小限走凶宫年
    → 感情压力大，需谨慎应对
```

### 4.2 感情时间线分析

```
【判断流程】
Step 1: 确定当前年龄
    │
    ├─ 计算法达主运/子运
    └─ 计算小限宫位

Step 2: 判断法达与感情关系
    │
    ├─ 主运行星与七宫主星关系
    └─ 主运行星宫性判断

Step 3: 判断小限与感情关系
    │
    ├─ 小限宫位是否为七宫/五宫
    └─ 年主星状态判断

Step 4: 综合感情运势
    │
    ├─ 法达基调
    ├─ 小限主题
    └─ 输出感情判断
```
