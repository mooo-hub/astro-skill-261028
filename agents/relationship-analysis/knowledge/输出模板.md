## 一、核心分析方法

### 1.1 感情双维度分析法（核心理念）

```
┌──────────────────────────────────────────────────────────────┐
│              感情论断双维度分析法                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心理念：                                                │
│  感情论断需要区分两个不同维度                                 │
│                                                              │
│  【维度一：配偶能力层次】                                     │
│  ├─ 配偶本身的能力、条件、格局                               │
│  ├─ 主要看第七宫                                             │
│  ├─ 配偶的事业、财富、社会地位                               │
│  └─ 回答：另一半是什么样的？                                 │
│                                                              │
│  【维度二：婚姻质量】                                         │
│  ├─ 两人关系的和谐程度                                       │
│  ├─ 幸福度、甜度、稳定度                                     │
│  ├─ 主要看七宫主与命主星的关系                               │
│  └─ 回答：我们过得怎么样？                                   │
│                                                              │
│  ★ 重要区分：                                                │
│  配偶能力强 ≠ 婚姻质量好                                     │
│  配偶能力弱 ≠ 婚姻质量差                                     │
│                                                              │
│  【四种组合】                                                │
│  ├─ 高+高：嫁入豪门，婚姻幸福                                │
│  ├─ 高+低：嫁入豪门，但各玩各的                             │
│  ├─ 低+高：贫贱夫妻，相濡以沫                               │
│  └─ 低+低：贫贱夫妻，感情不好                               │
│                                                              │
│  ★ 注意：贫贱夫妻可能相濡以沫，富贵夫妻可能各玩各的          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 恋爱阻碍判断（★测试验证新增★）

> **新增说明**：此章节用于识别恋爱客观阻碍，判断是否存在影响感情发展的结构性障碍。

```
┌──────────────────────────────────────────────────────────────┐
│              恋爱客观阻碍识别信号                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【核心判断】                                                │
│  恋爱阻碍 = 金星（5r桃花星）落在凶宫（6/8/12）               │
│           + 五宫主飞入凶宫                                   │
│                                                              │
│  【阻碍信号清单】                                            │
│  ├─ ★金星落在8宫（凶宫）→ 恋爱有客观阻碍                    │
│  │   └─ 表现：异性接触机会少                                │
│  │                                                          │
│  ├─ ★金星落在12宫（凶宫）→ 恋爱隐秘/机会少                  │
│  │   └─ 表现：可能暗恋多、表白少                            │
│  │                                                          │
│  ├─ ★金星落在6宫（凶宫）→ 恋爱受限                          │
│  │   └─ 表现：恋爱与工作绑定，机会少                        │
│  │                                                          │
│  ├─ ★五宫主飞入凶宫 → 恋爱条件受限                            │
│  │   └─ 表现：恋爱领域有客观困难                            │
│  │                                                          │
│  └─ 土星（7r）落陷 + 月土刑 → 进展慢、感受不佳              │
│      └─ 表现：有人表白但拒绝/大龄未婚未恋                   │
│                                                              │
│  【判断逻辑】                                                │
│  ├─ 金星落凶宫 + 五宫主飞凶宫 = 阻碍叠加                    │
│  ├─ 阻碍叠加时，桃花评分应降为2分或更低                     │
│  └─ 必须在输出中明确指出"恋爱有客观阻碍"                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**阻碍类型与表现对应表**：

| 阻碍信号 | 现实表现 | 验证方式 |
|----------|----------|----------|
| **金星落8宫** | 几乎没有异性接触机会 | 询问社交圈子情况 |
| **金星落12宫** | 暗恋多、表白少、隐秘关系 | 询问是否有暗恋经历 |
| **金星落6宫** | 恋爱机会与工作绑定 | 询问恋爱是否通过工作 |
| **月土刑** | 有人表白但拒绝/标准高 | 询问是否有拒绝经历 |
| **土星落陷** | 大龄未婚未恋/进展慢 | 询问年龄和恋爱历史 |

**阻碍判断后的输出规范**：

```
【输出要求】

如果识别到恋爱阻碍：
├─ 必须明确输出："恋爱有客观阻碍"
├─ 必须说明阻碍类型："异性接触机会少"或"恋爱条件受限"
├─ 必须给出具体行动建议："每周至少1次社交活动"
└─ 不能笼统表述："桃花一般，需要主动"

【禁止表述】
├─ ✗ 禁止："桃花中等"（实际有阻碍）
├─ ✗ 禁止："需要主动创造机会"（应说明是客观阻碍）
└─ ✗ 禁止：只给评分不说明阻碍原因

【正确表述示例】
├─ ✓ 正确："桃花有客观阻碍（金星落在八宫），异性接触机会少"
├─ ✓ 正确："建议：每周至少参加1次有异性参与的活动"
└─ ✓ 正确："这不是不想恋爱，而是没有机会恋爱，需要主动创造"
```

## 二、Synthesis 字段规范

> **核心要求**：必须是具体描述，禁止打分，必须有实例说明

### 2.1 配偶能力 synthesis

**正确示例**：

```json
{
  "spouse_ability_synthesis": "配偶能力层次中等偏上，七宫主星金星入庙在天秤座，得先天吉星加持。七宫主飞入十宫，配偶事业发展较好，可能从事管理或艺术相关领域。金星与木星形成互容结构，配偶有贵人运，社会关系较好。实例：配偶可能在设计公司或艺术机构担任管理职务，事业发展稳定，有一定社会地位。"
}
```

**错误示例**：

```json
{
  "spouse_ability_synthesis": "配偶能力：4分"  ✗ 禁止打分
  "spouse_ability_synthesis": "配偶能力中等"   ✗ 禁止笼统表述
}
```

---

### 2.2 婚姻质量 synthesis

**正确示例**：

```json
{
  "marriage_quality_synthesis": "婚姻质量中等，存在一定张力。七宫内落土星（8r），带来压制和冷感。月亮与木星（夫妻星）形成刑相，心理感受不佳，可能对配偶有挑剔和不满。但月亮入庙巨蟹座，有情感表达需求，需要配偶给予情感回馈。实例：婚姻中可能表现为日常相处平淡，一方可能感到冷暴力，建议通过定期深度交流来改善。"
}
```

---

### 2.3 桃花 synthesis

**正确示例**：

```json
{
  "peach_blossom_synthesis": "桃花旺度中等，金星与一宫主、七宫主、十一宫主均有相位关联，共关联3个宫位。但金星落陷于天蝎座，桃花质量受限，需要主动创造机会。实例：在工作场合或社交活动中认识新的人，但可能需要更长时间发展关系，不宜急于确定关系。"
}
```

## 五、输出禁忌

### 5.1 禁止格式

```json
// ✗ 禁止打分
"spouse_ability_synthesis": "配偶能力：4分"
"marriage_quality_score": 3

// ✗ 禁止笼统表述
"peach_blossom_synthesis": "桃花一般"
"marriage_quality_synthesis": "婚姻还可以"

// ✗ 禁止无实例
"spouse_ability_synthesis": "配偶能力较强，有社会地位"

// ✗ 禁止模糊时间
"key_periods": [{"period": "近期", "event": "..."}]
```

---

### 5.2 正确原则

```
1. 具体描述 > 笼统表述
2. 实例说明 > 空洞判断
3. 数据支撑 > 主观臆断
4. 明确时间 > 模糊表述
5. 可操作建议 > 空洞建议
```

## 六、具体化输出要求

### 6.1 感情分析具体化要求

| 分析维度 | 具体化要求 | 示例 |
|----------|------------|------|
| **桃花机会** | 具体时间+行动方法+场合建议 | "2026年9-11月感情能量高峰，具体行动：①每周参加1次兴趣社群活动（如读书会、运动群）；②让朋友介绍1-2个新认识的人；③选择有共同兴趣的场合（如心理学讲座）" |
| **伴侣选择** | 具体标准+筛选条件 | "具体标准：①能理解你边界需求（如尊重你19点后的个人时间）；②支持你事业发展；③内在品质重于外在条件；④不需要大量家庭时间投入" |
| **婚姻经营** | 具体方法+频率+时间 | "婚姻经营方法：①每周固定2小时深度交流时间（建议周六下午）；②财务上保持透明，每月初讨论家庭收支；③遇到分歧时，选择非工作时间讨论（避免工作压力影响）" |
| **时间节点** | 具体年月+能量状态+建议 | "2027年七宫年（小限），婚姻关系成为焦点，具体时间：3-5月、9-11月感情能量高峰，建议在这些月份主动社交或深化关系" |

### 6.2 抽象表述禁止清单

```
❌ 禁止表述                          → ✅ 具体化要求

"桃花弱，需要主动"                   → "感情方面需要主动创造机会，具体行动：每周参加1次兴趣社群活动，每月让朋友介绍1-2个新认识的人"
"选择合适的人"                       → "具体标准：①能理解你边界需求；②支持你事业发展；③内在品质重于外在条件"
"婚姻需要经营"                       → "婚姻经营方法：①每周固定2小时深度交流时间；②每月初讨论家庭收支；③遇到分歧选择非工作时间讨论"

"注意感情问题"                       → "具体注意：水土刑相可能带来沟通问题，建议每周至少1次深度交流"
"降低对配偶的期待"                   → "伴侣可能在某些方面需要你的支持，建议：关注内在品质而非外在条件"
```

## 七、常见错误警示

| 错误认知 | 正确认知 |
|----------|----------|
| 配偶能力强=婚姻幸福 | 配偶能力和婚姻质量是两个维度，必须分开判断 |
| 配偶能力弱=婚姻不幸 | 贫贱夫妻可能相濡以沫，富贵夫妻可能各玩各的 |
| 七宫主落陷=配偶不好 | 要看是否有贵星结构弥补 |
| 桃花评分高=容易恋爱 | 需要检查是否有恋爱阻碍信号（金星落凶宫） |
| 金星状态好=桃花旺 | 需要综合五宫、金星相位、宫位关联 |
