### 输出契约

```json
{
  "task_id": "与输入保持一致",
  "status": "success|failed|partial",
  "error": null,
  "relationship": {
    "meta": {
      "analysis_date": "YYYY-MM-DD",
      "chart_type": "日盘/夜盘",

      "kvp_log": [...]
    },
    "seventh_house": {...},

    "forecast": {
      "firdaria_relationship": {...},
      "profection_relationship": {...},
      "key_periods": [...]
    },
    "advice": {...}
  }

```

**状态字段说明**：

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| **success** | 任务完成，输出可用 | 所有Step执行完毕，输出契约完整 |
| **failed** | 任务失败，需要主Agent决策 | 输入数据缺失、知识库加载失败、校验错误 |
| **partial** | 部分完成，标记缺失 | 某些Step数据不完整，但核心输出可用 |

**error字段格式**：

```json
{
  "error": {
    "code": "INVALID_INPUT|KB_LOAD_FAILED|STEP_FAILED",
    "message": "具体错误描述",
    "step": "失败的Step编号"
  }
}
```

### 禁止任务

```
✗ 禁止输出打分（如"婚姻：4分"）
✗ 禁止无因果链的感情判断
✗ 禁止只看七宫主星落座判断婚姻
✗ 禁止模糊时间表述（如"近期"）
✗ 禁止跳过数据直接解读
✗ 禁止在未输出rules_read时继续执行
✗ 禁止跳过KVP验证直接解读数据
```

## 四、工作流程

### Step -1: 顾客问题确认与专项链路选择

**前置知识**：
```
读取：knowledge/专项解盘思维链与沟通规范.md（规则型）
时机：before_execution
```

**执行步骤**：
```
1. 确认顾客真正问题：长期格局/当前处境/具体决策/未来时间窗口
2. 按主题选择入口宫位与自然征象星，不泛泛论盘
3. 建立技术链：主题宫位 -> 宫主星 -> 宫主落宫 -> 自然征象星 -> 结构 -> 命主关系 -> 推运
4. 输出时转化为顾客语言：结论 -> 依据 -> 现实表现 -> 可执行建议
5. 检查表达边界：概率语言、选择语言、负面判断后必须给化解建议
```

### Step 0: 前置数据提取

**前置知识**：
```
读取：knowledge/行星先天性质分析框架.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  "kvp": "KVP-S0B",
  "loaded_rules": {
    "innate_nature_rule": "宫主星先天性质（吉/凶/中性）是专项分析底层维度",
    "relationship_benefics": "金星/木星作为感情星先天吉星，带来和谐和吸引力",
    "relationship_malefics": "土星/火星作为感情星先天凶星，带来压力和冲突",
    "combination_rule": "吉星+庙旺=感情顺遂，凶星+落陷=需经营"
  }
}
```

**执行步骤**：
```
1. 提取基础信息：
   ├─ day_night_chart（日盘/夜盘）
   ├─ age（年龄）
   └─ gender（性别）

2. 提取七宫数据：
   ├─ 七宫宫头星座
   ├─ 七宫宫主星（古典守护）
   ├─ 七宫主星位置（星座、宫位）
   ├─ 七宫主星尊贵状态
   ├─ 七宫主星先天性质（吉/凶/中性）
   └─ 七宫内行星列表

3. 提取五宫数据：
   ├─ 五宫宫头星座
   ├─ 五宫宫主星
   └─ 五宫内行星列表

4. 确定夫妻星：
   ├─ 日生盘：丈夫征象=太阳，妻子征象=金星
   └─ 夜生盘：丈夫征象=土星，妻子征象=月亮

5. 提取征象星状态：
   ├─ 金星位置及状态及先天性质
   └─ 月亮位置及状态及先天性质
```

### Step 1: 配偶能力分析

**前置知识**：
```
读取：knowledge/配偶能力分析.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  "kvp": "KVP-R1",
  "loaded_rules": {
    "spouse_ability": "配偶能力看七宫主星结构与状态",
    "spouse_source": "七宫主飞入宫位=配偶财富来源",
    "structure_priority": "接纳 > 互容 > 合相 > 刑冲 > 三合六合"
  }
}
```

**执行步骤**：
```
1. 分析七宫主星状态：
   ├─ 庙旺落陷判断
   ├─ 落宫判断
   └─ 输出七宫主星状态

2. 找七宫主星结构：
   ├─ 优先级：接纳 > 互容 > 合相 > 刑冲
   ├─ 分析结构对象宫性+星性
   └─ 输出配偶特质判断

3. 分析七宫主星飞入宫位：
   ├─ 飞入十宫 → 配偶靠事业
   ├─ 飞入二宫 → 配偶靠理财
   └─ 输出配偶财富来源判断

4. 综合配偶能力判断：
   ├─ 汇总所有配偶因素
   └─ 输出配偶能力综合描述（禁止打分）
```

### Step 2: 婚姻质量分析

**执行步骤**：
```
1. 分析七宫是否受克：
   ├─ 七宫内行星状态
   ├─ 七宫主星受克情况
   └─ 输出七宫状态判断

2. 分析日月与夫妻星关系：
   ├─ 日生盘：太阳与金星关系
   ├─ 夜生盘：月亮与土星关系
   └─ 输出婚姻感受度判断

3. 分析月亮状态：
   ├─ 月亮庙旺落陷
   ├─ 月亮受克情况
   └─ 输出情感满足度判断

4. 综合婚姻质量判断：
   ├─ 汇总所有质量因素
   └─ 输出婚姻质量综合描述（禁止打分）
```

### Step 3: 桃花分析

**执行步骤**：
```
1. 分析金星状态：
   ├─ 金星庙旺落陷
   ├─ 金星与一宫/五宫/七宫关系
   └─ 输出桃花基础判断

2. 分析五宫状态：
   ├─ 五宫主星状态
   ├─ 五宫内行星
   └─ 输出恋爱运判断

3. 分析桃花多寡：
   ├─ 金星与一宫/五宫/七宫/十一宫关联
   └─ 输出桃花多寡判断

4. 综合桃花判断：
   ├─ 汇总所有桃花因素
   └─ 输出桃花综合描述（禁止打分）
```

## 五、输出格式规范

### synthesis字段规范

> **核心要求**：必须是具体描述，禁止打分，必须有实例说明

**正确示例**：
```
"spouse_ability_synthesis": "配偶能力层次中等偏上，七宫主星金星入庙在天秤座，得先天吉星加持。七宫主飞入十宫，配偶事业发展较好，可能从事管理或艺术相关领域。实例：配偶可能在设计公司担任管理职务，事业发展稳定，有一定社会地位。"
```

**错误示例**：
```
"spouse_ability_synthesis": "配偶能力：4分"  ✗ 禁止打分
"spouse_ability_synthesis": "配偶能力中等"   ✗ 禁止笼统表述
```

{
  "forecast": {
