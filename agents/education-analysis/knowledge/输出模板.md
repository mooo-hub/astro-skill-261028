## 一、核心输出结构

```json
{
  "education": {
    "meta": {
      "analysis_date": "YYYY-MM-DD",
      "chart_type": "日盘/夜盘",
      "analysis_scope": "完整分析/简化分析",
      "kvp_log": [...]
    },
    "ninth_house": {...},
    "third_house": {...},
    "education_level_synthesis": "学历层次综合判断...",
    "exam_fortune_synthesis": "考试运综合判断...",
    "education_field": "学业领域方向",
    "forecast": {...},
    "advice": {...}
  }
}
```

## 二、Synthesis 字段规范

> **核心要求**：必须是具体描述，禁止打分，必须有实例说明

### 2.1 学历层次 synthesis

**正确示例**：

```json
{
  "education_level_synthesis": "学历层次较高，九宫主星木星入庙在九宫，得先天贵气，加上太阳与木星形成六合结构，整体格局清纯。这类盘主通常能获得重点本科或硕士学历。例如：可能毕业于985高校的教育学或法律专业，学业发展较为顺利。"
}
```

**错误示例**：

```json
{
  "education_level_synthesis": "学历：4分"  ✗ 禁止打分
  "education_level_synthesis": "学业一般"   ✗ 禁止笼统表述
}
```

---

### 2.2 考试运 synthesis

**正确示例**：

```json
{
  "exam_fortune_synthesis": "考试运较好，九宫主星木星入庙，与水星形成三合结构，考试时思维清晰、发挥稳定。木星被太阳接纳，考试有贵人支持。但土星与九宫主星刑相，大考时有压力感，需要提前准备心理调节。例如：高考可能因为心态调整而超常发挥，考研时导师可能给予重要帮助。"
}
```

## 四、Advice 字段规范

### 4.1 基础格式

```json
{
  "advice": {
    "direction": {
      "suitable": ["教育学", "法律", "哲学", "外语"],
      "avoid": ["需要大量动手操作的专业"],
      "reasoning": "九宫主星木星入庙，适合扩展型、教育型专业"
    },
    "timing": {
      "favorable_window": "法达水星运、小限九宫年",
      "risk_window": "土星回归前后、土星刑冲关键点",
      "reasoning": "水星运学习黄金期，土星周期有压力"
    },
    "action": [
      "在法达水星运期间积极备考",
      "把握小限九宫年的升学机会",
      "注意考前心理调节（土星刑）"
    ]
  }
}
```

## 五、输出禁忌

### 5.1 禁止格式

```json
// ✗ 禁止打分
"education_level_synthesis": "学历：4分"
"education_score": 3

// ✗ 禁止笼统表述
"exam_fortune_synthesis": "考试运一般"
"education_level_synthesis": "学业还可以"

// ✗ 禁止无实例
"education_level_synthesis": "学历较高，名校毕业"

// ✗ 禁止模糊时间
"key_periods": [{"period": "近期", "event": "..."}]
```

---

### 5.2 正确原则

```
1. 具体描述 > 笼统表述
2. 实例说明 > 空洞判断
3. 数据支撑 > 主观臆断
4. 明确时间 > 模糊表述
5. 可操作建议 > 空洞建议
```

## 六、具体化输出要求

### 6.1 学业分析具体化要求

| 分析维度 | 具体化要求 | 示例 |
|----------|------------|------|
| **学历层次** | 具体学历+实例学校+专业方向 | "重点本科或硕士学历，例如：可能毕业于985高校的教育学或法律专业" |
| **考试运** | 具体考试类型+表现特征+建议 | "高考发挥稳定，考研时导师可能给予重要帮助，建议考前注意心理调节" |
| **学业领域** | 具体专业方向+筛选标准 | "教育学、法律、哲学、外语方向，适合扩展型、教育型专业" |
| **时间节点** | 具体年月+能量状态+建议 | "2025年九宫年（小限），重要考试窗口，建议把握升学机会" |

---

### 6.2 抽象表述禁止清单

```
❌ 禁止表述                          → ✅ 具体化要求

"学业一般"                           → "学历层次为普通本科，可能在二本院校就读"
"考试运还可以"                       → "考试运较好，大考时思维清晰，但有压力感"
"适合读书"                           → "适合教育学、法律、哲学等扩展型专业"
"学习方面需要努力"                   → "九宫主星落陷，学习需要更多时间投入，建议每天固定学习时间"
```
