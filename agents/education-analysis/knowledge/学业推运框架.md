## 二、法达大运学业判断

### 2.1 法达主运与学业

| 主运行星 | 学业基调 | 具体表现 |
|----------|----------|----------|
| **太阳** | 学业认可期 | 获得认可、学业成就、自我发展 |
| **月亮** | 学业适应期 | 情感需求强、学习波动、家庭影响 |
| **水星** | 学习黄金期 | 沟通学习、考试运好、思维活跃 |
| **金星** | 学业顺遂期 | 学习享受、艺术方向、心态平稳 |
| **火星** | 学业竞争期 | 竞争激烈、需要行动、可能冲动 |
| **木星** | 学业扩展期 | 机会扩展、贵人相助、高等教育 |
| **土星** | 学业考验期 | 压力大、考验多、需要耐心 |
| **北交点** | 学业成长期 | 成长方向、业力推动 |

### 2.2 法达与九宫主星关系

```
【判断方法】
├─ 法达主运行星与九宫主星的关系
│   ├─ 接纳/互容 → 学业运强
│   ├─ 吉相位 → 学业顺遂
│   ├─ 凶相位 → 学业有挑战
│   └─ 无关系 → 中等影响
│
└─ 法达主运行星主什么宫位
    ├─ 主九宫 → 学业焦点期
    ├─ 主吉宫 → 学业有助力
    └─ 主凶宫 → 学业有阻碍
```

## 三、小限法学业判断

### 3.1 小限走宫与学业

| 小限宫位 | 年度学业主题 | 重点关注 |
|----------|--------------|----------|
| **一宫年** | 自我发展年 | 自学、个人兴趣 |
| **二宫年** | 价值确立年 | 学习动力调整 |
| **三宫年** | **基础学习年** | **短期培训、基础教育** |
| **四宫年** | 家庭根基年 | 家庭对学业影响 |
| **五宫年** | **智力创意年** | **考试表现、学习兴趣** |
| **六宫年** | 工作事务年 | 技能培训、职业学习 |
| **七宫年** | 合作关系年 | 合作学习、导师关系 |
| **八宫年** | 深度转化年 | 研究学习、心理学 |
| **九宫年** | **高等教育年** | **重要考试、升学转折** |
| **十宫年** | 事业名年 | 学业与事业结合 |
| **十一宫年** | 人脉社年 | 群体学习、社团活动 |
| **十二宫年** | 隐秘灵年 | 独自研究、冥想学习 |

### 3.2 九宫年（余数9）学业判断

```
【小限九宫年特征】
├─ 高等教育成为年度焦点
├─ 可能的重要考试
├─ 升学转折节点
├─ 学业发展方向调整
└─ 教育背景重要期

【判断要点】
├─ 年主星（九宫主星）状态
│   ├─ 庙旺 → 学业年顺遂
│   └─ 落陷 → 学业年有挑战
│
├─ 年主星与命主星关系
│   ├─ 和谐 → 学业发展顺畅
│   └─ 紧张 → 学业有压力
│
└─ 九宫内行星状态
    ├─ 吉星 → 学业有助力
    └─ 凶星 → 学业有阻碍
```

## 四、法达+小限配合判断

### 4.1 双重触发

```
【最强学业期】
├─ 法达主运 = 九宫主星
│   AND
└─ 小限走九宫年
    → 高等教育重大转折期，必须重点关注

【学业贵人期】
├─ 法达主运接纳九宫主星
│   AND
└─ 小限走吉宫年
    → 学业有贵人支持，顺遂期

【学业考验期】
├─ 法达主运刑冲九宫主星
│   AND
└─ 小限走凶宫年
    → 学业压力大，需谨慎应对
```
