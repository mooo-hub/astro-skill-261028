### 1.2 学业判断核心规则

> **来源**：ksc古典占星课程第九课、解盘班第八课（格局）

```
学业判断公式：
学业判断 = 三宫 + 九宫 + 宫主星 + 宫内星 + 结构

【关键原则】
├─ 宫主星为主，宫内星为辅
├─ 不能只看水星落座判断学习好坏
├─ 学业好坏和事业判断方法类似，看整体格局
└─ 太阳/命主星的贵气会提升学业层次
```

## 三-A、★九宫主星状态多重解读★

> **核心发现**：九宫主星落陷≠低学历，而可能指向"非传统教育路径"
> **版本**：v2.0新增 | 2026-06-30

### 3A.1 土星作为九宫主星的多重表现

| 九宫主星状态 | 表现方向A | 表现方向B | 判断方法 |
|--------------|-----------|-----------|----------|
| 土星落陷 | 学业受阻、低学历 | **非传统路径（出国留学）** | 有贵人结构→方向B |
| 土星落陷 | 国内困难、延迟 | 延迟成熟、大器晚成 | 命主强+贵人→方向B |
| 土星落陷 | 传统路径受阻 | **海外成功** | 九宫远方主题激活 |

**★关键判断逻辑**：
```
九宫 = 远方/异国/高等教育
土星落陷 = 脱离常规轨道/非传统路径
土木吉结构 = 贵人支持（导师/保研机会）

综合推论：
土星落陷 + 九宫远方主题 + 贵人结构
= 高概率选择出国留学而非国内常规路径 ✅
```

### 3A.2 出国留学倾向判断模块

#### 留学倾向判断因子表

| 因子 | 判断标准 | 权重 |
|------|----------|------|
| 九宫主题 | 远方/异国/高等教育 | 基础（必填）|
| 九宫主星状态 | 土星落陷=脱离常规 | +2 |
| 水星位置 | 8宫/12宫=异国相关 | +1 |
| 火土紧密相位（<2°）| 选择冲突=冒险倾向 | +1 |
| 推运触发 | 水星大运=学习+远方 | +1 |
| 贵人结构 | 土木/木星吉相=支持 | +1 |

#### 综合判断标准

| 总分 | 留学倾向 | 判断建议 |
|------|----------|----------|
| ≥5分 | **高概率出国留学** | 明确提示留学路径 |
| 3-4分 | 可能出国 | 配合推运确认时机 |
| <3分 | 国内教育为主 | 按传统路径分析 |

#### 留学判断示例

```
案例分析：
├─ 九宫主题 ✓（基础：远方/高等教育）
├─ 土星落陷（9r）✓（+2：脱离常规）
├─ 水星8宫 ✓（+1：异国相关）
├─ 火土对分0.39° ✓（+1：选择冲突）
├─ 水星大运（18-31岁）✓（+1：触发窗口）
├─ 土木六分相 ✓（+1：贵人支持）
└─ 总分：6分 → 高概率出国留学 ✅

推论：放弃国内保研，选择出国深造
```

## 三-B、★凶宫掺入的多重影响★

> **核心发现**：凶宫掺入≠学历降低，而可能指向"教育路径特殊性"

### 3B.1 九宫主星守护凶宫的多重含义

| 凶宫掺入 | 传统解读 | 补充解读 | 判断依据 |
|----------|----------|----------|----------|
| 9r=8r | 学业受阻 | **他人资源/合作教育** | 有吉结构→补充解读 |
| 9r=6r | 学习困难 | **技术/医学类专业** | 贵人支持→补充解读 |
| 9r=12r | 学业中断 | **研究/深层探索** | 命主强→补充解读 |

**★关键判断**：
```
土星同时守护7、8、9宫（凶宫掺入）：
├─ 传统解读：学历层次降低
├─ 补充解读：高等教育与"他人资源"相关
│   └─ 可能指向：金融、投资、风险管理等领域
│   └─ 或指向：需要合作/导师支持的学习路径
└─ 判断方法：结合贵人结构和推运触发
```
