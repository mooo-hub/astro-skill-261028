# 科目优势分析

科目优势分析是学业专项分析的新增模块，用于判断各科目的优势/弱势表现。

> **背景**：实际验证发现，科目优势/弱势是家长和学生的高频咨询需求，但原有知识库完全遗漏此维度。

---

## 三、科目分析思维链

### 3.1 完整分析流程

```
Step 1: 提取科目相关行星状态
    ├─ 水星：语文、数学、英语基础
    ├─ 月亮：语文（感受）、生物
    ├─ 土星：数学（计算）、物理、历史
    ├─ 火星：物理、体育
    ├─ 金星：艺术
    ├─ 木星：英语扩展、历史扩展
    └─ 太阳：政治、领导力

Step 2: 判断各行星庙旺落陷
    ├─ 查表：行星所在星座 → 庙旺状态
    └─ 记录：各行星状态评分

Step 3: 检查吉凶结构
    ├─ 吉星结构：科目有贵人支持
    └─ 凶星结构：科目有阻碍

Step 4: 综合科目优势排序
    ├─ 优势科目：相关行星庙旺
    ├─ 中等科目：相关行星入闲
    └─ 弱势科目：相关行星失势落陷

Step 5: 输出科目分析报告
    └─ 具体描述各科目表现（禁止打分）
```

## 四、具体科目判断规则

### 4.1 语文科目判断

```
【语文相关行星】
├─ 水星：语言逻辑、表达能力
├─ 月亮：文字感受、情感理解
└─ 3宫主星：沟通表达

【判断方法】
├─ 水星入庙入旺 + 月亮状态好 → 语文优秀
├─ 水星中性 + 月亮入庙 → 语文较好（偏感受型）
├─ 水星失势 + 月亮入庙 → 语文中等（感受好但表达弱）
└─ 水星落陷 + 月亮受克 → 语文困难

【示例】
水星入旺（水瓶座）+ 月亮入庙（巨蟹座）
= 语文优秀 ✅（语言逻辑+情感理解双强）
→ 常年年级前列
```

### 4.2 数学科目判断

```
【数学相关行星】
├─ 水星：概念思维、逻辑推理
└─ 土星：计算能力、结构理解

【判断方法】
├─ 水星入庙入旺 + 土星状态好 → 数学优秀
├─ 水星入旺 + 土星落陷 → 数学概念好但计算弱
│   └─ 区分：概念思维vs计算能力
├─ 水星中性 + 土星中性 → 数学中等
└─ 水星失势 + 土星落陷 → 数学困难

【注意】
水星入旺（水瓶座）= 概念思维强
但土星落陷 = 计算能力弱
→ 数学概念理解好，但计算可能出错
→ 实际表现：数学较差（计算拖后腿）
```

### 4.3 物理/生物科目判断

```
【物理相关行星】
├─ 土星：物理结构、力学
└─ 火星：动力、能量

【判断方法】
├─ 土星落陷 + 火星失势逆行 → 物理困难 ✅
└─ 需要补强：概念理解+实验操作

【生物相关行星】
├─ 月亮：生命、有机
└─ 6宫主星：健康、生命体

【判断方法】
├─ 月亮入庙 + 6宫状态好 → 生物优秀 ✅
└─ 自然理解生命现象
```
