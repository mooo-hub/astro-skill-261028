## 三-A、★火土紧密相位场景区分★

> **核心发现**：火土紧密相位（<2°）≠仅考试意外，而可能指向"人生选择冲突"
> **版本**：v2.0新增 | 2026-06-30

### 3A.1 火土相位的多场景解读

火土对分相代表两股力量的冲突：
- **火星** = 冒险/冲动/行动/突破
- **土星** = 稳定/结构/限制/保守
- **对分相** = 两股力量的拉扯与抉择

| 场景 | 判断方法 | 年龄阶段 | 具体表现 |
|------|----------|----------|----------|
| 考试意外 | 推运触考试期+无留学因子 | 学生期（15-22岁）| 考试突发状况 |
| **人生选择冲突** | 推运触毕业期+留学因子 | 毕业期（22-25岁）| 保研vs出国 |
| 学术竞争压力 | 推运触深造期 | 研究期（25-35岁）| 学术竞争环境 |

### 3A.2 火土相位场景判断流程

```
Step 1: 确认相位紧密程度
    ├─ <1°：紧密相位，指向重大人生节点
    └─ 1-2°：中等紧密，可能指向具体事件

Step 2: 检查年龄阶段
    ├─ 15-22岁：优先考虑考试场景
    ├─ 22-25岁：优先考虑选择场景（毕业/就业/深造）
    └─ 25岁+：考虑学术/职业竞争场景

Step 3: 检查留学因子
    ├─ 有留学因子（九宫远方+土星落陷+贵人结构）
    │   └─ 指向：人生选择冲突（保研vs出国）✅
    └─ 无留学因子
        └─ 指向：考试意外/竞争压力

Step 4: 输出判断
    └─ 给出具体场景描述（而非笼统"考试意外"）
```

### 3A.3 火土相位判断示例

```
案例分析：
├─ 火土对分相：0.39°（紧密）
├─ 年龄阶段：22-25岁（毕业期）
├─ 留学因子：
│   ├─ 九宫远方主题 ✓
│   ├─ 土星落陷 ✓
│   ├─ 水星8宫 ✓
│   └─ 土木六分贵人 ✓
└─ 判断：人生选择冲突（保研vs出国）✅

具体表现：
├─ 火星方：冒险、出国、突破
├─ 土星方：稳定、保研、保守
└─ 冲突：在稳定选择和冒险选择之间拉扯
    → 最终选择出国（火星突破土星限制）
```

### 3A.4 考试运修正判断表

| 原判断 | 修正条件 | 修正后判断 |
|--------|----------|------------|
| 火刑冲9r→考试意外 | 紧密相位+毕业期+留学因子 | 人生选择冲突 |
| 火刑冲9r→考试意外 | 考试推运+无留学因子 | 考试意外 |
| 土刑冲9r→考试压力 | 有贵人结构+命主强 | 考试压力但有化解 |
