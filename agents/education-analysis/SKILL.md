```json

  },

    "priority_1": "学业",
    ...
  }

```

### 输出契约

```json
{
  "task_id": "与输入保持一致",
  "status": "success|failed|partial",
  "error": null,
  "education": {
    "meta": {
      "analysis_date": "YYYY-MM-DD",
      "chart_type": "日盘/夜盘",
      "kvp_log": [...]
    },
    "ninth_house": {...},
    "third_house": {...},
    "education_level_synthesis": "学历层次综合判断...",
    "exam_fortune_synthesis": "考试运综合判断...",
    "education_field": "学业领域方向",
    "forecast": {
      "firdaria_education": {...},
      "profection_education": {...},
      "key_periods": [...]
    },
    "advice": {...}
  }
}
```

**状态字段说明**：

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| **success** | 任务完成，输出可用 | 所有Step执行完毕，输出契约完整 |
| **failed** | 任务失败，需要主Agent决策 | 输入数据缺失、知识库加载失败、校验错误 |
| **partial** | 部分完成，标记缺失 | 某些Step数据不完整，但核心输出可用 |

**error字段格式**：

```json
{
  "error": {
    "code": "INVALID_INPUT|KB_LOAD_FAILED|STEP_FAILED",
    "message": "具体错误描述",
    "step": "失败的Step编号"
  }
}
```

### 禁止任务

```
✗ 禁止输出打分（如"学业：4分"）
✗ 禁止只看水星落座判断学习好坏
✗ 禁止无因果链的学历判断
✗ 禁止模糊时间表述（如"近期"）
✗ 禁止跳过数据直接解读
✗ 禁止在未输出rules_read时继续执行
✗ 禁止跳过KVP验证直接解读数据
```

## 四、工作流程

### Step -1: 顾客问题确认与专项链路选择

**前置知识**：
```
读取：knowledge/专项解盘思维链与沟通规范.md（规则型）
时机：before_execution
```

**执行步骤**：
```
1. 确认顾客真正问题：长期格局/当前处境/具体决策/未来时间窗口
2. 按主题选择入口宫位与自然征象星，不泛泛论盘
3. 建立技术链：主题宫位 -> 宫主星 -> 宫主落宫 -> 自然征象星 -> 结构 -> 命主关系 -> 推运
4. 输出时转化为顾客语言：结论 -> 依据 -> 现实表现 -> 可执行建议
5. 检查表达边界：概率语言、选择语言、负面判断后必须给化解建议
```

### Step 1: 学历层次分析

**前置知识**：
```
读取：knowledge/学业专项框架.md（规则型）
时机：before_execution
```

**知识确认**：
```json
{
  "kvp": "KVP-E1",
  "loaded_rules": {
    "education_formula": "学业判断 = 三宫 + 九宫 + 宫主星 + 宫内星 + 结构",
    "main_rule": "宫主星为主，宫内星为辅",
    "nobility_rule": "太阳/命主星贵气提升学业层次"
  }
}
```

**执行步骤**：
```
1. 分析九宫主星结构：
   ├─ 优先级：接纳 > 互容 > 合相 > 刑冲 > 三合六合
   ├─ 检查：是否有凶宫掺入（3r/6r/8r/12r）
   └─ 输出：九宫主星结构分析

2. 分析三宫主星结构：
   ├─ 同上优先级
   └─ 输出：三宫主星结构分析

3. 检查整体格局贵气：
   ├─ 日生盘：太阳状态及与九宫主星关系
   ├─ 夜生盘：月亮状态，兼看太阳
   └─ 命主星：贵气来源判断

4. 检查水星状态（智力征象）

5. 综合学历层次判断：
   ├─ 汇总所有影响因素
   ├─ 判断学历层次：中专/大专/本科/硕士/博士
   └─ 输出学历层次综合描述（禁止打分）
```

---

### Step 2: 考试运分析

**执行步骤**：
```
1. 分析九宫主星状态：
   ├─ 庙旺：考试运好
   ├─ 落陷：考试运差
   └─ 输出：九宫主星状态

2. 检查吉星结构：
   ├─ 木星接纳九宫主星 → 考试贵人
   ├─ 太阳接纳九宫主星 → 考试得贵气
   └─ 输出：吉星结构判断

3. 检查凶星结构：
   ├─ 土星刑冲九宫主星 → 考试压力
   ├─ 火星刑冲九宫主星 → 考试意外
   └─ 输出：凶星结构判断

4. 综合考试运判断：
   ├─ 汇总所有考试因素
   ├─ 判断考试运：顺利/一般/困难
   └─ 输出考试运综合描述（禁止打分）
```

---

### Step 3: 学业领域分析

**执行步骤**：
```
1. 根据九宫主星飞入宫位判断学业领域

2. 结合九宫主星星性判断学业倾向

3. 输出学业领域方向建议
```

```json
  "kvp": "KVP-E3",

    "ninth_house_year": "小限九宫年：高等教育年",

  }

```

**执行步骤**：
```
1. 分析当前法达配置：
   ├─ 当前主运行星
   ├─ 当前子运行星
   ├─ 主子运与九宫关系
   └─ 输出：法达学业判断

2. 分析小限年运：
   ├─ 当年小限宫位
   ├─ 与学业宫位关系
   └─ 输出：小限学业判断

3. 定位关键学业期：
   ├─ 法达水星/木星大运 → 学习黄金期
   ├─ 小限九宫年 → 重要考试年
   └─ 输出：关键学业节点

4. 输出学业推运汇总
```

## 五、输出格式规范

### education_synthesis字段规范

> **核心要求**：必须是具体描述，禁止打分，必须有实例说明

**正确示例**：
```
"education_level_synthesis": "学历层次较高，九宫主星木星入庙在九宫，得先天贵气，加上太阳与木星形成六合结构，整体格局清纯。这类盘主通常能获得重点本科或硕士学历。例如：可能毕业于985高校的教育学或法律专业，学业发展较为顺利。"
```

**错误示例**：
```
"education_level_synthesis": "学历：4分"  ✗ 禁止打分
"education_level_synthesis": "学业一般"   ✗ 禁止笼统表述
```

```json
{
```
