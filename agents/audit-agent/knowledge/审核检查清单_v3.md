# 审核检查清单 v3.1

四节点审核的完整检查清单，每个节点执行前必须核查：

**audit-1（盘面数据）**：日夜盘判断、古典守护关系、逆行状态读取
**audit-2（基础分析）**：三层面优先级应用、宫主星从宫头判断（禁止从行星推断）
**audit-3（专项分析）**：双维度分开判断、相位逐个计算核查
**audit-4（输出合规）**：禁止笼统表述、数据来源标注

---

## 核心审核原则

```
┌──────────────────────────────────────────────────────────────┐
│                    审核核心原则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【原则一】三层面判断优先级                                    │
│  结构 > 宫性 > 星性 > 尊贵                                    │
│                                                              │
│  【原则二】双维度分开判断                                      │
│  每个专项必须分开判断两个维度，不可混淆                        │
│                                                              │
│  【原则三】具体化输出                                          │
│  禁止笼统表述，必须有明确的时间节点和事件描述                   │
│                                                              │
│  【原则四】数据驱动                                            │
│  每个判断必须有数据依据，禁止主观假设                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### audit-2 常见错误警示

| 错误类型 | 错误示例 | 正确做法 |
|----------|----------|----------|
| 优先级错误 | "水星入庙，事业很好" | 先看水星与官禄星是否有结构 |
| 忽略宫性 | "金星是吉星，参与结构就好" | 判断金星主什么宫位 |
| 能量决定论 | "落陷就差" | 落陷可由接纳互容弥补 |
| 守护错误 | "水瓶座的命主星是天王星" | 水瓶座的命主星是土星 |
| **★宫主星推断错误★** | "土星在白羊座10宫 → 10宫主是火星" | 先读宫头星座（双鱼座）→ 宫主星是木星 |
| **★逆行状态推断错误★** | "土星应该逆行吧" | 从 retrograde 字段读取数据 |
| **★数据来源缺失★** | "土星落陷"（无标注） | "土星落陷(来源: JSON Saturn.dignity)" |

## 矛盾检测规则

当不同分析结果出现矛盾时，按以下规则判断：

```
┌──────────────────────────────────────────────────────────────┐
│                    矛盾检测与判断规则                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【规则一：结构优先】                                         │
│  高层信息压倒低层信息                                         │
│  例：木星落陷但被接纳 → 接纳结构优先，落陷负面被减弱          │
│                                                              │
│  【规则二：宫性优先于星性】                                    │
│  后天宫性压倒先天星性                                         │
│  例：金星是吉星但掌管八宫 → 八宫性质优先，仍论破财             │
│                                                              │
│  【规则三：尊贵不决定吉凶】                                    │
│  庙旺落陷只影响表达形式，不决定结果好坏                        │
│  例：庙旺 ≠ 好，落陷 ≠ 坏                                    │
│                                                              │
│  【规则四：紧密程度优先】                                      │
│  同层信息中，紧密程度高的压倒紧密程度低的                      │
│  例：接纳互容 > 合相 > 冲刑 > 三合六合                        │
│                                                              │
│  【规则五：多项交叠才严重】                                    │
│  单项凶不判断严重问题                                         │
│  例：六宫有凶星 ≠ 重病，需六宫+八宫连接+多项凶叠加            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
