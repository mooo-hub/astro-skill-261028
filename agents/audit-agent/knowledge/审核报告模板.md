## 修正示例库

### 示例1：事业专项修正

**原文**（不合格）：
> "事业受火星影响，要注意风险"

**修正后**（合格）：
> "事业宫主星火星落在白羊座10宫，火星为先天凶星，代表冲突、竞争与行动。在白羊座入庙(来源: JSON Mars.dignity: 入庙)，能量强旺，从1宫飞入10宫形成命-官结构。这意味着事业上需要主动竞争才能获得成就，适合开拓性、竞争性强的工作如销售、创业等。火星入庙虽然能量强，但凶星性质不变，事业上可能遇到竞争冲突、短期波动等风险，2026年火星大运期间需要特别注意合作伙伴关系(来源: 七宫主金星与火星对冲)。"

**修正要点**：
1. 补充宫主星名称 + 先天属性
2. 补充状态 + 状态含义
3. 补充具体结果 + 情境化 + 时间节点
4. 标注数据来源

### 示例2：感情专项修正

**原文**（不合格）：
> "感情有挑战，婚姻质量一般"

**修正后**（合格）：
> "七宫主金星落在天秤座7宫，金星为先天吉星，代表感情、价值与和谐。在天秤座入庙(来源: JSON Venus.dignity: 入庙)，能量强旺。但金星与土星形成四分相(来源: 相位表，容许度1.8°)，土星为先天凶星，代表限制与压力。这意味着配偶条件不错、有审美品味(金星入庙)，但婚姻经营有一定压力，可能表现为配偶工作忙碌、两地分居等情况。婚姻质量中等(3分/5分)，需要双方共同努力经营。桃花运方面，金星与月亮三合(来源: 相位表)，有一定桃花机会，但不算旺盛。"

## 五、使用说明

### 5.1 模板选择指南

| 审核场景 | 推荐模板 |
|----------|----------|
| 全流程审核 | 完整审核报告模板 |
| 具体描述性审查 | audit-5 具体描述性审查报告模板 |
| 单点快速审核 | 简化审核报告模板 |
| 审核历史记录 | 审核日志模板 |

### 5.2 填写规范

1. **状态标记**：
   - ✅ pass：检查通过
   - ⚠️ warning：有轻微问题
   - ❌ error：有严重问题

2. **评分等级**：
   - A：完整描述
   - B：基本完整
   - C：部分缺失
   - D：严重缺失
   - F：完全不合格

3. **严重程度**：
   - high：必须修正
   - medium：建议修正
   - low：可选修正

4. **数据来源标注**：
   - 格式：`(来源: JSON字段名)` 或 `(来源: XX表)`
   - 必须标注实际数据来源，禁止伪造

### 5.3 输出要求

1. 每个检查项必须有明确的状态
2. 每个问题必须有修正建议
3. 每个修正建议必须有示例
4. 报告末尾必须有审核结论和后续行动
