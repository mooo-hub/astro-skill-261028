> **用途**：audit-agent执行审核任务的完整流程指南
> **版本**：v1.0 | 2026-06-09
> **重要级别**：★ 核心操作文档 ★

---

```

│              审核Agent解盘流程总览                              │
├──────────────────────────────────────────────────────────────┤

│                                                              │
│  ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐     │
```

## 一、流程入口

### 1.1 触发条件

| 触发词 | 执行的审核节点 |
|--------|----------------|
| "审核数据"、"audit-1" | audit-1: 盘面数据审核 |
| "审核基础"、"audit-2" | audit-2: 基础分析审核 |
| "审核专项"、"audit-3" | audit-3: 专项分析审核 |
| "审核输出"、"audit-4" | audit-4: 输出合规审核 |
| "审核描述"、"audit-5" | audit-5: 具体描述性审查 |
| "完整审核"、"全流程审核" | audit-1 → audit-5 顺序执行 |

### 1.2 接收任务流程

```
┌──────────────────────────────────────────────────────────────┐
│                  Step 1: 接收审核任务                         │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【输入解析】                                                 │
│  ├─ 识别审核类型：audit-1/2/3/4/5 或全流程                  │
│  ├─ 提取待审核内容：前序Agent的输出数据                      │
│  └─ 确定审核范围：全部检查项或指定检查项                    │
│                                                              │
│  【数据准备】                                                 │
│  ├─ 加载原始数据：排盘JSON、相位表、宫位表                   │
│  ├─ 加载前序输出：各Agent的分析结果                          │
│  └─ 加载检查清单：对应的审核检查项                          │
│                                                              │
│  【环境检查】                                                 │
│  ├─ 确认数据完整性：必要的JSON字段存在                      │
│  ├─ 确认检查清单可用：knowledge文件存在                      │
│  └─ 确认版本一致：使用最新版本的检查清单                    │
│                                                              │
│  【输出】                                                     │
│  └─ 审核任务确认：包含审核类型、范围、预期输出格式           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、各审核节点执行流程

### 2.1 audit-1: 盘面数据审核流程

```
┌──────────────────────────────────────────────────────────────┐
│              audit-1 执行流程（盘面数据审核）                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【Step 1-1】数据完整性检查                                   │
│  ├─ 检查出生时间：年月日时分是否完整                        │
│  ├─ 检查出生地点：经纬度是否完整                            │
│  ├─ 检查性别：是否确认                                      │
│  └─ 检查时区：是否确认                                      │
│                                                              │
│  【Step 1-2】日夜盘判断检查                                   │
│  ├─ 确认太阳位置：从JSON Sun.house读取                      │
│  ├─ 应用判断标准：                                          │
│  │   ├─ 太阳在7-12宫（地平线以上）= 日盘                   │
│  │   └─ 太阳在1-6宫（地平线以下）= 夜盘                   │
│  └─ 核对判断结果：与前序输出是否一致                        │
│                                                              │
│  【Step 1-3】四轴配置检查                                     │
│  ├─ 上升星座（ASC）：从JSON angles.ASC读取                 │
│  ├─ 中天星座（MC）：从JSON angles.MC读取                   │
│  ├─ 下降星座（DSC）：从JSON angles.DSC读取                 │
│  └─ 天底星座（IC）：从JSON angles.IC读取                   │
│                                                              │
│  【Step 1-4】行星配置检查                                     │
│  ├─ 七大行星位置：逐一从JSON planets读取                    │
│  ├─ 星座、宫位、度数：确认字段完整                          │
│  ├─ 庙旺落陷状态：从dignity字段读取并验证                   │
│  ├─ ★逆行状态：从retrograde字段读取（禁止推断）★           │
│  └─ ★灼烧状态：计算与太阳距离（<17°或>343°）               │
│                                                              │
│  【Step 1-5】宫位配置检查（★核心★）                          │
│  ├─ 宫头星座：从JSON houses字段直接读取                    │
│  ├─ 宫主星：从宫头星座推导古典守护星                       │
│  ├─ ★禁止：用行星所落星座推断宫头星座★                     │
│  └─ 标注数据来源：(来源: JSON houses.X.sign)                │
│                                                              │
│  【Step 1-6】相位表核查                                       │
│  ├─ 相位角度：逐一计算黄经差                                │
│  ├─ 容许度：核对是否在标准范围内                            │
│  ├─ 入相位/出相位：根据speed字段判断                        │
│  └─ 标注计算依据                                            │
│                                                              │
│  【Step 1-7】古典守护关系检查                                │
│  ├─ 水瓶座宫主星 = 土星（不是天王星）                       │
│  ├─ 双鱼座宫主星 = 木星（不是海王星）                       │
│  ├─ 天蝎座宫主星 = 火星（不是冥王星）                       │
│  └─ 其他星座守护关系正确                                    │
│                                                              │
│  【Step 1-8】生成审核报告                                    │
│  ├─ 汇总检查结果                                            │
│  ├─ 标注通过/警告/错误状态                                  │
│  ├─ 列出需要修正的问题                                      │
│  └─ 提供修正建议                                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 audit-2: 基础分析审核流程

```
┌──────────────────────────────────────────────────────────────┐
│              audit-2 执行流程（基础分析审核）                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【Step 2-1】行星尊贵评分检查                                 │
│  ├─ 确认评分对象：仅对7颗古典行星评分                        │
│  ├─ 入庙检查：+5分，从JSON dignity字段验证                   │
│  ├─ 入旺检查：+4分，从JSON dignity字段验证                   │
│  ├─ 失势检查：-5分，从JSON dignity字段验证                   │
│  ├─ 落陷检查：-4分，从JSON dignity字段验证                   │
│  ├─ 三分性检查：考虑日夜盘，验证正确版本                    │
│  ├─ 界检查：使用正确度数区间                                │
│  ├─ 面检查：使用正确度数区间                                │
│  ├─ ★逆行扣分：-2分（如适用）                               │
│  └─ 汇总评分：计算总分并评级                                │
│                                                              │
│  【Step 2-2】古典守护关系检查                                 │
│  ├─ 命主星：从上升星座推导，使用古典守护                    │
│  ├─ 各宫宫主星：从宫头星座推导，使用古典守护                │
│  └─ 验证前序输出中的守护关系是否正确                        │
│                                                              │
│  【Step 2-3】宫位判断优先级检查                               │
│  ├─ 检查分析顺序：是否遵循宫主星→宫内星→结构              │
│  ├─ 验证权重分配：宫主星是否作为决定性因素                  │
│  └─ 检查结构引用：是否正确引用相位结构                      │
│                                                              │
│  【Step 2-4】接纳互容关系检查                                 │
│  ├─ 接纳定义验证：                                          │
│  │   ├─ 行星A是否在行星B守护的星座                         │
│  │   └─ 两者是否有托勒密相位                                │
│  ├─ 互容定义验证：                                          │
│  │   └─ 两者是否各在对方守护的星座                          │
│  ├─ 效果判断检查：                                          │
│  │   ├─ 接纳：单向支持关系                                 │
│  │   └─ 互容：双向能量交换                                  │
│  └─ 宫位联动分析：是否正确关联宫位含义                      │
│                                                              │
│  【Step 2-5】最终定位星检查                                   │
│  ├─ 追踪定位星链：从每颗行星开始                            │
│  ├─ 确定最终定位星：找到链的终点                            │
│  ├─ 评估定位星状态：庙旺落陷、落宫                          │
│  └─ 分析定位星含义：对整体格局的影响                        │
│                                                              │
│  【Step 2-6】性格画像结构检查                                 │
│  ├─ 四层结构验证：上升→命主星→太阳→月亮                    │
│  ├─ 关键词数量：3-5个                                       │
│  ├─ 优缺点分析：是否具体                                    │
│  └─ 数据引用：每层是否有数据来源标注                        │
│                                                              │
│  【Step 2-7】十二宫断局检查                                   │
│  ├─ 三层分析法应用：是否逐宫应用                            │
│  ├─ 宫主星状态：是否完整分析                                │
│  ├─ 宫内行星：是否考虑                                      │
│  ├─ 结构关系：是否引用相位                                  │
│  └─ 结论具体化：是否避免笼统表述                            │
│                                                              │
│  【Step 2-8】三层面优先级应用检查                             │
│  ├─ 检查分析是否遵循：结构→宫性→星性→尊贵                  │
│  ├─ 检查是否有只看能量就下结论的情况                        │
│  ├─ 检查结构好坏判断是否正确                                │
│  └─ 检查宫性是否压倒星性应用正确                            │
│                                                              │
│  【Step 2-9】生成审核报告                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.3 audit-3: 专项分析审核流程

```
┌──────────────────────────────────────────────────────────────┐
│              audit-3 执行流程（专项分析审核）                  │

│                                                              │
│  【Step 3-1】双维度分开判断检查                               │
│  ├─ 事业：高度与稳定度是否分开判断                          │

│  └─ 六亲：层次与关系是否分开判断                            │
│                                                              │
│  【Step 3-2】事业专项完整性检查                               │
│  ├─ 十宫主状态分析：是否完整                                │
│  ├─ 中天状态分析：是否包含                                  │
│  ├─ ★ 命主星与事业关系分析：是否包含 ★                     │
│  ├─ ★ 日月状态与事业关系分析：是否包含 ★                   │
│  ├─ ★ 命主星与官禄星相位核查：是否计算正确 ★               │

│  ├─ 跳槽时机：是否有明确年份                                │
│  └─ 结论具体化：是否避免"事业有发展"等笼统表述            │
│                                                              │
│  【Step 3-3】感情专项完整性检查                               │
│  ├─ 七宫主状态分析：是否完整                                │
│  ├─ 金星状态分析：是否包含                                  │
│  ├─ 日月状态分析：是否包含                                  │

│  │   └─ 金星-11宫主相位角度计算                            │

│  ├─ 福点位置分析：是否包含                                  │
│  └─ 结论具体化：是否避免"感情有挑战"等笼统表述            │
│                                                              │
│  【Step 3-4】财运专项检查                                     │
│  ├─ 七步法完整性：是否逐一执行                              │
│  ├─ 九种收入类型判断：是否完整                              │
│  ├─ 二宫主状态：是否分析                                    │
│  ├─ 八宫主状态：是否分析                                    │
│  ├─ 木星状态：是否分析                                      │
```

### 2.4 audit-4: 输出合规审核流程

```
┌──────────────────────────────────────────────────────────────┐
│              audit-4 执行流程（输出合规审核）                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【Step 4-1】格式合规检查                                     │
│  ├─ 报告结构：是否遵循七步法/八板块结构                      │
│  ├─ 章节标题：是否清晰                                      │
│  ├─ 层次分明：是否合理                                      │
│  └─ 数据与解读分离：是否符合板块内结合原则                  │
│                                                              │
│  【Step 4-2】数据优先结构审核                                 │
│  ├─ 第一部分数据展示：是否完整                              │
│  │   ├─ 数据表格完整呈现                                    │
│  │   ├─ 度数精确到分（XX°XX'）                              │
│  │   ├─ 评分精确标注（±X分）                                │
│  │   └─ 相位容许度精确（X.XX°）                             │
│  ├─ 第二部分数据解读：是否符合规范                          │
│  │   ├─ 数据展示部分无解读性文字                            │
│  │   └─ 解读部分每条结论有数据引用                          │
│  └─ 分章节检查：每个板块是否符合                            │
│                                                              │
│  【Step 4-3】数据引用标注核查                                 │
│  ├─ 每个解读是否标注来源                                    │
│  ├─ 引用格式是否正确：（见XX表）或(来源: JSON字段)          │
│  ├─ 是否存在无依据判断                                      │
│  └─ 是否存在主观假设数据关系                                │
│                                                              │
│  【Step 4-4】禁止表述检查                                     │
│  ├─ 扫描全文，查找禁止表述：                                │
│  │   ├─ "可能会有变化"                                      │
│  │   ├─ "要注意健康"                                        │
│  │   ├─ "感情上会有挑战"                                    │
│  │   ├─ "事业有发展机会"                                    │
│  │   ├─ "财运整体平稳"                                      │
│  │   ├─ "整体运势一般"                                      │
│  │   └─ 其他笼统表述                                        │
│  ├─ 发现禁止表述时：                                        │
│  │   ├─ 标记位置                                            │
│  │   ├─ 记录原文                                            │
```
