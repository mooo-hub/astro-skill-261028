## 一、审查核心理念

```
┌──────────────────────────────────────────────────────────────┐
│                具体描述性审查核心理念                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【问题来源】                                                 │
│  古典占星Agent输出中常见以下问题：                            │
│  ├─ 标签式表述："事业受火星影响"                              │
│  ├─ 空洞式表述："事业运势好"                                  │
│  ├─ 跳跃式表述："木星在10宫，事业成功"                        │
│  └─ 笼统式表述："要注意健康"                                  │
│                                                              │
│  【解决目标】                                                 │
│  确保每一条占星论断都具备完整的因果链：                       │
│  能量来源 → 状态描述 → 结果描述                               │
│  行星属性 → 状态含义 → 具体推导                               │
│  什么星 → 什么状态 → 什么结果                                 │
│                                                              │
│  【核心公式】                                                 │
│  完整论断 = 能量来源描述 + 状态描述 + 结果描述                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、三层描述详解

### 2.1 能量来源描述详解

```
┌──────────────────────────────────────────────────────────────┐
│              第一层：能量来源描述                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【必须包含的四个要素】                                       │
│                                                              │
│  要素1：行星/宫主星名称                                       │
│  ├─ 明确说明是哪颗行星                                       │
│  ├─ 如果是宫主星，说明是哪个宫的主星                          │
│  └─ 示例："事业宫主星木星"、"10宫主土星"                     │
│                                                              │
│  要素2：行星的先天属性                                        │
│  ├─ 说明该行星在古典占星中代表什么                            │
│  ├─ 可参考下方"行星先天属性速查表"                            │
│  └─ 示例："木星为先天吉星，代表扩展与机遇"                    │
│                                                              │
│  要素3：行星与该领域的关系                                    │
│  ├─ 守护关系：是否为该宫宫主星                               │
│  ├─ 庙旺关系：在哪个星座、什么状态                           │
│  ├─ 相位关系：与其他关键行星的相位                           │
│  └─ 飞宫关系：从哪个宫飞来、落入哪个宫                       │
│                                                              │
│  要素4：数据来源标注                                          │
│  ├─ 标注数据从哪个字段读取                                   │
│  └─ 示例：(来源: JSON Jupiter.sign)                          │
│                                                              │
│  【合格模板】                                                 │
│  "XX宫主星是[行星名]，[行星名]为先天[吉/凶]星，               │
│   代表[核心含义]，目前在[星座名][状态]，                      │
│   从[X宫]飞入[Y宫](来源: JSON字段)"                          │
│                                                              │
│  【示例】                                                     │
│  "事业宫主星木星落在第10宫双鱼座，木星为先天吉星，            │
│   代表扩展与机遇、贵人与智慧，在双鱼座入庙(来源: JSON         │
│   Jupiter.sign: Pisces, Jupiter.dignity: 入庙)"              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 状态描述详解

```
┌──────────────────────────────────────────────────────────────┐
│              第二层：状态描述                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【必须包含的要素】                                           │
│                                                              │
│  要素1：行星的庙旺落陷状态                                    │
│  ├─ 入庙：能量最强，正面表达为主                             │
│  ├─ 入旺：能量强，正面表达需努力                             │
│  ├─ 入闲(中性)：能量一般，需要引导                           │
│  ├─ 失势：能量受阻，负面表达倾向                             │
│  ├─ 落陷：能量最弱，负面表达为主                             │
│  └─ 示例："木星入庙于射手座，能量强旺"                        │
│                                                              │
│  要素2：行星的宫位状态                                        │
│  ├─ 始宫(角宫)：能量最强，1/4/7/10宫                         │
│  ├─ 续宫：能量中等，2/5/8/11宫                               │
│  ├─ 果宫：能量最弱，3/6/9/12宫                               │
│  └─ 示例："木星落在10宫(始宫)，能量发挥充分"                  │
│                                                              │
│  要素3：行星的其他状态                                        │
│  ├─ 逆行：不稳定、反复、内在化                               │
│  ├─ 灼烧：能量被遮蔽、能力受限                               │
│  ├─ 相位：与其他行星的相位关系                               │
│  └─ 示例："木星无逆行，无灼烧，与太阳三合"                    │
│                                                              │
│  要素4：状态对领域的直接影响                                  │
│  ├─ 必须说明该状态如何影响该领域                              │
│  ├─ 不能只说状态，不说影响                                   │
│  └─ 示例："入庙状态意味着事业上的机遇容易被当事人把握"        │
│                                                              │
│  【合格模板】                                                 │
│  "[行星名][状态]，能量[强/中/弱]，这意味着在该领域            │
│   [具体影响]，可能导致[潜在结果]"                            │
│                                                              │
│  【示例】                                                     │
│  "木星入庙于射手座，能量强旺(来源: JSON Jupiter.dignity)，    │
│   这意味着事业上的扩展机遇容易被当事人把握，                  │
│   贵人运强，有提携和帮助的机会"                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.3 结果描述详解

```
┌──────────────────────────────────────────────────────────────┐
│              第三层：结果描述                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【必须包含的要素】                                           │
│                                                              │
│  要素1：具体结果推导                                          │
│  ├─ 基于"能量来源+状态"推导结果                              │
│  ├─ 结果必须具体，不能笼统                                   │
│  └─ 示例："因此事业上有贵人提携的迹象"                        │
│                                                              │
│  要素2：情境化描述                                            │
│  ├─ 适用领域：适合从事什么类型的工作/事业                    │
│  ├─ 行为建议：应该如何做/注意什么                            │
│  └─ 预期结果：可能达到什么层次/状态                          │
│                                                              │
│  要素3：时间节点（如适用）                                    │
│  ├─ 推运分析中必须有时间节点                                 │
│  ├─ 具体年份或时间段                                        │
│  └─ 示例："2027年木星大运期间有升职机会"                      │
│                                                              │
│  要素4：性质判断                                              │
│  ├─ 吉凶：吉/凶/中性 + 判断依据                             │
│  ├─ 高低：高成就/中等/低 + 依据                             │
│  └─ 稳定：稳定/波动/变数 + 原因                             │
│                                                              │
│  【合格模板】                                                 │
│  "因此，在该领域[具体结果]，[情境化描述]，                    │
│   [时间节点]，[性质判断]"                                     │
│                                                              │
│  【示例】                                                     │
│  "因此，事业上有贵人提携的迹象，适合从事教育、法律、          │
│   跨国贸易等领域(来源: 木星征象)，在2027年木星大运期间       │
│   有升职机会，事业高度中等偏上(来源: 结构分析)，稳定度较高    │
│   (来源: 无凶宫掺入)"                                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 四、能量权重判断系统

```
┌──────────────────────────────────────────────────────────────┐
│                  能量权重判断系统                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【权重层级】                                                 │
│                                                              │
│  一级权重（主要影响）：                                       │
│  ├─ 宫主星（权重：40%）                                      │
│  │   └─ 该宫位的守护星，是该领域的核心指示星                 │
│  ├─ 宫内星（权重：30%）                                      │
│  │   └─ 直接落在该宫位的行星，直接影响该领域                 │
│  └─ 核心结构（权重：30%）                                    │
│      └─ 与该领域相关的主要相位结构                           │
│                                                              │
│  二级权重（次要影响）：                                       │
│  ├─ 相位行星（权重：20%）                                    │
│  │   └─ 与核心指示星形成相位的行星                           │
│  ├─ 定位星链（权重：15%）                                    │
│  │   └─ 最终定位星的位置和状态                               │
│  └─ 三分主星（权重：10%）                                    │
│      └─ 该宫位星座的三分主星状态                             │
│                                                              │
│  三级权重（参考影响）：                                       │
│  ├─ 喜乐宫（权重：5%）                                       │
│  │   └─ 行星在其喜乐宫的位置                                │
│  ├─ 界主星（权重：5%）                                       │
│  │   └─ 行星所在度数的界主星状态                             │
│  └─ 面主星（权重：3%）                                       │
│      └─ 行星所在度数的面主星状态                             │
│                                                              │
│  【审查要点】                                                 │
│  ├─ 一级权重行星必须完整描述因果链                           │
│  ├─ 二级权重行星建议描述，可简化                             │
│  └─ 三级权重行星可提及，不强求完整因果链                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 五、负面案例库

### 5.1 标签式表述案例

| 错误类型 | 错误案例 | 问题分析 | 正确做法 |
|----------|----------|----------|----------|
| **只说行星名** | "事业受火星影响" | 未说明火星是什么、如何影响、产生什么结果 | "事业宫主星火星落在白羊座6宫，火星为先天凶星，代表冲突与行动，在白羊座入庙能量强，从6宫飞入10宫形成命-官结构，事业上需要主动竞争，适合开拓性工作" |
| **只说有相位** | "木土有相位" | 未说明相位类型、容许度、产生什么影响 | "木星与土星形成四分相，容许度2.3°(来源: 相位表)，木星扩展与土星限制形成张力，事业上机遇与压力并存" |
| **只说落宫** | "土星在10宫" | 未说明土星的状态、在10宫意味着什么 | "土星落在摩羯座10宫，土星在摩羯座入庙(来源: JSON Saturn.dignity)，代表事业需要长期积累、一步一个脚印，早年事业压力较大，中年后逐渐稳定" |

### 5.2 空洞式表述案例

| 错误类型 | 错误案例 | 问题分析 | 正确做法 |
|----------|----------|----------|----------|
| **无因果链** | "事业运势好" | 无任何推导过程，直接给结论 | "10宫主木星入庙于射手座(来源: JSON Jupiter.dignity: 入庙)，与太阳三合(来源: 相位表)，有贵人提携迹象，事业高度中等偏上，适合教育、法律领域" |
| **笼统评价** | "财运整体平稳" | 无具体分析，无法知道为什么平稳 | "2宫主金星入旺于双鱼座(来源: JSON Venus.dignity)，正财稳定，年入XX万级别；5宫弱(来源: 无宫内星)，偏财风险高，不建议重仓投机" |
| **模糊建议** | "要注意健康" | 无具体部位、无具体建议 | "6宫主水星落陷于射手座(来源: JSON Mercury.dignity)，神经系统需注意，避免过度焦虑；月亮受克(来源: 月土刑)，心理健康中等风险，建议规律作息" |

### 5.3 跳跃式表述案例

| 错误类型 | 错误案例 | 问题分析 | 正确做法 |
|----------|----------|----------|----------|
| **跳过状态** | "木星在10宫，事业成功" | 缺少木星状态、状态含义、中间推理 | "木星在10宫射手座入庙(来源: JSON Jupiter.dignity)，能量强旺，扩展机遇易把握，有贵人提携迹象，因此事业有成功的机会，适合教育、法律领域" |
| **跳过结果** | "土星在10宫，压力很大" | 缺少具体结果推导、情境化描述 | "土星在10宫摩羯座入庙(来源: JSON Saturn.dignity)，事业需要长期积累，早年压力大(30岁前)，中年后逐渐稳定，适合体制内、传统行业发展" |
| **跳过因果** | "火星落陷，事业不好" | 缺少中间推理，直接跳到结论 | "火星落在巨蟹座落陷(来源: JSON Mars.dignity)，行动力受阻，事业上可能遇到拖延、阻碍，需要更多耐心，适合幕后策划而非前线冲锋" |

## 六、占星原理引用表

### 6.1 核心原理来源

| 原理名称 | 核心内容 | 适用场景 | 引用格式 |
|----------|----------|----------|----------|
| **三位一体论法** | 宫位→宫主星→行星状态→结果描述 | 所有专项分析 | (来源: 三位一体论法) |
| **三层面优先级** | 结构 > 宫性 > 星性 > 尊贵 | 矛盾判断 | (来源: 三层面优先级规则) |
| **宫主星论法** | 宫主星的本质属性决定该领域的核心特征 | 宫位分析 | (来源: 宫主星体系详解) |
| **能量权重** | 宫主星(40%) > 宫内星(30%) > 结构(30%) | 影响程度判断 | (来源: 能量权重系统) |
| **庙旺不决定吉凶** | 庙旺只影响表达形式，不决定结果好坏 | 状态解读 | (来源: 核心方法论) |
| **结构决定格局** | 有结构先看结构，无结构才看庙旺落陷 | 格局判断 | (来源: 三层面优先级规则) |

## 七、审查流程详解

### 7.1 标准审查流程

```
┌──────────────────────────────────────────────────────────────┐
│                  audit-5 标准审查流程                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 1: 确定审查范围                                        │
│  ├─ 识别正在审查的专项领域（事业/感情/财运/健康/六亲）       │
│  ├─ 提取该领域的所有论断                                     │
│  └─ 按论断逐条进行审查                                       │
│                                                              │
│  Step 2: 三问审查                                            │
│  ├─ 问1：能量来源是否明确？                                  │
│  │   ├─ 行星/宫主星名称是否标注                             │
│  │   ├─ 先天属性是否说明                                   │
│  │   ├─ 与领域关系是否说明                                 │
│  │   └─ 数据来源是否标注                                   │
│  ├─ 问2：状态描述是否充分？                                 │
│  │   ├─ 庙旺落陷状态是否说明                               │
│  │   ├─ 宫位状态是否说明                                   │
│  │   ├─ 其他状态是否说明（逆行/灼烧）                       │
│  │   ├─ 状态含义是否解释                                   │
│  │   └─ 对领域影响是否说明                                 │
│  └─ 问3：结果描述是否具体？                                 │
│      ├─ 具体结果是否推导                                   │
│      ├─ 情境化描述是否包含                                 │
│      ├─ 时间节点是否给出（如适用）                         │
│      └─ 性质判断是否明确                                   │
│                                                              │
│  Step 3: 计算完整性得分                                      │
│  ├─ 能量来源得分：A/B/C/D/F                                 │
│  ├─ 状态描述得分：A/B/C/D/F                                 │
│  ├─ 结果描述得分：A/B/C/D/F                                 │
│  └─ 总体完整性：百分比%                                     │
│                                                              │
│  Step 4: 生成改进建议                                        │
│  ├─ 列出缺失项                                              │
│  ├─ 标注严重程度                                            │
│  ├─ 提供具体修正建议                                        │
│  └─ 给出修正后示例                                          │
│                                                              │
│  Step 5: 综合判断                                            │
│  ├─ pass：三层均达到B级以上                                 │
│  ├─ warning：某层为C级                                     │
│  └─ error：某层为D/F级                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 八、修正示例库

### 8.1 事业专项修正示例

```
【原始表述】（不合格）
"事业受火星影响，要注意风险"

【问题分析】
- 能量来源：只有"火星"，无先天属性、无与领域关系
- 状态描述：无状态、无状态含义
- 结果描述：只有"有风险"，无具体说明、无情境化

【修正后】（合格）
"事业宫主星火星落在白羊座10宫，火星为先天凶星，代表冲突、竞争与行动。
在白羊座入庙(来源: JSON Mars.dignity: 入庙)，能量强旺，从1宫飞入10宫
形成命-官结构。这意味着事业上需要主动竞争才能获得成就，适合开拓性、
竞争性强的工作如销售、创业等。火星入庙虽然能量强，但凶星性质不变，
事业上可能遇到竞争冲突、短期波动等风险，2026年火星大运期间需要
特别注意合作伙伴关系(来源: 七宫主金星与火星对冲)。"

【修正要点】
1. 补充宫主星名称 + 先天属性
2. 补充状态 + 状态含义
3. 补充具体结果 + 情境化 + 时间节点
4. 标注数据来源
```

### 8.2 感情专项修正示例

```
【原始表述】（不合格）
"感情有挑战，婚姻质量一般"

【问题分析】
- 能量来源：无行星信息、无宫主星信息
- 状态描述：无状态说明
- 结果描述：笼统标签，无具体描述

【修正后】（合格）
"七宫主金星落在天秤座7宫，金星为先天吉星，代表感情、价值与和谐。
在天秤座入庙(来源: JSON Venus.dignity: 入庙)，能量强旺。但金星与土星
形成四分相(来源: 相位表，容许度1.8°)，土星为先天凶星，代表限制与压力。
这意味着配偶条件不错、有审美品味(金星入庙)，但婚姻经营有一定压力，
可能表现为配偶工作忙碌、两地分居等情况。婚姻质量中等(3分/5分)，
需要双方共同努力经营。桃花运方面，金星与月亮三合(来源: 相位表)，
有一定桃花机会，但不算旺盛。"

【修正要点】
1. 补充七宫主信息 + 状态
2. 补充关键相位结构
3. 补充具体结果 + 评分 + 情境化
```

### 8.3 财运专项修正示例

```
【原始表述】（不合格）
"财运平稳，收入稳定"

【问题分析】
- 能量来源：无任何行星信息
- 状态描述：无
- 结果描述：笼统标签

【修正后】（合格）
"二宫主太阳落在水瓶座9宫，太阳为日盘核心星，代表核心价值与生命力。
在水瓶座失势(来源: JSON Sun.dignity: 失势)，能量受阻。这意味着正财方面
需要通过远方、高等教育、出国等途径获得收入(来源: 2宫主飞9宫)，可能
从事教育、外贸、跨国业务等领域。收入稳定性中等，早期可能不太稳定，
30岁后逐渐稳定。二宫内无行星，正财主要看宫主星状态，失势意味着
需要更多努力才能获得理想收入，年入XX万级别(来源: 结构分析)。五宫
弱(来源: 无宫内星，宫主星土星落陷)，偏财风险高，不建议重仓投机。"

【修正要点】
1. 补充二宫主 + 状态 + 含义
2. 补充飞宫解读
3. 补充收入类型 + 预期 + 时间线
4. 补充偏财情况
```
