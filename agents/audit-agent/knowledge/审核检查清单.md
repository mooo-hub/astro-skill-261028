## 相位核查规范（新增章节）

### 相位计算步骤

```
┌──────────────────────────────────────────────────────────────┐
│                相位核查规范                                    │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【步骤1：计算黄经差】                                        │
│  ├─ 获取行星1黄经（ecl_lon）                                 │
│  ├─ 获取行星2黄经（ecl_lon）                                 │
│  └─ 计算差值：|lon1 - lon2| 或 360 - |lon1 - lon2|           │
│                                                              │
│  【步骤2：判断相位类型】                                      │
│  ├─ 合相：接近0°                                             │
│  ├─ 六分相：接近60°                                          │
│  ├─ 四分相：接近90°                                          │
│  ├─ 三分相：接近120°                                         │
│  └─ 对分相：接近180°                                         │
│                                                              │
│  【步骤3：计算容许度】                                        │
│  ├─ 古典占星：(行星1容许度 + 行星2容许度) / 2              │
│  ├─ 例如：月火相位容许度 = (12+8)/2 = 10°                   │
│  └─ 偏离度 < 容许度 → 有效相位                               │
│                                                              │
│  【步骤4：判断入相位/出相位】                                 │
│  ├─ 计算两行星速度（speed字段）                              │
│  ├─ 速度快的行星是主动方                                     │
│  └─ 主动方接近对方 → 入相位；远离 → 出相位                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 行星容许度表

| 行星 | 容许度 |
|------|--------|
| 太阳 | 15° |
| 月亮 | 12° |
| 木星 | 12° |
| 土星 | 9° |
| 火星 | 8° |
| 金星 | 7° |
| 水星 | 7° |

### 常见错误警示

| 错误类型 | 错误示例 | 正确做法 |
|----------|----------|----------|
| 主观假设相位 | "金月六分相"（未计算）| 计算黄经差，核对是否为60°±容许度 |
| 忽略容许度 | 任意相位都算有效 | 必须核对容许度 |
| 不计算角度 | 直接写"金土相位" | 必须计算具体角度，判断是否为标准相位 |

## 审核失败处理

### 高严重性问题

| 问题类型 | 严重性 | 处理方式 |
|----------|--------|----------|
| 相位主观假设 | high | 必须重新计算相位角度 |
| 桃花评分相位未核查 | high | 必须逐个计算相位 |
| 事业判断缺少命主星/日月分析 | high | 必须补充完整分析 |
| 数据与解读混合 | high | 必须重新组织报告结构 |

### 中等严重性问题

| 问题类型 | 严重性 | 处理方式 |
|----------|--------|----------|
| 缺少数据引用 | medium | 补充数据来源标注 |
| 结论不够具体 | medium | 补充时间节点、具体事件 |
| 禁止表述出现 | medium | 修改为具体化表述 |
