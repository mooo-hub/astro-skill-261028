# 父母分析

父母分析是六亲专项分析的第一步，判断父母的层次、与自己的关系以及父母的身体状况。

## 一、核心概念

### 1.1 父母分析的两个维度

```
┌──────────────────────────────────────────────────────────────┐
│              父母判断两个维度                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【维度一：父母层次】                                         │
│  ├─ 有钱没钱、有官没官、富不富、贵不贵                       │
│  └─ 父母的层次直接影响子女的起点                             │
│                                                              │
│  【维度二：父母与自己的关系】                                 │
│  ├─ 关系好坏、是否有刑克                                     │
│  └─ 刑克严重程度                                             │
│                                                              │
│  ★ 重要：层次和关系是两个问题，必须分开判断                   │
│         父母层次低 ≠ 刑克父母                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、父母判断完整思维链

### 2.1 完整思维链流程

```
┌──────────────────────────────────────────────────────────────┐
│              父母判断完整思维链                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 1: 确定父母征象星                                       │
│    │                                                         │
│    ├─ 1.1 判断日生盘或夜生盘                                 │
│    │   ├─ 日生盘：太阳在地平线之上（7-12宫）                 │
│    │   └─ 夜生盘：太阳在地平线之下（1-6宫）                 │
│    │                                                         │
│    └─ 1.2 确定征象星                                        │
│        ├─ 日生盘：父亲=太阳，母亲=金星                       │
│        └─ 夜生盘：父亲=土星，母亲=月亮                       │
│                                                              │
│  Step 2: 判断父母的层次（维度一）                              │
│    │                                                         │
│    ├─ 2.1 看征象星是否得贵气                                │
│    │   │                                                     │
│    │   ├─ 贵气来源：太阳、月亮、木星                        │
│    │   │                                                     │
│    │   └─ 贵气判断                                          │
│    │       ├─ 得日/月/木贵气 → 层次高、有官有钱            │
│    │       ├─ 无贵气但得吉 → 中等层次                      │
│    │       └─ 受克、无贵气 → 层次普通                      │
│    │                                                         │
│    └─ 2.2 看四宫/十宫主的结构                               │
│        │                                                     │
│        └─ 分析方法                                          │
│            ├─ 四宫主与哪些星体形成结构？                    │
│            ├─ 那个星体是吉星还是凶星？（星性）              │
│            ├─ 那个星体主什么宫位？（宫性）                  │
│            └─ 综合判断父母层次                              │
│                                                              │
│  Step 3: 判断父母与自己的关系（维度二）                        │
│    │                                                         │
│    ├─ 3.1 看征象星是否被刑克                                │
│    │   │                                                     │
│    │   ├─ 单纯刑一下 → 轻刑克，像掉了一片羽毛，伤害不大     │
│    │   ├─ 多项凶像叠加 → 重刑克，严重程度叠加               │
│    │   └─ 本命凶+转宫凶 → 最严重，非常凶险                  │
│    │                                                         │
│    └─ 3.2 看转宫的凶星                                      │
│        │                                                     │
│        └─ 转宫法在刑克判断中的作用                          │
│            ├─ 看转宫的8r、12r是否刑克征象星                │
│            └─ 本命凶星刑克+转宫凶星刑克 = 最严重            │
│                                                              │
│  Step 4: 判断父母的身体                                       │
│    │                                                         │
│    ├─ 4.1 身体与事业通常连锁                                │
│    │   ├─ 很少只克事业不克身体                              │
│    │   ├─ 或者只克身体不克事业                              │
│    │   └─ 基本是连锁的                                      │
│    │                                                         │
│    └─ 4.2 判断方法                                          │
│        ├─ 征象星是否被本命凶星刑克                          │
│        ├─ 转宫的凶星（转宫的8r、12r）是否刑克征象星        │
│        └─ 本命凶星+转宫凶星都刑克，非常不吉利              │
│                                                              │
│  Step 5: 输出父母综合判断                                     │
│    │                                                         │
│    ├─ 父亲层次判断                                          │
│    ├─ 父亲关系判断                                          │
│    ├─ 母亲层次判断                                          │
│    └─ 母亲关系判断                                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、父母层次判断标准

### 3.1 高层次父母特征

```
【高层次父母特征】
├─ 征象星得贵气（日/月/木）
├─ 四宫主/十宫主入庙入旺
├─ 征象星与吉星有和谐相位
├─ 无凶星严重刑克
└─ 有官有钱、社会地位高
```

### 3.2 中等层次父母特征

```
【中等层次父母特征】
├─ 征象星无贵气但得吉
├─ 有小干扰但有化解
├─ 父母能力尚可
└─ 普通工薪阶层
```

### 3.3 低层次父母特征

```
【低层次父母特征】
├─ 征象星受克、无贵气
├─ 凶星刑克严重
├─ 无明显支持结构
└─ 基层工作、体力劳动
```

## 四、转宫法使用原则

### 4.1 转宫法基本原理

```
【定义】
以某宫为第一宫，逆时针转一圈，形成该人物的12宫位

【示例】
├─ 四宫 = 父亲的第一宫（父亲本人）
├─ 四宫的五宫 = 父亲的二宫（父亲的财帛宫）
├─ 四宫的六宫 = 父亲的三宫
└─ 十宫 = 母亲的宫位
```

### 4.2 转宫法核心原则

```
★ 严格要求：只论与征象星有结构的星体

【错误做法】
├─ 把所有宫位都转一遍
├─ 企图看爷爷、奶奶、叔叔等所有亲戚
└─ 这是不可能也不切实际的

【正确做法】
├─ 只看重要信息：格局层次、事业、身体
├─ 只看一代：父母、伴侣、子女
├─ 要看其他人，拿出他们自己的盘看
└─ 不在结构内的星体不要去论
```

## 五、刑克程度判断表

| 刑克情况 | 程度 | 比喻 |
|----------|------|------|
| 单纯刑一下 | 轻刑克 | 像掉了一片羽毛，伤害不大 |
| 两项凶像叠加 | 中等刑克 | 开始有实质影响 |
| 本命凶+转宫凶 | 重刑克 | 最严重，非常凶险 |
