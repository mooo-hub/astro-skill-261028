### 1.2 配偶征象星

```
【配偶宫位】第七宫
【配偶征象星】第七宫宫主星

【注意事项】
├─ 七宫主 ≠ 夫妻星（概念不同）
├─ 七宫主 = 配偶宫的宫主星
└─ 夫妻星 = 日生盘太阳/金星，夜生盘土星/月亮
```

## 三、配偶层次判断方法

### 3.1 七宫主结构分析

```
【分析方法】
├─ 七宫主与哪些星体形成结构？
├─ 那个星体是吉星还是凶星？（星性）
├─ 那个星体主什么宫位？（宫性）
└─ 综合判断配偶层次

【结构优先级】
├─ 接纳 > 互容 > 合相 > 刑冲 > 三合六合
└─ 紧密程度决定配偶层次高低
```

### 3.2 七宫主飞入宫位解读

| 七宫主飞入 | 配偶层次来源 | 判断 |
|------------|--------------|------|
| **一宫** | 靠自己、个人能力 | 始宫，稳定 |
| **二宫** | 靠金钱、理财 | 续宫，一般 |
| **四宫** | 靠家庭、房地产 | 始宫，稳定 |
| **七宫** | 靠合作、客户 | 始宫，稳定 |
| **十宫** | 靠事业、名声 | 始宫，最稳 |

## 四、配偶关系判断方法

### 4.1 七宫主与命主星关系

| 关系类型 | 配偶关系判断 | 具体表现 |
|----------|--------------|----------|
| **和谐相位** | 关系和谐 | 相互理解、支持 |
| **紧张相位** | 关系有挑战 | 需要磨合、沟通 |
| **无相位** | 关系疏离 | 缺乏情感连接 |
| **接纳** | 单向支持 | 一方支持另一方 |
| **互容** | 互相支持 | 相互帮助 |

---

## 五、配偶身体判断方法

### 5.1 判断原则

```
【基本原则】
├─ 与父母身体判断方法相同
├─ 看七宫主是否被刑克
├─ 看转宫凶星是否刑克
└─ 本命凶+转宫凶 = 最严重

【转宫凶星判断】
├─ 看转宫的8r、12r是否刑克七宫主
└─ 多项凶像叠加才严重
```
