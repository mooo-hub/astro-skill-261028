## 一、核心分析方法

### 1.1 六亲核心理念

```
┌──────────────────────────────────────────────────────────────┐
│                六亲论断核心理念                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心理念：父母决定前20年的层次，是子女的起点               │
│                                                              │
│  【重要概念】                                                 │
│  ├─ 父母的层次直接影响子女的起点                             │
│  ├─ 阶级固化：父母的层次基本决定子女阶层                     │
│  ├─ 六亲缘分薄：盘里显示父母层次低，不是"克父母"             │
│  ├─ 旺夫命：对方本身命能旺，不是你旺他                       │
│  └─ 一切已经写在本命盘里                                     │
│                                                              │
│  【两个维度】                                                 │
│  ├─ 维度一：六亲的层次（能力、事业）                         │
│  │   └─ 有钱没钱、有官没官、富不富、贵不贵                   │
│  │                                                          │
│  └─ 维度二：六亲与自己的关系（刑克程度）                     │
│      └─ 关系好坏、是否有刑克、刑克严重程度                   │
│                                                              │
│  ★ 重要：层次和关系是两个问题，必须分开判断                   │
│         父母层次低 ≠ 刑克父母                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 转宫法核心原则（★严格限制★）

```
┌──────────────────────────────────────────────────────────────┐
│              转宫法使用限制                                   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 严格要求：只论与征象星有结构的星体                        │
│                                                              │
│  【错误做法】                                                 │
│  ├─ 把所有宫位都转一遍                                      │
│  ├─ 企图看爷爷、奶奶、叔叔等所有亲戚                         │
│  └─ 这是不可能也不切实际的                                   │
│                                                              │
│  【正确做法】                                                 │
│  ├─ 只看重要信息：格局层次、事业、身体                       │
│  ├─ 只看一代：父母、伴侣、子女                               │
│  ├─ 要看其他人，拿出他们自己的盘看                           │
│  └─ 不在结构内的星体不要去论                                 │
│                                                              │
│  【本命占星与卜卦占星的区别】                                │
│  ┌─────────────┬─────────────────────────────┐               │
│  │    类型     │      转宫法使用            │               │
│  ├─────────────┼─────────────────────────────┤               │
│  │ 本命占星   │ 只能看结构内的信息         │               │
│  │ 卜卦占星   │ 可以一宫一宫看             │               │
│  └─────────────┴─────────────────────────────┘               │
│                                                              │
│  ★ 记住：不要用卜卦占星的方法看本命盘                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**转宫法基本原理**：

```
【定义】
以某宫为第一宫，逆时针转一圈，形成该人物的12宫位

【示例】
├─ 四宫 = 父亲的第一宫（父亲本人）
├─ 四宫的五宫 = 父亲的二宫（父亲的财帛宫）
├─ 四宫的六宫 = 父亲的三宫
└─ 十宫 = 母亲的宫位
```

## 二、Synthesis 字段规范

> **核心要求**：必须是具体描述，禁止打分，必须区分层次与关系

### 2.1 父亲层次 synthesis

**正确示例**：

```json
{
  "father_level_synthesis": "父亲层次中等偏高，太阳入庙得贵气，四宫主木星与太阳形成六合结构，有贵人支持。实例：父亲可能在教育行业或政府机构工作，有一定社会地位和稳定收入。"
}
```

**错误示例**：

```json
{
  "father_level_synthesis": "父亲：4分"  ✗ 禁止打分
  "father_level_synthesis": "父亲层次低"   ✗ 禁止笼统表述
}
```

---

### 2.2 父亲关系 synthesis

**正确示例**：

```json
{
  "father_relationship_synthesis": "与父亲关系整体和谐，征象星太阳无严重受克。但土星（转宫8r）与太阳有刑相，可能存在一些代沟或沟通障碍。实例：可能与父亲在某些价值观上有分歧，但整体关系尚可。刑克程度：轻。"
}
```

---

### 2.3 母亲层次 synthesis

**正确示例**：

```json
{
  "mother_level_synthesis": "母亲层次中等，金星入庙在天秤座，得先天吉星加持。十宫主火星落陷，母亲事业可能较为辛苦。实例：母亲可能在服务行业工作，靠技术吃饭，收入稳定但不是很高。"
}
```

---

### 2.4 配偶层次 synthesis

**正确示例**：

```json
{
  "spouse_level_synthesis": "配偶层次中等偏上，七宫主金星入庙在七宫，配偶有美感、有人缘。七宫主与木星形成三合结构，配偶有贵人运。实例：配偶可能在艺术、设计或公关领域工作，事业发展顺利。"
}
```

---

### 2.5 子女层次 synthesis

**正确示例**：

```json
{
  "children_level_synthesis": "子女层次较高，五宫主木星入庙在射手座，子女有福气、教育背景好。木星与太阳形成结构，子女有贵气。实例：子女可能在学习上表现优秀，有高等教育机会。"
}
```

## 五、输出禁忌

### 5.1 禁止格式

```json
// ✗ 禁止打分
"father_level_synthesis": "父亲：4分"
"mother_score": 3

// ✗ 禁止笼统表述
"spouse_level_synthesis": "配偶一般"
"children_relationship_synthesis": "子女关系还可以"

// ✗ 禁止无层次关系区分
"father_synthesis": "父亲好"

// ✗ 禁止模糊时间
"key_periods": [{"period": "近期", "event": "..."}]
```

---

### 5.2 正确原则

```
1. 层次与关系分开判断
2. 具体描述 > 笼统表述
3. 实例说明 > 空洞判断
4. 明确时间 > 模糊表述
5. 可操作建议 > 空洞建议
```

## 六、常见错误警示

| 错误认知 | 正确认知 |
|----------|----------|
| 父母层次低=刑克父母 | 层次和刑克是两个问题，分开判断 |
| 转宫法可以随便转 | 只能看结构内的星体 |
| 可以看所有亲戚 | 只看一代：父母、伴侣、子女 |
| 单一刑克就很严重 | 多项凶像叠加才严重 |
| 本命盘可以用卜卦方法 | 本命只能看结构内信息 |
