│   └─ 刑冲 → 父亲关系有挑战

└─ 法达主运行星与五宫主星的关系
    ├─ 接纳/互容 → 子女关系重要

## 四、法达+小限配合判断

### 4.1 双重触发

```
【最强父亲期】
├─ 法达主运 = 四宫主星/太阳（日盘）/土星（夜盘）
│   AND
└─ 小限走四宫年
    → 父亲重大相关期，必须重点关注

【最强配偶期】
├─ 法达主运 = 七宫主星
│   AND
└─ 小限走七宫年
    → 配偶重大相关期，婚姻转折

【最强子女期】
├─ 法达主运 = 五宫主星/木星
│   AND
└─ 小限走五宫年
    → 子女重大相关期，子女事务
```

### 4.2 六亲时间线分析

```
【判断流程】
Step 1: 确定当前年龄
    │
    ├─ 计算法达主运/子运
    └─ 计算小限宫位

Step 2: 判断法达与六亲关系
    │
    ├─ 主运行星与四宫/七宫/五宫主星关系
    └─ 主运行星宫性判断

Step 3: 判断小限与六亲关系
    │
    ├─ 小限宫位是否为四宫/十宫/七宫/五宫
    └─ 年主星状态判断

Step 4: 综合六亲运势
    │
    ├─ 法达基调
    ├─ 小限主题
    └─ 输出六亲判断
```
