## 三、子女层次判断方法

### 3.1 五宫主状态判断

| 五宫主状态 | 子女层次判断 | 具体表现 |
|------------|--------------|----------|
| **入庙入旺** | 子女有能力 | 事业有成就 |
| **外来** | 子女能力中等 | 普通水平 |
| **落陷失势** | 子女能力受限 | 需要支持 |

### 3.2 五宫主结构判断

```
【结构分析】
├─ 五宫主与哪些星体形成结构？
├─ 那个星体是吉星还是凶星？（星性）
├─ 那个星体主什么宫位？（宫性）
└─ 综合判断子女层次

【贵气判断】
├─ 得日/月/木贵气 → 子女有成就
├─ 无贵气但得吉 → 子女能力尚可
└─ 受刑克、无贵气 → 子女有困难
```

## 四、子女关系判断方法

### 4.1 五宫主与命主星关系

| 关系类型 | 子女关系判断 | 具体表现 |
|----------|--------------|----------|
| **和谐相位** | 子女听话、关系好 | 相互理解 |
| **紧张相位** | 子女叛逆、关系有挑战 | 需要沟通 |
| **无相位** | 关系疏离 | 缺乏互动 |
| **接纳** | 单向支持 | 一方支持另一方 |
| **互容** | 互相支持 | 相互帮助 |

---

## 五、子女数量判断方法

### 5.1 五宫内行星影响

| 五宫内行星数量 | 子女数量倾向 |
|----------------|--------------|
| 多行星（3颗以上） | 子女多 |
| 中等（1-2颗） | 子女中等 |
| 无行星 | 子女较少 |

### 5.2 木星状态影响

| 木星状态 | 子女运判断 |
|----------|------------|
| 庙旺 | 子女运好，子女多 |
| 中等 | 子女运一般 |
| 落陷 | 子女运受限，子女少 |
