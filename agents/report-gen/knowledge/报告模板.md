> **版本**：v7.0 | 2026-06-25
> **核心原则**：**每个维度遵循「结论→依据→含义→表现→建议」五段式因果链**
> **更新说明**：
> - v7.0：整合解盘思维链框架，采用五段式因果链输出结构
> - v6.0：结构调整为"板块内数据+解读结合"

## 报告生成核心原则

```
┌──────────────────────────────────────────────────────────────┐
│                ★ 报告结构原则（v7.0）★                        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【五段式因果链】每个专项维度必须包含：                         │
│  1. 结论：一句话概括整体模式（概率语言）                       │
│  2. 依据：入口宫位+宫主星+结构+推运触发                        │
│  3. 含义：将配置翻译为占星含义                                │
│  4. 表现：场景化描述+具体实例                                 │
│  5. 建议：适合方向+避免方向+时间节点+行动步骤                   │
│                                                              │
│  【跨维度整合】报告最后必须包含：                              │
│  ├─ 反复出现的主题行星                                       │
│  ├─ 同频共振的维度                                           │
│  ├─ 维度冲突与核心张力                                       │
│  └─ 统一人生叙事（一句话总结）                                │
│                                                              │
│  【禁止事项】                                                 │
│  ✗ 禁止打分评分                                              │
│  ✗ 禁止笼统标签                                              │
│  ✗ 禁止宿命化语言                                            │
│  ✗ 禁止模糊时间（"近期""以后"）                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

```markdown
└─ 注意事项：压力大时症状可能加重

情绪管理（水土刑相）：
├─ 每日：睡前10分钟冥想或深呼吸
├─ 每周：至少3次30分钟有氧运动（跑步/游泳/瑜伽）
├─ 定期：找到1-2个可信赖的人倾诉（每周至少1次深度交流）
└─ 必要时：如持续低落超过2周，寻求专业心理咨询

执行时间表：
├─ 每天：23点前入睡，保证7-8小时睡眠
├─ 每周二、四、六：30分钟有氧运动
├─ 每周六下午：2小时个人反思/写作时间
└─ 每年体检：关注胃肠镜、肝功能、甲状腺
```

### 具体化自查清单

生成报告时，必须检查以下内容：

```
□ 每个建议都有具体举例（至少1个）
□ 每个时间节点都有具体年月（精确到季度或月份）
□ 每个行动建议都有具体步骤（至少3步）
□ 避免了以下抽象表述：
  ├─ "需要注意XX"
  ├─ "建议建立XX"
  ├─ "适合XX方向"
  ├─ "近期/长期"
  ├─ "适度/合理"
  ├─ "选择合适的人"
  └─ "主动社交"
□ 具体数字包含：频率（每天/每周/每月）、时长（XX分钟）、数量（XX次）
```
