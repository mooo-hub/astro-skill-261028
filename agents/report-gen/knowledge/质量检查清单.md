# 质量检查清单

> **用途**：report-gen Agent和audit-agent共用的质量检查清单
> **版本**：v2.0 | 2026-06-08
> **更新说明**：新增表述风格检查项

---

## 一、具体性检查

### 必须通过的检查项

- [ ] 每个结论有具体时间点或时间范围
- [ ] 每个结论有具体事件描述
- [ ] 每个建议有可操作性
- [ ] 无"可能"、"也许"、"大概"等模糊词
- [ ] 使用"什么时候""什么事""怎么做"框架

### 检查方法

```
对于每个结论，问三个问题：
1. 什么时候？（具体年份/月份）
2. 什么事？（具体事件类型）
3. 怎么做？（具体行动建议）

如有任一问题无法回答，该结论不通过。
```

## 二、禁止表述检查

### 必须不出现的表述

```
【事业类】
✗ "事业有发展机会"
✗ "工作上会有变动"
✗ "事业运势整体平稳"
✗ "工作方面需要注意"

【感情类】
✗ "感情上会有挑战"
✗ "感情运势一般"
✗ "感情方面需要经营"

【财运类】
✗ "财运整体平稳"
✗ "财运有波动"
✗ "投资需谨慎"

【健康类】
✗ "要注意健康"
✗ "身体状况一般"

【综合类】
✗ "可能会有变化"
✗ "整体运势一般"
✗ "需要多加注意"
```

### 检查方法

```
使用文本搜索功能，逐一检查上述禁止表述是否出现。
如发现任何一项，该部分需修改。
```

## 三、表述风格检查（★新增★）

### 评分式表述转换检查

- [ ] 无"桃花评分：X分/5分" → 改为描述性表述
- [ ] 无"配偶能力评分：X分/5分" → 改为描述性表述
- [ ] 无"事业评分：X分/5分" → 改为描述性表述
- [ ] 无"财运评分：X分/5分" → 改为描述性表述
- [ ] 无"健康风险：高/中/低" → 改为关注建议

### 冷硬术语转换检查

- [ ] 无"能量弱" → 改为"需要更多努力"
- [ ] 无"能量差" → 改为"面临挑战，有成长空间"
- [ ] 无"凶相，拉扯消耗" → 改为"需要找到平衡"
- [ ] 无"缺乏联系" → 改为"需要建立连接"

### 温暖支持性检查

- [ ] 报告结尾有支持性语言
- [ ] 强调个人选择权
- [ ] 提供化解方向而非仅警示
- [ ] 使用"你可以考虑"而非"你应该"

### 检查方法

```
1. 搜索"评分"字样，确认全部转换为描述性表述
2. 搜索"能量弱""能量差"等冷硬术语，确认已转换
3. 检查报告结尾是否有"写在最后"部分
```

## 四、具体化检查（★新增★）

### 抽象表述检查

**必须不出现的抽象表述**：

```
【边界类】
✗ "需要建立边界"
✗ "设立明确边界"
✗ "需要划分"

【社交类】
✗ "需要主动社交"
✗ "扩大社交圈"
✗ "多认识人"

【健康类】
✗ "注意健康"
✗ "关注情绪管理"
✗ "适度运动"

【时间类】
✗ "近期"
✗ "长期"
✗ "适当时候"

【建议类】
✗ "选择合适的人"
✗ "适合XX行业"
✗ "稳定发展"
```

### 具体化要求检查

- [ ] 每个建议都有具体举例（至少1个）
- [ ] 每个时间节点都有具体年月（精确到季度或月份）
- [ ] 每个行动建议都有具体步骤（至少3步）
- [ ] 事业建议有具体职业方向和行业细分
- [ ] 感情建议有具体筛选标准和行动方法
- [ ] 财务建议有具体金额或比例参考
- [ ] 健康建议有具体执行频率

### 具体化转换检查表

| 检查项 | 原表述 | 具体化表述 | 是否通过 |
|--------|--------|------------|----------|
| 边界建议 | "建立边界" | "工作日19点后不处理工作邮件；周末至少1天完全休息" | ☑/□ |
| 社交建议 | "主动社交" | "每周参加1次兴趣社群活动；每月让朋友介绍1-2个新认识的人" | ☑/□ |
| 健康建议 | "注意情绪管理" | "每周至少3次30分钟有氧运动；每天睡前10分钟冥想" | ☑/□ |
| 时间节点 | "近期" | "2026年Q3-Q4" 或 "2026年9-11月" | ☑/□ |
| 职业方向 | "适合教育" | "适合成人教育领域，特别是心理学教育，建议从小班教学开始" | ☑/□ |

### 检查方法

```
1. 搜索"需要建立""需要主动""需要注意"等表述
2. 确认每个建议后都有具体举例
3. 确认时间节点精确到年月或季度
4. 确认行动建议有具体数字（频率、时长、数量）
```
