# 数据优先结构规范

> **用途**：确保报告遵循"板块内数据展示+解读结合"的结构原则
> **版本**：v2.0 | 2026-06-04
> **更新说明**：v2.0调整为"板块内数据+解读结合"结构，而非大板块分离

## 审核检查点

### 数据层审核

```
□ 所有数据表格完整呈现
□ 度数精确到分（XX°XX'）
□ 庙旺落陷评分准确（±X分）
□ 相位容许度精确（X.XX°）
□ 入相位/出相位判断正确
□ 古典守护关系正确（水瓶→土星、双鱼→木星、天蝎→火星）
□ 日夜盘判断正确
□ 小限宫位计算正确（年龄÷12余数）
□ 法达大运顺序正确
```

### 解读层审核

```
□ 每个解读标注数据来源
□ 遵循三层面论断（星性→宫性→结构）
□ 结论具体化（无禁止表述）
□ 时间节点明确
□ 可操作性建议
```

### 结构审核

```
□ 数据展示与数据解读明确分离
□ 数据展示部分无解读性文字
□ 解读部分每个结论都有数据引用
□ 附录包含完整原始数据JSON
```
