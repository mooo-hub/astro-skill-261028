## 二、输出要求（强制）

### 禁止行为

```
✗ 禁止输出任何形式的评分（如"事业高度：3分"、"桃花运评分：1/5分"）
✗ 禁止输出笼统标签（如"事业运势好"、"感情有挑战"）
✗ 禁止输出空洞建议（如"需要注意健康"、"需要经营感情"）
✗ 禁止输出无因果链结论（如"木星在10宫，事业成功"）
```

### 必须行为

```
✓ 每个维度必须具体描述状态（如"事业可能比较辛苦，需要在严格的环境中发展...")
✓ 每个维度必须举例说明（如"实例：可能在金融机构的后台风控部门工作..."）
✓ 每个结论必须有因果链支持（如"十宫主星土星落陷，导致事业表达受限..."）
✓ 每个建议必须具体可操作（如"建议在土星回归前后避免重大决策..."）
✓ 必须遵循五段式因果链：依据→含义→现实表现→优势/风险→建议
```

## 三、五段式因果链输出格式（★核心★）

> 所有专项维度的输出必须遵循以下因果链结构，确保每条结论都有完整可追溯的依据链。

### 3.1 通用输出模板

```markdown
### [专项名称]分析

#### [专项]结论
【一句话概括该维度整体模式，使用概率语言】

#### 分析依据
- **入口宫位**：X宫（XX座），宫主星XX星，落X宫，状态（±X分）
- **核心结构**：XX相位/接纳/互容（结构星：XX星）
- **自然征象星**：XX星，状态（±X分）
- **与命主星关系**：XX相位/无相位
- **推运触发**：法达XX运/小限X宫年（如有）

#### 含义解读
【将上述配置翻译为占星含义，说明该维度的能量运作方式】

#### 现实表现
1. 【场景化表现1】
2. 【场景化表现2】
3. 【场景化表现3】

**具体实例**：
- 【生活化举例，如职业、关系模式、财务行为等】

#### 优势与挑战
- **优势**：【基于好结构、庙旺行星等】
- **挑战**：【基于受克、落陷、凶宫掺入等】

#### 发展建议
- **适合方向**：【方向词群，非单一答案】
- **避免方向**：【基于凶相、弱陷等】
- **关键时间点**：【明确年月，避免"近期"】
- **具体行动**：【可执行步骤，含频率/时长/数量】
```

### 3.2 跨维度整合（★必做★）

报告最后必须包含跨维度整合章节，识别重复主题：

```markdown
### 跨维度整合分析

#### 反复出现的主题行星
【识别在多个维度中反复扮演关键角色的行星】
- 行星：XX星
- 涉及维度：事业、感情、财运...
- 统一含义：【该行星代表的主题叙事】

#### 同频共振的维度
【识别相互支持的维度组合】
- 事业与财运：XX主星与XX主星吉相 → 【共振含义】

#### 维度冲突与核心张力
【识别相互刑克的维度组合，命名核心矛盾】
- 事业与感情：XX主星与XX主星刑克 → 【张力含义】
- 命名核心矛盾：【一句话总结人生主线张力】

#### 统一人生叙事
【用一两句话将所有维度提炼为连贯的人生主题】
> 你的盘核心是——【统一叙事】
```

## 三、专项分析输出格式

### 事业分析输出模板

**正确格式**：
```markdown
### 事业分析

#### 事业状态描述

事业可能比较辛苦，需要在严格的环境中发展，可能涉及他人资源/投资等领域。十宫主星土星为先天凶星，落陷于巨蟹座，能量表达受限。但贵人结构（土木互容）可能带来关键的转折机会和支持。

**具体表现实例**：
- 可能从事风控、审计、合规等需要长期积累的工作
- 工作环境可能较为严格，有较多规章制度
- 上级领导可能在关键时刻给予支持（土木互容带来的贵人）
- 事业发展节奏较慢，需要耐心等待机会

**影响因素**：
- 十宫主星土星（先天凶星）→ 事业需要长期积累
- 土星落陷 → 事业表达受限，需要更多努力
- 土星落8宫 → 事业可能涉及他人资源、深度转化
- 土木互容 → 可能遇到贵人帮助

#### 发展建议

**适合方向**：长期积累型行业、他人资源管理、深度专业领域
**避免方向**：短期投机、依赖人气的职业、快速变现模式

**关键时间点**：
- 有利时机：土木互容激活期、木星过境相关宫位时
- 需谨慎：土星回归前后、土星刑冲关键点

**具体行动建议**：
- 主动建立深度合作而非广泛社交
- 专注专业积累而非频繁跳槽
- 在贵人结构激活期把握机会
```

**错误格式（禁止）**：
```markdown
### 事业分析

#### 事业高度：★★★★☆（4分）
事业运势一般，需要经营。注意把握机会。
```

### 感情分析输出模板

**正确格式**：
```markdown
### 感情分析

#### 配偶能力描述

配偶可能具有一定能力和审美品味。七宫主金星入庙于天秤座，能量强旺，意味着伴侣可能有良好的社交能力、审美意识和和谐追求。但金星与土星形成四分相，可能带来一些经营压力。

**配偶特质实例**：
- 可能从事艺术、设计、咨询、一对一服务等领域
- 性格可能温和、有品味、注重和谐
- 工作可能较为忙碌，或有两地分居情况

#### 婚姻质量描述

婚姻经营有一定压力，需要双方共同努力。金星入庙带来良好的感情基础，但土星的限制性质可能表现为工作压力、时间安排紧张等情况。

**具体表现实例**：
- 可能因为工作安排而聚少离多
- 需要在事业与感情之间找到平衡
- 双方可能需要主动创造相处时间

#### 桃花运描述

桃花运中等，有恋爱机会但不算旺盛。金星与月亮三合，带来一定的感情缘分，但需要注意主动创造社交机会。
```

## 四、表述风格转换

### 从 synthesis 字段读取

| 专项Agent输出 | report-gen转换 |
|--------------------|----------------|
| synthesis（具体描述） | 直接引用，不做修改 |
| influencing_factors | 转化为报告语言描述 |
| advice.direction.suitable | → "建议她可以考虑..." |
| advice.direction.avoid | → "需要注意避免..." |
| advice.timing | → 具体时间描述 |
| advice.action | → 生活场景举例 |

### 温暖表述转换表

| ❌ 避免的表述 | ✅ 推荐的表述 |
|--------------|--------------|
| "桃花评分：1/5分" | "感情方面需要主动创造机会" |
| "配偶能力有限" | "伴侣可能需要你的支持" |
| "事业高度中等" | "事业有中等的发展空间" |
| "财运一般" | "财务方面建议采取稳健策略" |
