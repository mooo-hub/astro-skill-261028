# /astro-chart

精确计算西方占星本命盘。基于**Swiss Ephemeris**天文计算库，支持多种分宫制，提供准确的行星黄道位置、宫位分配、相位分析和元素分布统计。

**分宫制选择**：
- **阿卡比特制（默认）**：古典占星（中世纪占星）推荐，Crystal课程原话"因为我们学的是中世纪占星，所以就用这个排"
- **Placidus**：现代占星默认
- **整宫制**：古典占星辅助，解决劫夺宫位问题

---

## Step 1: 检查pyswisseph库是否可用

运行检测命令确认`pyswisseph`库已安装：

```bash
python -c "import swisseph as swe; print('Swiss Ephemeris版本:', swe.version)"
```

如果pyswisseph不可用，执行安装：

```bash
pip install pyswisseph
```

国内镜像加速：

```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pyswisseph
```

## Step 3: 执行排盘计算

运行排盘脚本：

```bash
python ~/.claude/skills/astro-chart/astro_calc.py 年 月 日 时 分 经度 纬度 时区 [分宫制]
```

**分宫制参数**（可选）：
- `alcabitius` - 阿卡比特制（**默认**，古典占星推荐）
- `placidus` - Placidus（现代占星默认）
- `whole` - 整宫制（古典占星辅助）
- `koch` - Koch分宫制
- `equal` - 等宫制

示例：

```bash
# 古典占星排盘（默认阿卡比特制）
python ~/.claude/skills/astro-chart/astro_calc.py 1997 2 18 13 34 118.5 37.4 8

# 明确指定阿卡比特制
python ~/.claude/skills/astro-chart/astro_calc.py 1997 2 18 13 34 118.5 37.4 8 alcabitius

# 现代占星排盘（Placidus分宫制）
python ~/.claude/skills/astro-chart/astro_calc.py 1997 2 18 13 34 118.5 37.4 8 placidus

# 整宫制排盘
python ~/.claude/skills/astro-chart/astro_calc.py 1997 2 18 13 34 118.5 37.4 8 whole

# 1996年11月15日12:00 安徽池州
python ~/.claude/skills/astro-chart/astro_calc.py 1996 11 15 12 0 117.5 30.7 8
```

## 技术说明

### 计算精度

- **天文库**：Swiss Ephemeris 2.10+（业界最高精度）
- **分宫制**：默认阿卡比特制（古典占星推荐），支持Placidus、整宫制等
- **历元**：使用当前历元计算

### ★ 古典占星 vs 现代占星模式

本脚本支持两种占星体系模式：

| 特性 | 古典占星模式（默认） | 现代占星模式 |
|------|---------------------|-------------|
| **触发方式** | 默认（无参数）或 `classical` | `modern` 参数 |
| **分宫制** | 阿卡比特制（默认） | Placidus（默认） |
| **参与相位行星** | 七大古典行星 | 十大行星（含三王星） |
| **相位容许度** | William Lilly行星容许度 | 固定容许度 |
| **推荐场景** | 古典占星断局SOP | 现代占星分析 |

**使用方法**：

```bash
# 古典占星模式（默认，推荐）
python astro_calc.py 1997 2 18 13 34 118.5 37.4 8

# 明确指定古典占星模式
python astro_calc.py 1997 2 18 13 34 118.5 37.4 8 alcabitius classical

# 现代占星模式
python astro_calc.py 1997 2 18 13 34 118.5 37.4 8 placidus modern
```

### 分宫制对比

| 分宫制 | 代码 | 特点 | 推荐体系 |
|--------|------|------|----------|
| **阿卡比特制** | `alcabitius` | 中世纪占星标准，Crystal课程推荐 | **古典占星** |
| **Placidus** | `placidus` | 时间分宫，西方主流 | **现代占星** |
| **整宫制** | `whole` | 每宫30°，解决劫夺宫位 | 古典占星辅助 |
| **Koch** | `koch` | 地点分宫 | 美国常用 |
| **等宫制** | `equal` | 简单但不精确 | 辅助参考 |

### 古典占星相位判断标准（William Lilly体系）

古典占星模式采用传统的**行星容许度（Orb by Planet）**，而非固定容许度。

#### 行星容许度表

| 行星 | 容许度 | 说明 |
|------|--------|------|
| 太阳 | 15° | 最大，象征生命核心 |
| 月亮 | 12° | 次大，运行最快 |
| 木星 | 12° | 吉星，影响范围广 |
| 土星 | 9° | 凶星，限制性强 |
| 火星 | 8° | 凶星，力量集中 |
| 金星 | 7° | 吉星，影响适中 |
| 水星 | 7° | 最小，影响有限 |

#### 相位容许度计算

两行星之间的相位容许度 = (行星1容许度 + 行星2容许度) / 2

**示例**：
- 土星-月亮相位容许度 = (9 + 12) / 2 = **10.5°**
- 土星-木星相位容许度 = (9 + 12) / 2 = **10.5°**
- 土星-火星相位容许度 = (9 + 8) / 2 = **8.5°**

### 现代占星相位判断标准（固定容许度）

现代占星模式使用固定容许度：

| 相位类型 | 固定容许度 |
|---------|-----------|
| 合相（0°） | 10° |
| 六分相（60°） | 6° |
| 四分相（90°） | 8° |
| 三分相（120°） | 8° |
| 对分相（180°） | 10° |

### 入相位/出相位判断

两种模式均基于两颗行星的**实际运行速度**（包含逆行状态）：

- **入相位（Applying）**：偏离度正在变小，即将形成精确相位
- **出相位（Separating）**：偏离度正在变大，已离开精确相位

判断方法：模拟下一步的位置，比较偏离度变化。
