# 量化评分标准

> **用途**：专项分析评分标准，供domain-analysis Agent调用
> **版本**：v1.0 | 2026-06-15
> **来源**：古典占星完备课程第五卷

---

## 一、事业高度评分标准

| 评分 | 判断标准 | 具体条件 |
|------|----------|----------|
| **5分** | 极高层次 | 贵星（日/月/木）支持 + 结构清纯 + 无凶宫掺入 + 有接纳/互容 |
| **4分** | 高层次 | 有贵星支持 + 结构较好 + 凶宫掺入≤1个 |
| **3分** | 中等层次 | 有一定结构支持 + 无贵星但结构尚可 |
| **2分** | 普通偏下 | 结构一般 + 有凶宫掺入 + 贵星支持弱 |
| **1分** | 较低层次 | 结构混乱 + 多处凶宫掺入 + 无贵星支持 |

### 加分项

```
├─ 有日/月/木贵星结构：+2分
├─ 有接纳/互容关系：+1分
├─ 结构清纯（无凶宫掺入）：+1分
├─ 官禄星入庙入旺：+0.5分（辅助）
└─ 日月结构支持：+1分
```

### 减分项

```
├─ 凶宫（3r/6r/8r/12r）掺入：-1分/个
├─ 结构破损（刑冲无接纳）：-1分
├─ 官禄星落陷且无结构弥补：-1分
└─ 多项凶叠加：-1分
```

## 二、事业稳定度评分标准

| 评分 | 判断标准 | 具体条件 |
|------|----------|----------|
| **5分** | 极稳定 | 无凶宫掺入 + 结构完整 + 有贵星化解 |
| **4分** | 稳定 | 凶宫掺入≤1个 + 有结构支持 |
| **3分** | 一般 | 有凶宫掺入但不严重 |
| **2分** | 不太稳定 | 多处凶宫掺入 + 结构有破损 |
| **1分** | 不稳定 | 凶星+凶宫+凶相位叠加 |

### 稳定性加分项

```
├─ 结构清纯无破损：+2分
├─ 有贵星化解：+1分
├─ 官禄星落在始宫（1/4/7/10）：+1分
└─ 官禄星与命主星和谐：+0.5分
```

### 稳定性减分项

```
├─ 凶宫（3/6/8/12）掺入：-1分/个
├─ 刑冲相位且无接纳：-1分
├─ 官禄星落在果宫（3/6/9/12）：-0.5分
└─ 凶星+凶宫+凶相位三重叠加：-2分
```

## 三、配偶能力评分标准

| 评分 | 判断标准 | 具体条件 |
|------|----------|----------|
| **5分** | 极强 | 七宫主得贵星（日/月/木）支持 + 结构清纯 + 入庙 |
| **4分** | 强 | 有贵星结构 + 七宫主有力 |
| **3分** | 中等 | 结构一般但七宫主尚可 |
| **2分** | 偏弱 | 七宫主受克或凶宫掺入 |
| **1分** | 弱 | 七宫主落陷且无结构弥补 |

### 加分项

```
├─ 七宫主与贵星（日/月/木）有结构：+2分
├─ 七宫内有吉星：+1分
├─ 七宫主入庙入旺：+1分
└─ 七宫主飞入始宫：+0.5分
```

### 减分项

```
├─ 七宫内有凶星（火/土）：-1分
├─ 七宫主与凶星刑冲：-1分
├─ 七宫主落陷且无弥补：-1分
└─ 七宫主飞入凶宫：-0.5分
```

## 六、健康风险评估标准

| 风险等级 | 判断标准 | 具体条件 |
|----------|----------|----------|
| **低** | 单项或无凶像 | 日月得吉 + 六八宫无连接 + 凶像交叠≤1项 |
| **中** | 两项凶像叠加 | 日月一般 + 六八宫有连接 + 凶像交叠=2项 |
| **高** | 三项及以上叠加 | 日月受克 + 六八宫连接 + 凶像交叠≥3项 |

### 凶像类型（每项算1分）

```
├─ 征象星被先天凶星（火/土）刑克
├─ 征象星被后天凶星（6r/8r/12r）刑克
├─ 征象星落陷
├─ 六宫、八宫、十二宫主星相互连接
├─ 转宫凶星刑克
└─ 火土同时掺入结构
```
