### 1.2 推运方法分类

| 类型 | 方法 | 原理 | 特点 |
|------|------|------|------|
| **外因** | 行运法（Transit） | 当下行星与本命盘对应 | 真实环境变化 |
| **内因** | 次限法（Progression） | 浓缩时间对应 | 内在心境变化 |
| **周期** | 返照法（Return） | 行星回归到原点 | 周期整体运势 |
| **结构** | 太阳弧法（Direction） | 整体星盘等距移位 | 结构性变化 |

## 二、次限法详解

### 2.1 次限法定义

**定义**：以一天代表一年的推运方法。

**原理**：
- 出生后第一天的行星位置 = 第一年的推运位置
- 出生后第十天的行星位置 = 第十年的推运位置
- 以此类推

### 2.2 次限法特点

| 特点 | 说明 |
|------|------|
| 主要看推运太阳、月亮 | 其他行星变化缓慢 |
| 推运月亮两三年走一圈 | 速度较慢 |
| 推运太阳一年走一度 | 非常缓慢 |
| 次限行星变化缓慢 | 外行星几乎不动 |

### 2.3 次限法应用

**应用要点**：

```
┌──────────────────────────────────────────────────────────────┐
│                次限法应用要点                                   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【重点行星】                                                 │
│  ├─ 推运太阳：代表当年的核心主题                              │
│  ├─ 推运月亮：代表心境变化和情感需求                          │
│  └─ 其他行星：几乎不变，参考意义小                            │
│                                                              │
│  【关键时机】                                                 │
│  ├─ 推运太阳换星座：人生主题转变                              │
│  ├─ 推运月亮换星座：心境转变                                  │
│  └─ 推运行星与本命形成相位：事件触发                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、太阳弧法详解

### 3.1 太阳弧法定义

**定义**：以太阳移动带动全盘行星移动的推运方法。

**原理**：
- 太阳每年约走1度
- 全盘行星都随太阳移动1度
- 形成向运盘（Solar Arc）

### 3.2 太阳弧法特点

| 特点 | 说明 |
|------|------|
| 全盘行星同步移动 | 保持原有相位结构 |
| 形成的相位稳定不变 | 结构不改变 |
| 与本命盘形成相位时有事件触发 | 关键判断点 |

### 3.3 太阳弧法应用

**应用方法**：

```
┌──────────────────────────────────────────────────────────────┐
│                太阳弧法应用步骤                                 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一步】计算太阳弧推进                                      │
│  ├─ 年龄 = 太阳弧推进度数                                     │
│  ├─ 如30岁，太阳弧推进30度                                    │
│  └─ 全盘行星推进相应度数                                      │
│                                                              │
│  【第二步】检查与中天的相位                                    │
│  ├─ 太阳弧行星与本命盘形成相位                                │
│  ├─ 特别是太阳、月亮、命主星                                  │
│  └─ 触发重要事件                                              │
│                                                              │
│  【第三步】结合行运验证                                        │
│  ├─ 太阳弧触发 + 行运激活                                    │
│  └─ 双重验证更准确                                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 四、行运法详解

### 4.1 行运法定义

**定义**：用当前时刻的行星位置与本命盘对照，判断即时影响。

**本质**：真实环境的外在变化（外因）

### 4.2 行运法特点

| 特点 | 说明 |
|------|------|
| 最直接的推运方法 | 当下天象直接对照 |
| 实时反映当前天象 | 行运行星位置 |
| 行运行星触发本命盘事件 | 事件触发机制 |

### 4.3 行运行星影响时长

| 行运行星 | 影响时长 | 事件特点 |
|----------|----------|----------|
| 行运太阳 | 约1个月 | 短期影响 |
| 行运月亮 | 约2天 | 最短期影响 |
| 行运水星 | 约几天 | 短期影响 |
| 行运金星 | 约1周 | 中短期影响 |
| 行运火星 | 约2周 | 中期影响 |
| 行运木星 | 约1年 | 长期影响 |
| 行运土星 | 约2-3年 | 最长期影响 |

### 4.4 行运法解读步骤

```
┌──────────────────────────────────────────────────────────────┐
│                行运法解读步骤                                   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一步】查看运行星位置                                      │
│  ├─ 当前时刻行星所在位置                                      │
│  └─ 所在的星座和宫位                                          │
│                                                              │
│  【第二步】检查与本命盘相位                                    │
│  ├─ 与本命行星形成相位                                        │
│  ├─ 与本命四轴形成相位                                        │
│  └─ 判断相位性质（入相位/出相位）                              │
│                                                              │
│  【第三步】判断影响性质                                        │
│  ├─ 和谐相位（三合/六合）：过程顺畅                             │
│  ├─ 紧张相位（刑/冲）：过程有挑战                               │
│  ├─ 结合星性判断：吉星/凶星本质                                 │
│  ├─ 结合宫性判断：所主事项领域                                  │
│  └─ 注意入相位代表即将发生（出相位代表逐渐离开）                  │
│  │                                                              │
│  【第四步】判断结果性质 ★重要★                                  │
│  ├─ 相位只代表过程，不代表结果                                  │
│  ├─ 结果需看接纳结构：有无接纳/互容                             │
│  └─ 无接纳结构时，相位不产生实质性帮助                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 五、推运方法学习顺序

### 5.1 古典推运优先

**推荐顺序**：

| 顺序 | 方法 | 重要性 | 原因 |
|------|------|--------|------|
| 1 | 法达星限法 | 最重要 | 古典核心方法 |
| 2 | 小限法 | 重要 | 配合法达使用 |
| 3 | 太阳返照 | 次要 | 年度运势判断 |
| 4 | 行运法 | 辅助 | 触发事件判断 |

### 5.2 现代推运辅助

**次要推运**：

| 方法 | 用途 | 优先级 |
|------|------|--------|
| 次限法 | 内在心境变化 | 辅助 |
| 太阳弧法 | 结构性变化 | 辅助 |
