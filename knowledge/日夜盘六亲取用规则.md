## 三、父亲征象星

### 日盘取太阳

```
【日盘父亲】
├── 主征象：太阳
├── 辅助征象：四宫宫主星（4r）
├── 判断方法：
│   ├── 看太阳的状态（力量、落宫）
│   ├── 看太阳与其他行星的结构
│   └── 结合4r的状态综合判断
└── 太阳好 = 父亲层次高、有帮助
```

### 夜盘取土星

```

├── 主征象：土星
```

## 六、事业主星

### 日盘事业

```
【日盘事业】
├── 主征象：太阳
├── 辅助征象：官禄主星（10r）+ 命主星
├── 判断方法：
│   ├── 太阳是官禄主 → 月亮不用参与判断
│   ├── 太阳非官禄主 → 太阳+官禄主+命主都要看
│   └── 太阳不管怎样都很重要
└── 太阳好 = 事业成就高
```

### 夜盘事业

```
【夜盘事业】
├── 主征象：月亮
├── 辅助征象：太阳 + 官禄主星（10r）+ 命主星
├── 判断方法：
│   ├── 月亮得吉 → 事业好
│   ├── 月亮不佳 → 看其他辅助征象
│   └── 太阳也要参考进来
└── 夜盘太阳也要参与判断
```

## 七、子女星

### 通用规则

```
【子女星】
├── 主征象：木星
├── 辅助征象：五宫宫主星（5r）
├── 判断方法：
│   ├── 看木星的状态（力量、落宫）
│   ├── 看五宫的状态
│   └── 结合5r的状态综合判断
└── 木星好 = 子女优秀、听话
```

### 应用扩展

```
【学生星】
├── 木星可当学生星使用
├── 判断学生听不听话、是否优秀
└── 同样看木星+五宫状态
```

## 八、六亲层次判断方法

### 判断步骤

```markdown
## XX（父亲/母亲/配偶）层次分析

### 第一步：确定征象星
- 日盘/夜盘：确认主征象星是谁
- 辅助征象：确认宫主星是谁

### 第二步：分析征象星状态
- 征象星落座：......
- 征象星落宫：......
- 征象星尊贵：入庙/入旺/失势/落陷
- 征象星结构：
  - 接纳关系：......
  - 互容关系：......
  - 相位关系：......

### 第三步：判断贵气来源
- 有无得贵星加持（太阳、月亮、木星）
- 贵星状态如何
- 结构紧密程度

### 第四步：综合判断
- 层次评估：高层/中层/普通
- 具体分析：......
```

### 贵气来源

```
【贵星定义】
├── 太阳：王、领导、官方
├── 月亮：后、情感资源
└── 木星：贵人、机会、仁慈

【贵气判断】
├── 征象星得贵星加持 = 有贵气
├── 木星本身是贵星，但要看宫性
│   ├── 木星主1、4、5、9、10、11宫 = 有气
│   └── 木星主3、6、8、12宫 = 无气
└── 日月本身是贵星，可忽略宫性
```

## 九、刑克判断

### 轻重程度

```
【轻刑克】
├── 单纯刑一下，伤害不大
└── 像掉了一片羽毛

【重刑克】
├── 多项凶像叠在一起
└── 严重程度叠加

【最重刑克】
├── 本命凶星刑克 + 转宫凶星刑克
├── 三宫、六宫、八宫信息太多
└── 一宫、十宫、八宫混在一起
```

### 判断原则

```
【核心原则】
├── 六亲缘分薄 = 盘里显示父母层次低
├── 不是"克父母"这样的负面表述
├── 一切已经写在本命盘里
└── 不要用宿命论吓唬客户
```
