## 三、组合属性解读

### 热+干（太阳、火星）

```
【性格特点】
├── 热情、急躁
├── 直接、不遮掩
├── 像男生、缺乏阴柔特质
├── 做事干脆、不拖泥带水
└── 容易冲动、脾气急

【案例：太阳刑火星】
├── 性格像男生
├── 缺乏女性阴柔特质
├── 类似八字"阳刃强、比劫旺"的女性
└── 热情但可能冲动急躁
```

### 冷+湿（月亮、金星）

```
【性格特点】
├── 阴柔、母性
├── 情绪化、敏感
├── 包容、融合
├── 湿润、感性
└── 缺乏阳刚之气（男性）

【案例：命主月亮合金星】
├── 性格阴柔
├── 有母性特质
└── 男性缺乏阳刚之气
```

### 热+湿（木星）

```
【性格特点】
├── 乐观大方
├── 包容度高
├── 眼光长远
├── 喜欢哲思
├── 不小家子气
└── 讲大道理
```

### 冷+干（土星）

```
【性格特点】
├── 务实、悲观
├── 固执、保守
├── 界限分明
├── 压制、收敛
└── 耐力、坚持
```

## 四、性格分析案例

### 案例1：微博红人盘

```
【配置】
├── 太阳射手 + 日水合 + 日火三合（火星入庙）
├── 月亮摩羯 + 月土合 + 月火刑
└── 组合分析：

| 组合 | 属性 | 解读 |
|------|------|------|
| 太阳射手+火星 | 热+干 | 燥、直接、竞争性强 |
| 月亮+土星 | 冷+干 | 湿冷被土星压制、悲观、务实、冷酷、现实 |
| 月亮+火星刑 | 脾气 | 脾气不小、不服输 |

【综合结论】
├── 性格不好、嫉妒心强、脾气暴躁、不服输
├── 内心冷酷、功利性强
├── 幸福度低、幸福感受度差
└── 婚姻感受度和幸福度不好
```

## 五、干湿冷热论性格方法

### 分析步骤

```
【第一步】找出关键的行星组合
├── 太阳与什么星有相位？
├── 月亮与什么星有相位？
├── 命主星与什么星有相位？
└── 重点看凶相位（刑、冲）

【第二步】判断属性组合
├── 热星 + 热星 = 更热
├── 冷星 + 冷星 = 更冷
├── 干星 + 干星 = 更干
├── 湿星 + 湿星 = 更湿
└── 热星 + 冷星 = 中和或冲突

【第三步】综合判断
├── 偏热偏干：热情、急躁、直接
├── 偏冷偏湿：阴柔、情绪化、依赖
├── 偏热偏湿：乐观、包容、大方
└── 偏冷偏干：务实、固执、悲观
```

### 重点相位

```
【重点看】
├── 日月相位（自我与情感的关系）
├── 太阳与土星相位（自我与责任）
├── 月亮与土星相位（情感与安全感）
├── 月亮与火星相位（情感与冲动）
└── 命主星与主要行星相位

【凶相位优先】
├── 刑相位：阻碍大、不好解
├── 冲相位：立场不同
└── 吉相只是性格好的一面，凶相才是性格挑战
```

## 六、元素分布论性格

### 元素对应属性

| 元素 | 属性 | 性格特点 |
|------|------|----------|
| **火象** | 热+干 | 勇往直前、积极、冲动、大度、不记仇 |
| **水象** | 冷+湿 | 敏感、直觉强、情绪化、调查能力强 |
| **风象** | 热+湿 | 理性、适合出主意、不愿坚持、遇压力跑路 |
| **土象** | 冷+干 | 坚持、能忍、踏实、注重实际、容易养备胎 |

### 元素强弱判断

```
【统计方法】
统计：太阳、月亮、水星、金星、火星、木星、土星 + 上升星座
★ 不统计天王星、海王星、冥王星

【分布判断】
├── 火象强（≥4颗）：热情主动、有冲劲，可能冲动
├── 土象强（≥4颗）：务实稳重、有耐心，可能固执
├── 风象强（≥4颗）：理性社交、有智慧，可能疏离
├── 水象强（≥4颗）：情感直觉、有同理心，可能情绪化
├── 平衡分布：性格全面，适应力强
└── 缺失元素：该元素特质表达不畅
```

## 七、静态性格与动态性格

### 静态性格（待人接物）

```
【分析方法】看星体落座

【核心参考】
├── 命度（上升）
├── 命宫落星
├── 命主落座
├── 太阳星座
├── 月亮星座
└── 干湿冷热特质
```

### 动态性格（遇事反应）

```
【分析方法】看相位结构

【核心原则】
├── 相位表示心理状态和动机
├── 以合相和凶相（冲、刑）为主
└── 遇事反应才是真正的性格

【案例：日土刑】
├── 太阳巨蟹（表面温和）
├── 刑土星金牛
├── 土星 = 干冷特质压制月亮的湿冷
└── 结论：固执、倔强、自我

【案例：月火刑】
├── 月亮白羊 = 竞争性、要面子
├── 火星落陷 = 脾气爆发
└── 结论：敏感、易被激怒、情绪化
```
