## 一、南北交点运期顺序

### 1.1 法达大运中的位置

南北交点是法达大运的最后两个运期：

```
【日升盘完整顺序】
太阳→金星→水星→月亮→土星→木星→火星→北交点→南交点

【夜升盘完整顺序】
月亮→土星→木星→火星→北交点→南交点→太阳→金星→水星
```

### 1.2 运期长度

| 运期 | 长度 | 年龄范围（日升盘） |
|------|------|-------------------|
| 北交点 | 3年 | 70-73岁 |
| 南交点 | 2年 | 73-75岁 |

## 三、南北交点运期判断方法

### 3.1 宫位判断

```
【北交点宫位】好运领域
├─ 1宫：自我发展有好运
├─ 2宫：财务收入有好运
├─ 5宫：恋爱子女有好运
├─ 7宫：婚姻合作有好运
├─ 10宫：事业发展有好运
└─ 11宫：社交团体有好运

【南交点宫位】考验领域
├─ 1宫：自我认同有课题
├─ 2宫：财务收入有课题
├─ 5宫：恋爱子女有课题
├─ 7宫：婚姻合作有课题
├─ 10宫：事业发展有课题
└─ 11宫：社交团体有课题
```

### 3.2 与行星合相判断

```
【北交点与吉星合相】吉上加吉
├─ 北交点+木星：极度幸运，扩展顺利
├─ 北交点+金星：感情顺利，财运好
└─ 北交点+太阳：贵人相助，成就突出

【北交点与凶星合相】凶性减弱
├─ 北交点+土星：土星阻碍被减轻
├─ 北交点+火星：火星冲突被缓解
└─ 凶星负面影响减弱

【南交点与吉星合相】吉性减弱
├─ 南交点+木星：木星好运被削弱
├─ 南交点+金星：金星感情受阻
└─ 吉星正面影响减弱

【南交点与凶星合相】凶上加凶
├─ 南交点+土星：土星阻碍加剧
├─ 南交点+火星：火星冲突加剧
└─ 凶星负面影响增强
```

### 3.3 定位星判断

```
【无合相时看定位星】
├─ 南北交点所在星座的守护星
├─ 定位星的状态影响运期质量
└─ 定位星宫位显示影响领域
```

## 四、南北交点运期实务应用

### 4.1 运期预测

```
【北交点运期预测】
├─ 整体基调：顺遂期
├─ 关键领域：北交点宫位
├─ 机会方向：北交点定位星
└─ 建议：顺势而为，把握机缘

【南交点运期预测】
├─ 整体基调：考验期
├─ 关键领域：南交点宫位
├─ 挑战方向：南交点定位星
└─ 建议：谨慎行事，内省修行
```

### 4.2 小运搭配

```
【北交点大运+小运行星】
├─ 北交点+木星小运：最顺利的组合
├─ 北交点+吉星小运：好运加持
├─ 北交点+凶星小运：困难减轻
└─ 小运仍按法达顺序排列

【南交点大运+小运行星】
├─ 南交点+土星小运：最困难的组合
├─ 南交点+凶星小运：困难加剧
├─ 南交点+吉星小运：困难有所缓解
└─ 需要特别注意健康和财务
```

## 五、南北交点在法达中的特殊性

### 5.1 不掌管小运

```
【重要规则】
南北交点在法达大运中不掌管小运周期。

【计算说明】
├─ 小运仍按七大行星顺序排列
├─ 南北交点运期的小运计算方式相同
└─ 小运总年数 = 南北交点运期年数
```

### 5.2 小运计算示例

```
【北交点大运（3年）的小运分配】
├─ 太阳小运：3×(10/70) ≈ 0.43年（5个月）
├─ 金星小运：3×(8/70) ≈ 0.34年（4个月）
├─ 水星小运：3×(13/70) ≈ 0.56年（7个月）
├─ 月亮小运：3×(9/70) ≈ 0.39年（5个月）
├─ 土星小运：3×(11/70) ≈ 0.47年（6个月）
├─ 木星小运：3×(12/70) ≈ 0.51年（6个月）
└─ 火星小运：3×(7/70) ≈ 0.30年（4个月）

【南交点大运（2年）的小运分配】
├─ 太阳小运：2×(10/70) ≈ 0.29年（3-4个月）
├─ 金星小运：2×(8/70) ≈ 0.23年（3个月）
├─ 水星小运：2×(13/70) ≈ 0.37年（4-5个月）
├─ 月亮小运：2×(9/70) ≈ 0.26年（3个月）
├─ 土星小运：2×(11/70) ≈ 0.31年（4个月）
├─ 木星小运：2×(12/70) ≈ 0.34年（4个月）
└─ 火星小运：2×(7/70) ≈ 0.20年（2-3个月）
```
