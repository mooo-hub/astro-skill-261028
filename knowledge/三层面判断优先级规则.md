# 三层面判断优先级规则

判断优先级：**结构 > 宫性 > 星性 > 尊贵**。高层信息压倒低层信息。

核心规则：
- 有结构先看结构（接纳>互容>合相>刑冲）
- 宫性压倒星性（金星主8宫仍是破财）
- 尊贵只表示能量强度，不决定结果好坏

## 二、四层判断规则详解

### 第一层：结构（最优先）

```
┌──────────────────────────────────────────────────────────────┐
│                    结构层判断规则                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【结构定义】                                                 │
│  行星之间的相位关系，代表能量传递的渠道。                     │
│                                                              │
│  【结构优先级】                                               │
│  ├─ 接纳/互容：最紧密的连接（优先级最高）                     │
│  │   ├─ 接纳：行星A在行星B守护的星座，且有相位               │
│  │   └─ 互容：两行星互相在对方守护的星座                     │
│  ├─ 合相：能量融合（优先级高）                               │
│  ├─ 刑/冲：有张力和拉锯（优先级中）                          │
│  └─ 三合/六合：松散的"远亲"关系（优先级低）                  │
│                                                              │
│  【结构本身无吉凶】                                           │
│  ├─ 结构只是"载体"                                          │
│  ├─ 星性+宫性是"内容"                                       │
│  └─ 结构好坏 = 结构类型 + 星性 + 宫性                       │
│                                                              │
│  【好结构判断公式】                                           │
│  好结构 = 紧密结构 + 吉星 + 吉宫                             │
│  坏结构 = 紧密结构 + 凶星 + 凶宫                             │
│                                                              │
│  【关键规则】                                                 │
│  ├─ 有结构先看结构                                           │
│  ├─ 无结构才看尊贵                                           │
│  └─ 接纳互容可以弥补落陷的负面影响                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

#### 接纳与互容详解

```
┌──────────────────────────────────────────────────────────────┐
│                    接纳判断规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【定义】                                                     │
│  当一行星进入某星座，与主宰该星座的行星形成重要相位。         │
│                                                              │
│  【必要条件】                                                 │
│  ├─ 行星A在行星B守护的星座                                   │
│  └─ 两行星有托勒密相位（合/刑/冲/拱/六）                     │
│                                                              │
│  【效果】                                                     │
│  ├─ 使两个宫位产生联动                                       │
│  ├─ 即使是凶相位，也能使凶相减弱                             │
│  └─ 形成能量的接受与认可                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│                    互容判断规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【定义】                                                     │
│  两颗行星各自进入对方主宰的星座（或庙旺星座）。               │
│                                                              │
│  【必要条件】                                                 │
│  └─ 两行星各在对方守护的星座（不需要有相位）                 │
│                                                              │
│  【效果】                                                     │
│  ├─ 为彼此带来额外的力量                                     │
│  ├─ 两星成为互助状态                                         │
│  ├─ 原来的弱陷状态消失，反而成为吉利状态                     │
│  └─ 形成宫位之间的双向联动                                   │
│                                                              │
│  【互容类型与力量】                                           │
│  ├─ 庙庙互容：最强                                           │
│  ├─ 庙旺互容：强                                             │
│  ├─ 旺旺互容：中等                                           │
│  └─ 其他互容：较弱                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

#### 接纳互容案例

```
【案例：金星与火星互容】

初始状态：
- 金星在白羊座（失势，因白羊由火星守护）
- 火星在天秤座（失势，因天秤由金星守护）

互容效果：
- 原本两星都失势
- 互容使两星成为互助状态
- 第七宫（金星守护）与第一宫（火星守护）产生联动
- 配偶与自己的关系得到改善

判断：
- 不再判断为"失势"
- 而是判断为"互容吉象"
```

### 第二层：宫性（高优先）

```
┌──────────────────────────────────────────────────────────────┐
│                    宫性判断规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【宫性定义】                                                 │
│  行星作为宫主星所代表的领域（后天宫性）。                     │
│                                                              │
│  【吉宫】                                                     │
│  1宫、4宫、5宫、9宫、10宫、11宫                               │
│  ├─ 代表积极、正面的领域                                     │
│  └─ 宫主星参与结构时，增加贵气                               │
│                                                              │
│  【凶宫】                                                     │
│  3宫、6宫、8宫、12宫                                          │
│  ├─ 代表困难、挑战的领域                                     │
│  └─ 宫主星参与结构时，降低贵气                               │
│                                                              │
│  【关键规则】                                                 │
│  ├─ 宫性压倒星性                                             │
│  │   例：金星是吉星但掌管八宫 → 八宫性质优先，仍论破财       │
│  ├─ 同一星体主不同宫位，结构好坏不同                         │
│  │   例：木星主9r（吉）+ 主12r（凶）→ 吉凶参半              │
│  └─ 吉星主凶宫 = 无气 → 降低贵气                             │
│                                                              │
│  【日月例外】                                                 │
│  ├─ 日月本身就是天王天后级别                                 │
│  ├─ 如果日月本身是官禄星或夫妻星，直接作为贵星参考           │
│  └─ 不需要看日月主什么宫位                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

#### 宫性判断案例

```
【案例一：金星主八宫参与事业结构】

盘面数据：
- 金星是8r
- 金星与官禄星有相位

判断：
- 金星本身是吉星
- 但金星主八宫（凶宫）
- 宫性压倒星性
- 结论：事业有破财风险，非纯吉

【案例二：木星主9r和12r】

盘面数据：
- 木星是9r和12r
- 木星与官禄星有接纳关系

判断：
- 木星本身是吉星
- 木星主9r（吉宫）→ 增加贵气
- 木星主12r（凶宫）→ 降低贵气
- 综合：吉凶参半，中等偏好结构

【案例三：火星主1r和10r】

盘面数据：
- 火星是1r和10r
- 火星与官禄星有刑相

判断：
- 火星本身是凶星
- 但火星主1r和10r（都是吉宫）
- 宫性压倒星性
- 结论：刑相有挑战，但非纯凶
```

### 第三层：星性（中优先）

```
┌──────────────────────────────────────────────────────────────┐
│                    星性判断规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【星性定义】                                                 │
│  行星本身的性质（先天吉凶）。                                 │
│                                                              │
│  【先天吉星】                                                 │
│  ├─ 木星：扩张、幸运、哲学、贵气                             │

│                                                              │

│  ├─ 火星：行动、冲突、性欲、意外                             │

│  ├─ 太阳：尊贵、领导、父亲（贵星）                           │

│  ├─ 星性次于宫性                                             │

│                                                              │
```

### 第四层：尊贵（最低优先）

```
┌──────────────────────────────────────────────────────────────┐
│                    尊贵判断规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【尊贵定义】                                                 │
│  行星的先天禀赋状态（庙旺落陷）。                             │
│                                                              │
│  【必然尊贵】                                                 │
│  ├─ 入庙（Domicile）：行星回到自己守护的星座，+5分           │
│  ├─ 擢升（Exaltation）：行星在旺宫星座，+4分                 │
│  ├─ 三分性（Triplicity）：行星在日生/夜生的三分主星座，+3分  │
│  ├─ 界（Term）：行星在所主管的界区间，+2分                   │
│  └─ 面（Face）：行星在所主管的十度区间，+1分                 │
│                                                              │
│  【必然无力】                                                 │
│  ├─ 失势（Detriment）：行星在自己主管星座的正对面，-5分      │
│  ├─ 落陷（Fall）：行星在旺宫星座的正对面，-4分               │
│  └─ 外来（Peregrine）：行星所落位置完全没有必然尊贵，-5分    │
│                                                              │
│  【★ 关键规则 ★】                                            │
│  ├─ 尊贵只表示能量强度，不决定结果好坏                       │
│  ├─ 庙旺 ≠ 好，落陷 ≠ 坏                                    │
│  ├─ 有结构时，尊贵是辅助参考                                 │
│  ├─ 无结构时，才看尊贵作为判断依据                           │
│  └─ 落陷+有贵星结构：可以弥补能量不足                        │
│                                                              │
│  【错误认知纠正】                                             │
│  ├─ 官禄星庙旺 ≠ 事业一定好                                 │
│  ├─ 官禄星落陷 ≠ 事业一定差                                 │
│  └─ 庙旺只是"能量强"，不代表结果好坏                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、信息冲突解决规则

```
┌──────────────────────────────────────────────────────────────┐
│                    信息冲突解决规则                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【规则一：结构优先】                                         │
│  高层信息压倒低层信息                                         │
│  例：木星落陷但被接纳 → 接纳结构优先，落陷负面被减弱         │
│                                                              │
│  【规则二：宫性优先于星性】                                    │
│  后天宫性压倒先天星性                                         │
│  例：金星是吉星但掌管八宫 → 八宫性质优先，仍论破财           │
│                                                              │
│  【规则三：尊贵不决定吉凶】                                    │
│  庙旺落陷只影响表达形式，不决定结果好坏                       │
│  例：庙旺 ≠ 好，落陷 ≠ 坏                                    │
│                                                              │
│  【规则四：紧密程度优先】                                      │
│  同层信息中，紧密程度高的压倒紧密程度低的                     │
│  例：接纳互容 > 合相 > 冲刑 > 三合六合                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 五、实战案例

### 案例一：事业判断

```
【盘面数据】
- 十宫宫主：水星（双子座）
- 水星位置：双子座九宫，入庙
- 水星与木星相位：木星接纳水星
- 木星宫性：9r、12r

【判断流程】

第一步：看结构
- 木星接纳水星 → 紧密结构
- 结构类型：接纳

第二步：分析木星宫性
- 木星是9r（吉宫）→ 增加贵气
- 木星是12r（凶宫）→ 降低贵气
- 综合：吉凶参半

第三步：分析木星星性
- 木星是吉星 → 增加和谐

第四步：分析水星尊贵
- 水星入庙 → 能量强

第五步：综合判断
- 结构：接纳（紧密）→ 好
- 宫性：9r+12r → 吉凶参半
- 星性：木星吉 → 好
- 尊贵：入庙 → 能量强

结论：
- 事业高度：中等偏上（有接纳结构，但12r减分）
- 事业稳定度：需注意（12宫掺入）
```

### 案例二：感情判断

```
【盘面数据】
- 七宫宫主：土星（水瓶座）
- 土星位置：狮子座一宫，落陷
- 土星与木星相位：木星互容土星
- 木星宫性：4r、7r

【判断流程】

第一步：看结构
- 木星互容土星 → 紧密结构
- 结构类型：互容

第二步：分析木星宫性
- 木星是4r（吉宫）→ 增加贵气
- 木星是7r（吉宫）→ 增加贵气
- 综合：纯吉

第三步：分析木星星性
- 木星是吉星 → 增加和谐

第四步：分析土星尊贵
- 土星落陷 → 能量弱
- 但有互容 → 弥补落陷

第五步：综合判断
- 结构：互容（紧密）→ 好
- 宫性：4r+7r → 纯吉
- 星性：木星吉 → 好
- 尊贵：落陷但有互容 → 弥补

结论：
- 配偶能力：中等（土星落陷但有互容弥补）
- 婚姻质量：中上（木星互容带来和谐）
```

### 案例三：健康判断

```
【盘面数据】
- 六宫主：火星（白羊座）
- 八宫主：金星（天秤座）
- 六宫主与八宫主关系：无相位
- 土星（12r）与火星刑相

【判断流程】

第一步：看六八宫连接
- 无相位 → 无重病风险

第二步：统计凶像交叠
- 土星（12r）刑火星（6r）→ 1项
- 单项凶 → 轻微问题

第三步：分析各维度
- 身体健康：低风险（无六八连接）
- 心理健康：需关注（有土星刑火星）
- 意外伤害：低风险（无三/六/八/十二串联）

结论：
- 身体健康：低风险
- 心理健康：中等风险
- 意外伤害：低风险
```

## 六、常见错误警示

| 错误认知 | 正确认知 | 判断规则 |
|----------|----------|----------|
| 庙旺就好 | 庙旺只表示能量强，不决定结果好坏 | 尊贵层优先级最低 |
| 落陷就差 | 落陷可以由接纳互容弥补 | 结构优先于尊贵 |
| 有结构就是好事 | 结构只是载体，要看星性+宫性 | 结构本身无吉凶 |
| 金星一定是吉星 | 金星主凶宫时，宫性压倒星性 | 宫性优先于星性 |
| 三合六合很重要 | 是"远亲"，优先看接纳/互容 | 紧密程度优先 |
