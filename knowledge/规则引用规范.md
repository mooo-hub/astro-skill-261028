# 知识文件规则引用规范

> **版本**：v1.0 | 日期：2026-06-16
> **用途**：建立单一来源原则，消除标准漂移

---

## 一、单一来源原则

### 核心规则

```
┌──────────────────────────────────────────────────────────────┐
│                    ★ 单一来源原则 ★                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  每条核心规则有且只有一个"主文件"作为权威来源                │
│                                                              │
│  其他文件只能引用，不能完整复述                              │
│                                                              │
│  引用时必须标注："完整规则见 [[主文件]]"                      │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 引用格式模板

```markdown
## [规则名称]

→ 完整规则见 [[主文件路径]]
→ 本文仅引用结论：[核心结论一句话]

如需详细判断标准，请查阅主文件。
```

## 三、需要改为引用的文件

### 3.1 核心方法论.md

**修改前**：
```markdown
## 三层面判断优先级
结构 > 宫性 > 星性 > 尊贵 > 落宫
（完整描述...）
```

**修改后**：
```markdown
## 三层面判断优先级
→ 完整规则见 [[三层面判断优先级规则]]
→ 本文仅引用结论：结构 > 宫性 > 星性 > 尊贵 > 落宫
```

### 3.2 专项分析增强规则.md

同样改为引用模式，不完整复述三层面规则。

### 3.3 audit-agent检查清单

检查项中如需引用规则，使用引用格式：
```markdown
□ 三层面论断框架正确应用
  → 完整规则见 [[三层面判断优先级规则]]
```

## 四、新增规则的处理流程

当需要新增规则时：

1. **确定主文件位置**：在 `knowledge/` 目录下创建独立文件
2. **其他文件引用**：需要使用该规则时，使用引用格式
3. **禁止复述**：即使觉得"复述一下更方便"，也要克制

---

## 五、引用的好处

| 好处 | 说明 |
|------|------|
| **消除漂移** | 规则只有一处定义，不会出现版本不一致 |
| **便于维护** | 修改规则只需改一处 |
| **可追溯** | 每条规则都有明确来源 |
| **减少冗余** | 避免文件膨胀 |
