## 二、大运法（Transit）

### 2.1 核心原理

```
【大运法核心原理】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ★ 大运法是最直接的推断运势方法                               │
│                                                              │
│  【核心概念】                                                 │
│  ├─ 直接对应当下的行星状态                                   │
│  ├─ 看当下行星与你的本命盘行星是否产生感应                   │
│  └─ 本质：真实环境的外在变化（外因）                         │
│                                                              │
│  【解读步骤】                                                 │
│  第一步：查看运行星位置                                       │
│  第二步：对照本命盘行星位置                                   │
│  第三步：判断是否形成相位                                     │
│  第四步：解读具体影响                                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、推运法（Progression）

### 3.1 核心原理

```
【推运法核心原理】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【与大运法的区别】                                           │
│  ├─ 大运法：真实环境的变化（外因）                           │
│  └─ 推运法：内在心境的变化（内因）                           │
│                                                              │
│  【核心概念】                                                 │
│  ├─ 一段小周期的变化可以对应、扩张成一段大周期的变化         │
│  └─ 类似「天上一天，地上一年的概念」                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 三种推运方法对比

| 方法 | 时间对应 | 说明 |
|------|----------|------|
| **主限法** | 约4分钟=1年 | 以东升点为基准 |
| **次限法** | 1天=1年 | 出生后太阳走一度的位置对应一年 |
| **三限法** | 1天=1月 | 以月亮运行对应月份变化 |

### 3.3 次限法时间对应

```
【次限法时间对应】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  出生后第1天 → 1岁时的推运星分布                              │
│  出生后第30天 → 30岁时的推运星分布                            │
│  出生后第90天 → 90岁时的推运星分布                            │
│                                                              │
│  ★ 重要发现：                                                 │
│  出生后三个月（代表推运约90年）是人生最重要的时期             │
│  因为这三个月决定了一生的基本走向                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.4 次限法解读要点

| 要点 | 说明 |
|------|------|
| 推运太阳 | 内在自我的变化方向 |
| 推运月亮 | 情绪周期和内在需求（约2.5年换一宫） |
| 推运太阳与本命行星相位 | 内在驱动力的激活 |
| 推运月亮与本命行星相位 | 情绪感受的变化 |

## 四、返照法（Return）

```
【返照法核心原理】
┌──────────────────────────────────────────────────────────────┐
│                                                              │

│                                                              │
│  【类似中国的小限概念】                                       │
│                                                              │
│  【主要返照类型】                                             │
│  ├─ 太阳返照：1年周期，年度运势                              │
│  ├─ 月亮返照：1月周期，月度运势                              │
│  └─ 其他行星返照：各行星回归周期，特定领域运势               │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 返照类型

| 类型 | 周期 | 用途 |
|------|------|------|
| **太阳返照** | 1年 | 年度运势 |
| **月亮返照** | 1月 | 月度运势 |
| 其他行星返照 | 各行星回归周期 | 特定领域运势 |

## 五、向运法（Direction）

### 5.1 核心原理

```
【向运法核心原理】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ★ 以一个星体运行速度为基准                                   │
│    将整个命盘上的所有物件做相对性的移动                       │
│                                                              │
│  【太阳弧向运法】                                             │
│  ├─ 以太阳的移动速度为基准                                   │
│  ├─ 将整盘所有行星和点等距移位                               │
│  └─ 太阳每天移动约1度 → 代表1年的命运变化                    │
│                                                              │
│  【移动规则】                                                 │
│  出生后5天 → 太阳移动5度 → 代表5年后                         │
│  所有行星都等距移动5度                                       │
│  （包括月亮、金星、火星等）                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 与次限推运的区别

```
【向运法 vs 次限法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【次限法】                                                   │
│  ├─ 各行星按各自速度移动                                     │
│  └─ 月亮移动快，其他行星按各自周期移动                       │
│                                                              │
│  【向运法】                                                   │
│  ├─ 所有行星等距移动                                         │
│  └─ 都移动相同度数（太阳移动的度数）                         │
│                                                              │
│  【理解】                                                     │
│  ├─ 次限法：各行星独立运动                                   │
│  └─ 向运法：全盘同步移动                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 5.3 向运法解读要点

| 要点 | 说明 |
|------|------|
| 向运行星进入宫位 | 结构性变化进入新领域 |
| 向运行星与本命行星相位 | 触发本命潜能 |
| 向运四角变化 | 人生方向的结构性转变 |

## 六、四种方法综合应用

### 6.1 方法定位

| 方法 | 定位 | 主要用途 |
|------|------|----------|
| **大运法** | 外因 | 预测真实环境事件 |
| **推运法** | 内因 | 理解内在心境变化 |
| **返照法** | 周期 | 把握年度整体运势 |
| **向运法** | 结构 | 判断人生结构性转折 |

### 6.2 综合判断流程

```
【四种方法综合判断流程】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  第一步：看返照盘                                             │
│    └─ 把握年度整体运势基调                                   │
│                                                              │
│  第二步：看大运法                                             │
│    └─ 预测具体事件发生时间                                   │
│                                                              │
│  第三步：看推运法                                             │
│    └─ 理解内在心境和需求                                     │
│                                                              │
│  第四步：看向运法                                             │
│    └─ 判断结构性转折点                                       │
│                                                              │
│  第五步：综合判断                                             │
│    └─ 四法合一，得出完整结论                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 6.3 四法配合口诀

```
【四法配合口诀】

外因看大运，内因看推运
周期看返照，结构看向运
四法合一用，运势更精准
```
