# 核心方法论

宫位判断优先级：**宫主星 > 宫内星 > 结构**。宫主星是宫位的"代言人"，决定吉凶动态发展。

三大核心原则：
1. 宫主星决定该宫位的动态发展
2. 结构本身无吉凶，需结合宫性+星性判断
3. 太极点转化：同一结构不同太极点，结论不同

---

## 一、宫位判断优先级（★核心原则★）

```
┌──────────────────────────────────────────────────────────────┐
│                宫位判断三层次优先级                             │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一优先】宫主星（决定性因素）                               │
│  ├── 宫主星是谁（古典守护关系）                                │
│  ├── 宫主星力量（庙旺落陷）                                    │
│  ├── 宫主星飞入宫位                                           │
│  └── 宫主星结构关系                                           │
│                                                              │
│  【第二优先】宫内星（辅助参考）                                 │
│  ├── 有无宫内行星                                             │
│  ├── 宫内行星力量                                             │
│  └── 宫内行星作为哪宫宫主星（后天宫性）                         │
│                                                              │
│  【第三优先】结构（完整判断）                                   │
│  ├── 宫主星与其他行星的相位                                    │
│  ├── 接纳互容关系                                             │
│  └── 宫内星的结构关系                                          │
│                                                              │
│  ★ 完整判断 = 宫主星 + 宫内星 + 结构 ★                        │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 宫主星的重要性

```
宫主星 = 该宫位的"代言人"、"老板"
├── 决定该宫位的动态发展和吉凶
├── 比宫内星更重要
└── 空宫不代表该领域不好，应看宫主星状态

宫内星 = 该宫位的"静态状态"
├── 表示该宫位的静止状态
├── 把其他宫位的信息带入此宫位
└── 辅助参考，非决定性因素
```

### 实际应用示例

```
【判断事业运（十宫）】
正确顺序：
1. 先看十宫宫主星状态
   - 落什么宫？（连接哪个领域）
   - 落什么星座？（展现方式）
   - 有什么结构？（接纳互容、相位）
   - 宫主星本身能量（庙旺落陷）

2. 再看十宫宫内星
   - 有什么星？（先天吉凶）
   - 该星作为哪宫宫主星？（后天宫性）
   - 该星的结构如何？

3. 综合判断
   - 宫主星 + 宫内星 + 结构 = 完整判断
```

## 二、结构解读框架

### 结构本身无吉凶

```
┌──────────────────────────────────────────────────────────────┐
│                  结构的真正意义                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【相位吉凶】只表示心理体验，不代表事件结果                      │
│  ├── 凶相位不代表结果差                                       │
│  ├── 吉相位不代表结果好                                       │
│  └── 必须结合宫性、星性判断                                   │
│                                                              │
│  【结构真正意义】                                              │
│  结构 = 宫位之间的连接                                         │
│  ├── 冲相位 = 拉锯、冲突                                      │
│  ├── 合相位 = 支持、融合                                       │
│  ├── 刑相位 = 阻碍、挑战                                      │
│  └── 这些不表示事情结果的好坏                                  │
│                                                              │
│  ★ 真正吉凶要结合宫性和宫位判断 ★                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 结构优先级

```
结构优先级排序：

【第一优先】接纳互容（最紧密）
├── 接纳：行星A落在行星B守护的星座，且有相位
├── 互容：两行星互相落在对方守护的星座
└── 接纳互容后，两行星掌管的宫位联动

【第二优先】合相
├── 两行星紧密联系，无阻碍
└── 能量融合，共同作用

【第三优先】刑冲相位
├── 刑相：阻碍大，不好解
├── 冲相：立场不同，但不一定关系不好
└── 需结合宫性判断结果

【第四优先】三合六合（远亲）
├── 影响较弱
└── 基本不需要考虑太多
```

### 结构连接宫位判断

```
【案例分析】火星（8r）落三宫冲太阳（12r）落九宫

连接宫位：三、八、十二、九（共四个宫位）
综合判断：车祸意象
├── 八宫 = 意外
├── 三宫 = 交通
├── 十二宫 = 隐忧
└── 凶的原因：不是"冲"本身不好，而是连接了三、八、十二这些凶宫位
```

## 三、飞星理解框架

### 飞星定义

```
【飞星】某一宫的宫主星飞去其他宫位
├── 把本宫的信息带到其他宫位
├── 表示两宫之间的连接
└── 不建议逐宫列表记忆飞星含义

【理解方式】
熟悉宫位含义后，自行举例训练即可
飞星是动态的信息传递
```

### 飞星案例解读

```
【案例】上升狮子，命主太阳飞七宫水瓶

解读：
├── 太阳飞七宫：人生重点在合作关系
├── 太阳落陷：不太会在人际关系中展现自我意志
├── 水瓶方式：用水瓶座的方式构建合作关系
└── 交往中容易隐蔽自己
```

## 四、太极点转化

### 核心概念

```
┌──────────────────────────────────────────────────────────────┐
│                    太极点转化原则                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【核心理念】同一结构，太极点不同，结论不同                      │
│                                                              │
│  【必须原则】论任何事物必须有明确的立论中心/太极点               │
│  ├── 错误做法：空泛论盘，说到哪算哪                            │
│  └── 正确做法：根据问题确定宫位，再分析                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 一项多论案例

```
【案例】日火冲（太阳在九宫，火星8r在八宫落三宫）

不同太极点的解读：

【学业角度】
├── 三宫九宫 = 学业
└── 判断学业破格

【交通角度】
├── 三宫短途、九宫长途
└── 判断易有意外

【性格角度】
├── 太阳受冲
└── 性格受影响

【事业角度】
├── 太阳 = 事业征象星
└── 事业受损

【身体角度】
├── 太阳 = 生命征象星
└── 健康问题

★ 一个结构可从多个角度解读
★ 根据客户提问转换太极点
```

## 五、星宫真相结合

### 原则

```
宫位和星体同时代表一个人或一件事

【论父亲】
├── 宫位层面：四宫（作为父亲领域）
├── 星体层面：四宫宫主星（4r）
└── 先天征象星：太阳

【分析要点】
├── 四宫落凶星不好（用转宫法，四宫是父亲的一宫）
├── 四宫主星结构需分析
├── 太阳结构需分析
└── 多维度综合判断
```
