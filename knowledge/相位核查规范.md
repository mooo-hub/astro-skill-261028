# 相位核查规范

相位判断必须遵循四个步骤：
1. 获取行星黄经值
2. 计算黄经差（考虑圆周）
3. 判断相位类型（合/六/刑/拱/冲）
4. 计算容许度验证

**禁止主观假设相位存在**，每个相位都要有计算依据

## 一、相位计算步骤

### 步骤1：获取行星黄经

从排盘数据中获取行星的黄经值（ecl_lon）：

```json
{
  "planets": {
    "Sun": { "ecl_lon": 329.61, ... },
    "Moon": { "ecl_lon": 103.86, ... },
    ...
  }
}
```

### 步骤2：计算黄经差

```
方法1：直接差值
差值 = |lon1 - lon2|

方法2：考虑圆周
如果差值 > 180°，则 差值 = 360 - 差值

最终相位角度 = min(方法1, 方法2对应的补角)
```

### 步骤3：判断相位类型

| 相位类型 | 标准角度 | 判断条件 |
|----------|----------|----------|
| 合相 | 0° | 角度 < 容许度 |
| 六分相 | 60° | \|角度 - 60°\| < 容许度 |
| 四分相 | 90° | \|角度 - 90°\| < 容许度 |
| 三分相 | 120° | \|角度 - 120°\| < 容许度 |
| 对分相 | 180° | \|角度 - 180°\| < 容许度 |

### 步骤4：计算容许度

**古典占星容许度规则**：

```
相位容许度 = (行星1容许度 + 行星2容许度) / 2
```

**行星容许度表**：

| 行星 | 容许度 | 原因 |
|------|--------|------|
| 太阳 | 15° | 最大，象征生命核心 |
| 月亮 | 12° | 次大，运行最快 |
| 木星 | 12° | 吉星，影响范围广 |
| 土星 | 9° | 凶星，限制性强 |
| 火星 | 8° | 凶星，力量集中 |
| 金星 | 7° | 吉星，影响适中 |
| 水星 | 7° | 最小，影响有限 |

### 步骤5：判断入相位/出相位

```
【判断方法】
1. 获取两行星的运行速度（speed字段）
2. 速度快的行星是主动方
3. 模拟下一步位置，判断偏离度变化：
   - 偏离度变小 → 入相位（接近精确相位）
   - 偏离度变大 → 出相位（离开精确相位）

【特殊情况】
- 如果一颗行星逆行，速度为负值
- 月亮速度（约12°/天）> 其他行星 → 月亮通常是主动方
```

## 二、相位核查示例

### 示例1：金月相位核查

**数据**：
- 月亮黄经：103.86°（巨蟹座13.86°）
- 金星黄经：318.83°（水瓶座18.83°）

**计算**：
```
方法1：|318.83 - 103.86| = 214.97°
方法2：360 - 214.97 = 145.03°

相位角度：145.03°
```

**判断**：
- 标准相位：合0°/六60°/刑90°/拱120°/冲180°
- 145.03° ≠ 任何标准相位
- **结论：金月无相位**

**容许度验证**（假设有相位）：
```
金月相位容许度 = (7 + 12) / 2 = 9.5°
如果判断六分相：|145 - 60| = 85° >> 9.5° → 无效
如果判断四分相：|145 - 90| = 55° >> 9.5° → 无效
如果判断三分相：|145 - 120| = 25° >> 9.5° → 无效
```

---

### 示例2：金土相位核查

**数据**：
- 金星黄经：318.83°（水瓶座18.83°）
- 土星黄经：5.36°（白羊座5.36°）

**计算**：
```
方法1：|318.83 - 5.36| = 313.47°
方法2：360 - 313.47 = 46.53°

相位角度：46.53°
```

**判断**：
- 标准相位：合0°/六60°/刑90°/拱120°/冲180°
- 最接近的是六分相（60°）
- 偏差：|60 - 46.53| = 13.47°

**容许度验证**：
```
金土相位容许度 = (7 + 9) / 2 = 8°
偏差13.47° > 容许度8°
```

**结论：金土无相位**

---

### 示例3：月火相位核查

**数据**：
- 月亮黄经：103.86°（巨蟹座13.86°）
- 火星黄经：184.97°（天秤座4.97°）

**计算**：
```
方法1：|184.97 - 103.86| = 81.11°
方法2：360 - 81.11 = 278.89°

相位角度：81.11°（接近90°）
```

**判断**：
- 最接近的是四分相（90°）
- 偏差：|90 - 81.11| = 8.89°

**容许度验证**：
```
月火相位容许度 = (12 + 8) / 2 = 10°
偏差8.89° < 容许度10° → 有效相位
```

**结论：月火四分相有效，偏离度8.89°**

---

### 示例4：火土相位核查

**数据**：
- 火星黄经：184.97°（天秤座4.97°）
- 土星黄经：5.36°（白羊座5.36°）

**计算**：
```
方法1：|184.97 - 5.36| = 179.61°
方法2：360 - 179.61 = 180.39°

相位角度：179.61°（接近180°）
```

**判断**：
- 最接近的是对分相（180°）
- 偏差：|180 - 179.61| = 0.39°

**容许度验证**：
```
火土相位容许度 = (8 + 9) / 2 = 8.5°
偏差0.39° << 容许度8.5° → 极紧密有效相位
```

**结论：火土对分相有效，偏离度0.39°（极紧密）**

## 三、常见错误警示

### 错误类型

| 错误类型 | 错误示例 | 后果 |
|----------|----------|------|
| 主观假设相位 | "金月六分相"（未计算）| 桃花评分错误 |
| 忽略容许度 | 任意角度都算相位 | 判断不准确 |
| 不计算角度 | 直接写"金土相位" | 无法验证 |
| 引用不存在的相位 | 基于假设相位做判断 | 结论错误 |

### 桃花评分错误案例

**原判断**：
```
金月六分相 → +1分
金土六分相 → +1分
桃花评分：4分/5分（桃花较旺）
```

**实际核查**：
```
金月相位角度：145.03° → 无相位
金土相位角度：46.53° → 无相位（偏差13.47° > 容许度8°）
实际桃花评分：1分/5分（桃花弱）
```

**错误原因**：主观假设相位存在，未实际计算。
