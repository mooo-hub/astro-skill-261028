# 数据优先结构优化提示词汇总

> **用途**：确保报告遵循"先展示专业数据，再进行数据解读"的结构原则
> **版本**：v2.0 | 2026-06-03
> **适用Agent**：report-gen、domain-analysis、forecasting
> **更新说明**：v2.0新增事业完整分析、桃花评分相位核查

---

## 一、核心优化原则

```
┌──────────────────────────────────────────────────────────────┐
│                ★ 数据优先结构原则 ★                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一部分】专业数据展示（约占40%篇幅）                       │
│  ├── 所有数据表格完整呈现                                     │
│  ├── 度数精确到分（XX°XX'）                                  │
│  ├── 评分精确标注（±X分）                                    │
│  ├── 相位容许度精确（X.XX°）                                 │
│  └── 无解读性文字                                            │
│                                                              │
│  【第二部分】数据解读（约占60%篇幅）                          │
│  ├── 每个解读标注数据来源                                     │
│  ├── 遵循三层面论断（星性→宫性→结构）                       │
│  ├── 结论具体化（含时间节点）                                │
│  └── 禁止笼统表述                                            │
│                                                              │
│  ★ 禁止：数据与解读混合呈现 ★                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、优化提示词要点

### 3.1 报告模板优化提示词

```
【报告生成必须遵循的结构】

**第一部分：专业数据展示**
- 标题：# 第一部分：专业数据展示
- 内容：
  1. 基本信息（出生数据、盘面基础数据）
  2. 七大古典行星位置表（精确度数、庙旺落陷状态、评分）
  3. 十二宫位配置表（宫头度数、宫内行星、宫主星飞星）
  4. 主要相位表（相位类型、容许度、入/出相位）
  5. 行星必然尊贵评分表（完整评分、评级）
  6. 行星偶然尊贵分析（宫位力量、逆行、相位影响）
  7. 元素与性质分布表（分布、判断、含义）
  8. 当前时间节点（年龄、小限宫位、法达大运）
  9. 附录：原始数据JSON

**第二部分：数据解读**
- 标题：# 第二部分：数据解读
- 内容：
  1. 性格画像（四层结构，每层标注数据引用）
  2. 十二宫断局（逐宫分析，包含数据引用和解读）
  3. 专项领域分析（每项专项先展示数据表，再解读）
  4. 流年运势分析（先展示法达/小限数据表，再解读）
  5. 综合结论（基于数据提炼）
```

### 3.2 专项分析优化提示词

```
【专项分析输出结构】

**数据展示部分**
每项专项必须包含数据汇总表：
| 数据项 | 数值 | 数据来源 |
|--------|------|----------|
| 核心宫位宫头 | XX座 XX°XX' | context.chart_data |
| 宫主星 | XX星 | context.chart_data |
| 宫主星位置 | XX座 X宫 | context.planets |
| 宫主星状态 | 状态（±X分）| context.planet_power |
| 核心相位 | XX星与XX星XX相位（X.XX°）| context.planet_power |

**数据解读部分**
解读推理必须遵循：
1. 星性层面（数据依据：§数据表中XX项）
2. 宫性层面（数据依据：§数据表中XX项）
3. 结构层面（数据依据：§数据表中XX项）

结论必须具体化，包含时间节点。
```

### 3.3 流年分析优化提示词

```
【流年分析输出结构】

**数据展示部分**
必须包含：
1. 法达大运数据表（主运/子运行星、时间范围、状态）
2. 小限法数据表（年度宫位、年主星、状态）
3. 时间线图示

**数据解读部分**
必须遵循：
1. 主运分析（标注数据来源）
2. 子运分析（标注数据来源）
3. 直线性引动结构分析
4. 关键时间点（具体到月份）
```

## 四、禁止表述检查清单

### 4.1 数据展示部分禁止

```
□ 无解读性文字
□ 无"表示"、"说明"、"意味着"等解读词汇
□ 无推测性描述
□ 只呈现原始数据和计算结果
```

### 4.2 数据解读部分禁止

```
□ 禁止："可能会有变化"
□ 禁止："要注意健康"
□ 禁止："感情上会有挑战"
□ 禁止："事业有发展机会"
□ 禁止："财运整体平稳"
□ 禁止："整体运势一般"
□ 禁止："感情方面需要注意"
□ 禁止："工作上会有变动"

✓ 必须具体化（含时间节点、事件类型）：
  "2027年土星小限走7宫，婚姻是焦点，最佳结婚时机在3-5月"
  "2宫主木星入庙+5分，正财收入稳定，年入XX万级别"
```

## 七、审核检查点

### 7.1 数据层审核

```
□ 所有数据表格完整呈现
□ 度数精确到分（XX°XX'）
□ 庙旺落陷评分准确（±X分）
□ 相位容许度精确（X.XX°）
□ 入相位/出相位判断正确
□ 古典守护关系正确（水瓶→土星、双鱼→木星、天蝎→火星）
□ 日夜盘判断正确
□ 小限宫位计算正确（年龄÷12余数）
□ 法达大运顺序正确
```

### 7.2 解读层审核

```
□ 每个解读标注数据来源
□ 遵循三层面论断（星性→宫性→结构）
□ 结论具体化（无禁止表述）
□ 时间节点明确
□ 可操作性建议
```

### 7.3 结构审核

```
□ 数据展示与数据解读明确分离
□ 数据展示部分无解读性文字
□ 解读部分每个结论都有数据引用
□ 附录包含完整原始数据JSON
```

## 八、应用示例

### 8.1 事业专项分析示例

```markdown
### 1. 事业专项分析

#### 【数据展示】

##### 十宫数据汇总表

| 数据项 | 数值 | 数据来源 |
|--------|------|----------|
| 十宫宫头 | 双鱼座 18°49' | §2盘面基础数据 |
| 十宫宫主星 | 木星 | §5宫位配置表 |
| 宫主星位置 | 水瓶座 8宫 | §3行星位置表 |
| 宫主星状态 | 入闲（0分）| §7尊贵评分表 |
| 宫内行星 | 土星（落陷-4分）| §5宫位配置表 |
| 宫主星相位 | 木星与水星合相（7.15°）| §6相位表 |

---

#### 【数据解读】

##### 问题一：职业类型

**第一步：看官禄宫（十宫）**
- **宫内星（静态）**：土星（落陷，凶星）
- **宫主星（动态）★权重更高★**：木星，飞入8宫，含义：事业与投资、他人资源相关

**第二步：找结构（★最关键★）**
- 宫主星木星与水星合相 → 结构类型：合相
- 结构星主宫：水星主3宫、6宫、12宫（宫性）
- 结构星星性：吉（木星）、中性（水星）

**第三步：综合判断**
- 宫性：事业与沟通、工作、深层转化相关
- 星性：扩展、沟通
- 星座性：水瓶座（创新、独立）
- **职业类型**：教育、咨询、信息服务、创意设计、投融资

##### 问题二：事业运势

| 判断维度 | 数据依据 | 判断结果 |
|----------|----------|----------|
| **高度（成就）** | 宫内土星落陷，火土紧密对分（0.39°）| 中等偏低 |
| **稳定度（顺遂）** | 群星8宫（凶宫）| 稳定性一般 |

**十宫主飞入分析**：
- 飞入宫位：8宫（凶宫）
- 含义：事业与投资、他人资源、深层转化相关
- 稳定性：★★☆☆☆（需谨慎）

**结论**：
- **事业高度**：中等偏下，需长期积累，中年后期才有突破
- **事业稳定度**：稳定性一般，需注意投资风险
```

## 九、总结

本次优化确保所有古典占星本命盘分析报告遵循"板块内数据+解读结合"原则：

1. **报告模板**（v6.0）：
   - 结构调整为"板块内数据+解读结合"，每个板块内部先数据展示再解读
   - 新增事业完整分析（第三步日月、第四步命主星）
   - 新增桃花评分相位核查格式（含计算步骤和容许度核对）

2. **数据优先结构规范**（v2.0）：
   - 调整为"板块内数据+解读结合"结构
   - 定义板块内数据展示和解读格式

3. **planet-power SKILL**（v3.0）：
   - 新增灼烧状态判断章节（核心内、焦伤、太阳光束下）
   - 新增东出西入判断章节（阳性行星喜东出、阴性行星喜西入）

4. **forecasting SKILL**（v3.0）：
   - 新增直限星判断方法章节
   - 新增主线子线配合判断章节

5. **audit-agent 审核检查清单**（v3.0）：
   - 新增相位核查规范
   - 新增桃花评分核查清单
   - 新增事业判断完整性核查（命主星/日月）
   - 新增直限星判断、主线子线配合判断核查

6. **新增知识文件**：
   - 灼烧状态判断规范.md
   - 直限星判断方法.md

**核心原则**：
- 每个板块内部先数据展示，再分析解读
- 数据展示部分无解读性文字
- 解读部分每个结论有数据引用
- 禁止数据与解读跨板块混合
- **禁止主观假设相位存在，每个相位都必须计算角度并核对容许度**
