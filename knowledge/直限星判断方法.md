```

│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 一、直限星确定方法

### 1.1 主线判断

```
┌──────────────────────────────────────────────────────────────┐
│                    主线（主运星）判断                         │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【步骤】                                                     │
│  1. 确定法达主运星                                           │
│  2. 确定主运星守护的宫位                                     │
│  3. 确定主运星落宫位置                                       │
│  4. 分析主线指向的领域                                       │
│                                                              │
│  【示例】                                                     │
│  主运星：木星                                                 │
│  木星守护：射手座（9宫）、双鱼座（12宫）                      │
│  木星落宫：5宫                                               │
│  主线指向：5宫（子女、恋爱、创意）、9宫（学业、远行）         │
│                                                              │
│  【判断规则】                                                 │
│  ├─ 主运星守护的宫位是"来源领域"                             │
│  ├─ 主运星落入的宫位是"表现领域"                             │
│  └─ 主线 = 来源领域 + 表现领域                               │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.3 主线子线配合判断

```
┌──────────────────────────────────────────────────────────────┐
│                主线子线配合判断（★关键★）                     │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【核心原则】                                                 │
│  当主线和子线指向同一宫位时，该领域成为焦点。                 │
│                                                              │
│  【配合类型】                                                 │
│                                                              │
│  1. 同宫配合（最强）                                         │
│     ├─ 主线和子线都指向同一宫                                │
│     ├─ 该宫事务成为核心焦点                                  │
│     └─ 应验度最高                                            │
│                                                              │
│  2. 宫位联动（中等）                                         │
│     ├─ 主线指向A宫，子线指向B宫                              │
│     ├─ A宫与B宫有相位关系（对宫、三合、六合）                │
│     └─ 产生联动效应                                          │
│                                                              │
│  3. 星性联动（较弱）                                         │
│     ├─ 主线和子线无直接宫位配合                              │
│     ├─ 但主线星和子线星有相位                                │
│     └─ 产生星性联动效应                                      │
│                                                              │
│  4. 无配合（弱）                                             │
│     ├─ 主线和子线无任何配合                                  │
│     ├─ 分别影响不同领域                                      │
│     └─ 应验度分散                                            │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**配合判断示例**：

```
【示例：同宫配合】
主线（木星）：守护9宫、12宫，落5宫
子线（土星）：守护10宫、11宫，落5宫

判断：主线和子线都落5宫
结论：5宫事务（恋爱、子女、创意）成为核心焦点

【示例：宫位联动】
主线（木星）：守护9宫、12宫，落5宫
子线（土星）：守护10宫、11宫，落11宫

判断：5宫与11宫六合关系
结论：5宫与11宫联动，恋爱与社交互动，或子女与朋友相关
```

## 二、直限星分析流程

### 步骤1：确定主运星和子运星

```
1. 根据日夜盘确定法达顺序
2. 计算当前年龄对应的法达主运/子运
3. 确定主运星和子运星
```

### 步骤2：确定直限星

```
1. 主运星守护的宫位（来源领域）
2. 主运星落入的宫位（表现领域）
3. 子运星守护的宫位（来源领域）
4. 子运星落入的宫位（表现领域）
```

### 步骤3：分析配合关系

```
1. 主线和子线是否有同宫配合
2. 主线和子线是否有宫位联动
3. 主线和子线是否有星性联动
4. 确定焦点领域
```

### 步骤4：结合小限判断

```
1. 计算小限年宫位（年龄÷12余数）
2. 确定小限年主星
3. 分析小限与直限星的关系
4. 确定时间节点（月份）
```

## 三、小限与直限星配合

```
┌──────────────────────────────────────────────────────────────┐
│                小限与直限星配合判断                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【小限宫位计算】                                            │
│  小限宫位 = 年龄 ÷ 12 的余数                                 │
│  例：28岁 → 28 ÷ 12 = 2余4 → 小限走4宫                      │
│                                                              │
│  【小限主星判断】                                            │
│  小限主星 = 小限宫位的宫主星                                 │
│  例：小限走4宫，4宫宫头巨蟹座 → 月亮是小限主星               │
│                                                              │
│  【配合判断】                                                 │
│  ├─ 小限主星与直限星同星：极强触发                           │
│  ├─ 小限宫位与直限星落宫同宫：强触发                         │
│  ├─ 小限主星与直限星有相位：中等触发                         │
│  └─ 无直接配合：弱触发                                       │
│                                                              │
│  【月份触发】                                                 │
│  小限法月份触发：小限宫位 + 月份偏移                         │
│  例：小限走4宫，3月 → 4+3-1=6 → 6宫是3月焦点                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 五、实际案例

### 案例：28岁女性，日盘

```
【法达大运】
主运：木星（2020-2032）
子运：土星（2025-2028）

【主线分析】
木星守护：射手座（9宫）、双鱼座（12宫）
木星落宫：5宫（狮子座）
主线指向：5宫（恋爱、子女、创意）、9宫（学业、远行）、12宫（内心、隐蔽）

【子线分析】
土星守护：摩羯座（10宫）、水瓶座（11宫）
土星落宫：7宫（白羊座，落陷）
子线指向：7宫（婚姻、合作）、10宫（事业）、11宫（社交）

【配合判断】
5宫与7宫关系：三合（狮子座-白羊座-射手座火象三角）
配合类型：宫位联动
焦点领域：恋爱婚姻联动，或子女与合作相关

【小限分析】
28岁 → 小限走4宫（巨蟹座）
小限主星：月亮
月亮落宫：7宫（天秤座）
月亮与土星相位：月亮黄经103.86°，土星黄经5.36° → 月土四分相

【综合判断】
2025-2028年土星子运期间：
- 主线（木星）指向5宫（恋爱、子女）
- 子线（土星）指向7宫（婚姻）
- 5宫与7宫三合联动
- 小限主星月亮落7宫，与土星四分相

结论：婚姻是核心焦点，2025-2028年是关键婚姻运期，尤其是28岁（小限走4宫）时，月亮触发7宫，婚姻议题最为突出。
```
