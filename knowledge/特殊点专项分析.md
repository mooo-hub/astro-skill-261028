## 一、婚姻点分析

### 1.1 婚姻点计算

```
【公式】
婚姻点 = 7宫头 + 金星 - 土星

【计算步骤】
1. 确定7宫头度数
2. 确定金星度数
3. 确定土星度数
4. 计算：7宫头 + (金星 - 土星)
```

### 1.2 婚姻点判断方法

```
┌──────────────────────────────────────────────────────────────┐
│                    婚姻点分析框架                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  第一步：婚姻点宫位                                           │
│  ├── 婚姻点落入的宫位显示婚姻生活的表现领域                     │
│  └── 例：婚姻点在10宫 → 婚姻与事业紧密相关                     │
│                                                              │
│  第二步：婚姻点星座                                           │
│  ├── 婚姻点的星座显示婚姻特质                                  │
│  └── 例：婚姻点在狮子座 → 配偶有领导气质                       │
│                                                              │
│  第三步：婚姻点相位                                           │
│  ├── 与吉星相位 → 婚姻顺利                                    │
│  └── 与凶星相位 → 婚姻有阻碍                                  │
│                                                              │
│  第四步：婚姻点定位星                                         │
│  ├── 定位星状态影响婚姻质量                                    │
│  └── 例：婚姻点在金牛座 → 金星是定位星                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.3 婚姻点宫位解读

| 婚姻点宫位 | 婚姻表现 |
|------------|----------|
| 1宫 | 配偶对个人影响大，婚姻改变自我认同 |
| 2宫 | 婚姻与财务相关，可能因婚得财 |
| 4宫 | 婚姻与家庭紧密，家庭生活重要 |
| 5宫 | 婚姻与子女、创作相关 |
| 7宫 | 婚姻是人生核心，配偶地位重要 |
| 10宫 | 婚姻影响事业，可能事业伙伴结婚 |
| 11宫 | 婚姻与社交团体相关 |

### 1.4 婚姻点相位判断

| 相位关系 | 婚姻影响 |
|----------|----------|
| 婚姻点与木星和谐 | 婚姻顺利，配偶有助力 |
| 婚姻点与金星和谐 | 感情和谐，婚姻幸福 |
| 婚姻点与土星刑冲 | 婚姻有阻碍，需要努力经营 |
| 婚姻点与火星刑冲 | 婚姻有冲突，需要化解矛盾 |

## 二、子女点分析

### 2.1 子女点计算

```
【公式】
子女点 = ASC + 木星 - 火星
```

### 2.2 子女点判断方法

| 子女点位置 | 子女关系 |
|------------|----------|
| 吉宫（1,4,5,7,10,11）| 子女缘佳 |
| 凶宫（6,8,12）| 子女缘薄或有挑战 |
| 与吉星相位 | 子女孝顺有成 |
| 与凶星相位 | 子女关系需经营 |

## 三、事业点分析

### 3.1 事业点计算

```
【公式】
事业点 = 10宫头 + 太阳 - 月亮
```

### 3.2 事业点判断方法

```
【分析框架】
├─ 事业点宫位：事业成就的领域
├─ 事业点星座：事业成就的方式
├─ 事业点相位：事业发展的顺利程度
└─ 事业点定位星：事业方向的指引
```

| 事业点宫位 | 事业表现 |
|------------|----------|
| 1宫 | 自我创业，个人品牌 |
| 2宫 | 财务相关事业 |
| 5宫 | 创意、教育、娱乐事业 |
| 6宫 | 服务、医疗、技术事业 |
| 10宫 | 管理、领导事业 |
| 11宫 | 团体、社会事业 |

## 四、福点专项分析

### 4.1 福点计算

```
【日盘】福点 = ASC + 月亮 - 太阳
【夜盘】福点 = ASC + 太阳 - 月亮
```

### 4.2 福点在专项分析中的应用

#### 财运专项

```
【福点与财运】
├─ 福点在2宫：正财运势好
├─ 福点在5宫：偏财运势好
├─ 福点在8宫：可能因婚得财或遗产
├─ 福点与木星和谐：财运极佳
└─ 福点与土星刑冲：财运需努力
```

#### 事业专项

```
【福点与事业】
├─ 福点在10宫：事业有贵人相助
├─ 福点与太阳和谐：事业顺遂
├─ 福点与木星和谐：事业扩展顺利
└─ 福点与土星刑冲：事业有阻碍
```

#### 感情专项

```
【福点与感情】
├─ 福点在5宫：恋爱运势好
├─ 福点在7宫：婚姻运势好
├─ 福点与金星和谐：感情顺利
└─ 福点与土星刑冲：感情需经营
```

## 五、南北交点专项分析

### 5.1 北交点专项

```
【北交点性质】吉，前世业果，好运

【北交点在专项分析中】
├─ 北交点宫位：该领域有前世积累的好运
├─ 北交点与行星合相：增强该行星的正面力量
└─ 北交点相位关系：带来机缘和贵人

【北交点宫位解读】
├─ 2宫：财务领域有好运
├─ 5宫：恋爱子女领域有好运
├─ 7宫：婚姻合作领域有好运
├─ 10宫：事业领域有好运
└─ 11宫：社交团体领域有好运
```

### 5.2 南交点专项

```
【南交点性质】凶，前世业障，阻碍

【南交点在专项分析中】
├─ 南交点宫位：该领域有前世遗留的课题
├─ 南交点与行星合相：减弱该行星的力量
└─ 南交点相位关系：带来考验和阻碍

【南交点宫位解读】
├─ 2宫：财务领域有课题
├─ 5宫：恋爱子女领域有课题
├─ 7宫：婚姻合作领域有课题
├─ 10宫：事业领域有课题
└─ 11宫：社交团体领域有课题
```

### 5.3 南北交点轴线分析

```
【南北交点轴线】
├─ 北交点宫位：需要发展的方向
├─ 南交点宫位：需要放下的执着
└─ 轴线平衡：在两端找到平衡

【示例】
北交点在5宫，南交点在11宫：
├─ 需要发展：自我表达、恋爱、创作
├─ 需要放下：过度依赖团体、朋友认同
└─ 平衡点：在个人表达和团体利益之间找到平衡
```
