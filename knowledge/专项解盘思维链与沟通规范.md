# 专项解盘思维链与沟通规范

> **用途**：把专项星盘解答统一为"可复核的分析框架 + 可交付的顾客语言"。
> **核心原则**：每个维度思维链的底层逻辑是一样的——都遵循「问题定义 → 主题宫位 → 宫主星状态 → 自然征象星 → 相位/接纳/互容 → 与命主关系 → 推运触发 → 现实校准 → 可执行建议」这条主线。

---

## 一、总原则：五段式因果链

### 1.1 核心因果链（必须执行）

```text
依据 → 含义 → 现实表现 → 优势/风险 → 建议
```

| 阶段 | 内容 | 示例 |
|------|------|------|
| **依据** | 哪个宫位、主星、相位、尊贵状态显示了这个主题？ | 十宫主土星落8宫巨蟹座（失陷） |
| **含义** | 这个配置在古典占星中代表什么？ | 事业需要长期积累，可能涉及他人资源 |
| **现实表现** | 它可能如何体现在顾客生活里？ | 可能在金融机构后台风控部门工作 |
| **优势** | 这个结构带来什么资源？ | 土木互容可能带来贵人支持 |
| **风险** | 这个结构带来什么挑战？ | 事业发展节奏慢，早期压力大 |
| **建议** | 顾客应该如何使用这股能量？ | 专注专业积累，避免频繁跳槽 |

### 1.2 技术链：Agent内部判断顺序

```text
1. 先确认顾客问的是哪个主题，而不是泛泛论盘
2. 找该主题入口宫位
3. 看入口宫位的宫主星：是谁、落座、落宫、尊贵、逆行/灼烧等状态
4. 看宫内星：只作为静态状态与辅助信息
5. 找结构：接纳 > 互容 > 合相 > 刑冲 > 三合/六合
6. 看自然征象星：如事业看太阳/土星，财运看木星/金星，感情看金星/月亮等
7. 看主题宫主与命主星关系：此事与本人是否连得上、本人能否掌控
8. 看推运：法达、小限、返照或行运是否触发主题宫/宫主/自然征象星
9. 综合成本、机会、风险与可操作策略
```

### 1.3 顾客交付链（对外输出格式）

```text
结论 → 依据 → 表现 → 建议
```

**输出模板**：
```markdown
从盘面看，与你的【领域】相关的核心线索是：【宫位/主星/行星状态】。

这说明你的【领域】并不是以【简单方式】展开，而是通过【某种路径】实现。

现实中可能表现为：
1. ...
2. ...
3. ...

优势是：...

需要注意的是：...

所以更适合你的策略是：...
```

## 二、顾客沟通SOP

### 2.1 开始前先确认问题类型

不要在顾客说"看事业/感情/财运"后直接解读。**必须先确认具体问题类型**：

| 问题类型 | 示例问题 | 分析重点 |
|----------|----------|----------|
| **长期格局型** | "我适合做什么行业？"、"我这辈子财运怎么样？" | 本命盘结构 > 宫位主轴 > 主星状态 > 人生长期主题 |
| **当前处境型** | "我现在为什么事业不顺？"、"最近感情为什么反复？" | 本命承诺 + 当前时间触发 + 哪个领域被激活 |
| **具体决策型** | "我要不要辞职？"、"这个人适不适合结婚？" | 选择符合哪些结构 + 触发哪些风险 + 需补足哪些条件 |
| **未来窗口型** | "我什么时候事业会好？"、"什么时候容易遇到正缘？" | 本命有无此主题 + 哪个时间点激活 + 激活的是机会还是压力 |

### 2.2 专项分流话术

```text
你更关心的是：方向选择、当前处境、是否转换、未来一年走势，还是长期格局？
```

- **事业**：职业方向 / 跳槽窗口 / 晋升机会 / 创业适配度 / 事业长期格局
- **财运**：收入来源 / 守财能力 / 投资风险 / 合作财 / 未来财务窗口
- **感情**：新感情可能 / 现有关系走向 / 婚姻结构 / 择偶类型 / 桃花阶段
- **健康**：体质倾向 / 压力与作息 / 需关注部位 / 高压阶段提醒
- **学业**：学习方式 / 考试运 / 升学申请 / 专业方向 / 备考窗口
- **六亲**：父母/伴侣/子女层次 / 关系模式 / 家庭责任 / 阶段性事件

### 2.3 表述边界（强制遵守）

| ✅ 允许的表述 | ❌ 禁止的表述 |
|--------------|--------------|
| "容易、可能、倾向、需要留意、适合" | "一定、必然、注定" |
| "课题、张力、需要训练" | "缺陷、失败、没救" |
| 负面判断后必须接化解建议 | 只给负面判断不给方向 |
| "值得关注、适合加强调养方向" | "你会得某种病" |

**健康维度固定边界声明**：
```text
以下为占星角度的体质与压力倾向提示，不构成医学诊断；如已有症状或不适，应以正规医疗检查和医生意见为准。
```

## 三、专项思维链详解

### 3.1 事业专项

**核心问题链（Q1-Q5）**：

| 问题 | 分析内容 | 关键数据 |
|------|----------|----------|
| **Q1 这个人靠什么立足于世？** | 10宫宫头星座性质、MC元素、10宫主星位置与状态 | 10宫、MC、10宫主星 |
| **Q2 他用什么方式工作、服务？** | 6宫与6宫主、水星状态 → 工作是助力还是消耗 | 6宫、水星、6宫主星 |
| **Q3 他的才能与资源在哪里？** | 2宫+5宫禀赋池、木星落宫（扩展地）、土星落宫（耕耘地） | 2宫、5宫、木星/土星落宫 |
| **Q4 核心职业张力是什么？** | 10宫主与土星/火星/月亮/命主星关系 | 张力识别、相位质量 |
| **Q5 什么领域最适合？** | 综合宫性+星性+星座性，给方向词群 | 落地建议（非单一职业名称） |

**必看入口**：
```text
10宫/MC：事业目标、名声、社会角色
10宫主星：事业主线与动态发展
6宫/6宫主：日常劳动、工作环境、服务方式
2宫/2宫主：才能、收入变现、个人资源
太阳：贵气、领导力、可见度
土星：结构、责任、长期积累
命主星：本人能否承接事业主题
```

**输出结构**：
```markdown
### 事业分析

#### 事业结论
【一句话概括事业模式】

#### 分析依据
- 10宫主星：XX星，落X宫，状态（±X分）
- 核心结构：XX相位/接纳/互容
- 日月事业征象：...
- 命主与官禄关系：...

#### 现实表现
1. 职业风格：...
2. 工作方式：...
3. 发展节奏：...

#### 优势与挑战
- 优势：...
- 挑战：...

#### 发展建议
- 适合方向：...（方向词群，非单一职业）
- 避免方向：...
- 关键时间点：...

**常见错误**：
- ✗ 只看10宫忽略6宫：10宫是志向，6宫是日复一日的现实
- ✗ 直接给职业名称：给方向词群，如"权力、结构、管理、建筑、政府、法律"
```

```text

现代顾客问健康多关心「如何维护」而非「会生什么病」——把解读方向导向预防性习惯建议。
```

## 四、跨维度整合规则

真正有价值的洞见来自跨维度重复出现的主题。

### 4.1 整合方法

```text
1. 找反复出现的行星：同一行星在事业、财运、感情等多个维度中反复扮演关键角色
2. 找同频共振：如事业主与财帛主互相支持，说明专业方向与收入高度一致
3. 找维度冲突：如事业主与七宫主刑克，说明事业冲刺与关系经营存在张力
4. 命名核心矛盾：用一句话讲清楚顾客的人生主线
5. 给统一叙事：最后把各维度收束成一条可理解的人生主题
```

### 4.2 常见跨维度张力模式

| 模式 | 描述 | 叙事方向 |
|------|------|----------|
| 土星压制10宫主+刑7宫主 | 事业受阻同时关系带来责任 | 学习在压力中建立边界 |
| 月亮弱陷落2宫+影响7宫 | 情绪化消费驱动关系决策 | 建立财务边界是关系课题 |
| 木星落10宫+与2宫主三分 | 职业机遇顺畅带动财富 | 越专注越有回报 |
| 冥王合上升+主管7宫 | 气质控制力与关系权力动态 | 在关系中学习放下控制 |

### 4.3 统一叙事示例

```text
你的盘核心是——通过长期的专业深耕建立物质安全感，进而在关系中获得真正的平等与自由。
```

## 六、报告生成核心逻辑

### 6.1 维度之间的张力才是最值钱的洞见

当你发现土星同时影响10宫和7宫，这不是两条独立信息，而是一条关于「这个人的生命功课如何在职业和感情中同时展开」的统一叙事。给顾客说出这条叙事线，往往是让他们感到「被看穿」的那个瞬间。

### 6.2 "宫主落宫"是最容易被忽略的信息

举个例子：7宫主星落在10宫，说明这个人的感情与职业深度交织——很可能在工作中遇到伴侣，或伴侣对其职业影响极大。这一个信息比泛泛说「7宫有什么特征」要具体得多，也更贴近真实人生。

**养成习惯**：每解读一个宫位，就追问「它的宫主在哪里」。

### 6.3 真正有深度的解读，必然会走出入口宫位

区别在于每个维度的「入口宫位」不同——事业从10宫进，财运从2宫进，感情从7宫进。但真正有深度的解读，必然会走出入口宫位，追踪到整张盘里去。
