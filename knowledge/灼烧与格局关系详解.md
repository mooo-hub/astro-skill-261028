## 一、灼烧的定义与层次

### 1.1 灼烧的三种状态

```
┌──────────────────────────────────────────────────────────────┐
│                灼烧的三种状态                                   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【焦伤（Combust）】                                          │
│  ├─ 定义：行星与太阳同星座，距离17分至8度30分                  │
│  ├─ 含义：被太阳光芒遮蔽，难以被看见                          │
│  └─ 影响：行星能量受损，格局受影响                            │
│                                                              │
│  【太阳光束下（Under Sunbeams）】                              │
│  ├─ 定义：行星与太阳距离8度30分至17度                         │
│  ├─ 含义：被太阳光芒掩盖部分力量                              │
│  └─ 影响：行星能量部分受损                                    │
│                                                              │
│  【核心内（Cazimi）】                                         │
│  ├─ 定义：行星与太阳同星座，距离17分之内                       │
│  ├─ 含义：进入太阳的宫殿领域，受到保护                        │
│  └─ 影响：行星反得太阳加持，格局提升                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 灼烧程度速查表

| 状态 | 距离范围 | 影响 | 格局影响 |
|------|----------|------|----------|
| **核心内** | 17分之内 | 正面加持 | 格局提升 |
| **焦伤** | 17分-8度30分 | 能量遮蔽 | 格局受损 |
| **太阳光束下** | 8度30分-17度 | 部分受损 | 影响较小 |

## 二、灼烧对格局的影响

### 2.1 焦伤对格局的负面影响

**核心影响**：

```
焦伤的影响：
├─ 行星能量被太阳遮蔽
├─ 难以发挥正常功能
├─ 来自权威、父亲、老板的压力
└─ 格局整体受损
```

**纳入格局判断的减分标准**：

| 标准 | 说明 | 影响 |
|------|------|------|
| 焦伤 | 与太阳距离17分-8度30分 | 能量受损，格局减分 |
| 太阳光束下 | 与太阳距离8度30分-17度 | 部分受损，小幅减分 |

### 2.2 核心内对格局的正面影响

**核心内的正面效果**：

```
核心内的影响：
├─ 行星进入太阳宫殿领域
├─ 受到太阳的保护和加持
├─ 行星地位被提升至崇高位置
└─ 格局反而提升
```

**注意**：
- 必须在同一星座内
- 距离必须在17分之内
- 如超出17分则变为焦伤

## 三、灼烧对不同行星的影响

### 3.1 水星被灼烧

**焦伤状态**：
- 思考受权威影响
- 表达受压制
- 沟通困难

**核心内状态**：
- 思维敏锐
- 智慧出众
- 表达有权威加持

---

### 3.2 金星被灼烧

**焦伤状态**：
- 感情受父亲/丈夫影响
- 人际关系受压制
- 爱情表达困难

**核心内状态**：
- 魅力非凡
- 感情受祝福
- 人际关系有助力

---

### 3.3 火星被灼烧

**焦伤状态**：
- 行动受权威限制
- 斗志被压制
- 难以自主行动

**核心内状态**：
- 行动力强
- 有勇气和决断
- 斗志被太阳加持

---

### 3.4 木星被灼烧

**焦伤状态**：
- 运气受权威影响
- 扩张受限
- 机会被遮蔽

**核心内状态**：
- 运气极佳
- 扩张有力
- 机会被加持

---

### 3.5 土星被灼烧

**焦伤状态**：
- 责任受权威压力
- 限制更严重
- 困难加剧

**核心内状态**：
- 责任感强
- 有权威支持
- 限制转化为助力

## 四、灼烧在格局判断中的应用

### 4.1 纳入格局层次判断

**判断方法**：

```
┌──────────────────────────────────────────────────────────────┐
│                灼烧纳入格局判断                                 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一步】检查行星与太阳的距离                                │
│  ├─ 是否同星座                                               │
│  ├─ 距离是否在17度以内                                       │
│  └─ 确定灼烧状态                                              │
│                                                              │
│  【第二步】根据状态判断影响                                    │
│  ├─ 核心内：格局加分                                          │
│  ├─ 焦伤：格局减分                                            │
│  └─ 太阳光束下：小幅减分                                      │
│                                                              │
│  【第三步】结合行星性质综合判断                                │
│  ├─ 不同行星受灼烧影响不同                                    │
│  ├─ 结合宫主星状态判断                                        │
│  └─ 整体格局评估                                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 示例分析

**盘面信息**：
- 水星在狮子座
- 太阳在狮子座
- 水星与太阳距离：5度

**分析**：

| 步骤 | 分析 |
|------|------|
| 1 | 水星与太阳同星座，距离5度 |
| 2 | 距离在17分-8度30分之间，属于焦伤状态 |
| 3 | 水星能量受损，格局减分 |
| 结论 | 水星所掌管的宫位和事务受影响 |

## 六、常见问题解答

### 6.1 问：焦伤和落陷哪个影响更大？

**答**：两者性质不同：
- 焦伤：被太阳遮蔽，难以表达
- 落陷：先天能量弱，表现不佳
- 如同时存在，影响叠加

### 6.2 问：核心内是否一定正面？

**答**：不一定：
- 需在同一星座内
- 距离必须17分之内
- 如行星本身落陷，正面效果减弱

### 6.3 问：灼烧是否可以化解？

**答**：可以通过以下方式缓解：
- 被接纳或互容
- 有吉星和谐相位
- 行星本身庙旺
