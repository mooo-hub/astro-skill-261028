> **用途**：判断行星与太阳的距离关系，评估能量状态
> **版本**：v1.0 | 2026-06-04
> **重要性**：★ 影响行星偶然尊贵评分的关键因素 ★

## 一、三种灼烧状态

### 1.1 焦伤状态（Combust）

```
┌──────────────────────────────────────────────────────────────┐
│                    焦伤状态定义                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【条件】行星与太阳距离在17分-8度30分之间                     │
│                                                              │
│  【特征】                                                     │
│  ├─ 行星能量被太阳遮蔽                                       │
│  ├─ 表达困难、受阻                                           │
│  ├─ 需要更多努力才能发挥                                     │
│  └─ 影响：偶然尊贵评分-5分                                   │
│                                                              │
│  【含义】                                                     │
│  ├─ 不稳定、反复                                             │
│  ├─ 内在化、隐藏                                             │
│  └─ 需要时间转化                                             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**判断示例**：
```
太阳黄经：330°（摩羯座0°）
水星黄经：334°（摩羯座4°）
距离：|334 - 330| = 4°

判断：4°在17分-8度30分范围内 → 水星焦伤
影响：水星能量被遮蔽，沟通表达受阻，需要更多努力
```

---

### 1.2 太阳光束下（Under the Sunbeams）

```
┌──────────────────────────────────────────────────────────────┐
│                太阳光束下状态定义                             │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【条件】行星与太阳距离在8度30分-17度之间                     │
│                                                              │
│  【特征】                                                     │
│  ├─ 行星能量部分受损                                         │
│  ├─ 表达有一定困难                                           │
│  ├─ 比焦伤状态影响小                                         │
│  └─ 影响：偶然尊贵评分-2分                                   │
│                                                              │
│  【含义】                                                     │
│  ├─ 能量减弱但不完全遮蔽                                     │

│  └─ 有一定恢复空间                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**判断示例**：
```
太阳黄经：330°（摩羯座0°）
金星黄经：345°（摩羯座15°）
距离：|345 - 330| = 15°

判断：15°在8度30分-17度范围内 → 金星在太阳光束下
影响：金星能量部分受损，爱情表达需要调整
```

## 二、判断步骤

### 步骤1：获取太阳和行星黄经

```json
{
  "sun_ecl_lon": 329.61,
  "planet_ecl_lon": 332.50
}
```

### 步骤2：计算距离

```
方法1：直接差值
距离 = |planet_ecl_lon - sun_ecl_lon|

方法2：考虑圆周
如果差值 > 180°，则 距离 = 360 - 差值

最终距离 = min(方法1, 方法2对应的补角)
```

### 步骤3：判断状态

| 距离范围 | 状态 | 偶然尊贵评分影响 |
|----------|------|------------------|
| 0° - 17分 | 核心内 | +5分 |
| 17分 - 8度30分 | 焦伤 | -5分 |
| 8度30分 - 17度 | 太阳光束下 | -2分 |
| > 17度 | 正常 | 0分 |

### 步骤4：记录影响

在行星力量分析中标注灼烧状态和评分影响。

### 3.2 格局判断

- **核心内**：格局提升，行星获得太阳祝福
- **焦伤**：格局受损，需要更多努力才能发挥
- **太阳光束下**：格局减弱，需要调整表达方式

### 3.3 推运应验度

- 灼烧状态的行星在推运时应验度降低
- 核心内状态的行星在推运时应验度提高

## 四、特殊情况

### 4.1 月亮灼烧

月亮运行速度快，容易与太阳形成灼烧状态：
- 新月前后（月亮与太阳合相）：月亮焦伤
- 月亮焦伤影响情感表达和安全感

### 4.2 水星灼烧

水星总是在太阳附近，容易灼烧：
- 水星焦伤影响沟通和思考
- 但水星在核心内则获得智慧加持

### 4.3 金星灼烧

金星有时会远离太阳：
- 金星焦伤影响爱情和价值观
- 金星在核心内则获得魅力加持
