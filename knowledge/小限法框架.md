## 一、小限法核心概念

### 1.1 小限法的定义

```
【小限法（Profection）】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ★ 古典占星最重要的年度推运方法                               │
│                                                              │
│  【核心原理】                                                 │
│  ├─ 每年走一个宫位                                           │
│  ├─ 从第一宫开始，每年推进一宫                               │
│  ├─ 12年一个循环                                             │
│  └─ 配合年主星判断年度运势                                   │
│                                                              │
│  【本质理解】                                                 │
│  ├─ 小限宫位 = 年度主题宫位                                  │
│  ├─ 年主星 = 小限宫位的宫主星                                │
│  ├─ 年主星状态 = 年度运势基调                                │
│  └─ 小限触发本命盘中的结构                                   │
│                                                              │
│  【时间对应】                                                 │
│  ├─ 一年走一个宫位                                           │
│  ├─ 从出生开始计算（0岁起）                                  │
│  └─ 每年生日时推进一宫                                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 小限法的重要性

```
【小限法在推运中的地位】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【推运方法优先级】                                           │

│  【小限法的独特价值】                                         │
│  ├─ 简单直观，易于计算                                       │
│  ├─ 准确预测年度主题                                         │
│  ├─ 与法达配合使用效果更佳                                   │
│  └─ 可以快速定位重要年份                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、小限走宫规律

### 2.1 计算方法

```
【小限宫位计算方法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【方法一：年龄直接对应】                                     │
│  年龄 = 小限宫位（从0岁开始）                                 │
│                                                              │
│  示例：                                                      │
│  0-1岁 = 第一宫                                              │
│  1-2岁 = 第二宫                                              │
│  23-24岁 = 第十二宫 → 第二宫（24岁）                         │
│                                                              │
│  【方法二：取模计算】                                         │
│  年龄 ÷ 12 = 商 ... 余数                                     │
│  余数 = 小限宫位序号（0=第十二宫）                           │
│                                                              │
│  示例：                                                      │
│  24岁：24 ÷ 12 = 2 余 0 → 第十二宫 → 24岁回到第一宫         │
│  30岁：30 ÷ 12 = 2 余 6 → 第七宫                             │
│  36岁：36 ÷ 12 = 3 余 0 → 第十二宫 → 36岁回到第一宫         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、年主星判断方法

### 3.1 年主星定义

```
【年主星】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  年主星 = 小限宫位的宫主星                                   │
│                                                              │
│  【计算方法】                                                 │
│  1. 确定小限宫位                                             │
│  2. 找出该宫宫头所在的星座                                   │
│  3. 该星座的守护行星 = 年主星                                 │
│  4. 必须使用古典守护关系                                     │
│                                                              │
│  【重要原则】                                                 │
│  ├─ 年主星是当年的核心主题                                   │
│  ├─ 年主星的状态决定当年的运势                               │
│  ├─ 年主星触发的事件与该宫位相关                             │
│  └─ 年主星引动本命盘中的结构                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 年主星的作用

```
【年主星的作用】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【运势判断】                                                 │
│  ├─ 年主星入庙入旺 → 当年运势顺利                            │
│  ├─ 年主星中等力量 → 当年运势一般                            │
│  ├─ 年主星失势落陷 → 当年运势有挑战                          │
│  └─ 年主星有接纳互容 → 有助力或化解                          │
│                                                              │
│  【焦点领域】                                                 │
│  ├─ 年主星落在哪个宫位 → 当年焦点在该领域                    │
│  ├─ 年主星守护哪个宫位 → 该宫事务也重要                      │
│  └─ 小限宫位本身 → 该宫事务是年度主题                        │
│                                                              │
│  【事件触发】                                                 │
│  ├─ 年主星触发本命盘中的结构                                 │
│  ├─ 触发的结构决定事件类型                                   │
│  └─ 触发的时间点由行运配合                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 五、小限与法达配合

### 5.1 配合原则

```
【小限法 + 法达星限法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【配合方法】                                                 │
│  ├─ 法达主运决定大运基调                                     │
│  ├─ 小限年主星决定年运细节                                   │
│  └─ 小限宫位触发该领域事件                                   │
│                                                              │
│  【双重判断】                                                 │
│  ├─ 法达主运好 + 小限好年 → 最佳年份                         │
│  ├─ 法达主运好 + 小限差年 → 运势受影响但整体好               │
│  ├─ 法达主运差 + 小限好年 → 有缓解但整体差                   │
│  └─ 法达主运差 + 小限差年 → 困难年份                         │
│                                                              │
│  【触发原则】                                                 │
│  ├─ 小限宫位触发本命盘结构                                   │
│  ├─ 年主星激活本命盘相位                                     │
│  └─ 两者配合判断具体事件                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 配合判断示例

```
【示例：30岁判断】

法达：
  主运：水星大运（18-31岁）
  子运：假设当前在月亮子运

小限：
  年龄：30岁
  计算：30 ÷ 12 = 2 余 6
  小限宫位：第七宫
  年主星：假设7宫头天秤，年主星=金星

配合分析：
  法达水星大运 + 小限7宫年
  
  如果水星状态好，金星状态好：
  → 大运好 + 年运好 → 适合结婚的年份
  
  如果水星状态好，金星状态差：
  → 大运好但感情领域有挑战 → 感情需要经营
  
  如果水星状态差，金星状态好：
  → 大运差但感情有机会 → 可能结婚但其他方面有压力
```

## 六、分析流程

### 6.1 小限法分析六步法

```
【小限法分析六步法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  第一步：确定当年小限宫位                                     │
│    ├─ 计算年龄对应的小限宫位                                 │
│    ├─ 使用取模法：年龄 ÷ 12                                  │
│    └─ 确认年度主题宫位                                       │
│                                                              │
│  第二步：确定年主星                                          │
│    ├─ 找出小限宫位的宫主星                                   │
│    ├─ 必须使用古典守护关系                                   │
│    └─ 记录年主星                                             │
│                                                              │
│  第三步：分析年主星状态                                       │
│    ├─ 分析年主星的尊贵状态（庙旺落陷）                       │
│    ├─ 分析年主星的落宫                                       │
│    ├─ 分析年主星的相位                                       │
│    └─ 判断年主星力量强弱                                     │
│                                                              │
│  第四步：分析小限宫位                                        │
│    ├─ 分析小限宫位的宫内星                                   │
│    ├─ 分析小限宫位的能量                                     │
│    └─ 分析小限宫位的相位关系                                 │
│                                                              │
│  第五步：配合法达判断                                         │
│    ├─ 当前法达主运是什么？                                   │
│    ├─ 法达与小限如何配合？                                   │
│    └─ 综合判断年度运势                                       │
│                                                              │
│  第六步：预测具体事件                                        │
│    ├─ 年度主题领域是什么？                                   │
│    ├─ 可能的典型事件有哪些？                                 │
│    └─ 给出建议和注意事项                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
