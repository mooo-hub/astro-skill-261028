## 一、先天吉凶星定义

### 1.1 先天吉星（贵气之星）

| 行星 | 性质 | 核心特质 | 正面表现 | 负面表现 |
|------|------|----------|----------|----------|
| **木星** | 热湿、阳、大吉 | 扩展、机遇、贵人、智慧 | 有贵人、运气好、扩张力强 | 过度扩张、不够务实 |
| **金星** | 冷湿、阴、吉 | 和谐、感情、艺术、魅力 | 人缘好、有美感、财运好 | 享乐主义、缺乏进取 |
| **太阳** | 热干、阳、大吉 | 权威、名声、核心、生命力 | 有贵气、受瞩目、易获名声 | 自我中心、可能被灼烧 |
| **月亮** | 冷湿、阴、吉 | 情感、家庭、安全、滋养 | 情感丰富、人缘好 | 情绪化、不稳定 |

### 1.2 先天凶星（限制之星）

| 行星 | 性质 | 核心特质 | 正面表现 | 负面表现 |
|------|------|----------|----------|----------|
| **土星** | 冷干、阳、凶 | 限制、责任、压力、延迟 | 稳重、有责任感、持久 | 压力大、进展慢、辛苦 |
| **火星** | 热干、阳、凶 | 冲突、竞争、行动、风险 | 行动力强、开拓精神 | 冲动、竞争激烈、有风险 |

### 1.3 中性行星

| 行星 | 性质 | 核心特质 |
|------|------|----------|
| **水星** | 中性 | 沟通、思维、学习、商业 |

## 二、关键理解原则

```
┌──────────────────────────────────────────────────────────────┐
│              先天吉凶星关键理解                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【原则一】先天性质不因能量状态而改变                          │
│  ├─ 先天吉星即使能量弱（失势/落陷），仍有贵气性质              │
│  └─ 先天凶星即使庙旺，仍有压力性质                            │
│                                                              │
│  【原则二】先天性质需要结合其他因素综合判断                    │
│  ├─ 结构因素：接纳互容、相位关系                              │
│  ├─ 宫性因素：守护的宫位                                      │
│  ├─ 落宫因素：落入的宫位                                      │
│  └─ 能量因素：庙旺落陷状态                                    │
│                                                              │
│  【原则三】各因素有不同影响权重，需综合考虑                    │
│  ├─ 不强调单一因素的优先级层级                                │
│  └─ 需要综合所有因素得出判断                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、综合考虑方法

### 3.1 五因素综合分析框架

| 因素类型 | 影响特点 | 分析要点 |
|----------|----------|----------|
| **结构因素** | 决定能量的流动方向和支持关系 | 接纳互容、相位关系带来什么具体影响 |
| **星性因素** | 决定能量的先天属性 | 该行星先天性质带来的倾向 |
| **宫性因素** | 决定能量作用的领域 | 该行星守护的宫位带来的领域影响 |
| **落宫因素** | 决定能量表现的环境 | 该行星落入的宫位带来的支持或挑战 |
| **能量因素** | 决定能量表达的顺畅程度 | 庙旺落陷状态带来的利弊 |

### 3.2 综合判断步骤

```
Step 1: 识别行星先天性质（吉星/凶星/中性）
    ↓
Step 2: 分析结构关系（接纳互容、相位）
    ├─ 与哪些星体有结构关系？
    └─ 这些结构带来什么具体影响？
    ↓
Step 3: 分析宫性（守护的宫位）
    ├─ 守护哪些宫位？
    └─ 这些宫位带来什么领域影响？
    ↓
Step 4: 分析落宫（落入的宫位）
    ├─ 落入哪个宫位？
    └─ 该宫位环境带来什么影响？
    ↓
Step 5: 分析能量状态（庙旺落陷）
    ├─ 行星处于什么能量状态？
    └─ 该状态带来什么利弊？
    ↓
Step 6: 综合判断
    └─ 综合所有因素，得出整体判断
```

## 四、综合判断示例

### 示例一：土星为十宫主星

```
【情境】土星为十宫主星

【因素分析】

因素1：土星为先天凶星
├─ 性质：限制之星
└─ 具体影响：事业可能需要长期积累、较辛苦，可能涉及管理、结构化工作

因素2：土星落陷
├─ 性质：能量弱
└─ 具体影响：事业表达受限，可能需要更多努力，进展可能较慢

因素3：土星落8宫
├─ 性质：凶宫
└─ 具体影响：事业可能涉及他人资源、投资、深度转化领域，环境可能较为复杂

因素4：土星与木星互容
├─ 性质：贵人支持结构
└─ 具体影响：事业中可能遇到贵人帮助，获得扩张机会，有转机可能性

【综合判断】
事业可能比较辛苦，需要在严格的环境中发展，可能涉及他人资源、投资等领域。
虽然本身表达受限，但贵人结构可能带来关键的转折机会。
需要综合看待辛苦与贵人支持并存的情况。
```

### 示例二：木星为十宫主星

```
【情境】木星为十宫主星

【因素分析】

因素1：木星为先天吉星
├─ 性质：扩展之星
└─ 具体影响：事业可能有贵人支持，有扩张机会，运气较好

因素2：木星失势
├─ 性质：能量弱
└─ 具体影响：贵人运可能受限，扩张可能过度或不够务实

因素3：木星落6宫
├─ 性质：凶宫
└─ 具体影响：事业可能涉及服务、日常工作，可能有健康相关领域

因素4：木星主3宫和6宫
├─ 性质：凶宫
└─ 具体影响：降低贵气，事业可能与沟通、服务、健康相关

【综合判断】
事业可能有贵人支持，但贵气受宫性影响有所降低。
可能涉及教育、服务、健康等领域。
需要注意过度扩张的问题。
```

### 示例三：太阳为十宫主星

```
【情境】太阳为十宫主星

【因素分析】

因素1：太阳为先天吉星
├─ 性质：权威之星
└─ 具体影响：事业可能有领导特质、受瞩目、有名声

因素2：太阳入庙
├─ 性质：能量强
└─ 具体影响：事业表达顺畅，能量强，有助力

因素3：太阳落10宫
├─ 性质：始宫、吉宫
└─ 具体影响：事业位置得天独厚，适合公众视野

因素4：太阳与火星合相
├─ 性质：凶星结构
└─ 具体影响：事业可能有行动力，但也可能有冲突、竞争

【综合判断】
事业可能有领导特质，适合在公众视野中发展。
本身能量强，有助力，但与火星合相可能带来竞争或冲突。
需要平衡权威与行动力的关系。
```

## 五、特殊情况处理

### 5.1 吉星落凶宫

```
【理解】
├─ 吉星本身有贵气性质
├─ 落凶宫表示该领域的表达受限或复杂
└─ 需要综合看是否有其他结构支持

【示例】金星落8宫
├─ 金星本身有和谐、美感性质
├─ 8宫为凶宫，表示情感、财运表达受限
├─ 若有贵星接纳，可能减轻影响
└─ 综合判断：感情、财运可能有复杂性，但本身有美感特质
```

### 5.2 凶星落吉宫

```
【理解】
├─ 凶星本身有压力性质
├─ 落吉宫表示该环境可能提供一定支持
└─ 需要综合看是否有其他结构化解

【示例】土星落10宫
├─ 土星本身有限制、压力性质
├─ 10宫为始宫、吉宫，表示事业环境有支持
├─ 若有贵星结构，可能转化压力为成就
└─ 综合判断：事业可能辛苦但有成就，需要长期积累
```

### 5.3 凶星庙旺

```
【理解】
├─ 凶星庙旺表示能量强
├─ 但不改变其先天凶性
└─ 能量强意味着压力性质更明显

【示例】火星庙旺
├─ 火星能量强，行动力强
├─ 但仍有冲突、竞争性质
├─ 需要看主什么宫位
└─ 综合判断：行动力强但可能有冲突，需要引导方向
```

### 5.4 吉星落陷

```
【理解】
├─ 吉星落陷表示能量弱
├─ 但不改变其先天贵气性质
└─ 能量弱意味着贵气表达受限

【示例】金星落陷
├─ 金星能量弱，和谐表达受限
├─ 但仍有美感、魅力性质
├─ 需要看是否有其他结构支持
└─ 综合判断：感情、财运表达受限，但本身有美感特质
```

| 吉星+吉结构+吉宫 | 有贵气支持，表达顺畅 |

| 凶星+吉结构+吉宫 | 压力有支持，可能转化 |
| 凶星+凶结构+凶宫 | 压力叠加，需要化解 |
| 吉星落陷 | 贵气性质保留，表达受限 |
| 凶星庙旺 | 压力性质保留，能量强 |
