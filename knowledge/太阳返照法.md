## 一、太阳返照原理

### 1.1 太阳返照的定义

```
【太阳返照（Solar Return）】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ★ 太阳每年回到出生时太阳的位置，以这个时间起盘               │
│    判断当年的运势                                             │
│                                                              │
│  【核心概念】                                                 │
│  ├─ 太阳回归到本命太阳的精确度数                             │
│  ├─ 以返照时间起盘（使用出生地点的经纬度）                   │
│  ├─ 代表新的一年运势开始                                     │
│  └─ 需与本命盘叠加判断                                       │
│                                                              │
│  【返照时间】                                                 │
│  ├─ 大约在生日前后                                           │
│  ├─ 每年一次返照                                             │
│  └─ 精确时间需计算                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 太阳返照的特点

```
【太阳返照的特点】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【周期性】                                                   │
│  ├─ 一年一次返照                                             │
│  ├─ 代表当年的运势主题                                       │
│  └─ 从返照时间开始计算                                       │
│                                                              │
│  【叠加性】                                                   │
│  ├─ 需叠加本命盘判断                                         │
│  ├─ 返照盘激活本命盘                                         │
│  └─ 返照盘的行星落宫触发本命宫位                             │
│                                                              │
│  【主题性】                                                   │
│  ├─ 返照盘揭示年度主题                                       │
│  ├─ 返照盘的四轴代表年度表现                                 │
│  └─ 返照盘的日月代表年度核心                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、生日的重要性

### 2.1 生日与返照的关系

```
【生日与返照的关系】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【核心原理】                                                 │
│  ├─ 太阳返照的时间在生日前后                                 │
│  ├─ 这一年从返照时间开始计算                                 │
│  └─ 生日是运势的重要节点                                     │
│                                                              │
│  【返照时间的意义】                                           │
│  ├─ 代表新的一年运势开始                                     │
│  ├─ 返照盘的状态影响全年                                     │
│  ├─ 返照盘的日月尤其重要                                     │
│  └─ 返照时间前后需特别关注                                   │
│                                                              │
│  【重要提醒】                                                 │
│  ├─ 运势年不是从1月1日开始                                   │
│  ├─ 运势年从返照时间开始                                     │
│  └─ 生日前后是新旧运势交替期                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、返照盘判断方法

### 3.1 返照盘四轴含义

```
【返照盘四轴含义】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【返照上升】                                                 │
│  ├─ 当年的外在表现                                           │
│  ├─ 这一年给人的印象                                         │
│  └─ 当年的自我呈现方式                                       │
│                                                              │
│  【返照下降】                                                 │
│  ├─ 当年的伴侣关系                                           │
│  ├─ 当年的合作关系                                           │
│  └─ 与他人的互动方式                                         │
│                                                              │
│  【返照天顶】                                                 │
│  ├─ 当年的事业发展                                           │
│  ├─ 当年的社会形象                                           │
│  └─ 事业成就的方向                                           │
│                                                              │
│  【返照天底】                                                 │
│  ├─ 当年的家庭状况                                           │
│  ├─ 当年的内在需求                                           │
│  └─ 家庭和根基事务                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 返照盘日月含义

```
【返照盘日月含义】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【返照太阳】                                                 │
│  ├─ 当年的核心主题                                           │
│  ├─ 这一年最重要的领域                                       │
│  ├─ 太阳所落宫位 = 年度重点领域                              │
│  └─ 太阳的相位 = 年度事件类型                                │
│                                                              │
│  【返照月亮】                                                 │
│  ├─ 当年的情绪状态                                           │
│  ├─ 这一年内心的感受                                         │
│  ├─ 月亮所落宫位 = 情感焦点领域                              │
│  └─ 月亮的相位 = 情绪变化类型                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.3 返照盘判断要点

| 要点 | 判断方法 |
|------|----------|
| 返照盘太阳宫位 | 这一年重点关注的领域 |
| 返照盘月亮宫位 | 这一年情绪和家庭的重点 |
| 返照盘上升星座 | 这一年外在表现方式 |
| 返照盘与运行星对照 | 年内运势变化节奏 |

## 四、叠加效应判断

### 4.1 本命与返照叠加原则

```
【本命与返照叠加原则】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【叠加原则】                                                 │
│  ├─ 返照盘激活本命盘                                         │
│  ├─ 返照盘的行星落宫触发本命宫位                             │
│  ├─ 返照盘的相位触发本命相位                                 │
│  └─ 两者配合判断当年事件                                     │
│                                                              │
│  【重要叠加效应】                                             │
│  ├─ 返照行星落在本命敏感点 → 当年有重大事件                 │
│  ├─ 返照与本命形成相同相位 → 强化本命结构                   │
│  ├─ 返照行星刑克本命凶点 → 当年有困难                       │
│  └─ 返照行星照耀本命吉点 → 当年有好运                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 叠加效应表

| 效应 | 含义 | 判断方法 |
|------|------|----------|
| 返照行星落本命敏感点 | 当年有重大事件 | 返照行星与本命ASC/MC/日月合相 |
| 返照与本命相同相位 | 强化本命结构 | 返照盘重现本命主要结构 |
| 返照行星刑克本命凶点 | 当年有困难 | 返照凶星触发本命受克点 |
| 返照行星照耀本命吉点 | 当年有好运 | 返照吉星触发本命吉点 |

## 五、太阳返照解读步骤

### 5.1 解读步骤

```
【太阳返照解读步骤】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  第一步：计算返照时间                                         │
│    ├─ 太阳回到本命太阳精确度数的时间                         │
│    └─ 确定返照时间                                           │
│                                                              │
│  第二步：以返照时间起盘                                       │
│    ├─ 使用出生地点的经纬度                                   │
│    ├─ 起返照盘                                               │
│    └─ 记录返照时间                                           │
│                                                              │
│  第三步：分析返照盘                                           │
│    ├─ 行星分布                                               │
│    ├─ 相位关系                                               │
│    └─ 宫位位置                                               │
│                                                              │
│  第四步：对照本命盘                                           │
│    ├─ 返照行星与本命行星的关系                               │
│    ├─ 返照盘激活的本命结构                                   │
│    └─ 叠加效应判断                                           │
│                                                              │
│  第五步：综合判断年度运势                                     │
│    ├─ 年度主题                                               │
│    ├─ 重点领域                                               │
│    └─ 注意事项                                               │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
