## 一、推运的原理与意义

### 1.1 推运的定义

```
【推运的定义】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ★ 推运：预测人生不同阶段的运势变化，判断何时会发生何种事件    │
│                                                              │
│  【核心问题】                                                 │
│  ├─ 本命盘揭示的是"是什么"                                   │
│  ├─ 推运揭示的是"何时发生"                                   │
│  └─ 时间精灵启动本命密码                                     │
│                                                              │
│  【本质理解】                                                 │
│  ├─ 一颗种子种入土中，没有时间的继续                         │
│  │   它永远还是原来的那粒种子                                │
│  ├─ 本命盘只是知道你的命而已                                 │
│  └─ 时间是不断继续前进的，本命盘密码必须经由时间启动         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 推运的核心原理

```
【时间对应原理】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ★ 用较短的时间代表较长的时间                                │
│                                                              │
│  【基本原理】                                                 │
│  ├─ 用行星的运行变化对应人生的运势变化                       │
│  ├─ 行星周期性运动对应人生周期性变化                         │
│  └─ 行星位置触发本命盘中的事件                               │
│                                                              │
│  【时间精灵的作用】                                           │
│  ├─ 启动本命盘中的密码                                       │
│  ├─ 激活本命盘中的结构                                       │
│  └─ 触发本命盘中的事件                                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.3 本命与推运的关系

```
【本命与推运的关系】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【本命盘的作用】                                             │
│  ├─ 决定人生格局                                             │
│  ├─ 决定性格特质                                             │
│  ├─ 决定命运结构                                             │
│  └─ 决定"是什么"                                            │
│                                                              │
│  【推运盘的作用】                                             │
│  ├─ 决定何时触发本命盘中的事件                               │
│  ├─ 决定运势起伏周期                                         │
│  ├─ 决定事件发生的时机                                       │
│  └─ 决定"何时发生"                                          │
│                                                              │
│  【重要原则】                                                 │
│  ├─ 推运无法改变本命的格局                                   │
│  ├─ 推运只能激活或延迟                                       │
│  ├─ 本命盘决定上限和下限                                     │
│  └─ 推运决定何时触达                                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、推运方法分类

### 2.1 主要推运法对比

```
【主要推运法分类】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  方法        原理                    时间对应                 │
│  ─────────────────────────────────────────────────────       │
│  法达星限法  行星轮流掌管人生阶段   依行星顺序划分            │
│  小限法      每年走一个宫位         一年走一宫                │
│  太阳返照    太阳回归原点起盘       一年一返照                │
│  次限法      一天代表一年           出生后一天 = 一年         │
│  太阳弧法    太阳移动带动全盘       太阳走一度 = 全盘移一度   │
│  行运法      当时刻行星位置         即时影响                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 古典推运与现代推运

```
【古典推运法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【法达星限法】                                               │
│  ├─ 古典占星最重要的推运方法                                 │
│  ├─ 将人生分成多个阶段                                       │
│  ├─ 每个阶段由一颗行星掌管                                   │
│  └─ 主线与子线配合判断                                       │
│                                                              │
│  【小限法】                                                   │
│  ├─ 古典占星重要的年度推运方法                               │
│  ├─ 每年走一个宫位                                           │
│  ├─ 12年一个循环                                             │
│  └─ 配合年主星判断年度运势                                   │
│                                                              │
│  【太阳返照】                                                 │
│  ├─ 太阳每年回到出生时太阳的位置                             │
│  ├─ 以这个时间起盘                                           │
│  ├─ 判断当年的运势                                           │
│  └─ 需叠加本命盘判断                                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

```
【现代推运法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【次限法】                                                   │
│  ├─ 以一天代表一年                                           │
│  ├─ 出生后第一天的行星位置 = 第一年的推运位置               │
│  ├─ 主要看推运太阳、月亮                                     │
│  └─ 代表内在心境变化（内因）                                 │
│                                                              │
│  【太阳弧法】                                                 │
│  ├─ 以太阳移动带动全盘行星移动                               │
│  ├─ 太阳每年约走一度                                         │
│  ├─ 全盘行星都随太阳移动一度                                 │
│  └─ 形成向运盘                                               │
│                                                              │
│  【行运法】                                                   │
│  ├─ 用当前时刻的行星位置与本命盘对照                         │
│  ├─ 最直接的推运方法                                         │
│  ├─ 行运行星触发本命盘事件                                   │
│  └─ 代表真实环境变化（外因）                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 四、推运方法优先级

| 优先级 | 方法 | 重要程度 | 主要用途 |
|--------|------|----------|----------|
| 1 | 法达星限法 | 最重要 | 判断大运周期 |
| 2 | 小限法 | 很重要 | 判断年运 |
| 3 | 太阳返照 | 重要 | 年度主题 |
| 4 | 行运法 | 辅助 | 具体触发 |
| 5 | 次限法 | 参考 | 内在变化 |
| 6 | 太阳弧法 | 参考 | 结构转折 |

### 4.2 推运配合使用原则

```
【多法配合原则】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【配合方法】                                                 │
│  ├─ 法达决定大运基调                                         │
│  ├─ 小限决定年运细节                                         │
│  ├─ 太阳返照补充年度主题                                     │

│                                                              │
```

## 五、推运分析流程

### 5.1 推运分析五步法

```
【推运分析五步法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  第一步：确定法达大运                                         │
│    ├─ 判断日夜盘                                             │
│    ├─ 确定当前主运行星                                       │
│    ├─ 确定当前子运行星                                       │
│    └─ 分析大运基调                                           │
│                                                              │
│  第二步：确定小限年运                                         │
│    ├─ 计算年龄对应的小限宫位                                 │
│    ├─ 确定年主星                                             │
│    └─ 分析年度主题                                           │
│                                                              │
│  第三步：配合太阳返照                                         │
│    ├─ 起太阳返照盘                                           │
│    ├─ 分析返照盘主题                                         │
│    └─ 与本命盘叠加                                           │
│                                                              │
│  第四步：用行运定时间                                         │
│    ├─ 找关键触发时间点                                       │
│    ├─ 分析行运行星影响                                       │
│    └─ 确定事件发生时间                                       │
│                                                              │
│  第五步：综合判断                                             │
│    ├─ 多法一致判断                                           │
│    ├─ 给出运势预测                                           │
│    └─ 提供建议                                               │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 六、速查表

### 6.1 推运方法速查表

| 方法 | 原理 | 周期 | 主要用途 |
|------|------|------|----------|
| 法达星限法 | 行星轮流掌管 | 依行星年限 | 大运判断 |
| 小限法 | 每年走一宫 | 12年循环 | 年运判断 |
| 太阳返照 | 太阳回归原点 | 1年周期 | 年度主题 |
| 次限法 | 一天代表一年 | 持续推进 | 内在变化 |
| 太阳弧法 | 太阳带动全盘 | 持续移动 | 结构转折 |
| 行运法 | 当下行星位置 | 实时变化 | 具体触发 |

### 6.2 推运判断优先级速查

| 判断内容 | 优先使用的推运方法 |
|----------|---------------------|
| 大运周期 | 法达星限法 |
| 年度运势 | 小限法 |
| 年度主题 | 太阳返照 |
| 具体时间 | 行运法 |
| 内在变化 | 次限法 |
| 人生转折 | 太阳弧法 |
