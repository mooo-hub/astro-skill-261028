> **版本**：v1.0 | 2026-06-05
> **重要级别**：★ 强制执行 ★

## 一、核心原则

```
┌──────────────────────────────────────────────────────────────┐
│              ★ 相位判断强制原则 ★                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【原则一】相位必须从排盘数据中提取                            │
│  ├─ 只使用排盘脚本输出的相位表                                │
│  └─ 禁止主观假设任何行星之间存在相位                          │
│                                                              │
│  【原则二】每提到一个相位，必须有数据支撑                      │
│  ├─ 提到"XX刑XX" → 必须在相位表中存在该相位                  │
│  ├─ 提到"XX合XX" → 必须在相位表中存在该相位                  │
│  └─ 无数据支撑 → 不得提及相位关系                            │
│                                                              │
│  【原则三】无相位也是重要信息                                  │
│  ├─ 日月无相位 → 需要明确说明                                │
│  ├─ 命主与官禄无相位 → 需要明确说明                           │
│  └─ 无相位不代表无关系，但需要用其他方式描述                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

```
┌──────────────────────────────────────────────────────────────┐
│                    相位验证标准流程                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Step 1: 获取排盘数据                                         │
│  ├─ 运行排盘脚本获取完整数据                                  │
│  └─ 输出包含相位表（aspects字段）                             │
│                                                              │
│  Step 2: 提取相位表                                           │
│  ├─ 从JSON数据中提取aspects数组                              │
│  ├─ 列出所有存在的相位关系                                    │
│  └─ 明确哪些相位不存在                                        │
│                                                              │
│  Step 3: 关键相位核查                                         │
│  ├─ 日月相位：是否存在？                                     │
│  ├─ 命主与官禄星相位：是否存在？                             │
│  ├─ 命主与配偶星相位：是否存在？                             │
│  └─ 日/月与关键宫主星相位：是否存在？                         │
│                                                              │
│  Step 4: 基于数据写分析                                       │
│  ├─ 只提及相位表中存在的相位                                  │
│  ├─ 明确说明"无相位"的情况                                   │
│  └─ 禁止假设任何未验证的相位                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 四、相位计算公式（用于手动验证）

### 角度差计算

```python
# 行星黄经
lon1 = 329.61  # 太阳
lon2 = 103.86  # 月亮

# 计算角度差
diff = abs(lon1 - lon2)

# 计算短弧
if diff > 180:
    short_arc = 360 - diff
else:
    short_arc = diff

# 结果：134.25°
```

### 相位判断公式

```python
# 标准相位角度
aspects = {0: '合', 60: '六分', 90: '四分', 120: '三分', 180: '对分'}

# 行星容许度（William Lilly标准）
orbs = {
    'Sun': 15, 'Moon': 12, 'Mercury': 7, 'Venus': 7,
    'Mars': 8, 'Jupiter': 12, 'Saturn': 9
}

# 组合容许度
combined_orb = (orbs['Sun'] + orbs['Moon']) / 2  # = 13.5°

# 判断：short_arc = 134.25°
# 最接近三分相(120°)，偏离14.25°
# 14.25° > 13.5° → 超出容许度 → 无相位
```

## 六、错误案例与修正

### 案例：本次日月分析错误

```
【错误分析】

原始输出：
  "与命主月亮刑克 = 理性与感性冲突"

数据事实：
  ├─ 太阳黄经：329.61°
  ├─ 月亮黄经：103.86°
  ├─ 角度差：134.25°
  └─ 相位判断：无有效相位

错误原因：
  ├─ 未验证日月是否有相位就下结论
  ├─ 预设了"日月必有关系"的错误假设
  └─ 违反了"数据优先"原则

修正后输出：
  "太阳水瓶座与月亮巨蟹座无直接相位连接（角度差134.25°，超出三分相容许度），
   理性追求与情感需求缺乏直接能量通道，需要通过间接结构进行整合。"
```
