## 一、核心分析框架（所有专项通用）

```
┌──────────────────────────────────────────────────────────────┐
│                专项分析四步法                                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  【第一步：数据提取】                                          │
│  ├─ 核心宫位宫头位置、宫主星位置                               │
│  ├─ 宫内行星及其状态                                           │
│  ├─ 关键相位及容许度                                           │
│  └─ 日夜盘判断及取用规则                                       │
│                                                              │
│  【第二步：结构分析】                                           │
│  ├─ 查找接纳/互容关系（最高优先级）                            │
│  ├─ 查找合相关系（高优先级）                                   │
│  ├─ 查找刑冲关系（中优先级）                                   │
│  └─ 判断结构好坏 = 结构类型 + 星性 + 宫性                      │
│                                                              │
│  【第三步：维度分离】                                           │
│  ├─ 区分两个维度分开判断                                       │
│  ├─ 每个维度独立评分                                          │
│  └─ 不可混为一谈                                               │
│                                                              │
│  【第四步：具体化输出】                                         │
│  ├─ 明确时间节点                                               │
│  ├─ 具体事件描述                                               │
│  └─ 可操作建议                                                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 二、事业专项增强规则

### 2.1 事业双维度判断框架

```
┌──────────────────────────────────────────────────────────────┐
│                    事业双维度判断                              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心理念：格局好 ≠ 人生顺遂                               │
│                                                              │
│  【维度一：高度（成就）】                                       │
│  ├─ 判断内容：社会地位高低、富贵程度、阶级层次                  │
│  ├─ 判断依据：                                                │
│  │   ├─ 贵星（日/月/木）支持情况                             │
│  │   ├─ 结构清纯度（无凶宫掺入）                              │
│  │   ├─ 命主星力量                                           │
│  │   └─ 官禄星与贵星的关系                                   │
│  └─ 评分标准：1-5分                                           │
│                                                              │
│  【维度二：稳定度（顺遂程度）】                                 │
│  ├─ 判断内容：人生是否顺遂、事业是否稳定                       │
│  ├─ 判断依据：                                                │
│  │   ├─ 凶宫（3/6/8/12）掺入情况                             │
│  │   ├─ 结构破损情况                                         │
│  │   └─ 是否有化解因素                                       │
│  └─ 评分标准：1-5分                                           │
│                                                              │
│  【四种组合】                                                  │
│  ├─ 高度4-5 + 稳定4-5：事业有成，顺风顺水                      │
│  ├─ 高度4-5 + 稳定1-2：事业有成，但波折不断                    │
│  ├─ 高度1-2 + 稳定4-5：普通阶层，生活安稳                     │
│  └─ 高度1-2 + 稳定1-2：普通阶层，挑战较多                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 事业完整思维链

```
【问题一：职业类型？】

第一步：看十宫
├─ 宫内星（静态）：星性、状态
│   ├─ 太阳：领导、管理、政务
│   ├─ 月亮：服务、教育、餐饮
│   ├─ 水星：沟通、教育、交易、文书
│   ├─ 金星：艺术、美业、金融、社交
│   ├─ 火星：军警、体育、技术、外科
│   ├─ 木星：教育、法律、金融、传播
│   └─ 土星：工程、管理、建筑、政企
│
└─ 宫主星（动态）★权重更高★
    ├─ 落什么宫？（连接哪个领域）
    │   ├─ 一宫：自我品牌、个人事业
    │   ├─ 二宫：财务管理、金融投资
    │   ├─ 三宫：沟通教育、交通物流
    │   ├─ 四宫：房地产、家庭相关
    │   ├─ 五宫：创意娱乐、投资投机
    │   ├─ 六宫：服务业、技术工作
    │   ├─ 七宫：合作合伙、客户关系
    │   ├─ 八宫：金融投资、风险管理
    │   ├─ 九宫：高等教育、外贸法律
    │   ├─ 十宫：企业管理、政务
    │   ├─ 十一宫：互联网、社交平台
    │   └─ 十二宫：幕后工作、研究
    │
    └─ 落什么星座？（展现方式）

第二步：找结构（★最关键★）
├─ 接纳/互容：优先级最高
│   ├─ 官禄星被木星接纳 → 贵人相助
│   ├─ 官禄星被土星接纳 → 努力有回报
│   └─ 官禄星被火星接纳 → 竞争有结果
│
├─ 合相：优先级高
│   └─ 能量融合，共同作用
│
└─ 刑冲：优先级中
    └─ 有张力和拉锯

第三步：看日月（★事业主星★）
├─ 日生盘：太阳 + 官禄主 + 命主星
│   └─ 太阳状态、与官禄星的关系
│
└─ 夜生盘：月亮 + 官禄主 + 命主星 + 太阳
    └─ 月亮状态、与官禄星的关系

第四步：看命主星
├─ 命主星状态（庙旺落陷）
├─ 命主星与官禄星的关系
│   ├─ 有相位：自我与事业有关联
│   └─ 无相位：自我与事业关联弱
└─ 命主星飞入宫位对事业的影响

第五步：综合判断
└─ 宫性 + 星性 + 星座性 = 职业类型

─────────────────────────────────────

【问题二：事业运势？】

第一步：判断整体层次
├─ 命主星状态：人生根基强弱
├─ 官禄星状态：事业本身能量
└─ 日月状态：贵星支持程度

第二步：找最清纯的结构
├─ 先找接纳/互容
├─ 再看合相结构
└─ 判断结构好坏

第三步：看是否破格
├─ 凶宫掺入（3/6/8/12宫）
├─ 凶星刑冲（火/土）
└─ 宫主星落陷且无结构弥补

第四步：综合判断高度与稳定度
├─ 高度：贵星支持 + 结构清纯
└─ 稳定度：无凶宫掺入 + 无结构破损
```

### 2.3 事业评分标准

| 评分 | 高度判断 | 稳定度判断 |
|------|----------|------------|
| **5分** | 贵星（日/月/木）支持+结构清纯+无凶宫掺入 | 无凶宫掺入+结构完整+有贵星化解 |
| **4分** | 有贵星支持+结构较好 | 凶宫掺入≤1个+有结构支持 |
| **3分** | 有一定结构支持+无贵星但结构尚可 | 有凶宫掺入但不严重 |
| **2分** | 结构一般+有小破损 | 多处凶宫掺入+结构有破损 |
| **1分** | 结构混乱+多处凶宫掺入+无贵星支持 | 凶星+凶宫+凶相位叠加 |

### 3.2 感情完整思维链

```
【问题一：配偶能力？】

第一步：看七宫（宫主星→宫内星）
├─ 七宫主星结构（权重最高）
│   ├─ 七宫主是谁？
│   ├─ 七宫主飞入什么宫？
│   │   └─ 配偶财富来源：飞几宫靠什么赚钱
│   ├─ 七宫主与哪些星有结构？
│   └─ 立即判断结构好坏
│
└─ 七宫内星（权重次之）
    ├─ 表示配偶宫的静态状态
    └─ 吉星入内：配偶有助力

第二步：找结构（★最关键★）
├─ 七宫主与其他星体的结构
├─ 结构好坏判断：
│   ├─ 贵星（日/月/木）结构 → 配偶能力强
│   ├─ 凶星（火/土）结构 → 配偶有挑战
│   └─ 宫性判断：主吉宫/主凶宫
└─ 七宫主落陷+有接纳互容 → 弥补负面

第三步：分析配偶特质
├─ 性格：根据七宫主星座判断
├─ 职业方向：根据七宫主飞宫判断
├─ 财富来源：配偶靠什么赚钱
└─ 外在形象：七宫内星参考

─────────────────────────────────────

【问题二：婚姻质量？】

第一步：看七宫是否受克
├─ 七宫内有凶星 → 静态状态差
├─ 七宫主被刑冲 → 动态挑战
└─ 有化解（接纳互容）→ 减轻负面

第二步：看日月与夫妻星关系（★最关键★）
├─ 日月与夫妻星和谐 → 婚姻质量好
├─ 日月与夫妻星刑冲 → 婚姻有挑战
└─ 判断依据：相位计算（非主观假设）

第三步：看夫妻星本身状态
├─ 庙旺 → 能量强，表达好
├─ 落陷 → 能量弱，表达差
└─ 有结构弥补 → 减轻负面

第四步：看感情征象星
├─ 金星状态（女命看火星）
├─ 五宫状态（恋爱宫）
└─ 是否有不良结构
```

### 3.3 桃花评分法（修正版）

```
┌──────────────────────────────────────────────────────────────┐
│                桃花评分相位核查规则                            │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 必须计算相位角度，不能主观假设 ★                           │
│                                                              │
│  【核查步骤】                                                 │
│  1. 计算两行星黄经差                                         │
│  2. 与标准相位角度对比（0°/60°/90°/120°/180°）              │
│  3. 差值在容许度范围内才算有效相位                           │
│                                                              │
│  【容许度规则】                                               │
│  ├─ 古典占星：(行星1容许度 + 行星2容许度) / 2              │
│  └─ 例：金月相位容许度 = (7+12)/2 = 9.5°                   │
│                                                              │
│  【评分表】                                                   │
│  ├─ 金星与1宫主有相位（核查后）：+1分                       │
│  ├─ 金星与5宫有关联：+1分                                   │
│  ├─ 金星与7宫主有相位（核查后）：+1分                       │
│  ├─ 金星与11宫主有相位（核查后）：+1分                      │
│  └─ 有紧密结构：+1分                                        │
│                                                              │
│  【评分等级】                                                 │
│  ├─ 5分：桃花极旺，机会多                                   │
│  ├─ 3-4分：桃花较旺                                         │
│  ├─ 2分：桃花中等                                           │
│  └─ 1分：桃花较弱                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 凶像交叠判断规则

```
┌──────────────────────────────────────────────────────────────┐
│                凶像交叠判断规则                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ★ 核心原则：凶像必须多项交叠才能判断严重问题 ★              │
│                                                              │
│  【交叠程度判断】                                             │
│  ├─ 单项凶 → 轻微问题（像掉了一片羽毛）                      │
│  ├─ 两项叠加 → 需要关注                                      │
│  ├─ 三项叠加 → 严重问题                                      │
│  └─ 四项叠加 → 极严重问题                                    │
│                                                              │
│  【凶像类型】（每项算1分）                                    │
│  ├─ 征象星被先天凶星（火/土）刑克                            │
│  ├─ 征象星被后天凶星（6r/8r/12r）刑克                        │
│  ├─ 征象星落陷                                              │
│  ├─ 六宫、八宫、十二宫主星相互连接                           │
│  ├─ 转宫凶星刑克                                            │
│  └─ 火土同时掺入结构                                        │
│                                                              │
│  【身体健康核心规则】                                         │
│  ├─ 六宫与八宫相连 → 重病风险                               │
│  └─ 无连接 → 不判断重病                                     │
│                                                              │
│  【意外伤害核心规则】                                         │
│  ├─ 三+六+八+十二串联 → 意外风险                            │
│  └─ 无串联 → 不判断意外                                     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.3 健康思维链

```
【身体健康】

第一步：看日月状态
├─ 日月庙旺 → 生命能量强
└─ 日月落陷/受克 → 生命能量弱

第二步：看六宫八宫是否相连（★核心★）
├─ 有连接 → 重病风险（需多项叠加确认）
└─ 无连接 → 无重病风险

第三步：统计凶像交叠程度
├─ 单项 → 轻微问题
├─ 两项 → 需要关注
└─ 三项及以上 → 严重问题

第四步：确定具体身体部位
└─ 根据行星所落星座判断

─────────────────────────────────────

【心理健康】

第一步：看月亮状态
├─ 月亮庙旺 → 情绪稳定
└─ 月亮落陷/受克 → 情绪波动

第二步：看水星状态
├─ 水星庙旺 → 思维清晰
└─ 水星落陷/受克 → 思维混乱

第三步：看火土是否掺入
├─ 火土掺入月亮/水星结构 → 心理风险高
└─ 无火土掺入 → 心理风险低

第四步：判断是否影响身体健康
└─ 长期心理问题可能导致身体健康问题

─────────────────────────────────────

【意外伤害】

第一步：确定核心宫位
└─ 三宫（交通）+ 六宫（疾病）+ 八宫（意外）+ 十二宫（隐患）

第二步：判断宫位是否相连
├─ 多项串联 → 意外风险高
└─ 无串联 → 意外风险低

第三步：判断速度
├─ 月火结构 → 快（突发）
└─ 无月火结构 → 慢（渐进）

第四步：综合判断风险等级
└─ 低/中/高
```
