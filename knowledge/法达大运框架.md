## 一、法达星限法核心概念

### 1.1 法达的定义

```
【法达星限法（Firdaria）】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ★ 古典占星中最重要的推运方法                                 │
│                                                              │
│  【核心原理】                                                 │
│  ├─ 将人生分成多个阶段                                       │
│  ├─ 每个阶段由一颗行星掌管                                   │
│  ├─ 行星顺序依日生盘与夜生盘不同                             │
│  └─ 主线与子线配合判断                                       │
│                                                              │
│  【本质理解】                                                 │
│  ├─ 行星轮流掌管人生各阶段                                   │
│  ├─ 每颗行星掌管一定年限                                     │
│  ├─ 主线决定大方向                                           │
│  └─ 子线决定具体事件                                         │
│                                                              │
│  【应用场景】                                                 │
│  ├─ 判断人生不同阶段的主题                                   │
│  ├─ 预测重要事件发生时间                                     │
│  ├─ 判断运势起伏周期                                         │
│  └─ 配合本命盘综合分析                                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 日生盘与夜生盘

```
【日生盘与夜生盘的判断】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【判断方法】                                                 │
│  ├─ 日生盘：太阳在地平线上方（第七宫至第十二宫）             │
│  └─ 夜生盘：太阳在地平线下方（第一宫至第六宫）               │
│                                                              │
│  【重要性】                                                   │
│  ├─ 影响法达主运顺序                                         │
│  ├─ 影响三分主星的取用                                       │
│  ├─ 影响六亲征象星的取用                                     │
│  └─ 影响行星力量的判断                                       │
│                                                              │
│  【快速判断】                                                 │
│  看太阳所在宫位：                                            │
│  ├─ 太阳在7-12宫 → 日生盘                                   │
│  └─ 太阳在1-6宫 → 夜生盘                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 三、子运计算方法

### 3.1 子运计算公式

```
【子运计算公式】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  子运长度 = 主运长度 × (该行星大运年数 / 75)                 │
│                                                              │
│  【计算方法】                                                 │
│  1. 确定主运行星和主运长度                                   │
│  2. 按主运顺序依次计算各子运                                 │
│  3. 子运顺序与主运顺序相同                                   │
│  4. 子运总长度 = 主运长度                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 子运计算示例

```
【日盘水星大运（13年）的子运】

  子运行星    大运年数    计算           子运长度
  ────────────────────────────────────────────────
  水星        13         13×(13/75)     2.25年
  金星        8          13×(8/75)      1.39年
  月亮        9          13×(9/75)      1.56年
  土星        11         13×(11/75)     1.91年
  木星        12         13×(12/75)     2.08年
  火星        7          13×(7/75)      1.21年
  太阳        10         13×(10/75)     1.73年
  北交点      3          13×(3/75)      0.52年
  南交点      2          13×(2/75)      0.35年
  ────────────────────────────────────────────────
  合计        75         -              13年

★ 子运顺序与主运顺序相同
```

## 四、直线性引动结构（核心方法）

### 4.1 核心原则

```
【法达直线性引动结构规则】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【大小线同看规则】                                           │
│  ★ 大运线和小运线同一结构必须同看 ★                           │
│                                                              │
│  【优先级】                                                   │
│  接纳 > 互容 > 合相 > 刑冲 > 三合六合                        │
│                                                              │
│  【引动原则】                                                 │
│  ★ 引动时以直线性碰触的星体为主要事件发生点                   │
│  ★ 非大运/小运行星本身，而是其引动的星体决定事件              │
│                                                              │
│  【无结构处理】                                               │
│  看定位星（小运行星所在星座的守护星）                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 引动结构分析

```
【引动结构分析方法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【第一步：确定大运/小运行星】                                │
│    ├─ 当前大运行星是谁？                                     │
│    └─ 当前小运行星是谁？                                     │
│                                                              │
│  【第二步：寻找结构关系】                                     │
│    ├─ 大运行星与什么星有结构？                               │
│    ├─ 小运行星与什么星有结构？                               │
│    └─ 两运行星共同引动的星体是什么？                         │
│                                                              │
│  【第三步：判断优先级】                                       │
│    ├─ 有接纳关系优先分析                                     │
│    ├─ 有互容关系次之                                         │
│    ├─ 合相关系再次                                           │
│    └─ 其他相位最后                                           │
│                                                              │
│  【第四步：综合判断事件】                                     │
│    ├─ 引动的星体代表什么？                                   │
│    ├─ 引动的宫位代表什么？                                   │
│    └─ 结构类型决定事件性质                                   │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.3 引动示例

```
【示例：日生盘，30岁】

主运：水星大运（18-31岁）
子运：月亮子运

【分析】
第一步：确定运行星
  大运 = 水星
  小运 = 月亮

第二步：寻找结构
  假设本命盘：
  - 水星在巨蟹座
  - 月亮在巨蟹座（与水星合相）
  - 木星在天蝎座（与水星三分）
  
第三步：判断引动
  - 水星与月亮合相 → 日月水结构
  - 木星与水星三分 → 木星被引动
  
第四步：综合判断
  - 水星大运 + 月亮子运
  - 引动日月木结构
  - 事业、家庭、扩展相关事件
```

## 五、大运解读方法

### 5.1 主运解读要点

```
【主运行星状态决定运势基调】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【行星状态影响】                                             │
│  ├─ 入庙入旺 → 该时期运势好                                  │
│  ├─ 失势落陷 → 该时期运势差                                  │
│  ├─ 中等力量 → 该时期运势一般                                │
│  └─ 有接纳互容 → 有助力或化解                                │
│                                                              │
│  【行星落宫影响】                                             │
│  ├─ 落吉宫 → 该时期生活焦点在吉宫领域                        │
│  ├─ 落凶宫 → 该时期可能面临困难                              │
│  └─ 落角宫 → 该时期影响更大                                  │
│                                                              │
│  【行星相位影响】                                             │
│  ├─ 与吉星和谐 → 该时期有助力                                │
│  ├─ 与凶星刑冲 → 该时期有挑战                                │
│  └─ 无明显相位 → 该时期平稳                                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 六、善运与坏运判断

### 6.1 善运判断标准

```
【善运特征】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【主线行星状态】                                             │
│  ├─ 主线行星入庙或入旺                                       │
│  ├─ 主线行星落在吉宫                                         │
│  ├─ 主线行星与吉星有和谐相位                                 │
│  └─ 主线行星被接纳或互容                                     │
│                                                              │
│  【子线行星状态】                                             │
│  ├─ 子线行星也与主线行星有吉相位                             │
│  ├─ 子线行星状态良好                                         │
│  └─ 子线行星落在吉宫                                         │
│                                                              │
│  【整体特征】                                                 │
│  ├─ 无凶星严重刑克                                           │
│  ├─ 主子运配合良好                                           │
│  └─ 该时期整体顺利                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 6.2 坏运判断标准

```
【坏运特征】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  【主线行星状态】                                             │
│  ├─ 主线行星落陷或失势                                       │
│  ├─ 主线行星落在凶宫                                         │
│  ├─ 主线行星与凶星有紧张相位                                 │
│  └─ 主线行星无结构支持                                       │
│                                                              │
│  【子线行星状态】                                             │
│  ├─ 子线行星与主线行星有凶相位                               │
│  ├─ 子线行星状态不佳                                         │
│  └─ 子线行星落在凶宫                                         │
│                                                              │
│  【整体特征】                                                 │
│  ├─ 有凶星严重刑克                                           │
│  ├─ 主子运配合不佳                                           │
│  └─ 该时期整体困难                                           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

## 七、分析流程

### 7.1 法达分析六步法

```
【法达分析六步法】
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  第一步：确定日夜盘                                          │
│    ├─ 判断太阳在地平线上方还是下方                           │
│    └─ 确定使用哪个主运顺序                                   │
│                                                              │
│  第二步：确定当前主运                                        │
│    ├─ 根据年龄确定当前主运行星                               │
│    ├─ 确定主运起止时间                                       │
│    └─ 分析主运行星在本命盘的状态                             │
│                                                              │
│  第三步：确定当前子运                                        │
│    ├─ 计算当前子运行星                                       │
│    ├─ 确定子运起止时间                                       │
│    └─ 分析子运行星在本命盘的状态                             │
│                                                              │
│  第四步：分析引动结构                                        │
│    ├─ 主运行星引动什么结构？                                 │
│    ├─ 子运行星引动什么结构？                                 │
│  └─ 共同引动的星体是什么？                                   │
│                                                              │
│  第五步：判断运势好坏                                        │
│    ├─ 主运状态 = 大方向                                      │
│    ├─ 子运状态 = 具体事件                                    │
│    └─ 主子运配合 = 整体运势                                  │
│                                                              │
│  第六步：预测具体事件                                        │
│    ├─ 引动的宫位 = 事件领域                                  │
│    ├─ 引动的星体 = 事件性质                                  │
│    └─ 结构类型 = 事件发展过程                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
